# CSV/XMLインポート機能 動作確認手順書

- **対象機能**: ContentGridEditor（CSV/XML インポート）
- **作成日**: 2026-07-27
- **対応サンプルファイル**: `samples/` ディレクトリ内のファイルを使用

---

## 前提条件

### 環境準備

1. ローカル開発環境が起動していること
   ```bash
   docker-compose up -d
   ```
2. ブラウザで `http://localhost:3000`（または該当ポート）を開く
3. 実験作業者（ExperimentWorker）ロールのユーザーでログインする

### 画面遷移

```
ログイン → 実験作業メニュー → 「実験記録」タブ を選択
```

WorkRecordPanel が表示されることを確認する。

> **補足**: WorkRecordPanel は現時点でモックデータで動作している。
> プロジェクト選択は不要（モックデータが自動表示される）。

## テスト手順

### No.1: Content追加ボタンの動作確認

**手順**

1. WorkRecordPanel で作業中のトランジション（タスク2 / TR_A など）を表示する
2. 画面下部の「**Content 追加**」ボタン（紫枠 `+ Content 追加`）をクリックする

**確認事項**

- [ ] カスタム Content スロット（紫枠・`カスタム Content` ラベル）が追加される
- [ ] ContentGridEditor が **「Content Grid (1行 × 1列)」** と表示される
- [ ] グリッドに `0` が1セル表示される
- [ ] ヘッダー右側にインポートボタン（↓アイコン）とクリアボタン（☓アイコン）が表示される

---

### No.2: CSV正常インポート（ボタン選択）

**使用ファイル**: `samples/sample_normal.csv`

**手順**

1. No.1 の手順で ContentGridEditor を追加する
2. ContentGridEditor ヘッダー右の **↓（インポート）ボタン** をクリックする
3. ファイルダイアログで `sample_normal.csv` を選択する

**確認事項**

- [ ] 画面右上に「**インポート完了: 5行 × 4列**」の成功トーストが表示される
- [ ] DataGrid が 5行 × 4列 に更新される
- [ ] ヘッダーラベルが「**Content Grid (5行 × 4列)**」に変わる
- [ ] 各セルの値が以下の通りであること

  ```
  Row 1: 1.1  2.2  3.3  4.4
  Row 2: 5.5  6.6  7.7  8.8
  Row 3: 9.9  10.0 11.1 12.2
  Row 4: 13.3 14.4 15.5 16.6
  Row 5: 17.7 18.8 19.9 20.0
  ```

---

### No.3: CSV正常インポート（ドラッグ＆ドロップ）

**使用ファイル**: `samples/sample_normal.csv`

**手順**

1. No.1 の手順で ContentGridEditor を追加する（または No.2 でインポート済みのグリッドをそのまま使う）
2. OS のファイルエクスプローラーで `sample_normal.csv` を見つける
3. ContentGridEditor のグリッド枠内にファイルをドラッグする

**確認事項**

- [ ] ドラッグ中にグリッド枠が**青点線**に変わり、「CSVまたはXMLをドロップ」のヒントテキストが表示される
- [ ] ドロップするとインポートが実行され、No.2 と同じ結果になる

### No.8: 行/列の追加・削除

**手順**（No.2 でインポート済みの 5行×4列 グリッドを使用）

1. グリッド下部の **「行を追加」ボタン** をクリックする
2. 最末尾列ヘッダーの右側にある **「+」ボタン** をクリックする
3. Row 1 の行番号左の **ゴミ箱ボタン** をクリックする
4. Col 1 のヘッダー内 **ゴミ箱ボタン** をクリックする

**確認事項**

- [ ] 手順1: 6行目が追加され、値はすべて `0` になる。ヘッダーが「6行 × 4列」になる
- [ ] 手順2: 5列目が追加され、値はすべて `0` になる。ヘッダーが「6行 × 5列」になる
- [ ] 手順3: Row 1 が削除され「5行 × 5列」になる
- [ ] 手順4: Col 1 が削除され「5行 × 4列」になる
- [ ] 行が1行しかない場合、行削除ボタンが disabled になる（最低1行維持）
- [ ] 列が1列しかない場合、列削除ボタンが disabled になる（最低1列維持）

1. ContentGridEditor ヘッダー右側の **クリア（赤色 ClearOutlined）ボタン** をクリックする

**確認事項**

- [ ] DataGrid が **1行 × 1列・値 0** の初期状態に戻る
- [ ] ヘッダーラベルが「**Content Grid (1行 × 1列)**」になる

---

### No.10: 非対応拡張子エラー

**手順**

1. No.1 の手順で ContentGridEditor を追加する
2. インポートボタンをクリックし、`.txt` や `.json` などのファイルを選択する

> **補足**: ファイルダイアログは `.csv`, `.xml` のみ表示するが、OS によってはその他のファイルも選択可能な場合がある。

**確認事項**

- [ ] エラートースト「**CSVまたはXMLファイルを選択してください（.csv / .xml）**」が表示される
- [ ] DataGrid は変更されない

---

### No.11: 複数スロットの独立動作

**手順**

1. 「Content 追加」を **2回** クリックし、ContentGridEditor スロットを2つ追加する
2. 1つ目のスロットに `sample_normal.csv` をインポートする
3. 2つ目のスロットに `sample_content_direct.xml` をインポートする

**確認事項**

- [ ] 1つ目のスロット: 5行 × 4列のDataGridが表示される
- [ ] 2つ目のスロット: 3行 × 3列のDataGridが表示される
- [ ] 1つ目のスロットを編集しても2つ目のスロットに影響しない
- [ ] スロット右上の **ゴミ箱ボタン** でスロットを削除できる

---

### No.12: インポート後の手動編集

**手順**（No.2 でインポート済みの 5行×4列 グリッドを使用）

1. Row 1 / Col 1 のセル（値 `1.1`）をクリックし、`99.9` に変更する
2. Row 3 / Col 2 のセル（値 `10.0`）をクリックし、`-5` に変更する

**確認事項**

- [ ] 手順1: セルの値が `99.9` に更新される
- [ ] 手順2: 負数 `-5` も正常に入力できる
- [ ] InputNumber コントロールは整数・小数・負数のみ受け付け、文字は入力不可

## エラーケース確認

| 操作 | 使用ファイル | 期待するエラーメッセージ |
|------|------------|----------------------|
| 50MB超過ファイルを選択 | 50MB超のCSV/XML | 「ファイルサイズが上限（50 MB）を超えています（X.X MB）」|
| 不正なXMLを選択 | 壊れたXMLファイル | 「XMLのパースに失敗しました: {エラー詳細}」|
| 数値データがないXML | 空のXMLや非数値のみ | 「インポートできるデータが見つかりませんでした」|
