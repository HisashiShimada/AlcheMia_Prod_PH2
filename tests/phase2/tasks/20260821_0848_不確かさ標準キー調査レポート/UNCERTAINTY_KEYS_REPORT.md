# 不確かさ標準キー 技術調査レポート

> 作成日: 2026-08-21  
> 根拠資料: JIS K 0200:2024 / GUM（JCGM 100:2008）/ ISO 5725 シリーズ  
> 対象ネームスペース: `http://www.maiml.org/uncertainty/`

---

## 1. 概要

JIS K 0200 に定義された Uncertainty ネームスペースには、以下の 6 つの標準キーが存在する。
これらは GUM（測定不確かさ表現のガイド）および ISO 5725（測定方法の正確さ）に準拠した
測定品質指標であり、「測定値がどの程度信頼できるか」を定量的に表す。

| # | キー（英語） | 日本語名 | 分類 |
|---|---|---|---|
| 1 | `Bias` | かたより | 1点比較型 |
| 2 | `Precision` | 精度 | 繰り返し測定型 |
| 3 | `StandardDeviation` | 標準偏差 | 繰り返し測定型 |
| 4 | `SampleRange` | サンプル範囲 | 繰り返し測定型 |
| 5 | `StandardUncertainty` | 標準不確かさ | 不確かさ評価型 |
| 6 | `CombinedStandardUncertainty` | 合成標準不確かさ | 伝播合成型 |

---

## 2. 各キーの詳細

### 2.1 Bias（かたより）

#### JIS K 0200 定義
> 試験結果又は測定結果の期待値と真の値との差を用いる。

#### 技術定義
系統誤差の代表指標。測定値の**平均が真の値からどれだけずれているか**を表す。

#### 計算式
```
Bias = actual_value − expected_value
（繰り返し測定時）
Bias = x̄ − μ  （x̄: 平均, μ: 真値）
```

#### 必要入力
| 入力 | 説明 | 現状のデータ取得元 |
|---|---|---|
| `expected_value` | 想定値・真値 | experiment_instruction_detail.expected_value |
| `actual_value` | 測定実績値 | experiment_instruction_detail.actual_value |

#### 判定ロジック
```
|Bias| ≤ tolerance  → OK
|Bias| >  tolerance → NG
```

#### 自動計算可否
✅ **完全自動計算可能**（既存データで即実装可能）

#### ユースケース例
- 温度計: 標準 100.0℃ vs 実測 100.3℃ → Bias = +0.3℃
- 天秤: 標準分銅 10.000g vs 実測 9.997g → Bias = −0.003g

#### 注意事項
- Bias は符号を持つ（正 = 過大評価、負 = 過小評価）
- 許容値との比較は **絶対値** で行う

---

### 2.2 Precision（精度）

#### JIS K 0200 定義
> 定められた条件の下で繰り返された独立した試験結果と測定結果との間の一致の程度を示す。

#### 技術定義（ISO 5725-1 準拠）
同一条件での繰り返し測定における**値の一致度（ばらつきの小ささ）**。

#### 計算式
```
繰り返し精度標準偏差:
  Sr = √(Σ(xi − x̄)² / (n−1))
```
> 本システムスコープでは、実質 `StandardDeviation` と**同一の計算式**となる。

#### 必要入力
| 入力 | 説明 | 現状のデータ取得元 |
|---|---|---|
| `values[]` | 繰り返し測定値（n ≥ 2） | 繰り返し測定値テーブル（**未実装**） |

#### 自動計算可否
⚠️ **繰り返し測定値の蓄積が必要**（新規テーブル要）

#### StandardDeviation との関係
ISO 5725 上は「繰り返し精度」という**概念**であり、
その数値表現が `StandardDeviation`（標準偏差）。
→ 実装上は同一計算ロジックを共有できる。

---

### 2.3 StandardDeviation（標準偏差）

#### JIS K 0200 定義
> 測定結果とその平均値との差の2乗の期待値を分散といい、その分散の非負の平方根を標準偏差と呼ぶ。
> 平均値からのデータのばらつき具合を示す。

#### 計算式
```
s = √(Σ(xi − x̄)² / (n−1))  （標本標準偏差、n−1 補正）
x̄ = (Σxi) / n
```

#### 必要入力
| 入力 | 説明 | 現状のデータ取得元 |
|---|---|---|
| `values[]` | 繰り返し測定値（n ≥ 2） | 繰り返し測定値テーブル（**未実装**） |

#### 判定ロジック
```
s ≤ tolerance → OK
s >  tolerance → NG
n < 2          → SKIP（データ不足）
```

#### 自動計算可否
⚠️ **繰り返し測定値の蓄積が必要**

#### ユースケース例
- 5 回測定: [10.01, 9.99, 10.02, 10.00, 9.98] → s ≈ 0.015

---

### 2.4 SampleRange（サンプル範囲）

#### JIS K 0200 定義
> 最大の順序統計量から最少の順序統計量を引いた量を用いる。

#### 技術定義
測定値群の**最大値と最小値の差**。
計算が簡単だが外れ値の影響を強く受ける。小サンプル（n ≤ 10）の R 管理図に多用される。

#### 計算式
```
R = max(values) − min(values)
```

#### 必要入力
| 入力 | 説明 | 現状のデータ取得元 |
|---|---|---|
| `values[]` | 繰り返し測定値（n ≥ 2） | 繰り返し測定値テーブル（**未実装**） |

#### 判定ロジック
```
R ≤ tolerance → OK
R >  tolerance → NG
n < 2          → SKIP（データ不足）
```

#### 自動計算可否
⚠️ **繰り返し測定値の蓄積が必要**

#### StandardDeviation との比較
| 観点 | SampleRange | StandardDeviation |
|---|---|---|
| 計算コスト | 低（max−min のみ） | 中（全値の二乗和） |
| 外れ値への感度 | 高 | 中 |
| 適用サンプル数 | n ≤ 10 に有効 | n 数に依存しない |

---

### 2.5 StandardUncertainty（標準不確かさ）

#### JIS K 0200 定義
> 標準偏差で表す、測定結果の不確かさ。

#### 技術定義（GUM 準拠）
GUM では **A 型** と **B 型** の 2 種類の評価方法がある。

##### A 型評価（統計的解析）
```
u_A = s / √n
    = √(Σ(xi − x̄)² / (n(n−1)))

  s: 標本標準偏差,  n: 繰り返し測定回数
```
→ 繰り返し測定の**平均値の不確かさ**

##### B 型評価（統計以外の情報）

| 分布仮定 | 計算式 | 適用場面 |
|---|---|---|
| 矩形分布 | `u_B = a / √3` | 仕様書の限界値 ±a が均一分布 |
| 正規分布（k=2, 95%CI）| `u_B = a / 2` | 校正証明書に U, k=2 と記載 |
| 正規分布（k=3, 99%CI）| `u_B = a / 3` | k=3 の場合 |
| 三角分布 | `u_B = a / √6` | 中央に分布が集中する場合 |

#### 必要入力
| 評価型 | 入力 | 現状のデータ取得元 |
|---|---|---|
| A 型 | `values[]`（n ≥ 2） | 繰り返し測定値テーブル（**未実装**） |
| B 型 | 半幅 `a`、分布タイプ | 校正証明書・仕様書から**手動入力** |

#### 判定ロジック
```
u ≤ tolerance → OK
u >  tolerance → NG
```

#### 自動計算可否
- A 型: ⚠️ 繰り返し測定データが必要
- B 型: ⚠️ 半自動（`a` の値は外部資料から手動入力）

#### StandardDeviation との関係
```
u_A = s / √n
```
StandardDeviation（s）を測定回数 n で補正したもの。両者は密接に連携する。

---

### 2.6 CombinedStandardUncertainty（合成標準不確かさ）

#### JIS K 0200 定義
> 測定結果を幾つかの他の量から求めるときの、測定結果の標準不確かさ。

#### 技術定義（GUM 誤差伝播式）
出力量 y が複数の入力量 x1, x2, ..., xN の関数 y = f(x1,...,xN) のとき、
各入力量の不確かさが出力量に与える影響を合成する。

#### 計算式

##### 一般式
```
uc(y) = √(Σ_i ci² × u(xi)²)

  ci = ∂f/∂xi  （感度係数: 偏微分係数）
  u(xi): 入力量 xi の標準不確かさ
```

##### 簡易版（入力が独立かつ ci = 1 の場合）
```
uc = √(u1² + u2² + ... + uN²)
```

#### 必要入力
| 入力 | 説明 | 現状のデータ取得元 |
|---|---|---|
| `ui[]` | 各入力の StandardUncertainty | 他の不確かさ基準の計算結果 |
| `ci[]` | 感度係数（偏微分） | 測定モデル固有（**自動計算困難**） |

#### 自動計算可否
- 一般式: ❌ 感度係数は測定モデルに依存するため完全自動は困難
- 簡易版（ci=1）: ⚠️ 複数 ui が揃えば計算可能

#### 現実的な実装パターン（3案）
| パターン | 説明 | 自動化度 |
|---|---|---|
| A: 完全手動 | uc 値をユーザーが直接入力 → tolerance と比較のみ | 低 |
| B: 簡易自動 | ci=1 仮定で `√(Σui²)` を自動計算 | 中 |
| C: 係数入力 | ci をユーザーが入力し `√(Σci²ui²)` を計算 | 中〜高 |

## 3. キー間の関係性

```
繰り返し測定値 [x1, x2, ..., xn]
      │
      ├──→ 平均値 x̄ ──→ Bias (= x̄ − expected)
      │
      ├──→ StandardDeviation  s = √(Σ(xi−x̄)²/(n−1))
      │         │                       │
      │    （概念的同一）                └──→ StandardUncertainty  u_A = s/√n
      │         ↓                                    │
      │    Precision Sr ≡ s                    複数の u[] ──→ CombinedStdUncertainty
      │
      └──→ SampleRange  R = max − min
```

---

## 4. 自動計算難易度マトリクス

| キー | 計算複雑度 | 必要データ | 現状データ充足 | 自動計算可否 |
|---|---|---|---|---|
| `Bias` | 低 | expected + actual × 1件 | ✅ 既存 | ✅ **即実装可** |
| `SampleRange` | 低 | values[] × n件 | ❌ 要新設 | ⚠️ データ要整備 |
| `StandardDeviation` | 中 | values[] × n件 | ❌ 要新設 | ⚠️ データ要整備 |
| `Precision` | 中 | values[] × n件 | ❌ 要新設 | ⚠️ （StandardDeviation と同一） |
| `StandardUncertainty` (A型) | 中 | values[] × n件 | ❌ 要新設 | ⚠️ データ要整備 |
| `StandardUncertainty` (B型) | 低 | 半幅 a（手動） | ⚠️ 手動入力必要 | ⚠️ 半自動 |
| `CombinedStandardUncertainty` | 高 | ui[], ci[] | ❌ 感度係数は測定固有 | ❌（簡易版のみ可） |

## 5. フェーズ別実装可能性

```
フェーズ 1（現状データのみ・追加テーブル不要）
  ✅ Bias
     experiment_instruction_detail の expected_value / actual_value を使用

フェーズ 2（繰り返し測定値テーブル新設後）
  ⚠️ StandardDeviation
  ⚠️ SampleRange
  ⚠️ Precision          ← StandardDeviation と計算ロジック共用
  ⚠️ StandardUncertainty (A型)

フェーズ 3（拡張対応）
  ⚠️ StandardUncertainty (B型)        ← 半幅入力フォーム追加
  ⚠️ CombinedStandardUncertainty      ← 簡易版（ci=1）or パターン選択
```

## 6. 設計時の決定事項

| # | 論点 | 選択肢 |
|---|---|---|
| 1 | Precision の扱い | A: StandardDeviation と統合 / B: 両キーを保持（概念的区別） |
| 2 | 繰り返し測定データ | A: フェーズ1は Bias のみ先行 / B: 初版から繰り返し測定テーブルも設計 |
| 3 | CombinedStdUncertainty | A: 簡易版（ci=1）/ B: uc 直接手動入力 / C: 対象外 |
| 4 | StandardUncertainty B型 | A: 半幅 a の手動入力フォームを用意 / B: A型のみ対応 |
