## 1. タスク概要

実験作業者（ExperimentWorker）画面のUIを大きく変更する。
現在のダイアログベースの作業記録UIを、以下の2タブ構成の全画面UIに刷新する。

- **タブ1: 作業記録** — 一作業単位（トランジション）の詳細記録画面
- **タブ2: 全体進捗** — 全タスク・全トランジションの進捗一覧

問題報告機能はタブ外のボタンとして独立させる。

---

## 2. 変更の背景・目的

### 現状の課題
- `DataRecordDialog` がモーダルダイアログ形式 → 画面が狭く情報が入力しづらい
- プロジェクト指示・実験計画指示は別画面で確認する必要がある
- 問題報告ボタンが進捗確認の行に埋め込まれており、見つけにくい
- 全体の作業進捗が俯瞰できない

### 変更後の期待効果
- 指示を確認しながらそのまま記録できる
- プロパティ単位で想定値と実績値を並べて確認・入力できる
- 問題報告が常にアクセス可能
- 全体進捗が一画面で把握できる

```
└─────────────┴───────────────────────────────────────────┘
```

#### 作業順序の管理方針

- **初期表示**: 最初の未完了トランジションを自動選択
- **順序固定**: 作業順（MAIML定義順）に処理
- **完了済み**: 左サイドバーに完了マーク付きで表示、クリックでReadOnlyモードで確認可能
- **ReadOnlyモード**: 完了済みトランジション選択時、全フィールドが読み取り専用、想定値・実績値・差分を表示

#### プロパティカードのデザイン

```
┌─────────────────────────────────────────────────────────┐
│ 温度 (ns1:Temperature)                          Float   │
├────────────────────────┬────────────────────────────────┤
│ 想定値: 25 ℃          │ 実績値: [24.8____] ℃          │
└────────────────────────┴────────────────────────────────┘
```

**カラーコーディング**:
- 想定値エリア: 淡い青背景 (`#e6f7ff`)
- 実績値エリア: 白背景（入力可能）
- ReadOnly時: 淡いグレー背景 (`#fafafa`) + 差分表示

### 3-3. タブ2: 全体進捗

#### レイアウト概要

```
┌─────────────────────────────────────────────────────────┐
│ フィルタ: [タスクNo▼] [トランジション▼] [ステータス▼]   │
├─────────────────────────────────────────────────────────┤
│ タスク | トランジション名 | ステータス | 記録 | 操作      │
├────────┼─────────────────┼───────────┼──────┼──────────┤
│ #1     │ 混合              │ ✓完了     │ ✓あり│ [詳細]   │
│ #1     │ 加熱              │ ⚙作業中   │ -    │ [作業へ] │
│ #2     │ 混合              │ 未着手    │ -    │ -        │
│ #2     │ 加熱              │ 未着手    │ -    │ -        │
└─────────────────────────────────────────────────────────┘
```

**操作ボタン**:
- **完了済み**: `[詳細確認]` → タブ1に切り替え + ReadOnlyモードでそのトランジションを表示
- **作業中**: `[作業へ]` → タブ1に切り替え + そのトランジションを表示
- **未着手**: ボタンなし（または非活性）

---

### 3-4. 問題報告ボタン

- **配置**: 画面右上ヘッダーエリア（タブ外）
- **常時表示**: どのタブからでもアクセス可能
- **自動セット**: クリック時に現在作業中のトランジションを自動選択
  - 作業記録タブ表示中: 現在のトランジション
  - 全体進捗タブ表示中: 最後に作業中だったトランジション
