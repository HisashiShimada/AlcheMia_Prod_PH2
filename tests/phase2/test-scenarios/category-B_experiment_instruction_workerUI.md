## B-EI-01：実験指示の記入・XMLプレビュー確認

### 関連

| 項目 | 参照先 |
|------|--------|
| 要件 | F-01-01：指示記入機能 / F-01-02：XMLプレビュー機能 |

| API | `GET /api/v1/projects/:projectId/methods` / `GET /api/v1/projects/:projectId/experiment-instructions` |

- `experiment_admin` としてログイン済み
- プロジェクト `proj-test-001` が作成済みで MaiML ファイルが存在すること

## B-EI-04：テンプレート仮置き設定と全実施回への反映

### 概要

### 関連

| 項目 | 参照先 |
|------|--------|
| 要件 | F-04-01：テンプレート仮置き設定機能 |
| ユースケース | UC-08：全実施回共通のデフォルト指示をテンプレートに設定する |
| 業務フロー | BF-08（テンプレート仮置き設定） |
| 参考仕様 | MAIML-SPEC-003 v5.5 §2.3（追記（優先）の仕組み）/ §4.3（data層） |

- `experiment_admin` としてログイン済み
- 実験計画に Template（全回共通）とデータ層（実施回 #1・#2）が存在すること
- メソッド `method-A` にタスク・トランジションが2回分設定済みであること

### 操作手順

#### ステップ 1：Template への仮置き設定

| # | ロール | 操作 | 期待結果 |

#### ステップ 4：実験作業者への表示確認

| # | ロール | 操作 | 期待結果 |
|---|--------|------|---------|
| 9 | experiment_worker | 実施回 #1 のタスクを選択して指示を確認する | 温度の有効値（追記優先）`30.0` が表示される |
| 10 | experiment_worker | 実施回 #2 のタスクを選択して指示を確認する | Template の仮置き値 `25.0` が表示される |

### 確認ポイント

- [ ] Template に記入した仮置き値が全実施回にデフォルト表示される
- [ ] 実施回ごとの追記値が Template の値より優先して表示される（MAIML-SPEC §2.3 準拠）
