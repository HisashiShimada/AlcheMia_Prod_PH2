## B-UC-01：不確かさ基準キーの登録・定性評価スキーム定義

### 概要

実験管理者が不確かさ基準管理画面から、自分のスコープに定性評価・定量評価それぞれの基準キーを登録できることを確認する。また、定性評価のカスタムスキーム（選択肢）が定義できることを確認する。

### 関連

| 項目 | 参照先 |
|------|--------|
| 要件 | F-01-01：不確かさ基準キー登録機能 / F-01-04：定性評価スキーム定義機能 |
| ユースケース | UC-01-01：不確かさ基準キーを登録する / UC-01-04：定性評価スキームを定義する |
| 業務フロー | BF-01-01：不確かさ基準キーを登録する / BF-01-04：定性評価スキームを定義する |
| API | `POST /api/v1/uncertainty-criteria` |

### 前提条件

- `experiment_admin` としてログイン済み
- 不確かさ基準キー管理画面にアクセスできること

### 操作手順

| 12 | — | 一覧を確認する | 「測定不確かさ」が一覧に表示されている |

## B-UC-02：JIS標準キーの参照・上位層キーの継承・用語管理連携

### 概要

全ユーザーが Global 層に登録された JIS K 0200 附属書B の標準キーを参照できることを確認する。また、実験管理者が上位層の基準キーを自スコープで継承でき、用語管理画面から基準キーを上位層へ公開できることを確認する。

### 関連

| 項目 | 参照先 |
|------|--------|
| 要件 | F-01-02：標準キー提供機能 / F-01-03：基準キー参照・継承機能 / F-01-05：用語管理連携機能 |
| ユースケース | UC-01-02：JIS規格の標準キーを参照する / UC-01-03：上位層の基準キーを参照・継承する / UC-01-05：基準キーを上位層に公開する |
| 業務フロー | BF-01-02 / BF-01-03 / BF-01-05 |
| API | `GET /api/v1/uncertainty-criteria?scope=global` / `POST /api/v1/uncertainty-criteria/:id/inherit` |

### 前提条件

- `experiment_admin` としてログイン済み
- Global 層に `Bias`・`StandardDeviation`・`CoverageInterval` が登録済みであること
- B-UC-01 で登録した「信頼性評価」キーが存在すること

### 操作手順

#### ステップ 1：JIS 標準キーの参照

| # | ロール | 操作 | 期待結果 |
|---|--------|------|---------|
| 1 | experiment_admin | 不確かさ基準キー管理画面 → スコープ「Global」を選択する | Global 層の標準キー一覧が表示される |
| 2 | — | 一覧の内容を確認する | `Bias`・`StandardDeviation`・`CoverageInterval` が表示されている |
| 3 | — | `StandardDeviation` の詳細を確認する | JIS K 0200 附属書B 準拠の説明・型・単位が表示される |
| 4 | — | Global 層の標準キーに「編集」「削除」ボタンがないことを確認する | 標準キーは参照のみで変更不可であることが確認できる |

#### ステップ 3：上位層の基準キーを継承する

| # | ロール | 操作 | 期待結果 |
|---|--------|------|---------|
| 6 | experiment_admin | 不確かさ基準キー管理画面 → Global 層の `Bias` を選択する | `Bias` の詳細画面が表示される |
| 7 | experiment_admin | 「継承して利用する」操作を行う | 継承確認ダイアログが表示される |

#### ステップ 4：用語管理画面での基準キー確認・上位層公開

| # | ロール | 操作 | 期待結果 |
|---|--------|------|---------|

## B-UC-03：基準キーの非推奨切り替え・バージョン履歴確認

### 概要

実験管理者が使用しなくなった基準キーを非推奨に切り替えられること（使用中キーも削除不可で非推奨に変更可能）、および基準キーのバージョン履歴と旧バージョンとの差分を確認できることを確認する。

### 関連

| 項目 | 参照先 |
|------|--------|
| 要件 | F-02-01：基準キー状態変更機能 / F-02-02：基準キーバージョン履歴管理機能 |

| 業務フロー | BF-02-01 / BF-02-02 |
| API | `PATCH /api/v1/uncertainty-criteria/:id/status` / `GET /api/v1/uncertainty-criteria/:id/history` |

- `experiment_admin` としてログイン済み
- B-UC-01 で登録した「信頼性評価」キーが存在すること
