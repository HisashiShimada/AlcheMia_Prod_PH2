# Chrome で HTTPS アクセスするための証明書設定手順

- **作成日**: 2026-04-17
- **対象**: アプリにアクセスするエンドユーザー

---

## 概要

本アプリへのアクセスには以下の2種類の証明書が必要です。

| 証明書 | 用途 | 入手方法 |
|--------|------|---------|
| **CA証明書**（`ca.crt`） | Chrome の「保護されていない通信」警告を解消する | 管理者から入手 |
| **クライアント証明書**（`.p12`） | アプリへのアクセス認証 | アプリの組織管理画面からダウンロード |

> **クライアント証明書のパスワード**: `mmdpf123`

---

## Step 1: CA証明書の登録

CA証明書をブラウザに信頼させることで「保護されていない通信」警告を解消します。

### Windows

1. 管理者から受け取った `ca.crt` ファイルを**ダブルクリック**
2. 「証明書のインストール」をクリック
3. **「ローカルコンピュータ」** を選択 → 「次へ」
   > ※「現在のユーザー」でも可ですが、ローカルコンピュータ推奨
4. **「証明書をすべて次のストアに配置する」** を選択 → 「参照」
5. **「信頼されたルート証明機関」** を選択 → 「OK」 → 「次へ」
6. 「完了」をクリック
7. セキュリティ警告が表示された場合は「はい」をクリック
8. 「正しくインポートされました」と表示されれば完了

#### インポート確認方法（任意）

1. `Win + R` キー → `certmgr.msc` を入力して Enter
2. 「信頼されたルート証明機関」→「証明書」を開く
3. 発行者 `MMDPF CA` の証明書が存在することを確認

---

## Step 2: クライアント証明書の登録（.p12）

クライアント証明書はアプリへのアクセス認証に使用します。

### .p12 ファイルのダウンロード

1. アプリにアクセスし、組織管理画面を開く
2. 対象組織の **「証明書DL」ボタン** をクリック
3. `.p12` ファイルがダウンロードされる

---

### 方法A: Chrome の設定画面からインポート（推奨）

Chrome の設定画面から直接インポートできます。

1. Chrome を開き、アドレスバーに以下を入力してアクセス
   ```
   chrome://settings/certificates
   ```
   > ※ Windows の場合、上記 URL にアクセスすると自動的に Windows の証明書マネージャーが開きます。その場合は [方法B](#方法b-windows証明書マネージャーからインポートwindows) を参照してください。

2. **「Your certificates（あなたの証明書）」** タブを選択

3. **「Import（インポート）」** ボタンをクリック

4. ダウンロードした `.p12` ファイルを選択

5. **パスワードに `mmdpf123` を入力** → 「OK」

6. 証明書一覧に追加されれば完了 ✅

---

### 方法B: Windows証明書マネージャーからインポート（Windows）

1. ダウンロードした `.p12` ファイルを**ダブルクリック**
2. 「証明書のインポートウィザード」が起動
3. 保存場所は **「現在のユーザー」** を選択 → 「次へ」
4. ファイルパスが表示されていることを確認 → 「次へ」
5. **パスワードに `mmdpf123` を入力** → 「次へ」
   > ※「このキーをエクスポート可能にする」はオフのまま（デフォルト）で問題ありません
6. 証明書ストアは **「証明書の種類に基づいて、自動的に証明書ストアを選択する」** を選択 → 「次へ」
7. 「完了」をクリック
8. 「正しくインポートされました」と表示されれば完了 ✅

---

## Step 3: Chrome を完全再起動

証明書の変更を Chrome に反映させるため、**必ず完全再起動**してください。

### Windows / macOS 共通

- Chrome のすべてのウィンドウを閉じる: `Ctrl + Shift + Q`（macOS: `Cmd + Q`）
- Chrome を再度起動する

> ⚠️ タブを閉じるだけでは不十分です。プロセスを完全に終了してください。

---

## Step 4: ブラウザでアクセス

1. Chrome でアプリの URL にアクセス
   ```
   https://alchemia-staging-nlb-0fd64d466d1b557b.elb.ap-northeast-1.amazonaws.com/
   ```

2. **クライアント証明書の選択ダイアログ**が表示される

3. 組織名の入ったクライアント証明書を選択 → **「OK」**

4. アプリのログイン画面が表示されれば完了 ✅

---

## トラブルシューティング

### 「保護されていない通信」が表示される

| 原因 | 対処方法 |
|------|---------|
| CA証明書が登録されていない | Step 1 を実施してください |
| Chrome が再起動されていない | `Ctrl+Shift+Q` で完全再起動してください |
| CA証明書のインポート先が誤っている | Windows: 「信頼されたルート証明機関」に登録されているか `certmgr.msc` で確認 |

### クライアント証明書の選択ダイアログが表示されない

| 原因 | 対処方法 |
|------|---------|
| クライアント証明書が登録されていない | Step 2 を実施してください |
| Chrome が再起動されていない | `Ctrl+Shift+Q` で完全再起動してください |
| 接続先が HTTP になっている | URL が `https://` で始まっているか確認してください |

### .p12 インポートでパスワードエラーが出る

- パスワードが `mmdpf123` であることを確認してください
- `.p12` ファイルが壊れていないか確認し、アプリの管理画面から再ダウンロードしてください

### 証明書を選択しても「アクセス拒否」になる

- クライアント証明書の有効期限が切れていないか確認してください（有効期限: 発行から365日）
- アプリの管理画面から証明書を再発行・再ダウンロードしてください

### 一時的な回避方法（staging環境のみ）

Chrome の「保護されていない通信」警告画面にフォーカスした状態でキーボードから **`thisisunsafe`** と入力すると、そのセッション中のみ警告をスキップできます。

> ⚠️ これは一時的な回避策です。本番環境では使用しないでください。
