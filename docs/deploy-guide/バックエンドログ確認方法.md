## 基本的なログ取得コマンド

### 1. ロググループの存在確認

```bash
aws logs describe-log-groups \
  --log-group-name-prefix "/ecs/alchemia-backend" \
  --region ap-northeast-1 \
  --output table
```

### 2. 指定時間帯のログを全件取得

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time <開始タイムスタンプ(ミリ秒)> \
  --end-time <終了タイムスタンプ(ミリ秒)> \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

### 3. キーワードで絞り込んでログを取得

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time <開始タイムスタンプ(ミリ秒)> \
  --end-time <終了タイムスタンプ(ミリ秒)> \
  --filter-pattern "<検索キーワード>" \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

---

## タイムスタンプの変換方法

CloudWatch Logs の `--start-time` / `--end-time` は **UTC ミリ秒（エポックタイム）** で指定します。

> ⚠️ JST は UTC+9 のため、JST の時刻から **9時間引いて** UTC に変換してください。

### JST → UTCミリ秒 の変換コマンド（Linux）

```bash
# 例: JST 2026-05-11 12:00:00 → UTC ミリ秒
date -d "2026-05-11 03:00:00" +%s000
# → 1778468400000
```

### よく使う時間帯の変換例

| JST | UTC | UTCミリ秒 |
|---|---|---|
| 2026-05-07 15:50 | 2026-05-07 06:50 | 1746593400000 |
| 2026-05-07 17:10 | 2026-05-07 08:10 | 1746598200000 |
| 2026-05-11 10:00 | 2026-05-11 01:00 | 1778461200000 |
| 2026-05-11 12:00 | 2026-05-11 03:00 | 1778468400000 |
| 2026-05-11 12:10 | 2026-05-11 03:10 | 1778469000000 |
| 2026-05-11 12:20 | 2026-05-11 03:20 | 1778469600000 |

## よく使う検索パターン

### エラーログの確認

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time 1778468400000 \
  --end-time 1778469600000 \
  --filter-pattern "ERROR" \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

### 公開（Publish）関連ログの確認

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time 1778468400000 \
  --end-time 1778469600000 \
  --filter-pattern "publish" \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

### 特定プロジェクトに関するログの確認

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time 1778468400000 \
  --end-time 1778469600000 \
  --filter-pattern "ExpermentDeployTest3" \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

### 特定ユーザーの操作ログ確認

```bash
aws logs filter-log-events \
  --log-group-name "/ecs/alchemia-backend" \
  --start-time 1778468400000 \
  --end-time 1778469600000 \
  --filter-pattern "data.admin@aiml.com" \
  --region ap-northeast-1 \
  --output json \
  | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"'
```

### AND 条件で複数キーワードを絞り込む

CloudWatch Logs のフィルターパターンは、スペース区切りで AND 条件になります。

```bash
# 例: "publish" かつ "ERROR" を含むログ
--filter-pattern "publish ERROR"
```

### OR 条件で複数キーワードを検索する

```bash
# 例: "publish" または "Publish" を含むログ
--filter-pattern "?publish ?Publish"
```

## 注意事項

- **ログの保持期間**: CloudWatch Logs のデフォルト保持期間を確認すること（期限切れのログは取得不可）
- **大量ログ**: 時間範囲が広い場合、`--output json` の結果が大きくなることがある。ファイルに保存する場合は以下のようにリダイレクト：

  ```bash
  aws logs filter-log-events \
    --log-group-name "/ecs/alchemia-backend" \
    --start-time 1778468400000 \
    --end-time 1778469600000 \
    --region ap-northeast-1 \
    --output json \
    | jq -r '.events[] | "\(.timestamp | . / 1000 | strftime("%Y-%m-%dT%H:%M:%SZ")) \(.message)"' \
    > /tmp/backend_logs.txt && echo "保存完了: /tmp/backend_logs.txt"
  ```

- **ページネーション**: ログが多い場合、`nextToken` が返されることがある。続きを取得するには `--next-token` オプションを使用：

  ```bash
  aws logs filter-log-events \
    --log-group-name "/ecs/alchemia-backend" \
    --start-time 1778468400000 \
    --end-time 1778469600000 \
    --region ap-northeast-1 \
    --output json \
    --next-token "<前回のレスポンスのnextToken値>"
  ```
