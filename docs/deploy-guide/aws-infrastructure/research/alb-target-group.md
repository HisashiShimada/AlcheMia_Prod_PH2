# ターゲットグループ（Target Group）とは

- **作成日**: 2026-04-23
- **対象**: ARCHITECTURE.md のシステム構成図に登場する「ターゲットグループ」の解説

---

## 一言で言うと

> 「ALB がリクエストを振り分ける宛先のリスト」です。

**ターゲットグループ**とは、AWS の **ALB（Application Load Balancer）が転送先として管理するリソースのグループ**です。

---

## このシステム構成図での役割

構成図では ALB のルーティングルールが以下のように定義されています。

```
ルーティングルール:
├── /api/* → alchemia-backend-tg  (port 3001)  ← バックエンド用ターゲットグループ
└── /*     → alchemia-frontend-tg (port 3000)  ← フロントエンド用ターゲットグループ
```

| ターゲットグループ名 | 転送先 | ポート |
|---|---|---|
| `alchemia-backend-tg` | `alchemia-backend-service`（ECS Fargate）のタスク群 | 3001 |
| `alchemia-frontend-tg` | `alchemia-frontend-service`（ECS Fargate）のタスク群 | 3000 |

---

## ターゲットグループの主な機能

### 1. 転送先タスクの管理

ECS の `desiredCount ≥ 2` で複数タスクが起動していますが、**どのタスクが稼働中か**をターゲットグループが追跡します。

### 2. ヘルスチェック

各タスクに対して定期的にヘルスチェックを実施し、**異常なタスクを自動的に振り分け対象から除外**します。

### 3. 負荷分散（ロードバランシング）

複数の ECS タスクが起動している場合、ターゲットグループがリクエストを**均等に分散**して転送します。

---

## ALB ↔ ターゲットグループ ↔ ECS タスクの関係図

```
ユーザーリクエスト
       ↓
     ALB
       │
       ├── /api/* ──→ [alchemia-backend-tg]
       │                     ├── ECS タスク① (mmdpf-backend:3001)
       │                     └── ECS タスク② (mmdpf-backend:3001)
       │
       └── /*     ──→ [alchemia-frontend-tg]
                             ├── ECS タスク① (mmdpf-frontend:3000)
                             └── ECS タスク② (mmdpf-frontend:3000)
```

---

## まとめ

ターゲットグループは ALB と ECS の**仲介役**です。  
ALB 自体は「どこに転送するか（ルール）」だけを持ち、**実際の転送先リストの管理・ヘルスチェック・負荷分散はターゲットグループが担当**します。

この構成のおかげで、ECS のタスクが自動スケーリングで増減しても、ALB 側の設定を変更することなく動的に転送先を更新できます。
