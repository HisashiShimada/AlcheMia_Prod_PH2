## タスク概要

MAIMLエディタ画面での使用に備え、`attribute` テーブルへ属性名 `units` / `formatString` / `scaleFactor` の初期値データを登録するための**CSVファイルとINSERT文**を作成する。

自動登録機能の実装は行わない。手動でCSVアップロードまたはSQL実行により登録する。

---

## 目的と期待される成果

### 目的
MAIMLエディタでattributeテーブルを使用する際に選択できる初期値（単位・フォーマット・スケール係数）のデータを、手動で登録できる状態にする。

### 期待される成果
- [ ] マスタ管理画面のCSVアップロードで使用できる形式のCSVファイルが作成される
- [ ] 直接DBに投入できるINSERT文（SQL）が作成される
