## 1. タスク概要

現在のS3ファイルダウンロード処理を、署名付きURL方式からバックエンドプロキシ方式に変更します。

### 現在の実装
- バックエンドが署名付きURL（Pre-signed URL）を生成
- フロントエンドが署名付きURLを使用してS3/Swiftから直接ダウンロード
- フロントエンドがS3/Swiftのエンドポイントと直接通信

### 変更後の実装
- バックエンドがS3/Swiftからファイルを取得し、ストリームとしてレスポンス
- フロントエンドはバックエンドのエンドポイントからファイルをダウンロード
- フロントエンドはバックエンドとのみ通信（S3/Swiftのエンドポイントを知らない）

## 2. 目的と期待される成果

### 目的
1. **セキュリティ強化**: S3/Swiftのエンドポイントをフロントエンドに公開しない
2. **通信の一元化**: すべてのAPI通信をバックエンド経由に統一
3. **アクセス制御の強化**: バックエンドで完全なアクセス制御を実施
4. **監査ログの一元化**: ファイルダウンロードをすべてバックエンドで記録

### 期待される成果
- [x] フロントエンドがバックエンドとのみ通信する
- [x] S3/Swiftのエンドポイント情報がフロントエンドに漏洩しない
- [x] バックエンドで完全なアクセス制御とログ記録が可能
- [x] 既存のAPIエンドポイントを変更せずに実装（互換性維持）

### バックエンド実装方針

#### ファイルストリーミング

#### メモリ効率化
- 小さいファイル（<10MB）: Buffer方式
- 大きいファイル（>=10MB）: Stream方式（必要に応じて実装）

### フロントエンド実装方針

#### Blob URLを使用したダウンロード
```typescript
const response = await client.get(`/files/download-url`, {
  responseType: 'blob', // 重要: Blobとして受信
  data: { fileKey }
});

const blob = new Blob([response.data]);
const url = window.URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = fileName;
link.click();
window.URL.revokeObjectURL(url);
```

## 補足: メソッド変更の詳細

### 変更前（署名付きURL方式）
```typescript
// Service層 (backend/src/services/fileAccessService.ts)
async downloadFile(...): Promise<FileDownloadResponse> {
  const signedUrl = await storageService.getSignedUrl(...);
  return { downloadUrl: signedUrl, fileName, fileSize, contentType, ... };
}

// Controller層 (backend/src/controllers/fileAccessController.ts)
const result = await service.downloadFile(...);
res.json({ success: true, data: result }); // { downloadUrl: "https://s3...", ... }

// Frontend (frontend/src/api/fileAccessService.ts)
const response = await client.get(`/projects/${projectId}/files/${fileName}/download`);
const { downloadUrl } = response.data.data;
executeFileDownload(downloadUrl, fileName); // 新しいタブで開く
```

### 変更後（プロキシ方式）
```typescript
// Service層 - 新メソッド追加
interface FileStreamResponse {
  buffer: Buffer;
  metadata: {
    fileName: string;
    contentType: string;
    fileSize: number;
  };
}

async streamFile(...): Promise<FileStreamResponse> {
  const buffer = await storageService.downloadFile(organizationId, filePath);
  return { 
    buffer, 
    metadata: { fileName, contentType, fileSize: buffer.length } 
  };
}

async streamFileByKey(...): Promise<FileStreamResponse> {
  const buffer = await storageService.downloadFile(organizationId, fileKey);
  return { 
    buffer, 
    metadata: { fileName, contentType, fileSize: buffer.length } 
  };
}

// 既存メソッドは非推奨化
/** @deprecated Use streamFile() instead */
async downloadFile(...): Promise<FileStreamResponse> {
  return this.streamFile(...);
}

// Controller層
const result = await service.streamFile(...);
const encodedFileName = encodeURIComponent(result.metadata.fileName);
res.setHeader('Content-Type', result.metadata.contentType);
res.setHeader('Content-Disposition', `attachment; filename*=UTF-8''${encodedFileName}`);
res.setHeader('Content-Length', result.buffer.length.toString());
res.send(result.buffer);

// Frontend
const response = await client.get(`/projects/${projectId}/files/${fileName}/download`, {
  responseType: 'blob' // 重要: Blobとして受信
});
const blob = response.data; // Blob
const url = URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = fileName;
link.click();
URL.revokeObjectURL(url); // メモリ解放
```
