## タスク概要

`NamespaceMain.tsx` の左ペインにある名前空間ツリーを、ログイン中ユーザーのロール（部署代表者 / チーム代表者 / 一般メンバー）に応じて表示範囲を切り替える。

## 目的と期待される成果

- [ ] 部署代表者がログインした場合、自分の部署・配下の全チーム・各チームメンバーのネームスペースを左ツリーに表示する
- [ ] チーム代表者がログインした場合、自分のチーム・そのチームメンバーのネームスペースを左ツリーに表示する
- [ ] 一般メンバーは現状（自分への祖先パスのみ）と変わらない

## 実装ステップ

### Phase 1: モック定数の追加
- [ ] `UserNsRole` 型定義を追加（`kind: 'dept_owner' | 'team_owner' | 'member'`）
- [ ] `CURRENT_USER_ROLE` モック定数を追加（切り替えで動作確認可能）
- [ ] 既存 `CURRENT_USER_NS_KEY` を `CURRENT_USER_ROLE` から動的に導出するよう変更

### Phase 2: filterTreeForUser の拡張
- [ ] `dept_owner` の場合: `deptKey` のノード配下を全展開するロジック追加
- [ ] `team_owner` の場合: `teamKey` のノード配下を全展開・祖先の部署は非表示のロジック追加
- [ ] `member` の場合: 現状維持（祖先パスのみ）

### Phase 3: ハイライト対象の調整
- [ ] `CURRENT_USER_NS_KEY`（自分のノードを青背景強調）を `CURRENT_USER_ROLE` から取得するよう修正
