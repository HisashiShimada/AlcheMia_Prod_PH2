## タスク概要

CSV等のインポート/エクスポート機能で「アップロード/ダウンロード」と「インポート/エクスポート」が混在している状態を案Aの方針で統一する。

**方針（案A）**:
- アップロード/ダウンロード → ファイルをサーバ（S3等）へ送受信する場合
- インポート/エクスポート → データをシステムへ取り込む/書き出す場合（CSVデータ登録等）
- 「取り込み」→「インポート」に統一

変更対象は翻訳ファイル（ja.json / en.json）の表示文言のみ。翻訳キー名・ソースコード・バックエンドAPIパスは変更しない。
