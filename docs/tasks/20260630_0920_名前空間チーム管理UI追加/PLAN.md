## タスク概要

実験管理者メニューの名前空間管理ページ（`/namespace-management`）に、チーム管理機能を追加する。
現在の用語管理UIをサブタブ「用語管理」として残しつつ、新たに「チーム管理」サブタブを追加し、案Aの2ペインレイアウトで実装する。

## 目的と期待される成果

- [ ] 名前空間管理ページにサブタブ（用語管理 / チーム管理）が表示される
- [ ] チーム管理タブで、ログイン中の実験管理者が作成したチーム一覧が左ペインに表示される
- [ ] チームを選択すると右ペインにチーム詳細（代表者・Prefix・URI・メンバー）が表示される
- [ ] 一人のユーザーが複数チームに所属できる（メンバー一覧で表現）
- [ ] チームを作成した実験管理者がそのチームの代表者として表示される
- [ ] 既存の TeamAddDialog / TeamEditDialog を再利用する

## 実装ステップ

### Phase 1: TeamManagementPanel コンポーネントの新規作成
- [ ] `frontend/src/components/namespace/TeamManagementPanel.tsx` を新規作成
- [ ] 左ペイン: 自分が作成したチーム一覧（List）＋「チームを作成」ボタン
- [ ] 右ペイン: 選択チームの詳細表示（代表者・Prefix・URI・表示名）＋メンバー一覧テーブル
- [ ] メンバー追加・削除の操作（TeamEditDialog を再利用）
- [ ] チーム作成（TeamAddDialog を再利用）

### Phase 2: NamespaceMain.tsx にサブタブを追加
- [ ] Ant Design `<Tabs>` を用いてページ上部にサブタブを追加
- [ ] タブ1: 「用語管理」→ 既存の左ツリー＋用語テーブルをそのまま表示
- [ ] タブ2: 「チーム管理」→ TeamManagementPanel を表示
