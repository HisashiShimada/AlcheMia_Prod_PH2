## タスク概要

実験作業者メニューの実験記録タブで、実績値入力後「保存して次へ」押下時に
テンプレートごとの不確かさ選択画面へ遷移するフローを追加する。
不確かさ選択後「保存して次へ」を押すと次テンプレートの実績値入力画面へ遷移する。

## 変更フロー

```
【変更前】
実績値入力 → 「保存して次へ」→ 次トランジションへ

【変更後】
実績値入力（phase: actuals）
  ↓「保存して次へ」
不確かさ選択（phase: uncertainty）
  ↓「保存して次へ」（次テンプレートがあれば）
次テンプレートの実績値入力（phase: actuals）
  ↓（最後のテンプレートなら）
次トランジションへ
```
