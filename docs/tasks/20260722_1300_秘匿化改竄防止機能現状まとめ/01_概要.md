## 1. 対象機能の概要

本ドキュメントは mmdpf プロジェクトにおける「秘匿化（暗号化）」および「改竄防止（電子署名・タイムスタンプ）」機能について、現時点での実装状況・残課題を整理したものです。

### 機能の位置づけ

| 機能 | 目的 | 対象データ |
|------|------|-----------|
| **秘匿化（暗号化）** | MAIMLファイル内の特定要素を暗号化し、不正閲覧を防止する | MAIMLの`<material>` / `<condition>` / `<result>` 等の要素 |
| **改竄防止（電子署名）** | MAIMLファイルに電子署名・タイムスタンプを付与し、改竄を検知できるようにする | MAIMLファイル全体 |

### 推奨実行順序

```
① MAIMLファイル登録（プロジェクト管理）
   ↓
② 秘匿化（暗号化）  ← 先に暗号化する
   ↓
③ 署名（改竄防止）  ← 暗号化済みの状態で署名する（重要）
   ↓
④ 検証              ← 署名・タイムスタンプの正当性確認
   ↓
⑤ 復号化            ← 必要時に復号化
```

> ⚠️ 暗号化を実行すると既存の署名は無効化されます。暗号化後は必ず再署名を実行してください。

## 3. 全体アーキテクチャ

```
[フロントエンド]
  ├── 暗号化管理モーダル（EncryptionManagementModal）
  │     ├── MAIMLツリー表示（parseMaimlToEncryptionTree）
  │     ├── 暗号化設定パネル（秘匿レベルL1/L2）
  │     ├── 鍵設定パネル（新規生成/ファイル読込/公開鍵）
  │     └── プレビューパネル（暗号化前後）
  │
  └── 署名管理モーダル（SignatureManagementModal）
        ├── 署名状態表示（署名なし/署名済み）
        ├── 署名実行ボタン
        └── 署名削除ボタン（スタブ）

       ↕ HTTP API

[バックエンド]
  ├── /api/v1/encryption/*
  │     ├── encryptionController.ts
  │     ├── maimlEncryptionService.ts（暗号化コアロジック）
  │     └── maimlEncryptionXmlHelper.ts（MAIML XML操作）
  │
  ├── /api/v1/signature/*
  │     ├── signatureController.ts
  │     └── maimlIntegrityService.ts（署名・検証コアロジック）
  │
  └── maimlSchemaHelper.ts（UPA制約チェック・XSD解析）

       ↕ DB / ストレージ

[データ層]
  ├── PostgreSQL
  │     ├── encryption_keys テーブル（暗号化鍵のメタデータ）
  │     └── integrity_audit_log テーブル（署名・検証履歴）
  │
  └── Swift/S3ストレージ
        └── MAIMLファイル（暗号化/署名済みのXML）
```
