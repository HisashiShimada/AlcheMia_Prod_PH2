## 1. タスク概要

組織追加ダイアログの「保存」ボタン押下後、organizationテーブルだけでなく、以下の関連テーブルにもデータを挿入する必要があります：

1. **organization_user（組織利用者）** - 代表システム管理者のユーザーレコード
2. **role（ロール）** - ROLE002（システム管理者）ロールの作成
3. **role_permission（ロール権限）** - 4つの機能権限の作成

---

### 目的
組織追加時に代表システム管理者と必要なロール・権限を自動的に作成し、組織が即座に利用可能な状態にする。

### アーキテクチャ上の考慮事項

#### トランザクション管理
```typescript
const pool = getPool();
const client = await pool.connect();

try {
  await client.query('BEGIN');
  
  // 1. organizationテーブル挿入
  const org = await organizationRepository.create(...);
  
  // 2. organization_userテーブル挿入
  await organizationRepository.createOrganizationUser(...);
  
  // 3. roleテーブル挿入
  await organizationRepository.createRole(...);
  
  // 4. role_permissionテーブル挿入（4件）
  await organizationRepository.createRolePermissions(...);
  
  await client.query('COMMIT');
} catch (error) {
  await client.query('ROLLBACK');
  throw error;
} finally {
  client.release();
}
```

#### 既存ロールの重複チェック
同一organization_id内にROLE002が既に存在する場合はスキップ（INSERT時にON CONFLICT処理）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| トランザクション途中で失敗 | 高 | 中 | トランザクション管理とロールバック実装 |
