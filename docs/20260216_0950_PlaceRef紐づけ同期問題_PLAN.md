## 1. タスク概要

PlaceRefでノードとの紐づけを行った際に、ペトリネット側のノードと同期がとれておらず、PropertyPanelから編集ダイアログを開いた際に紐づけをしたテンプレートの編集ではなく新規の編集になっているように見える問題を修正する。

## 3. 問題分析

### 3.1. 現在のフロー

1. **PlaceRef追加時** (TemplateEditorDialog.tsx)
   - ユーザーがPlace Reference追加ダイアログから既存Placeを選択
   - `placeRefs` 配列に `{id: '', ref: nodeId}` を追加
   - 保存時に `handleSaveTemplate` が呼ばれる

2. **保存処理** (PetriNetEditorInner.tsx の handleSaveTemplate)
   ```typescript
   // placeRefsに含まれる全てのノードにテンプレートを設定
   const newNodes = nds.map((node: Node<NodeData>) => {
     if (placeRefsToUpdate.some((pr) => pr.ref === node.id)) {
       return {
         ...node,
         data: {
           ...node.data,
           template: convertedTemplateRef,
           templateRef: convertedTemplateRef,
           isCommonTemplate: isCommonTemplate,
         },
       };
     }
     return node;
   });
   ```

3. **PropertyPanelからの編集** (PropertyPanel → TemplateEditorDialog)
   - ノードを選択してPropertyPanelを表示
   - 「編集」ボタンをクリック
   - `handleOpenTemplateEditor(node)` が呼ばれる
   - TemplateEditorDialogが開く

4. **TemplateEditorDialogの初期化**
   ```typescript
   const mergedTemplate: Template | null = useMemo((): Template | null => {
     if (!node) return null;
     
     const template = (node.data.template || {}) as Partial<Template>;
     const templateRef = (node.data.templateRef || {}) as Partial<Template>;
     
     return {
       id: template.id || templateRef.id || '',
       uuid: template.uuid || templateRef.uuid || '',
       name: template.name || templateRef.name || '',
       // ...
       placeRefs: template.placeRefs || templateRef.placeRefs || [],
     };
   }, [node]);
   ```

### 3.2. 問題の原因（推測）

**原因1**: PlaceRef追加後、最初のPlaceにのみテンプレートが設定され、追加されたPlaceには設定されていない可能性

**原因2**: `handleSaveTemplate` で全ての `placeRefs` に含まれるノードにテンプレートを設定しているが、TemplateContextに保存されているテンプレートの `placeRefs` が更新されていない可能性

**原因3**: PropertyPanelから開いた際に、ノードの `template` または `templateRef` が空、または初期値のまま

### 調査結果

**原因特定:**

PlaceRef追加保存時のフローを調査した結果、以下の問題が判明しました：

1. **TemplateEditorDialog.tsx側の問題**:
   - PlaceRef追加時に`placeRefs`配列に`{id: '', ref: nodeId}`を追加
   - 保存時に`handleSaveTemplate`を呼び出してPetriNetEditorInner側に渡す
   - この時点では問題なし

2. **PetriNetEditorInner.tsx側の問題**:
   - `handleSaveTemplate`で`placeRefsToUpdate`の全ノードにテンプレートを設定
   - ただし、**TemplateContext（window.clineUpdateTemplate）の更新が先**に実行される
   - その後、`setNodes`でノードにテンプレートを設定
   - この順序が問題を引き起こしている可能性

3. **PropertyPanelから編集ダイアログを開いた時の問題**:
   - ノードの`data.template`または`data.templateRef`からテンプレートを読み込む
   - しかし、PlaceRefで追加したノードは、最初のノード以外`template`が設定されていない可能性
   - または、TemplateContextとノードのテンプレートが同期していない
