## リスク

| リスク | 対策 |
|--------|------|
| TemplateEditorDialogのdata-testidが未定義 | `getByRole` / `.ant-*` クラスで特定。表示されない場合は `$testInfo.skip()` でスキップ |
| XMLビューのTextArea特定が困難 | dialogスコープ内の `textarea` / `[role="textbox"]` で特定 |
| 保存後の確認が困難（API未実装の可能性） | 保存ボタンクリック後のUI変化（成功メッセージ / エラーAlert）で確認 |
