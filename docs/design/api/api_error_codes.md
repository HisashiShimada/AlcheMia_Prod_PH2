# エラーコード仕様書

**作成日**: 2026-03-23  
**最終更新**: 2026-03-23  
**バージョン**: 1.0.0  
**対象**: フロントエンド・バックエンド共通  

---

## 概要

本ドキュメントは mmdpf プロジェクトで使用するエラーコード体系を定義します。  
バックエンドが返すエラーレスポンスと、フロントエンドのユーザー向けメッセージ変換の対応表を一元管理します。

### 関連ファイル

| ファイル | 役割 |
|--------|------|
| `backend/src/enums/errorCodes.ts` | バックエンド側エラーコード定数 |
| `frontend/src/utils/errorCodes.ts` | フロントエンド側エラーコード定数・型定義・HTTPステータスマッピング |
| `frontend/src/utils/errorMapper.ts` | エラーコード → 日本語メッセージ変換（唯一の変換場所） |
| `frontend/src/utils/errorUtils.ts` | AxiosError からエラーコードを抽出して `errorMapper` を呼ぶユーティリティ |

## エラーコード一覧

### E1xxx: CLIENT — クライアント操作・入力エラー

| コード | 定数名 | ユーザー向けメッセージ | 発生条件 |
|--------|--------|----------------------|---------|
| E1001 | `E1001` | ファイルサイズが上限を超えています | アップロードファイルがサイズ制限を超過 |
| E1002 | `E1002` | ファイル形式が正しくありません | 許可されていない拡張子のファイル |
| E1003 | `E1003` | 入力内容に誤りがあります | バリデーションエラー全般（HTTP 400 フォールバック） |
| E1004 | `E1004` | 必須項目が入力されていません | 必須フィールド未入力 |
| E1005 | `E1005` | 入力形式が正しくありません | 形式違反（メール形式、日付形式など） |
| E1006 | `E1006` | フォルダ名が正しくありません | フォルダ名に不正文字を含む |
| E1007 | `E1007` | サブフォルダ名が正しくありません | サブフォルダ名に不正文字を含む |
| E1008 | `E1008` | コンテンツ形式が正しくありません | リクエストボディの Content-Type 不一致 |
| E1009 | `E1009` | フォーマット名が指定されていません | フォーマット名パラメータが空 |

### E3xxx: NETWORK — ネットワーク・通信エラー

| コード | 定数名 | ユーザー向けメッセージ | 発生条件 |
|--------|--------|----------------------|---------|
| E3001 | `E3001` | サーバーに接続できません。ネットワークを確認してください | レスポンスなし / 502 / 503 |
| E3002 | `E3002` | リクエストがタイムアウトしました。再度お試しください | `ECONNABORTED` / 504 |
| E3003 | `E3003` | ネットワークエラーが発生しました。接続を確認してください | 一般的なネットワークエラー |

> フロントエンドの `extractErrorCode()` が AxiosError の `code` および `response` の有無から自動判定します。

## HTTPステータス → エラーコード フォールバックマッピング

バックエンドがエラーコードを返さなかった場合（旧API互換など）のフォールバックです。

| HTTP ステータス | エラーコード | 説明 |
|---------------|------------|------|
| 400 | E1003 | Bad Request → バリデーションエラー |
| 401 | E5013 | Unauthorized → 認証必須 |
| 403 | E5012 | Forbidden → アクセス拒否 |
| 404 | E6001 | Not Found → リソース不存在 |
| 409 | E6005 | Conflict → 重複 |
| 429 | E5007 | Too Many Requests → レート制限 |
| 500 | E4001 | Internal Server Error → サーバー内部エラー |
| 502 | E3001 | Bad Gateway → サーバー接続失敗 |
| 503 | E3001 | Service Unavailable → サーバー接続失敗 |
| 504 | E3002 | Gateway Timeout → タイムアウト |

## フロントエンドのエラー処理フロー

```
API呼び出し
  ↓
【成功（2xx）】
  ├─ success: true  → 正常処理
  └─ success: false → result.error?.message を表示
                      または extractErrorMessage(null) でデフォルトメッセージ

【例外（AxiosError）】
  └─ extractErrorMessage(error)
       ↓
       extractErrorCode(error)
         ├─ axiosError.code === 'ECONNABORTED'     → E3002
         ├─ axiosError.response なし                → E3001
         ├─ axiosError.response.data.error.code あり → そのコードを使用
         └─ axiosError.response.status             → HTTP_STATUS_TO_ERROR_CODE[status]
       ↓
       mapErrorToMessage(code)
         ├─ ERROR_MESSAGE_MAP に存在 → 対応する日本語メッセージ
         └─ 存在しない              → デフォルトメッセージ
```

### 実装例

```typescript
import { extractErrorMessage } from '@/utils/errorUtils';

// catch ブロックでの使用（AxiosError）
try {
  const response = await apiCall();
} catch (error) {
  message.error(extractErrorMessage(error));
}

// success: false の場合
const result = await getWorkerAccessibleProjects();
if (!result.success) {
  message.error(result.error?.message || extractErrorMessage(null));
}
```

## バックエンドのエラーレスポンス形式

### 統一エラーレスポンス

```json
{
  "success": false,
  "error": {
    "code": "E5001",
    "message": "ユーザー名またはパスワードが正しくありません",
    "details": []
  },
  "meta": {
    "timestamp": "2026-03-23T12:00:00Z",
    "requestId": "req_abc123"
  }
}
```

### バックエンド実装規約

- エラーレスポンスには必ず `error.code` を含める
- `error.code` は本仕様書のエラーコード（`E1001` 〜 `E9999`）を使用する
- `error.message` は英語または日本語どちらでも可（フロントは `error.code` で変換するため）
- `details` は入力バリデーションエラー時に各フィールドのエラーを配列で返す

```typescript
// バックエンド実装例
import { ErrorCodes } from '../enums/errorCodes';
import { createErrorResponse } from '../utils/responseUtils';

// 認証失敗
throw createErrorResponse(ErrorCodes.E5001, 'Login failed', 401);

// バリデーションエラー
throw createErrorResponse(ErrorCodes.E1003, 'Validation failed', 400, [
  { field: 'email', message: 'Invalid email format', code: 'E1005' }
]);
```
