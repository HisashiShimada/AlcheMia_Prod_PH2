# ボタン制御一覧 - 索引

## 目的

各ロールメニュー・各画面ごとのボタン押下時の **「メイン操作」** と **「活性 / 非活性の制御条件」** を一覧化する設計書です。

各画面のUI仕様書（`docs/design/ui/*/ui_*.md`）に分散しているボタン挙動を横断的に把握できるよう整理しています。

## ドキュメント構成

各ロールファイルは以下の構成で記述しています。

```
# ボタン制御一覧 - ①ロール名

## メニュー構成（タブ一覧）
## タブN：画面名
  ### N-1. エリア名（ツールバー / 行操作 / ダイアログ など）
  | # | ボタン名 | アイコン | メイン操作 | 活性条件 | 非活性条件 | 備考 |
```

## 表記ルール

### 活性 / 非活性の判定フラグ

| フラグ / 条件 | 意味 |
|-------------|------|
| `isReadOnly` | 閲覧専用権限。`getMenuPermission(role) === 0` の場合 `true` |
| `isEditable` | 編集権限あり（組織グループ権限）。`false` の場合は変更系ボタンを無効化 |
| `selectedRowKeys.length === 0` | テーブル行が未選択 |
| `record.isActive` | 対象レコードがアクティブ状態 |
| `viewOnly` | 読み取り専用モードで開かれているコンポーネント（Props 経由） |

### プロジェクトステータス（実験管理者タブで使用）

| status | 名称 | 説明 |
|--------|------|------|
| 0 | プロジェクト計画中 | 初期状態。編集・アップロード可能 |
| 1 | タスク実行待ち | チェックアウト中 |
| 2 | タスク実行中 | チェックアウト中 |
| 3 | 承認待ち | レビュー待ち。公開可能 |
| 4 | プロジェクト完了 | 全タスク完了。編集系ボタン無効 |
| 5 | タスク異常終了 | エラー発生。編集系ボタン無効 |
| 6 | レビュー差戻 | NGタスクのみ残存。強制終了ボタンが活性 |

### 記号

| 記号 | 意味 |
|------|------|
| ○ | 常に活性（条件なし） |
| △ | 条件付き活性（備考欄に詳細） |
| ✕ | 常に非活性（表示はされるが押せない） |
| — | 該当なし |
