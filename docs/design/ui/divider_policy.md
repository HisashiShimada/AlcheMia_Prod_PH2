# セクション区切り線形状ポリシー

## 標準3パターン

### パターン1: 水平線（標準）
**用途**: セクション間の視覚的な区切り
- 方向: 水平（horizontal）
- 線の太さ: 1px
- 線の色: `token.colorBorderSecondary` (rgba(0,0,0,0.06))
- マージン: 上下 `token.margin` (16px)
- 幅: 100%（親要素いっぱい）

---

### パターン2: 垂直線
**用途**: サイドバイサイドのコンテンツ区切り
- 方向: 垂直（vertical）
- 線の太さ: 1px
- 線の色: `token.colorBorderSecondary` (rgba(0,0,0,0.06))
- マージン: 左右 `token.marginSM` (12px)
- 高さ: `1em`（テキストの高さに合わせる）

---

### パターン3: テキスト付き水平線
**用途**: タイトル・ラベル付きセクション区切り
- 方向: 水平（horizontal）
- 線の太さ: 1px
- 線の色: `token.colorBorderSecondary` (rgba(0,0,0,0.06))
- マージン: 上下 `token.margin` (16px)
- テキスト位置: 左揃え（left）/ 中央揃え（center）/ 右揃え（right）
- テキストフォントサイズ: `token.fontSize` (14px)
- テキスト色: `token.colorText` (#212121)
- テキスト左右のスペース: `token.marginSM` (12px)

---

## 共通仕様（全パターン）

### 色定義
**通常**
- 線の色: `token.colorBorderSecondary` (rgba(0,0,0,0.06))
- テキスト色: `token.colorText` (#212121)

**強調**
- 線の色: `token.colorBorder` (rgba(0,0,0,0.12))
- テキスト色: `token.colorText` (#212121)

**淡色**
- 線の色: `token.colorSplit` (rgba(0,0,0,0.06))
- テキスト色: `token.colorTextSecondary` (#757575)

### スペーシング
**マージン（水平線）**
- 上下: `token.margin` (16px)

**マージン（垂直線）**
- 左右: `token.marginSM` (12px)

**テキスト周りのスペース**
- 左右: `token.marginSM` (12px)

---

## パターン選択

- セクション間の区切り → **パターン1（水平線）**
- インライン要素の区切り（例: タグ、ボタン群） → **パターン2（垂直線）**
- タイトル付きセクション区切り → **パターン3（テキスト付き水平線）**

---

## 使用例

### パターン1: 水平線（標準）
```tsx
<Divider />
```

### パターン2: 垂直線
```tsx
<Space split={<Divider type="vertical" />}>
  <Button>ボタン1</Button>
  <Button>ボタン2</Button>
  <Button>ボタン3</Button>
</Space>
```

### パターン3: テキスト付き水平線
```tsx
// 左揃え（デフォルト）
<Divider orientation="left">セクション1</Divider>

// 中央揃え
<Divider>セクション2</Divider>

// 右揃え
<Divider orientation="right">セクション3</Divider>
```

## 除外されたパターンと標準パターンの対応

### カスタムカラーDivider
- **対応する標準パターン**: パターン1（水平線）の色変化版
- **除外理由**: 使用頻度が低く、特殊用途のため
- **形状**: パターン1と同じ（太さ1px、マージン16px）
- **差異**: 線の色をカスタマイズ可能（例: エラー色、成功色）
- **用途**: 特定の状態を強調する場合のみ

### 破線Divider
- **対応する標準パターン**: パターン1（水平線）のスタイル変化版
- **除外理由**: 使用頻度が低いため
- **形状**: パターン1と同じ（マージン16px）
- **差異**: `dashed` プロパティで破線化
- **用途**: 視覚的な区別が必要な場合のみ

### プレーンテキストDivider
- **対応する標準パターン**: パターン3（テキスト付き水平線）の変種
- **除外理由**: 使用頻度が低いため
- **形状**: パターン3と同じ
- **差異**: `plain` プロパティでテキストを淡色化
- **用途**: テキストを目立たせたくない場合のみ

## アクセシビリティ

### セマンティック
- Dividerは `<hr>` タグとしてレンダリングされます
- スクリーンリーダーはDividerをセクション区切りとして認識します

### ARIA属性
- `role="separator"` が自動的に付与されます
- テキスト付きDividerは `aria-label` を持ちます

## レスポンシブ対応

### モバイル（xs, sm）
- 水平線: 幅100%、マージン上下12px
- 垂直線: 表示しない（Spaceがwrapされるため）
- テキスト付き水平線: 幅100%、マージン上下12px

### タブレット（md）
- 水平線: 幅100%、マージン上下16px
- 垂直線: 表示する、マージン左右12px
- テキスト付き水平線: 幅100%、マージン上下16px

### デスクトップ（lg, xl, xxl）
- 水平線: 幅100%、マージン上下16px
- 垂直線: 表示する、マージン左右12px
- テキスト付き水平線: 幅100%、マージン上下16px

---

## ベストプラクティス

### DO（推奨）
✅ セクション区切りにはシンプルな水平線を使用する
✅ 垂直線はインライン要素の区切りのみに使用する
✅ テキスト付き水平線はセクション見出しとして使用する
✅ 過度な使用を避け、視覚的な階層を保つ
✅ カードやパネル内のセクション区切りに使用する

### DON'T（非推奨）
❌ 垂直線をブロック要素の区切りに使用しない
❌ 隣接するDividerを連続して配置しない
❌ カスタムカラーを乱用しない
❌ テキストが長すぎるDividerを使用しない
❌ ページ全体を細かく分割しすぎない

## 実装メモ

### Ant Design標準プロパティ
```tsx
interface DividerProps {
  type?: 'horizontal' | 'vertical';        // 方向（デフォルト: horizontal）
  orientation?: 'left' | 'center' | 'right'; // テキスト位置（デフォルト: center）
  plain?: boolean;                          // テキストを淡色化（デフォルト: false）
  dashed?: boolean;                         // 破線化（デフォルト: false）
  style?: CSSProperties;                    // カスタムスタイル
  className?: string;                       // カスタムクラス
  children?: ReactNode;                     // テキストコンテンツ
}
```

### パフォーマンス
- Dividerは軽量なコンポーネントでパフォーマンスへの影響は最小限
- 大量のDividerを使用する場合でも問題なし
