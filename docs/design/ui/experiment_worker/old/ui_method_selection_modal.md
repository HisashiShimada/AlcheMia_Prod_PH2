## 1. 画面概要

### 1.1. 目的

プロジェクトに紐づくメソッド一覧を**テーブル形式**で表示し、ラジオ選択するモーダルです。
フィルタ検索・列ソートに対応しており、一覧から1件を選択して「決定」するか「選択解除」します。

### 1.2. 主要機能

1. メソッド一覧のテーブル表示（メソッド名・説明・所有者）
2. キーワード検索（メソッド名・説明）
3. メソッド名フィルター（ドロップダウン）
4. 所有者フィルター（ドロップダウン）
5. テーブル列のソート（メソッド名・所有者）
6. ラジオ選択 + ページネーション
7. 選択解除ボタン

## 3. コンポーネント Props 定義

```typescript
interface MethodSelectionModalProps {
  open: boolean;
  onClose: () => void;
  selectedProject: string;
  selectedMethodId: string | null;
  onMethodChange: (methodId: string | null) => void;
  methods?: Method[];
}
```

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | モーダル表示/非表示 |
| `onClose` | `() => void` | ✅ | 閉じるコールバック |
| `selectedProject` | `string` | ✅ | 選択中プロジェクトID（表示用）|
| `selectedMethodId` | `string \| null` | ✅ | 現在選択中のメソッドID |
| `onMethodChange` | `(methodId: string \| null) => void` | ✅ | メソッド変更確定コールバック |
| `methods` | `Method[]` | ❌ | メソッド一覧（デフォルト: `[]`）|

## 4. フィルタ仕様

| フィルタ | 種別 | 対象 | プレースホルダー |
|--------|------|-----|--------------|
| キーワード検索 | `Input` テキスト | メソッド名 + 説明（部分一致・大文字小文字無視）| 「メソッド名、説明で検索」|
| メソッド名 | `Select`（クリア可）| メソッド名（完全一致）| 「メソッド名」|
| 所有者 | `Select`（クリア可）| 所有者（完全一致）| 「所有者」|

フィルタ値は3条件のAND結合。

---

## 5. テーブル仕様

| カラム | dataIndex | ソート | 幅 |
|-------|----------|--------|-----|
| メソッド名 | `methodName` | ✅ | 200px |
| 説明 | `description` | ❌ | 残り全幅（ellipsis）|
| 所有者 | `owner` | ✅ | 150px |

- 行選択: `type='radio'`（1件のみ）
- スクロール: `y: 350px`
- ページネーション: 20/50/100件、クイックジャンプあり
