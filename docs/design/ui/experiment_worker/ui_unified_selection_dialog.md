## 1. 画面概要

### 1.1. 目的

プロジェクト→メソッド→タスクを**3ステップで順番に選択**する統合ダイアログです。
各ステップでリスト選択するとそのまま次ステップに進みます（シングルクリック遷移）。

### 1.2. 主要機能

1. ステップ1: プロジェクト選択
2. ステップ2: メソッド選択（プロジェクト名をサブタイトルに表示）
3. ステップ3: タスク選択（プロジェクト名 + メソッド名をサブタイトルに表示）
4. 各ステップに「戻る」ボタンで前ステップへ戻れる
5. 「-」（未選択）オプション付き
6. キャンセルで変更を破棄

## 3. コンポーネント Props 定義

```typescript
interface UnifiedSelectionDialogProps {
  open: boolean;
  onClose: () => void;
  selectedProject: string;
  selectedMethodId: string | null;
  selectedTaskId: string | null;
  onProjectChange: (value: string) => void;
  onSelectMethod: (methodId: string) => void;
  onSelectTask: (taskId: string) => void;
  projects?: ProjectInfo[];
}
```

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | ダイアログ表示/非表示 |
| `onClose` | `() => void` | ✅ | 閉じるコールバック |
| `selectedProject` | `string` | ✅ | 現在選択中プロジェクトID |
| `selectedMethodId` | `string \| null` | ✅ | 現在選択中メソッドID |
| `selectedTaskId` | `string \| null` | ✅ | 現在選択中タスクID |
| `onProjectChange` | `fn` | ✅ | プロジェクト変更確定コールバック |
| `onSelectMethod` | `fn` | ✅ | メソッド変更確定コールバック |
| `onSelectTask` | `fn` | ✅ | タスク変更確定コールバック |
| `projects` | `ProjectInfo[]` | ❌ | プロジェクト一覧（デフォルト: `[]`）|

## 4. ステップ遷移ロジック

```
open時 → step='project' にリセット

[プロジェクト選択]
  → "-"選択: 即時決定・閉じる
  → プロジェクト選択: step='method' に進む

[メソッド選択]
  → "-"選択: 即時決定・閉じる
  → メソッド選択: step='task' に進む
  → 戻る: step='project'

[タスク選択]
  → タスク選択: tempTaskId を更新（確定はしない）
  → 決定: 全変更を確定・閉じる
  → 戻る: step='method'

[キャンセル]: 全一時変数リセット・閉じる
```
