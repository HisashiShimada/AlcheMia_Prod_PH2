## 1. 画面概要

### 1.1. 目的

実験作業者（Worker）が、選択したトランジションに対して**実験データを記録**するためのパネルコンポーネントです。
実験管理者が設定した**想定値を参照しながら**実績値を入力し、トランジションのステータスを更新します。

旧来の `DataRecordDialog.tsx`（モーダル形式）のロジックを統合・インライン化したコンポーネントです。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_worker` | ✅ 閲覧・編集可 |
| `experiment_admin` | ✅ 閲覧可（readOnlyモード） |

### 1.3. 主要機能

1. トランジション情報の表示（名称・ステータス）
2. 想定値の表示（`mgr-instruction:` プレフィックス付きプロパティから取得）
3. 実績値の入力（テンプレートフォーム）
4. トランジションステータスの更新
5. みなし進捗更新
6. 作業コメントの入力・保存
7. 保存処理（`saveTransitionData` API呼び出し）

### 1.4. DataRecordDialog との関係

| 項目 | DataRecordDialog | WorkRecordPanel |
|------|-----------------|----------------|
| 表示形式 | モーダルダイアログ | インラインパネル |
| 想定値表示 | なし | あり（新機能） |
| ステータス更新 | 別セクション | 統合済み |
| コメント機能 | なし | あり |
| 状態 | 参照用（削除しない） | 現行コンポーネント |

## 5. 想定値表示仕様

### 5.1. 想定値の取得ロジック

想定値は `transition.properties` 内の `mgr-instruction:` プレフィックスを持つプロパティから取得する。

```typescript
/**
 * 指定フィールドの想定値を取得する
 * @param propertyKey テンプレートのフィールドキー
 * @param transition トランジションデータ
 */
const getExpectedValue = (
  propertyKey: string,
  transition: TransitionData
): string | null => {
  const expectedProp = transition.properties?.find(
    p => p.key === `mgr-instruction:${propertyKey}`
  );
  return expectedProp?.value ?? null;
};
```

### 5.2. 想定値の表示形式

| 状態 | 表示 | スタイル |
|------|------|---------|
| 想定値あり | 値を表示（例: `25`） | グレーテキスト |
| 想定値なし | `（未設定）` | グレー・イタリック |

### 5.3. 実績値と想定値の差異表示

各フィールドの実績値入力欄右側に差異インジケーターを表示する。

| 条件 | アイコン | 色 |
|------|---------|-----|
| 想定値と一致（数値誤差 5% 以内） | ✓ | 緑（`#52c41a`） |
| 想定値と乖離（数値誤差 5% 超過） | ⚠ | 橙（`#fa8c16`） |
| 実績値が未入力 | — | 表示なし |
| 想定値が未設定 | — | 表示なし |
| 数値以外（テキスト型） | — | 表示なし |

## 9. API連携

### 9.1. 使用APIエンドポイント

| API | メソッド | パス | 用途 |
|-----|---------|------|------|
| トランジションデータ取得 | GET | `/api/v1/experiments/projects/:projectName/methods/:methodId/tasks/:taskNo/data` | フォームの初期データ取得 |
| 実験データ保存 | POST | `/api/v1/experiments/projects/:projectName/methods/:methodId/tasks/:taskNo/data` | 実績値・ステータスの保存 |

### 9.2. データ取得フロー

```
コンポーネントマウント時（transitionId 変更時）
  ↓
GET /experiments/projects/:projectName/methods/:methodId/tasks/:taskNo/data
  → transitionData（テンプレート定義・既存実績値・想定値プロパティ）を取得
  ↓
想定値を抽出:
  transition.properties.filter(p => p.key.startsWith('mgr-instruction:'))
  ↓
formValues に既存実績値を復元
  ↓
表示完了
```

### 9.3. 保存処理フロー

```
[保存] ボタン押下
  ↓
isSaving = true
  ↓
POST /experiments/projects/:projectName/methods/:methodId/tasks/:taskNo/data
  Body: {
    transitionId: string,
    templateData: { [templateId]: { [fieldKey]: value } },
    status: selectedStatus,
    progress: progressPercent,
    comment: comment
  }
  ↓
成功時:
  → message.success("保存しました")
  → onSaved?() コールバック
  → データ再取得（フォームリセット）

失敗時:
  → message.error("保存に失敗しました")
  ↓
isSaving = false
```

## 13. 備考・注意事項

1. **DataRecordDialog との共存**: `DataRecordDialog.tsx` はコメントアウトされた状態で残す（削除しない）。将来的な参照用。
2. **想定値の取得元**: `mgr-instruction:` プレフィックス付きプロパティは MAIML ファイルに書き込まれたもの（チェックアウト時に反映）。DB の `experiment_plan` テーブルから直接取得するのではなく、MAIML 経由のデータを使用する。
3. **差異判定閾値**: 数値フィールドの差異判定は5%を基準とするが、将来的には設定可能にする予定。
