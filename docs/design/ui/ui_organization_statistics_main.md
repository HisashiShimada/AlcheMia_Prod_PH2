## 1. 概要

### 1.1. 目的

システム管理者が自組織のリソース使用状況をリアルタイムで確認するための統計情報画面を定義します。ストレージ使用量・プロジェクト数・アクティブユーザー数の3つの指標を可視化し、組織の利用状況の把握と管理に役立てます。

### 1.2. 利用権限

- **System Admin（システム管理者）**: 使用可能

### 1.3. URL

`/system-management` の「統計情報」タブ

## 5. ツールバー

### 5.1. 配置

外枠カードの `extra` 領域（右上）に配置します。

```
[ 最終更新: YYYY/MM/DD HH:MM:SS ]  [ 🔄 リロード ]
```

### 5.2. 最終更新日時テキスト

**コンポーネント**: `<span>`

**仕様**:
| 項目 | 値 |
|------|-----|
| フォーマット | `YYYY/M/D HH:MM:SS` |
| 色 | `#757575` |
| フォントサイズ | 14px |
| 表示条件 | `lastUpdated` が空文字でない場合に表示 |
| 初期表示 | 非表示（空文字） |

**フォーマット実装**:
```typescript
function formatNow(): string {
  const now = new Date();
  return `${now.getFullYear()}/${now.getMonth() + 1}/${now.getDate()} `
    + `${String(now.getHours()).padStart(2, '0')}:`
    + `${String(now.getMinutes()).padStart(2, '0')}:`
    + `${String(now.getSeconds()).padStart(2, '0')}`;
}
```

**表示例**:
```
最終更新: 2026/2/25 18:45:30
```

### 5.3. リロードボタン

**コンポーネント**: `<Button>`

**仕様**:
| 項目 | 値 |
|------|-----|
| ラベル | 「リロード」 |
| タイプ | `default` |
| アイコン | `<ReloadOutlined />` |
| ローディング | API取得中は `true`（`loading={loading}`） |

**動作**:
1. ボタンクリックで `loadStatistics()` を呼び出し
2. ローディング状態に変更（ボタンスピナー表示）
3. API呼び出し: `GET /api/v1/systemManagement/organization_statistics`
4. 成功時: 統計情報を更新し、最終更新日時を現在時刻にセット
5. 失敗時: エラーメッセージを表示

## 6. APIリクエスト仕様

### 6.1. 統計情報取得

**エンドポイント**: `GET /api/v1/systemManagement/organization_statistics`

**認証**: JWT必須（`Authorization: Bearer {token}` または HTTPOnly Cookie）

**リクエスト例**:
```http
GET /api/v1/systemManagement/organization_statistics
Authorization: Bearer {jwt_token}
```

**レスポンス（成功時）**:
```json
{
  "success": true,
  "data": {
    "storage": {
      "used": 0.00000042,
      "total": 999.0,
      "unit": "GB",
      "usageRate": 0.000000
    },
    "projects": {
      "count": 12,
      "total": 999
    },
    "activeUsers": {
      "count": 3,
      "total": 25
    }
  },
  "meta": {
    "timestamp": "2026-02-25T09:45:30.000Z",
    "requestId": "req_abc123"
  }
}
```

**レスポンス（エラー時）**:
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "組織IDが取得できません"
  },
  "meta": {
    "timestamp": "2026-02-25T09:45:30.000Z",
    "requestId": "req_abc123"
  }
}
```

### 6.2. レスポンスデータ型定義

```typescript
export interface OrganizationStatistics {
  storage: {
    /** 使用中ストレージ量（GB）小数8桁 */
    used: number;
    /** 最大ストレージ量（GB）環境変数 MAX_STORAGE_GB_PER_ORG */
    total: number;
    /** 単位: 'GB' 固定 */
    unit: string;
    /** 使用率（0〜1）小数6桁 */
    usageRate: number;
  };
  projects: {
    /** 現在のプロジェクト数 */
    count: number;
    /** 上限値 環境変数 MAX_PROJECTS_PER_ORG */
    total: number;
  };
  activeUsers: {
    /** アクティブセッション数（Redis） */
    count: number;
    /** 組織の全ユーザー数（organization_userテーブル） */
    total: number;
  };
}
```

### 6.3. エラーコード一覧

| エラーコード | HTTPステータス | 説明 |
|------------|--------------|------|
| `UNAUTHORIZED` | 401 | 認証失敗・組織IDが取得できない |
| `INTERNAL_SERVER_ERROR` | 500 | サーバー内部エラー |

### 6.4. データソース詳細

バックエンドサービス（`organizationStatisticsService.ts`）は以下3つのデータソースから並列で取得します。

| データ | ソース | 取得方法 | エラー時 |
|--------|--------|----------|---------|
| ストレージ使用量 | StorageService（Swift/S3） | 組織IDフォルダ配下全ファイルのサイズ合計（最大10,000件） | 0として扱い続行 |
| プロジェクト数 | PostgreSQL `project` テーブル | `organization_id` でCOUNT | 例外をスロー |
| アクティブユーザー数（分子） | Redis | 全アクティブトークンを取得し`organizationId`でフィルタ | 0として扱い続行 |
| 全ユーザー数（分母） | PostgreSQL `organization_user` テーブル | `organization_id` でCOUNT | 例外をスロー |

## 7. ローディング・エラー状態

**コンポーネント**: `<Spin>`

**表示例**:

│                                  │
│         ⟳ （スピナー）            │
│                                  │

```

### 7.2. リロード時ローディング

- リロードボタンクリック時も `loading = true` に変更

- カードエリアも同様にスピン表示

### 7.3. エラー表示

**表示条件**: `error` 状態変数が `null` でない場合

**コンポーネント**: `<Alert>`

| 項目 | 値 |

| `type` | `error` |
| `title` | エラーメッセージ文字列 |

| 配置 | カードエリア内の最上部 |
| `style` | `{ marginBottom: '24px' }` |

**エラーメッセージ**:

**エラー表示例**:

┌──────────────────────────────────┐
│ 統計情報         [🔄 リロード]   │
│                                  │
│  ❌ 統計情報の取得に失敗しました。│
│     再度リロードしてください。    │

### 7.4. 状態遷移

```
[初期表示]
    ↓ useEffect → loadStatistics()
[loading=true]
    ↓ API呼び出し
[成功] → loading=false, statistics=データ, lastUpdated=現在時刻, error=null
[失敗] → loading=false, error='統計情報の取得に失敗しました...'
    ↓ リロードボタンクリック
[loading=true]
    ↓ API呼び出し
[成功/失敗] → 同上
```

```

- `gutter={[24, 24]}`: 水平・垂直ともに24pxのガター（間隔）
- `marginTop: '60px'`: カードタイトルと統計カードの間に余白

## 9. アクセシビリティ

### 9.1. キーボード操作

| キー | 動作 |
|------|------|
| Tab | 次の操作可能要素（リロードボタン）へフォーカス移動 |
| Shift + Tab | 前の要素へフォーカス移動 |
| Enter / Space | リロードボタンの実行 |

**Tab順序**:
1. リロードボタン
2. （統計カードは読み取り専用のため操作対象外）

### 9.2. スクリーンリーダー対応

#### ローディング状態の通知

```tsx
<Spin spinning={loading} aria-label="統計情報を読み込み中">
```

#### エラーメッセージの通知

```tsx
{error && (
  <Alert
    type="error"
    title={error}
    showIcon
    role="alert"
    aria-live="assertive"
  />
)}
```

#### 統計カードのラベル

各統計カードは読み取り専用の情報表示エリアのため、適切な `aria-label` を付与します。

```tsx
{/* ストレージ使用量カード */}
<Card
  variant="outlined"
  aria-label={`ストレージ使用量: ${statistics?.storage.used ?? 0} / ${statistics?.storage.total ?? 0} ${statistics?.storage.unit ?? 'GB'}`}
>
```

### 9.3. 色のみに依存しない情報伝達

- 統計情報はすべてテキストで数値を表示（色のみで状態を表現しない）
- エラー状態はアイコン＋テキストの組み合わせで表示（`<Alert showIcon>`）

### 9.4. フォーカスの視認性

- Ant Design のデフォルトフォーカススタイルを維持
- リロードボタンにフォーカスが当たった際、ブラウザのデフォルトアウトラインを表示
