# UI要素カタログ

## 概要

このドキュメントは、MaiML Viewerで使用されている全てのUI要素（Ant Designコンポーネント）を分類・一覧化したものです。

**調査対象**: frontend/src/components/ 配下の全 .tsx ファイル（60ファイル）  
**最終更新日**: 2024-12-24

---

## 1. UI要素の全体概要

### 1.1 カテゴリ別統計

| カテゴリ | UI要素数 | 主な用途 |
|---------|---------|---------|
| **レイアウト** | 5種類 | 画面構造、配置 |
| **データ表示** | 13種類 | 情報の視覚化、表示 |
| **データ入力** | 10種類 | ユーザー入力、選択 |
| **フィードバック** | 9種類 | 状態通知、確認 |
| **ナビゲーション** | 6種類 | 画面遷移、メニュー |
| **その他** | 3種類 | テーマ、ユーティリティ |
| **合計** | **46種類** | - |

## 2. カテゴリ別UI要素一覧

### 2.1 レイアウトコンポーネント（5種類）

| # | コンポーネント | 説明 | 使用頻度 | 主な使用画面 |
|---|--------------|------|---------|------------|
| 1 | **Layout** | ページ全体のレイアウト構造 | ★★★★★ | 全画面 |
| 2 | **Card** | コンテンツをカード形式で表示 | ★★★★★ | 全画面 |
| 3 | **Space** | 要素間のスペーシング調整 | ★★★★★ | 全画面 |
| 4 | **Row / Col** | グリッドレイアウト | ★★★★☆ | フォーム、検索画面 |
| 5 | **Flex** | フレキシブルレイアウト | ★★★☆☆ | ビューア、実験作業者 |

**詳細:**

- **Layout**: Header, Sider, Content, Footer のサブコンポーネントを持つ
- **Card**: タイトル、ボーダー、シャドウなど高度なカスタマイズ可能
- **Space**: direction (vertical/horizontal)、size (small/middle/large) で調整
- **Row / Col**: 24カラムグリッドシステム、レスポンシブ対応
- **Flex**: justify, align, gap などのプロパティで柔軟な配置
