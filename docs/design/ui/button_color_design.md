# ボタン配色・共通化設計書

## 1. 配色設計の基本方針

### 1.1 設計原則

✅ **用途に応じた色の使い分け**
- データ作成・追加 → Success色（緑系）
- データ編集 → Primary色（赤系）
- データ削除・状態変更 → Success/Error色（緑/赤系）
- データ入出力 → Info色（青系）または標準色
- 表示制御 → 標準色（黒系）
- ワークフロー制御 → Warning色（オレンジ系）またはInfo色

✅ **重要度に応じたtype指定**
- 主要アクション → `type="primary"`
- 一般アクション → `type="default"`
- 危険なアクション → `type="primary" danger`
- 補助的アクション → `type="text"` または `type="link"`

✅ **Ant Designカラートークンの活用**
- カスタムカラー指定を最小限に
- `token.colorSuccess`, `token.colorPrimary`, `token.colorInfo` 等を使用
- アクセシビリティ（コントラスト比）を確保

### 1.2 Ant Design標準カラートークン

システム全体で使用するカラートークンの定義です。

| トークン名 | 視覚イメージ | 用途 | 適用ボタン例 |
|-----------|-------------|------|-------------|
| `token.colorPrimary` | 🔴 赤 | 主要アクション | 編集、検索、指示送信、選択、保存、確定 |
| `token.colorSuccess` | 🟢 緑 | 成功・作成・有効化 | 新規作成、アップロード、アクティブ化、チェックイン |
| `token.colorInfo` | 🔵 青 | 情報表示・取得 | ダウンロード、公開 |
| `token.colorWarning` | 🟠 オレンジ | 注意・警告 | チェックアウト、保留 |
| `token.colorError` | 🔴 赤 | エラー・削除・無効化 | 削除、非アクティブ化 |
| `token.colorText` | ⚫ 黒 | 標準テキスト | defaultボタン全般 |
| `token.colorBgContainer` | ⚪ 白 | 標準背景 | defaultボタン全般 |

### 1.3 Buttonのtype一覧

Ant Design Buttonコンポーネントの`type`プロパティの種類と用途です。

#### 基本的なtype

| type | 視覚イメージ | 用途 | 適用例 |
|------|-------------|------|--------|
| `primary` | 塗りつぶし（カラー背景） | 主要アクション | 保存、確定、新規作成、編集、検索 |
| `default` | アウトライン（白背景） | 一般アクション | 追加、リロード、キャンセル、詳細 |
| `dashed` | 点線アウトライン（白背景） | 補助的な追加アクション | 項目追加、領域追加 |
| `text` | テキストのみ | 軽量なアクション | 詳細表示、インラインリンク |
| `link` | リンク風テキスト | ナビゲーション | 詳細表示、ページ遷移 |

#### dangerプロパティとの組み合わせ

| type + danger | 視覚イメージ | 用途 | 適用例 |
|--------------|-------------|------|--------|
| `primary` + `danger` | 塗りつぶし（Error色背景） | 危険な主要アクション | 削除 |
| `default` + `danger` | アウトライン（Error色枠） | 危険な一般アクション | 非アクティブ化 |
| `text` + `danger` | テキストのみ（Error色） | 危険な軽量アクション | 削除リンク |
| `link` + `danger` | リンク風（Error色） | 危険なナビゲーション | 削除確認ページへ遷移 |

#### カラートークンとの組み合わせ（styleで指定）

`type="primary"` に以下のカラートークンをstyleで適用できます：

| type + style | 視覚イメージ | 用途 | 適用例 |
|-------------|-------------|------|--------|
| `primary` + `colorSuccess` | 塗りつぶし（緑背景） | 作成・成功アクション | 新規作成、アップロード、有効化 |
| `primary` + `colorInfo` | 塗りつぶし（青背景） | 情報取得アクション | ダウンロード、公開 |
| `primary` + `colorWarning` | 塗りつぶし（オレンジ背景） | 注意が必要なアクション | チェックアウト、保留 |
| `primary` + `colorError` | 塗りつぶし（赤背景） | エラー・削除アクション | 削除、非アクティブ化 |

**使い分けの原則:**
- **primary**: ページ内で最も重要なアクション（1〜2個まで）
- **default**: 通常のアクション（複数配置可能）
- **dashed**: プレースホルダー的な追加アクション
- **text/link**: 控えめなアクション、テーブル内リンク
- **danger**: 取り返しのつかない操作（削除など）
- **カラートークン**: 用途に応じた色分け（Success/Info/Warning/Error）

## 2. 用途別カラーパレット定義

### 2.1 【データ作成・追加】ボタン

**配色コンセプト:** 「新しいものを生み出す」ポジティブなアクション → **Success色（緑系）**

| ボタン種別 | type | 配色指定 | 使用トークン | 視覚イメージ |
|-----------|------|---------|-------------|-------------|
| 追加（一般） | default | 標準 | - | 黒テキスト・白背景 |
| 新規作成（重要） | primary | Success色 | `token.colorSuccess` | 白テキスト・緑背景 |
| 新規フォルダ | primary | Success色 | `token.colorSuccess` | 白テキスト・緑背景 |

**使い分けルール:**
- **default**: CRUD画面の一覧上部（標準的な追加）
- **primary + Success色**: プロジェクト・ファイル作成など重要度の高い作成操作

---

### 2.2 【データ編集】ボタン

**配色コンセプト:** 「既存データの変更」 → **Primary色（赤系）** または **標準色**

| ボタン種別 | type | 配色指定 | 使用トークン | 視覚イメージ |
|-----------|------|---------|-------------|-------------|
| 編集（テーブル行内） | default | 標準 | - | 黒テキスト・白背景 |
| 編集（ツールバー） | primary | Primary色 | `token.colorPrimary` | 白テキスト・赤背景 |

**使い分けルール:**
- **default**: テーブル行内（各行に配置、控えめ）
- **primary**: ツールバー・操作バー（選択した項目を編集、強調）

---

### 2.3 【データ削除・状態変更】ボタン

**配色コンセプト:** 「状態の切替・削除」 → **Success色（緑）/ Error色（赤）**

| ボタン種別 | type | 配色指定 | 使用トークン | 視覚イメージ |
|-----------|------|---------|-------------|-------------|
| アクティブ化 | default | Success色 | `token.colorSuccess` | 緑テキスト・白背景 |
| 非アクティブ化 | default | Error色 | `token.colorError` | 赤テキスト・白背景 |
| 削除（危険） | primary | Error色 | `token.colorError` | 白テキスト・赤背景 |
| 個別状態切替 | default/danger | 状態依存 | - | 状態に応じた色 |

**使い分けルール:**
- **Success色（緑）**: アクティブ化、有効化、承認など
- **Error色（赤）**: 非アクティブ化、無効化、削除など
- **type="default"**: 一括操作（ツールバー）
- **danger**: 削除など取り返しのつかない操作
