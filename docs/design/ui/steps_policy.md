# ステップ表示形状ポリシー

## 標準3パターン

### パターン1: 水平ステップ（標準）
**用途**: フォーム入力・登録プロセス・短いワークフロー

- 方向: 水平（horizontal）
- サイズ: default
- タイプ: default
- ステップ数: 3-5ステップ推奨
- 幅: 親要素に合わせる（100%）
- アイコン: 数字（1, 2, 3...）
- ラベル位置: アイコン下
- 完了表示: チェックマークアイコン

**状態別スタイル:**
- **待機中（wait）**: グレー、未完了
- **進行中（process）**: プライマリカラー（#CF0027）、現在のステップ
- **完了（finish）**: プライマリカラー（#CF0027）、チェックマーク
- **エラー（error）**: エラーカラー（#d32f2f）、エラーアイコン

---

### パターン2: 垂直ステップ
**用途**: 長いプロセス・詳細説明付きステップ・サイドバー配置

- 方向: 垂直（vertical）
- サイズ: default
- タイプ: default
- ステップ数: 制限なし（5ステップ以上推奨）
- 幅: 親要素に合わせる（通常200-300px）
- アイコン: 数字（1, 2, 3...）
- ラベル位置: アイコン右
- 説明文: 各ステップの下に表示可能
- 完了表示: チェックマークアイコン

**状態別スタイル:**
- **待機中（wait）**: グレー、未完了
- **進行中（process）**: プライマリカラー（#CF0027）、現在のステップ
- **完了（finish）**: プライマリカラー（#CF0027）、チェックマーク
- **エラー（error）**: エラーカラー（#d32f2f）、エラーアイコン

---

### パターン3: ナビゲーションステップ
**用途**: ページ間の遷移・ウィザード形式の入力

- 方向: 水平（horizontal）
- サイズ: default
- タイプ: navigation
- ステップ数: 3-5ステップ推奨
- 幅: 親要素に合わせる（100%）
- アイコン: なし（ラベルのみ）
- ラベル位置: 中央
- クリック可能: 過去のステップに戻れる
- スタイル: ボタン風の外観

**状態別スタイル:**
- **待機中（wait）**: グレー背景、未完了
- **進行中（process）**: プライマリカラー背景（#CF0027）、白文字
- **完了（finish）**: グレー背景、クリック可能
- **エラー（error）**: エラーカラー背景（#d32f2f）、白文字

## 共通仕様（全パターン）

### 色定義

**待機中（wait）**
- アイコン背景: `token.colorBgContainer` (#ffffff)
- アイコンボーダー: `token.colorBorder` (rgba(0,0,0,0.12))
- アイコンテキスト: `token.colorTextSecondary` (#757575)
- ラベル: `token.colorTextSecondary` (#757575)
- 説明文: `token.colorTextTertiary` (#9e9e9e)
- 接続線: `token.colorBorder` (rgba(0,0,0,0.12))

**進行中（process）**
- アイコン背景: `token.colorPrimary` (#CF0027)
- アイコンボーダー: `token.colorPrimary` (#CF0027)
- アイコンテキスト: `#ffffff`
- ラベル: `token.colorPrimary` (#CF0027)
- 説明文: `token.colorText` (#212121)
- 接続線: `token.colorBorder` (rgba(0,0,0,0.12))

**完了（finish）**
- アイコン背景: `token.colorPrimary` (#CF0027)
- アイコンボーダー: `token.colorPrimary` (#CF0027)
- アイコンテキスト: `#ffffff`（チェックマーク）
- ラベル: `token.colorText` (#212121)
- 説明文: `token.colorTextSecondary` (#757575)
- 接続線: `token.colorPrimary` (#CF0027)

**エラー（error）**
- アイコン背景: `token.colorError` (#d32f2f)
- アイコンボーダー: `token.colorError` (#d32f2f)
- アイコンテキスト: `#ffffff`
- ラベル: `token.colorError` (#d32f2f)
- 説明文: `token.colorError` (#d32f2f)
- 接続線: `token.colorBorder` (rgba(0,0,0,0.12))

### サイズ定義

**default サイズ**
- アイコン直径: 32px
- アイコン内数字: 16px
- ラベルフォント: 14px
- 説明文フォント: 14px
- 接続線太さ: 1px
- ステップ間隔（水平）: auto（均等配置）
- ステップ間隔（垂直）: 16px

**small サイズ**
- アイコン直径: 24px
- アイコン内数字: 14px
- ラベルフォント: 12px
- 説明文フォント: 12px
- 接続線太さ: 1px
- ステップ間隔（水平）: auto（均等配置）
- ステップ間隔（垂直）: 12px

---

## パターン選択

- フォーム入力・登録プロセス・短いワークフロー → **パターン1（水平ステップ）**
- 長いプロセス・詳細説明付きステップ・サイドバー配置 → **パターン2（垂直ステップ）**
- ページ間の遷移・ウィザード形式の入力 → **パターン3（ナビゲーションステップ）**

## 実装ガイドライン

### 基本実装

```tsx
import { Steps } from 'antd';

// パターン1: 水平ステップ
<Steps
  current={1}
  items={[
    { title: 'ステップ1' },
    { title: 'ステップ2' },
    { title: 'ステップ3' },
  ]}
/>

// パターン2: 垂直ステップ
<Steps
  direction="vertical"
  current={1}
  items={[
    {
      title: 'ステップ1',
      description: '詳細説明テキスト',
    },
    {
      title: 'ステップ2',
      description: '詳細説明テキスト',
    },
  ]}
/>

// パターン3: ナビゲーションステップ
<Steps
  type="navigation"
  current={1}
  onChange={(current) => console.log(current)}
  items={[
    { title: 'ステップ1' },
    { title: 'ステップ2' },
    { title: 'ステップ3' },
  ]}
/>
```

### エラー表示

```tsx
<Steps
  current={1}
  status="error"
  items={[
    { title: 'ステップ1', status: 'finish' },
    { title: 'ステップ2', status: 'error' },
    { title: 'ステップ3', status: 'wait' },
  ]}
/>
```

### カスタムアイコン

```tsx
import { UserOutlined, SolutionOutlined, LoadingOutlined } from '@ant-design/icons';

<Steps
  current={1}
  items={[
    {
      title: 'ログイン',
      icon: <UserOutlined />,
    },
    {
      title: '認証中',
      icon: <LoadingOutlined />,
    },
    {
      title: '完了',
      icon: <SolutionOutlined />,
    },
  ]}
/>
```

## 使用上の注意点

### DO（推奨）
✅ ステップ数は3-5個を目安にする（水平ステップ）
✅ 各ステップのラベルは簡潔に（2-8文字）
✅ 現在のステップを明確に表示する
✅ 完了したステップはチェックマークで表示する
✅ エラーが発生したステップは赤色で強調する
✅ ナビゲーションタイプでは過去のステップに戻れるようにする
✅ 垂直ステップでは説明文を活用する

### DON'T（非推奨）
❌ 水平ステップで8個以上のステップを配置しない
❌ ラベルが長すぎて折り返しが発生する
❌ 各ステップの幅が不均等になる（水平ステップ）
❌ エラー状態を放置する（ユーザーに修正方法を示す）
❌ ステップをスキップできるようにする（順次進行が原則）
❌ モバイルで水平ステップを使用する（垂直推奨）

## レスポンシブ対応

### モバイル（～768px）
- 水平ステップ → 垂直ステップに変更
- アイコンサイズ: small
- ラベルは省略せず表示
- 説明文は折り返しを許容

### タブレット（768px～1024px）
- 水平ステップ: そのまま使用可能
- ステップ数: 最大5個推奨
- ラベルは適宜省略を検討

### デスクトップ（1024px～）
- 全パターンで制約なし
- ステップ数: 最大7個まで許容

## アクセシビリティ

- 各ステップに `aria-label` を設定
- 現在のステップに `aria-current="step"` を設定
- 完了したステップに `aria-disabled="false"` を設定
- キーボード操作: 矢印キーでステップ間移動（ナビゲーションタイプ）
- スクリーンリーダー: ステップの状態を音声で通知
