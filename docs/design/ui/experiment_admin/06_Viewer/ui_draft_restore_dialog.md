## 1. 画面概要

### 1.1. 目的

Viewerを開いた際に**未保存のドラフトが存在する場合**、ドラフトの復元を促すダイアログです。
自動保存されたドラフトを復元するか、破棄して最新の保存済みデータを使用するかを選択できます。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 表示される |
| `experiment_worker` | ✅ 表示される |

### 1.3. 主要機能

1. ドラフトの存在通知
2. ドラフト復元の実行
3. ドラフトの破棄（最新保存済みデータを使用）

---

## 2. 画面レイアウト

```
┌──────────────────────────────────────────────────────┐
```

---

## 3. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | ダイアログ表示/非表示 |
| `draftSavedAt` | `string \| null` | ❌ | ドラフト保存日時（ISO文字列）|
| `onRestore` | `() => void` | ✅ | 復元コールバック |
| `onDiscard` | `() => void` | ✅ | 破棄コールバック |

---

## 4. 表示ロジック

- `draftSavedAt` が存在する場合: `YYYY/MM/DD HH:mm:ss` 形式でドラフト保存日時を表示。
- 存在しない場合: 日時表示を省略。

---

## 5. 使用コンポーネント

- `Modal` - ダイアログコンテナ
- `Button` - 「破棄して続ける」（デフォルト）・「ドラフトを復元」（primary）
- `Typography.Text` - 説明文・日時表示

---

## 6. 備考・注意事項

1. Viewer / エディタの起動時に `DraftManager` と連携してドラフトの有無を確認し、存在する場合に表示。
2. 「破棄して続ける」を選択した場合、ローカルストレージのドラフトデータを削除する。
