# CreateFormatModal - フォーマットフォルダ作成モーダル

## 1. 概要

### 1.1 コンポーネントの目的
部門直下に新規フォーマットフォルダを作成するためのモーダルダイアログ。フォルダ名を入力して、ユーザーの所属部門配下に新しいフォーマットフォルダを作成する。

### 1.2 使用場面
- FormatManagement画面の「新規フォーマットフォルダ」ボタンクリック時

### 1.3 アクセス権限
- **対象ロール**: Experiment Admin（実験管理者）
- **必須認証**: JWT認証必須

## 3. 機能仕様

### 3.1 モーダル表示・初期化

**処理フロー:**
1. 親コンポーネントから `open=true` で呼び出される
2. `useEffect` でモーダルが開いた際にフォームとエラーメッセージをリセット

```typescript
useEffect(() => {
  if (open) {
    form.resetFields();
    setErrorMessage(null);
  }
}, [open, form]);
```

### 3.2 作成処理

**処理フロー:**
1. 「作成」ボタンをクリック
2. フォームバリデーション実行（`form.validateFields()`）
3. `loading=true` に設定
4. 親コンポーネントの `onSubmit(folderName)` コールバックを呼び出し
5. 成功時:
   - フォームをリセット
   - エラーメッセージをクリア
   - `onCancel()` を呼び出してモーダルを閉じる
6. 失敗時:
   - APIエラーメッセージをフォームの `help` 欄に表示
   - モーダルは開いたまま

### 3.3 キャンセル処理

**処理フロー:**
1. 「キャンセル」ボタンまたは × ボタンをクリック
2. `onCancel()` コールバックを呼び出し
3. モーダルを閉じる（`form.resetFields()` は次回 `open=true` 時に実行）

### 3.4 バリデーションルール

| フィールド | ルール | エラーメッセージ |
|----------|--------|----------------|
| フォルダ名 | 必須 | 「フォルダ名を入力してください」 |
| フォルダ名 | 英数字とアンダースコアのみ `/^[a-zA-Z0-9_]+$/` | 「英数字とアンダースコアのみ使用できます」 |
| フォルダ名 | 1〜255文字 | 「フォルダ名は1〜255文字で指定してください」 |

## 4. データ仕様

### 4.1 Props定義

```typescript
interface CreateFormatModalProps {
  open: boolean;                           // モーダル表示状態
  onCancel: () => void;                    // キャンセル時のコールバック
  onSubmit: (folderName: string) => Promise<void>;  // 送信時のコールバック
  departmentName?: string;                 // 所属部門名（表示用、オプション）
}
```

### 4.2 フォーム値

```typescript
{
  folderName: string;  // フォルダ名（英数字+アンダースコア）
}
```

## 5. API連携

- なし（親コンポーネントの `onSubmit` コールバック経由でデータを渡す）

## 6. エラーハンドリング

### 6.1 エラーケース

| エラーケース | 処理 |
|------------|------|
| バリデーションエラー | フォーム項目下にエラーメッセージ表示 |
| APIエラー（`response.data.error.message` あり） | フォルダ名フィールドの `help` にAPIエラーメッセージを表示 |
| その他エラー（`message` あり） | フォルダ名フィールドの `help` にエラーメッセージを表示 |
