# WorkflowSelectorDialog UI仕様書

## 1. 概要

### 1.1. コンポーネントの目的

S3に保存されたMAIMLファイルを選択してサブネット（ワークフロー）として追加するダイアログ。フォルダ階層表示、ファイル検索、ファイル選択機能を提供します。

## 3. Props定義

| プロパティ名 | 型 | 必須 | 説明 |
|------------|---|-----|------|
| open | boolean | ✓ | Modal表示状態 |
| onClose | () => void | ✓ | Modalを閉じる |
| onSelect | (file) => Promise<void> | ✓ | ファイル選択時の処理 |
| availableFiles | FileInfo[] | | 利用可能なファイル一覧 |

**FileInfo型:**
```typescript
interface FileInfo {

  name?: string;      // ファイル名

}
```

## 5. 主要機能

### 5.1. フォルダツリー表示

**処理フロー:**
1. availableFilesからフォルダ階層を構築
2. buildFolderTree()でFolderNode配列作成
3. Treeコンポーネントで表示
4. 各フォルダにファイル数をバッジ表示

**機能:**
- フォルダ展開/縮小
- ルートフォルダは自動展開
- ファイル数表示（Tag）

### 5.2. ファイル検索

**処理フロー:**
1. Inputに検索クエリを入力
2. ファイル名またはキー（パス）で部分一致検索
3. filteredFilesを更新

**動作:**
- 検索時はフォルダ選択をクリア
- リアルタイム検索

### 5.3. フォルダ選択によるフィルタ

**処理フロー:**
1. Treeでフォルダをクリック
2. selectedFolderを更新
3. 該当フォルダ内のファイルのみ表示

**動作:**
- フォルダ選択時は検索クエリをクリア
- 同じフォルダを再クリックで選択解除

### 5.4. ファイル選択

**処理フロー:**
1. Listでファイルをクリック
2. selectedFileを更新
3. 選択中の背景色を変更（#e6f7ff）
4. 選択ファイル情報をAlert表示

### 5.5. ワークフロー追加

**処理フロー:**
1. 「ワークフロー追加」ボタンをクリック
2. onSelect(selectedFile)を実行
3. 成功時: Modalを閉じる
4. 失敗時: エラーメッセージ表示

**バリデーション:**
- ファイル未選択時はボタン無効化

## 8. ヘルパー関数

### 8.1. buildFolderTree()

ファイル一覧からフォルダ階層を構築。

**処理:**
1. ファイルキーからフォルダパスを抽出
2. FolderNodeツリーを構築
3. 各フォルダのファイル数をカウント
4. 名前順でソート

### 8.2. formatFileSize()

ファイルサイズをフォーマット。

**出力例:**
- 500 → "500 B"
- 2048 → "2.0 KB"
- 1048576 → "1.0 MB"
