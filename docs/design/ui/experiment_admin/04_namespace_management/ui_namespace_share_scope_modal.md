## 1. 画面概要

### 1.1. 目的

選択した用語を別の名前空間（組織・部署・チーム・ユーザー）に共有するためのモーダルです。
組織階層ツリーから共有先を選択すると、用語がその名前空間にコピーされます（元の用語はそのまま残ります）。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 操作可 |
| `system_admin` | ✅ 操作可 |

### 1.3. 主要機能

1. ロール別の共有先制限メッセージの表示
2. 組織階層ツリーからの共有先選択（ロールに応じて選択可能範囲が制限される）
3. 選択した共有先の確認表示
4. 共有実行

## 3. ロール別の共有先制限

### 3.1. Alert メッセージ

| ロール種別 (`kind`) | 表示メッセージ |
|---|---|
| `sys_admin` | 「組織まで共有できます」 |
| `dept_owner` | 「「{部署名}」（部署）まで共有できます」 |
| `team_owner` | 「「{チーム名}」（チーム）まで共有できます」 |

### 3.2. ツリーノードの選択可否

| ノード深度 | 対象 | sys_admin | dept_owner | team_owner |
|---|---|---|---|---|
| depth=0 | 組織 | ✅ 選択可 | ❌ 選択不可 | ❌ 選択不可 |
| depth=1 | 部署 | ✅ 選択可 | ✅ 選択可 | ❌ 選択不可 |
| depth=2 | チーム | ✅ 選択可 | ✅ 選択可 | ✅ 選択可 |
| depth=3 | ユーザー | ✅ 選択可 | ✅ 選択可 | ✅ 選択可 |

選択不可ノードは薄いグレーで表示され、「（選択不可）」ラベルが付く。

## 4. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | モーダル表示/非表示 |
| `termCount` | `number` | ✅ | 共有対象の用語件数（タイトルに表示） |
| `sourceRole` | `ShareSourceRole` | ✅ | 操作ユーザーのロール（共有先制限に使用） |
| `scopeNodes` | `ScopeNode[]` | ✅ | ツリー表示用の組織階層データ |
| `onClose` | `() => void` | ✅ | キャンセル/閉じるコールバック |
| `onShare` | `(target: ShareTarget) => void` | ✅ | 共有実行コールバック（選択ノード情報を渡す） |

### 4.1. 型定義

```typescript
// 操作ユーザーのロール種別
type ShareSourceRole =
  | { kind: 'sys_admin' }
  | { kind: 'dept_owner'; deptLabel: string }
  | { kind: 'team_owner'; teamLabel: string };

// 共有先ノード（ツリーデータ）
interface ScopeNode {
  key: string;
  label: string;
  prefix?: string;
  children?: ScopeNode[];
}

// 共有実行時に onShare に渡すデータ
interface ShareTarget {
  key: string;
  label: string;
  prefix: string;
}
```

## 6. 備考・注意事項

1. ツリーは常に全展開状態（`expandedKeys` に全ノードキーをセット）
2. 共有は「コピー」であり、元の用語は削除されない
3. 「共有する」ボタンは共有先が未選択の場合は非活性（`disabled`）
4. 「共有する」ボタン活性時の色は緑（`#52c41a`）
5. モーダルを閉じると選択状態がリセットされる
