## 1. 画面概要

### 1.1. 目的

選択した用語または Prefix を上位の名前空間（組織・部署・チーム・ユーザー）に共有するためのモーダルです。
組織階層ツリーから共有先を選択すると、用語/Prefix がその名前空間に移動されます（元の用語/Prefix は残りません）。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 操作可 |
| `system_admin` | ✅ 操作可 |

### 1.3. 主要機能

1. 組織階層ツリーからの共有先選択（`<Tree>` コンポーネントで階層表示）
2. Global ノードは親コンポーネント（呼び出し側）の `scopeNodes` に含めないことで非表示にする
3. 選択した共有先の確認表示
4. 共有実行

## 3. ツリー表示仕様

### 3.1. Globalノード

Global ノードは呼び出し側コンポーネント（`UncertaintyManagement` など）が渡す `scopeNodes` に含めないことで非表示にする。
モーダル内部での除外処理はなく、渡されたツリーをそのまま表示する。

### 3.2. アイコン

ツリーノードにアイコンは表示しない（`getNodeIcon()` 関数は存在せず、アイコン用 import もない）。

### 3.3. 全展開

ツリーは常に全展開状態（`expandedKeys` に全ノードキーをセット）。

## 4. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | モーダル表示/非表示 |
| `termCount` | `number` | ❌ | 共有対象の用語/Prefix 件数（省略時はタイトルに件数を表示しない）|
| `sourceRole` | `ShareSourceRole` | ✅ | 操作ユーザーのロール（型定義上必須。ただしコンポーネント本体では未使用のため全ノード選択可）|
| `scopeNodes` | `ScopeNode[]` | ✅ | ツリー表示用の組織階層データ（Global ノードを除いたものを渡す）|
| `onClose` | `() => void` | ✅ | キャンセル/閉じるコールバック |
| `onShare` | `(target: ShareTarget) => void` | ✅ | 共有実行コールバック（選択ノード情報を渡す） |

### 4.1. 型定義

```typescript
// 操作ユーザーのロール種別（型定義上必須だがコンポーネント本体では参照しない）
type ShareSourceRole =
  | { kind: 'sys_admin' }
  | { kind: 'dept_owner'; deptKey: string; deptLabel: string }
  | { kind: 'team_owner'; teamKey: string; teamLabel: string };

// 共有先ノード（ツリーデータ）
interface ScopeNode {
  key: string;
  label: string;
  prefix?: string;
  icon?: React.ReactNode;    // 現在は未使用（アイコンなし）
  selectable?: boolean;
  children?: ScopeNode[];
}

// 共有実行時に onShare に渡すデータ
interface ShareTarget {
  key: string;
  label: string;
  prefix: string;
}
```

## 6. 備考・注意事項

1. ツリーは常に全展開状態（`expandedKeys` に全ノードキーをセット）
2. 共有は「移動」であり、元の用語/Prefix は残らない
3. 「共有する」ボタンは共有先が未選択の場合は非活性（`disabled`）
4. 「共有する」ボタン活性時の色は緑（`#52c41a`）
5. モーダルを閉じると選択状態がリセットされる
6. ツリーノードにアイコンは表示しない（v1.2.0 で削除）
