## 1. 画面概要

### 1.1. 目的

名前空間管理画面内の**用語（ローカル名）管理セクション**です。
`namespace_term` テーブルで管理される用語（ローカル名・型ヒント・単位ヒント等）の一覧表示・追加・編集・有効化/無効化を行います。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 閲覧・編集可 |
| `system_admin` | ✅ 閲覧・編集可 |
| `experiment_worker` | ✅ 閲覧のみ（`viewOnly=true`） |

### 1.3. 主要機能

1. 用語一覧の表示（名前空間ツリーの選択スコープに連動して自動絞り込み）
2. 新規用語のインライン追加（行追加 → 保存）
3. 既存用語のインライン編集（表示名・説明・型ヒント・単位の変更）
4. 用語の有効化/無効化（削除ではなく `isActive` フラグのトグル）
5. CSV インポート・エクスポート
6. フリーテキスト検索 + Prefix フィルター + 型フィルター

## 2. 画面レイアウト

### ツールバー

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [🔍 検索（ローカル名・表示名等）]  [Prefix を絞り込む ▼]  [型を絞り込む ▼]   │
│ [インポート]  [エクスポート]  [+ 用語追加]  [保存]  [キャンセル]              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 一覧テーブル

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ☐ │ Prefix │ ローカル名   │ 表示名     │ 説明 │ 型     │ 単位 │ スコープ │ 操作          │
│───┼────────┼─────────────┼────────────┼──────┼────────┼──────┼──────────┼───────────────│
│ ☐ │ chem   │ SampleTemp  │ サンプル温度 │      │[float] │ °C  │ 開発部   │ 編集  無効化  │
│ ☐ │ lab    │ ReactTime   │ 反応時間    │      │[float] │ h   │ TeamA    │ 編集  無効化  │
└──────────────────────────────────────────────────────────────────────────────┘
                                               全N件  20件/ページ ▼
```

> **型** 列は色付き Tag で表示（例: floatType → cyan の Tag）

### 新規行追加時（インライン入力、黄色背景）

```
│ 🟡 │ [Prefix ▼] │ [ローカル名] │ [表示名] │ [説明] │ [型 ▼] │ [単位] │ — │ [☑指示用語] │ ✕削除 │
```

- `localName` 未入力時はチェックボックスを `disabled` 表示
- チェック ON で保存すると `SupervisorDirective{localName}` を元の用語と同一 Prefix に同時登録
- どちらかの INSERT が失敗した場合はトランザクションロールバック（両方登録されない）

### 既存行編集時

```
│ ☐ │ chem │ SampleTemp │ [表示名入力] │ [説明入力] │ [型 ▼] │ [単位入力] │ 開発部 │ [保存][キャンセル] │
```

### 非アクティブ行

`isActive=false` の行はグレーテキスト・グレー背景（`#f5f5f5`）で表示。型 Tag も半透明になる。

## 3. テーブルカラム定義

| カラム | キー | 説明 | 備考 |
|--------|------|------|------|
| （チェックボックス） | — | 行選択 | 新規行は選択不可 |
| Prefix | `prefix` | 名前空間の接頭辞 | ソート可。新規行はプルダウン選択 |
| ローカル名 | `localName` | xs:NCName 規則準拠 | ソート可。`code` スタイルで表示 |
| 表示名 | `displayName` | 日本語等の表示用名称 | 編集可 |
| 説明 | `description` | 用語の説明 | 省略表示あり。編集可 |
| 型 | `type` | 推奨 xsi:type | 色付き Tag 表示。編集可（Select） |
| 単位 | `unitHint` | 推奨単位 | 編集可 |
| スコープ | — | prefix に対応するスコープ名（`prefixScopeMap` 経由）| geekblue Tag 表示 |
| 操作 | — | 編集・有効化/無効化ボタン（編集中は保存・キャンセル）。`hasDirectiveTerm=true` の場合は「指示あり」バッジを表示。| `viewOnly=true` 時は全ボタン非活性 |

### 型の色 Tag

| 型 | Tag 色 |
|----|--------|
| stringType | blue |
| integerType | green |
| floatType | cyan |
| booleanType | orange |
| dateTimeType | purple |
| uriType | magenta |

## 4. ツールバー

| 要素 | 説明 | 備考 |
|------|------|------|
| 検索欄 | prefix / ローカル名 / 表示名 / 説明 でリアルタイムフィルタ | ページを1にリセット |
| Prefix フィルター | 特定 prefix に絞り込む Select | クリア可。`Prefix を絞り込む` プレースホルダー |
| 型フィルター | 特定型に絞り込む Select | クリア可。`型を絞り込む` プレースホルダー |
| インポート | CSV ファイル読み込みで一括登録 | `viewOnly` 時は非活性 |
| エクスポート | フィルタ後の一覧を CSV でダウンロード（`terms.csv`）| |
| + 用語追加 | テーブル先頭に新規入力行を追加 | `viewOnly` 時は非活性 |
| 保存 | 新規入力行を一括保存（API 登録） | 新規行がない場合は非活性 |
| キャンセル | 新規入力行を全て破棄 | 新規行がない場合は非活性 |

## 5. 有効化/無効化（isActive トグル）

- 用語の**削除は行わない**。代わりに `isActive` フラグを切り替える
- 無効化時：確認ダイアログ表示 → 「無効化」ボタンで実行
- 有効化時：確認ダイアログ表示 → 「有効化」ボタンで実行
- 非アクティブ行は視覚的に区別（グレー背景・薄いテキスト）

## 6. 重複チェック（保存時）

保存時に以下の順序でクライアントサイド・サーバーサイドの重複チェックが行われる。

### フェーズ①：完全一致チェック（クライアントサイド）

同 `prefix:localName` が既存の用語 `terms` に存在する場合、**`Modal.error` を表示して登録をブロック**する（登録不可）。

### フェーズ②：部分一致チェック（クライアントサイド）

異なる prefix で同 `localName` が既存に存在する場合、**`Modal.confirm` を1件ずつ表示**してユーザーに確認を求める。

| ユーザー操作 | 結果 |
|------------|------|
| OK（はい） | 該当行を登録対象として続行 |
| キャンセル（いいえ） | 該当行をスキップして `newRows` に残存。他の行は登録処理に進む |

### フェーズ③：API 409 Conflict（サーバーサイド）

`POST /api/v1/namespace-terms` がサーバー側で 409 を返した場合、`Modal.error` を表示する。

### DuplicateSuggestModal

コード上は `duplicates` 配列が空でない場合に `DuplicateSuggestModal` を開く処理が存在するが、**現在のフローでは `duplicates` は常に空のため実質未到達**。

## 7. CSV フォーマット

| 列 | 内容 |
|----|------|
| prefix | 接頭辞（必須）|
| localName | ローカル名（必須）|
| displayName | 表示名（任意）|
| description | 説明（任意）|
| type | 型ヒント（任意）|
| unitHint | 単位ヒント（任意）|

- エクスポート: ヘッダー行あり、BOM 付き UTF-8
- インポート: 1行目をヘッダーとしてスキップ、prefix/localName が空の行はスキップ

## 9. API 連携

| API | 用途 |
|-----|------|
| `GET /api/v1/namespaces` | Prefix 一覧取得（フィルタ用）|
| `GET /api/v1/namespace-terms` | 用語一覧取得（`scopeKey` でフィルタ可能）|
| `POST /api/v1/namespace-terms` | 用語新規登録。リクエストボディに `createDirectiveTerm?: boolean`（指示用語同時登録フラグ、デフォルト: `true`）と `scopeKey?: string`（左ツリー選択スコープキー）を追加 |
| `PUT /api/v1/namespace-terms/:prefix/:localName` | 用語更新（表示名・説明・型・単位）|
| `PATCH /api/v1/namespace-terms/:prefix/:localName/active` | 有効化/無効化トグル（`toggleTermActive`）|

> **注意**: 用語の削除 API は呼び出されていません（有効化/無効化で管理）。
