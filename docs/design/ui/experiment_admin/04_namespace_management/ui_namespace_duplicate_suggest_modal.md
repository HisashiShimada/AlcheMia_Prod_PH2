## 1. 画面概要

### 1.1. 目的

名前空間の新規追加時に、**既存の類似・重複名前空間を提案**するモーダルです。
入力したprefixやURIに類似する既存名前空間を表示し、重複登録を防ぎます。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 操作可 |
| `system_admin` | ✅ 操作可 |

### 1.3. 主要機能

1. 類似・重複する既存名前空間一覧の表示
2. 既存名前空間の選択（再利用）
3. 新規追加を強制続行

## 3. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | モーダル表示/非表示 |
| `duplicates` | `NamespaceRow[]` | ✅ | 類似・重複する名前空間一覧 |
| `onCancel` | `() => void` | ✅ | キャンセルコールバック |
| `onContinue` | `() => void` | ✅ | 新規追加を続けるコールバック |
| `onSelect` | `(prefix: string) => void` | ✅ | 既存名前空間選択コールバック |
