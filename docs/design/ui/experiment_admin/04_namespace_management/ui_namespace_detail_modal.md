## 1. 画面概要

### 1.1. 目的

名前空間管理画面から呼び出される、**名前空間の詳細情報を表示・編集するモーダル**です。
接頭辞（prefix）・URI・スコープ・用語リスト等の詳細を確認・編集できます。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 閲覧・編集可 |
| `system_admin` | ✅ 閲覧・編集可 |
| `experiment_worker` | ✅ 閲覧のみ |

### 1.3. 主要機能

1. 名前空間の詳細情報（prefix・URI・スコープ・説明）の表示
2. 編集モードでの情報更新
3. 登録済み用語（`namespace_term`）の一覧表示


## 3. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | モーダル表示/非表示 |
| `prefix` | `string \| null` | ✅ | 表示対象の prefix |
| `onClose` | `() => void` | ✅ | 閉じるコールバック |
| `onEdit` | `(prefix: string) => void` | ❌ | 編集ボタン押下コールバック |
| `isEditable` | `boolean` | ❌ | 編集ボタン表示フラグ |

---

## 4. 表示データ

| フィールド | 取得元 |
|-----------|--------|
| prefix / URI / スコープ等 | `namespace` テーブル（API: `GET /api/v1/namespaces/:prefix`）|
| 用語一覧 | `namespace_term` テーブル（API: `GET /api/v1/namespaces/:prefix/terms`）|
