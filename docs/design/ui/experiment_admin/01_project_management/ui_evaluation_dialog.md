## 1. 画面概要

### 1.1. 目的

実験管理者（Manager）が、プロジェクトの各単位（メソッド・タスク・トランジション）に対して**定性評価**を登録・確認するためのダイアログです。
評価登録確認パネル（`ResultPanel`）と評価入力モーダル（`InputModal`）の2層構成になっています。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 閲覧・操作可 |
| `system_admin` | ✅ 閲覧・操作可 |
| `experiment_worker` | ❌ アクセス不可 |

### 1.3. 主要機能

1. 評価結果一覧の表示（評価単位別にグループ化）
2. 評価単位・不確かさ基準・メソッド・タスクNoによるフィルタリング
3. 「評価を入力」ボタンから `InputModal` を開いて評価を登録
4. 登録後に評価一覧を自動リフレッシュ

## 3. コンポーネント Props 定義

```typescript
export interface EvaluationDialogProps {
  open: boolean;
  projectId: string;
  allMethods: Array<{ id: string; name: string }>;
  reviewWaitingTasks: Array<{ methodId: string; methodName: string; taskNumber: number }>;
  criteriaList: UncertaintyCriteriaForSelector[];
  onCancel: () => void;
}
```

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | ダイアログ表示/非表示 |
| `projectId` | `string` | ✅ | プロジェクトID |
| `allMethods` | `Array<{id, name}>` | ✅ | 全メソッド一覧 |
| `reviewWaitingTasks` | `Array<...>` | ✅ | レビュー待ちタスク一覧 |
| `criteriaList` | `UncertaintyCriteriaForSelector[]` | ✅ | 不確かさ基準リスト |
| `onCancel` | `() => void` | ✅ | 閉じるコールバック |

## 4. 評価単位（EvaluationUnit）

| 値 | 表示名 | 説明 |
|-----|--------|------|
| `method` | メソッド単位 | メソッド全体への評価 |
| `task` | タスク単位 | 特定タスク番号への評価 |
| `transition_method` | トランジション（メソッド別）| メソッド内のトランジションへの評価 |
| `transition_task` | トランジション（タスク別）| 特定タスクのトランジションへの評価 |

---

## 5. ResultPanel（評価結果確認パネル）

### 5.1. フィルタ構成

| フィルタ | コンポーネント | 説明 |
|---------|--------------|------|
| 評価単位 | `Radio.Group`（全て含む5種類）| 表示する評価単位を絞り込む |
| 不確かさ基準 | `Select`（`allowClear`、幅240px）| 使用された基準キー一覧から選択 |
| メソッド選択 | `Select`（transition系の時のみ表示）| トランジション系絞り込み用 |
| タスクNo | `Select`（`transition_task` 時のみ）| メソッド選択と連動 |

### 5.2. 評価結果テーブル

評価単位ごとに `Collapse` でグループ化して表示。

| カラム | 幅 | 説明 |
|--------|-----|------|
| 対象 | 200px | メソッドID / タスクNo / トランジション名 |
| 基準名 | 180px | 不確かさ基準ラベル（criteriaListから解決）|
| 評価値 | 120px | 色付き `Tag` で表示（displayColorを使用）|
| コメント | — | フリーテキスト |
| 評価日時 | 140px | `YYYY/MM/DD HH:mm` 形式 |

## 6. InputModal（評価入力フォーム）

### 6.1. レイアウト

```
┌────────────────────────────────────────────────┐
│ Modal (width: 760px)                           │
│ Title: 評価を入力                               │
├────────────────────────────────────────────────┤
│ 評価単位: ○ メソッド ○ タスク               │
│           ○ トランジション(メソッド別)          │
│           ○ トランジション(タスク別)            │
│ （transition系のみ）メソッド [選択 ▼]           │
│ （transition_taskのみ）タスクNo [選択 ▼]        │
│ 不確かさ基準 [選択 ▼]  [定性 badge]            │
│ ┌────────────────────────────────────────┐    │
│ │ 対象        | 評価値 [▼]  | コメント   │    │
│ │ メソッド1   | [選択 ▼]   | [入力]     │    │
│ └────────────────────────────────────────┘    │
├────────────────────────────────────────────────┤
│ Footer: ※評価値が選択された行のみ保存           │
│         [キャンセル]  [評価を保存]              │
└────────────────────────────────────────────────┘
```

### 6.2. 評価値セレクト

不確かさ基準の `intuitionOptions` から選択肢を生成。
各オプションには `displayColor` の円形インジケーター付き。

### 6.3. 保存処理

評価値が入力された行のみ `saveEvaluations` API へ送信。
保存後に `ResultPanel` をリフレッシュし、InputModal を閉じる。

## 8. 使用コンポーネント

- `Modal` - ダイアログコンテナ（width: 900px）
- `Tabs` - 外部タブ（1タブ構成）
- `Radio.Group` - 評価単位フィルタ
- `Select` - 基準・メソッド・タスクNo選択
- `Table` - 評価一覧・入力テーブル
- `Collapse` - 評価単位別グループ化
- `Tag` - 評価値カラー表示
- `Empty` - データなし表示
- `Spin` - ローディング
- `Button` + `EditOutlined` - 評価を入力ボタン

## 9. 備考・注意事項

1. **モックデータ**: トランジション名一覧は現在モック（`MOCK_TRANSITION_NAMES`）。MAIML パース統合後はAPIへ置換予定。
2. **定性評価のみ**: `criteriaList.filter(c => c.evaluationMethod === 2)` で定性基準（`evaluationMethod=2`）のみを選択肢に表示。
3. **リフレッシュ制御**: `refreshKey` ステートで `ResultPanel` の再取得をトリガーする。
