## 1. 画面概要

### 1.1. 目的

実験管理者（Manager）が、プロジェクトを**完了状態**に遷移させるための確認ダイアログです。
完了処理の前に最終確認を行い、実行します。

### 1.2. アクセス権限

| ロール | アクセス |
|--------|---------|
| `experiment_admin` | ✅ 操作可 |
| `system_admin` | ✅ 操作可 |
| `experiment_worker` | ❌ アクセス不可 |

### 1.3. 主要機能

1. プロジェクト完了の最終確認表示
2. 完了処理の実行

## 3. コンポーネント Props 定義

| Prop名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| `open` | `boolean` | ✅ | ダイアログ表示/非表示 |
| `projectId` | `string` | ✅ | プロジェクトID |
| `projectName` | `string` | ✅ | プロジェクト名（確認文言表示用）|
| `onCancel` | `() => void` | ✅ | キャンセルコールバック |
| `onComplete` | `() => Promise<void>` | ✅ | 完了処理コールバック |
| `loading` | `boolean` | ❌ | 処理中フラグ |

---

## 4. 備考・注意事項

1. 完了処理は非可逆。実行後はプロジェクトステータスが「完了」に変更され、以降の変更系操作が不可になる。
2. `onComplete` は親コンポーネント（`ProjectManagement`）から渡され、API呼び出しを担う。
