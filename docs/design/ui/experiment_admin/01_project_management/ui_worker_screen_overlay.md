# WorkerScreenOverlay - ワーカー画面オーバーレイ

## 1. 概要

### 1.1 コンポーネントの目的
実験ワーカーが作業中の画面にオーバーレイとして表示されるコンポーネント。プロジェクト管理画面の上に重なり、ワーカー向けの指示内容・タスク進捗・ファイル操作UIを提供する。

### 1.2 使用場面
- プロジェクト管理画面（ProjectManagement）内でワーカーモードが有効な場合に表示
- 実験管理者がワーカーに指示を送信した後、ワーカーが作業を行う際

### 1.3 アクセス権限
- **必須ロール**: experiment_worker
- **認証**: JWT + Session Hybrid認証

## 2. 画面構成

### 2.1 レイアウト構造

```
┌──────────────────────────────────────────────────────────┐
│ [画面全体オーバーレイ - 半透明背景]                      │
│  ┌────────────────────────────────────────────────────┐  │
│  │ ワーカー操作パネル                         [×]    │  │
│  ├────────────────────────────────────────────────────┤  │
│  │ [指示内容タブ] [タスク一覧タブ] [ファイルタブ]    │  │
│  ├────────────────────────────────────────────────────┤  │
│  │                                                    │  │
│  │ タブ毎のコンテンツ                                 │  │
│  │                                                    │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### 2.2 タブ構成

| タブ | キー | 内容 |
|------|------|------|
| 指示内容 | `instruction` | 現在の指示内容・条件情報を表示 |
| タスク一覧 | `tasks` | 割り当てられたタスクの一覧と進捗 |
| ファイル | `files` | ファイルのアップロード・ダウンロード操作 |

### 2.3 主要UI要素

#### 2.3.1 指示内容タブ
- 指示のタイトル・本文
- 条件（Condition）情報の表示
- 送信日時・送信者情報

#### 2.3.2 タスク一覧タブ
- タスクカード一覧
- 各タスクのステータス（未着手・作業中・完了）
- タスク完了ボタン

#### 2.3.3 ファイルタブ
- 結果ファイルのアップロードフォーム
- アップロード済みファイルの一覧
- ファイルダウンロードリンク

## 3. 機能仕様

### 3.1 オーバーレイ表示制御
- `visible` プロップが `true` のとき画面全体に重なって表示
- 閉じるボタン（×）でオーバーレイを非表示にする
- 背景クリックでは閉じない（誤操作防止）

### 3.2 タスク完了操作

```typescript
const handleCompleteTask = async (taskId: string) => {
  await updateTaskStatus(taskId, 'completed');
  message.success('タスクを完了しました');
  onTaskComplete?.(taskId);
};
```

### 3.3 ファイルアップロード
- ドラッグ&ドロップまたはボタンクリックでファイル選択
- アップロード完了後にファイル一覧を更新
