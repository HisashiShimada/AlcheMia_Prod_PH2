# テストケース: XMLプレビュー保存バグ修正

## 対象機能
`TemplateEditorDialog` の XMLプレビュー機能（XMLタブ）

## 優先順位
- **必須**: TC-1, TC-2, TC-3
- **推奨**: TC-4, TC-5

---

## TC-1: XMLタブで編集→保存→内容が反映されること（今回の修正対象）

**目的**: XMLタブで編集した内容が保存後に正しく反映されることを確認する

**手順**:
1. テンプレートノードをダブルクリックしてダイアログを開く
2. **XMLタブ**に切り替える
3. XMLの値を書き換える  
   例: `<name>旧名前</name>` → `<name>新名前</name>`
4. 保存ボタンをクリック
5. ノードを再度ダブルクリックしてダイアログを開く

**期待結果**:
- [ ] ダイアログが正常に閉じること
- [ ] 再度開いたとき変更後の値（`新名前`）が表示されること
- [ ] PetriNetエディタのノード上にも変更が反映されること

**修正前の動作（バグ）**: 古い値（`旧名前`）のままだった

---

## TC-2: UIタブで編集→保存（既存動作の退行確認）

**目的**: 修正によって既存のUIタブ保存が壊れていないことを確認する

**手順**:
1. テンプレートノードをダブルクリックしてダイアログを開く
2. **UI編集タブ**のままプロパティ値や名前を変更する
3. 保存ボタンをクリック
4. ノードを再度ダブルクリックしてダイアログを開く

**期待結果**:
- [ ] ダイアログが正常に閉じること
- [ ] 再度開いたとき変更後の値が表示されること
- [ ] 修正前と同じ動作であること

---

## TC-3: XMLにエラーがある場合に保存できないこと

**目的**: 不正なXMLで保存しようとした場合に適切にエラー表示されることを確認する

**手順**:
1. ダイアログを開き、XMLタブに切り替える
2. XMLを不正な状態にする  
   例: タグを閉じない → `<property key="x"` で行を終わらせる
3. 保存ボタンをクリック

**期待結果**:
- [ ] エラーメッセージが表示されること
- [ ] ダイアログが閉じないこと
- [ ] データが変更されていないこと

---

## TC-4: XMLタブ編集→UIタブ切り替え→UIに反映されること

**目的**: タブ間の同期が正しく動作することを確認する（XML→UI方向）

**手順**:
1. ダイアログを開き、XMLタブに切り替える
2. XMLの値を変更する（例: `<name>変更後</name>`）
3. UIタブに切り替える

**期待結果**:
- [ ] UIタブのName欄に `変更後` が表示されること
- [ ] プロパティ一覧にXMLで変更した内容が反映されていること

---

## TC-5: UIタブ編集→XMLタブ切り替え→XMLに反映されること

**目的**: タブ間の同期が正しく動作することを確認する（UI→XML方向）

**手順**:
1. ダイアログを開き、UIタブのままName欄を変更する（例: `変更後`）
2. XMLタブに切り替える

**期待結果**:
- [ ] XMLの `<name>` タグに `変更後` が表示されること
- [ ] UIで変更したプロパティがXMLに反映されていること
