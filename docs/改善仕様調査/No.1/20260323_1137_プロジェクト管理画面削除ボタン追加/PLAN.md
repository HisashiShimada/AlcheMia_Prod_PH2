### 実装詳細

#### 1. プロジェクト削除ボタンの追加
プロジェクト選択時の操作ボタンエリアに削除ボタンを追加しました。

**配置位置**: 編集ボタンとチェックアウトボタンの間

**実装内容**:
```tsx
<Button
  danger
  icon={<DeleteOutlined />}
  onClick={() => console.log('プロジェクト削除（未実装）')}
>
  削除
</Button>
```

**特徴**:
- `danger`属性で赤色の警告スタイル
- `DeleteOutlined`アイコンを使用
- 一時的なonClickハンドラを設定（コンソールログ出力）

#### 2. ファイル削除ボタンの追加
ファイル管理タブの操作カラムに削除ボタンを追加しました。

**実装内容**:
```tsx
<Button
  type="text"
  danger
  icon={<DeleteOutlined />}
  onClick={() => console.log('ファイル削除（未実装）', record.file_name)}
>
  削除
</Button>
```

**特徴**:
- `type="text"`でテキストボタンスタイル
- `danger`属性で赤色の警告スタイル
- `DeleteOutlined`アイコンを使用
- 一時的なonClickハンドラを設定（ファイル名をログ出力）

#### 3. 参考実装
フォーマット管理画面の削除ボタン実装パターンを参考にしました。
