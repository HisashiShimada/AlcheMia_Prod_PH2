## 1. タスク概要

指示送信ダイアログのタスク詳細カードに対して、以下の追加修正を実施：
1. 条件指定欄と試行回数欄をタスク詳細カードの最下部に移動
2. タスク名を必須項目とする
3. タスク名のデフォルト値を自動設定
   - メソッド総数が1の場合：プロジェクト名
   - メソッド総数が2以上の場合：メソッド名

## 2. 目的と期待される成果

### 目的
- タスク詳細に関連する項目を1つのカードにまとめ、UIの一貫性を向上
- タスク名の入力を必須化し、データ品質を向上
- デフォルト値の自動設定により、ユーザーの入力負担を軽減

### 期待される成果
- [x] 条件指定欄と試行回数欄がタスク詳細カード内に移動される
- [x] タスク名が必須項目となる
- [x] メソッド数に応じてタスク名のデフォルト値が自動設定される

## 3. 実装ステップ

### Phase 1: レイアウトの変更

- [ ] タスク詳細カード内の最下部に条件指定・試行回数を配置
- [ ] 実験条件セクション（Card）を削除
