## 1. タスク概要

現在、ログイン時のユーザー名は`organization_user`テーブルの`user_name`カラムを参照していますが、これを`mail_address`カラム（メールアドレス）を参照するように変更します。

### 目的
- ユーザーがメールアドレスでログインできるようにする
- ユーザー名を覚える必要をなくし、ユーザビリティを向上させる
- メールアドレスによる統一的な認証方式を実現する

## 📋 事前確認が必要な項目

### データベース確認クエリ
```sql
-- mail_addressの重複チェック（組織内）
SELECT 
  organization_id,
  mail_address,
  COUNT(*) as count
FROM organization_user
GROUP BY organization_id, mail_address
HAVING COUNT(*) > 1;

-- mail_addressカラムの制約確認
SELECT
  tc.constraint_name,
  tc.constraint_type,
  kcu.column_name
FROM information_schema.table_constraints tc
JOIN information_schema.key_column_usage kcu
  ON tc.constraint_name = kcu.constraint_name
WHERE tc.table_name = 'organization_user'
  AND kcu.column_name = 'mail_address';
```
