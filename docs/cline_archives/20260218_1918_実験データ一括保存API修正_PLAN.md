## 1. タスク概要

API設計書（`docs/design/api/api_experiment_data.md`）に基づき、実験データ一括保存APIのエンドポイントパラメータと権限設定を修正します。

### 主な変更内容
1. **エンドポイントパラメータ変更**: `:projectId` (UUID) → `:projectName` (文字列)
2. **権限チェック追加**: `experiment_worker` のみ書込可に明示的に変更
3. **バリデーション修正**: projectName用のバリデーションに変更
4. **サービス層修正**: projectNameからproject_idを取得する処理を追加

### プロジェクト名→ID変換の実装方針
```sql
-- プロジェクト名からプロジェクトIDとステータスを取得
SELECT id, status 
FROM projects 
WHERE organization_id = $1 AND project_name = $2
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| プロジェクト名重複 | 中 | 低 | organization_idと組み合わせて一意性を保証（既存のDB設計で対応済み） |
| エンドポイント変更によるフロントエンド影響 | 高 | 高 | 別タスクでフロントエンド側のAPIコールを修正する必要あり |
| 権限チェック追加による既存動作への影響 | 中 | 低 | experiment_worker以外のロールには403エラーを返す（仕様通り） |
| プロジェクト名取得クエリの追加によるパフォーマンス影響 | 低 | 低 | トランザクション内の1クエリ増加のみ、インデックスで最適化済み |
