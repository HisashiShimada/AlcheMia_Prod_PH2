## 5. 技術的詳細

### インポートパスの調整

editorv2のファイルは以下のようなインポートを持つ可能性があります：

```typescript
// editorv2内での相対パス
import { SomeType } from '../types';
import { SomeHook } from '../hooks';
```

これを components/editor/ に配置する場合：

```typescript
// 調整後（必要に応じて）
import { SomeType } from '@/components/editorv2/types';
import { SomeHook } from '@/hooks';
```

### 型定義の互換性

- editorv2の型定義が現行プロジェクトと互換性があるか確認
- 必要に応じて型定義を調整

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| インポートパスの不整合 | 中 | 中 | バックアップから復元、パス調整 |
| 型定義の不一致 | 中 | 低 | TypeScriptエラーを確認し修正 |
| 依存コンポーネントの不足 | 高 | 低 | 必要なコンポーネントを追加インポート |
| 既存機能の動作不良 | 高 | 低 | バックアップから復元、段階的に確認 |

## 8. ロールバック計画

問題が発生した場合：

1. **即座にロールバック**
   ```bash
   # バックアップから復元
   cp -r components/editor/_backup_20260130/* components/editor/
   ```

2. **段階的ロールバック**
   - 問題のあるファイルのみバックアップから復元
   - 他のファイルは置換したまま

3. **原因調査**
   - エラーログを確認
   - インポートパスを確認
   - 型定義を確認
