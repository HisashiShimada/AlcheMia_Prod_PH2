## 4. 影響範囲

### 参照するファイル
1. `config/nginx/mmdpf-ssl.conf` - 既存のSSL設定（参考）
2. `certs/ca/ca.crt` - CA証明書
3. `certs/server/server.crt` - サーバー証明書
4. `certs/server/server.key` - サーバー秘密鍵
5. `certs/clients/*.p12` - クライアント証明書（PKCS#12形式）

### 新規作成するファイル
1. `config/nginx/nginx-windows-ssl.conf` - クライアント証明書認証付き設定
2. `docs/Windows_nginx_クライアント証明書認証_手順.md` - 証明書インストール手順書

## 5. 技術的詳細

### 証明書ファイルの配置
```
nginx-1.29.5\nginx-1.29.5\
├── conf\
│   └── nginx.conf (nginx-windows-ssl.confをコピー)
└── certs\  ← 新規作成
    ├── ca\
    │   └── ca.crt
    └── server\
        ├── server.crt
        └── server.key
```

### nginx SSL設定のポイント
- `listen 443 ssl;` - HTTPSポート
- `ssl_verify_client on;` - クライアント証明書認証を必須化
- `ssl_client_certificate` - CA証明書のパス
- `ssl_certificate` - サーバー証明書のパス
- `ssl_certificate_key` - サーバー秘密鍵のパス

### 組織ID抽出
証明書のCNフィールドから組織IDを抽出：
```
CN={a0718dc5-21f3-44e6-87e9-cc2ae83f3385}
→ organization_id = a0718dc5-21f3-44e6-87e9-cc2ae83f3385
```
