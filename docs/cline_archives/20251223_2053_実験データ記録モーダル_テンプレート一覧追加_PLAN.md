## 1. タスク概要

「実験作業者メニュー」画面の「実験記録」タブで使用される「実験データ記録」モーダルに、テンプレート一覧テーブルを追加します。

## 2. 目的と期待される成果

### 目的
実験データ記録時に、利用可能なテンプレートを一覧表示し、検索・絞り込み機能を提供することで、ユーザーがテンプレートを選択しやすくする。

### 期待される成果
- [ ] テンプレート一覧テーブルの表示
- [ ] テンプレート名でのあいまい検索機能
- [ ] テンプレート種別での絞り込み機能
- [ ] ページネーション機能

## 3. 実装ステップ

## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Table, Input, Select, Pagination コンポーネント
- React Hooks: useState（状態管理）

### UIコンポーネント構成
```tsx
<Modal>
  {/* 既存の作業指示エリア */}
  
  {/* 新規: テンプレート一覧エリア */}
  <Space direction="vertical" style={{ width: '100%' }}>
    {/* フィルタリングエリア */}
    <Row gutter={16}>
      <Col flex="400px">
        <Input placeholder="テンプレート名で検索" />
      </Col>
      <Col flex="150px">
        <Select placeholder="テンプレート種別" />
      </Col>
    </Row>
    
    {/* テーブル */}
    <Table
      columns={[
        { title: 'テンプレート名', dataIndex: 'name' },
        { title: 'テンプレート種別', dataIndex: 'type' },
        { title: 'プロパティ数', dataIndex: 'propertyCount', align: 'right' },
      ]}
      pagination={{ pageSize: 10 }}
    />
  </Space>
</Modal>
```

### データ構造
```typescript
interface Template {
  id: string;
  name: string;
  type: 'material' | 'condition' | 'result';
  propertyCount: number;
}
```

## 6. リスク と対策
