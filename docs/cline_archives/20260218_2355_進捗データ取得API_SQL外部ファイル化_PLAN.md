## 6. 技術的詳細

### 使用する技術・ライブラリ
- **pg-promise**: PostgreSQL用のPromiseベースのデータベースライブラリ
- **loadSqlFile**: SQL外部ファイル読み込みユーティリティ
- **getPgp()**: pg-promiseインスタンス取得関数

### 実装パターン（参考: departmentRepository.ts）

```typescript
import { getPgp } from '../database/db';
import { loadSqlFile } from '../sql/loader';

async function example(param1: string, param2: string): Promise<ResultType | null> {
  const pgp = getPgp();
  
  // 外部SQLファイルを読み込み
  const sqlQuery = await loadSqlFile('category/queryName.sql');
  
  const params = [param1, param2];
  
  // pg-promiseのメソッドを使用
  // - oneOrNone: 0または1件の結果を期待
  // - one: 必ず1件の結果を期待
  // - any: 0件以上の結果を期待
  const result = await pgp.oneOrNone<ResultType>(sqlQuery, params);
  
  return result;
}
```

### pg-promiseのメソッド

- `oneOrNone<T>()`: 0または1件の結果を期待（見つからない場合はnull）
- `one<T>()`: 必ず1件の結果を期待（0件または2件以上の場合はエラー）
- `any<T>()`: 0件以上の結果を期待（配列を返す）
- `none()`: 結果を返さないクエリ（INSERT/UPDATE/DELETE）
