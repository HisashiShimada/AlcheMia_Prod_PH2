## 5. 技術的詳細

### API仕様書の構造
```markdown
# [画面名]API仕様書

## 概要
- 画面の説明
- 総API数
- 実装状況

## API一覧
- エンドポイント一覧表

## 各APIの詳細
### 1. [API名]
- エンドポイント
- HTTPメソッド
- 認証・認可
- リクエスト仕様
- レスポンス仕様
- エラーレスポンス
- 使用例

## セキュリティ考慮事項
- マルチテナント分離
- 権限チェック

## 関連ドキュメント
```

### 統一レスポンス形式
```typescript
// 成功時
{
  "success": true,
  "data": { ... },
  "pagination": { ... },  // オプショナル
  "meta": {
    "timestamp": "2026-01-21T16:00:00Z",
    "requestId": "req_abc123"
  }
}

// エラー時
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "エラーメッセージ",
    "details": []
  },
  "meta": { ... }
}
```
