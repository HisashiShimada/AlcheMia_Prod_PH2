## 5. 技術的詳細

### 現在の実装の問題点（推測）

```typescript
// ProgressCheckTab.tsx
<Tabs
  activeKey={selectedMethodId || undefined}  // ← 親から受け取る値
  onChange={onSelectMethod}                   // ← 親に通知
  items={methodTabs}
/>
```

**問題の可能性:**
1. 親コンポーネントが`selectedMethodId`を正しく更新していない
2. `onSelectMethod`コールバックが正しく処理されていない
3. 状態の初期化タイミングの問題

### 調査項目
- [ ] 親コンポーネントの`selectedMethodId`状態管理
- [ ] `onSelectMethod`ハンドラーの実装
- [ ] useEffectの依存配列と実行タイミング
- [ ] Tabsコンポーネントの制御方式（controlled vs uncontrolled）
