## 1. タスク概要

フォーマット管理画面において、新規XMLファイル・新規MAIMLファイルを作成する際の仕様を変更します。
現在はテンプレート内容が含まれたファイルを生成していますが、完全に空のファイル（中に何も記載されていない）を生成するように変更します。

## 2. 目的と期待される成果

- 不要なテンプレート生成ロジックを削除し、コードの保守性を向上させる

## 5. 技術的詳細

### 変更前の動作
```typescript
// formatFileUtils.tsでテンプレート生成
const content = generateXmlTemplate(description);
await storageService.uploadFile(organizationId, filePath, content);
```

### 変更後の動作
```typescript
// 空の文字列をアップロード
const content = '';
await storageService.uploadFile(organizationId, filePath, content);
```

### アーキテクチャ上の考慮事項
- 空のファイルでもStorageServiceは正常に動作する
- S3/Swiftに空のファイルが保存される
- XMLパーサーは空のファイルを適切に処理する必要がある（既存の実装で確認）

### セキュリティ考慮事項
- [ ] organization_idによるテナント分離は維持される
- [ ] ファイルパスのバリデーションは既存のまま維持
- [ ] 空のファイルでもセキュリティ上の問題はない
