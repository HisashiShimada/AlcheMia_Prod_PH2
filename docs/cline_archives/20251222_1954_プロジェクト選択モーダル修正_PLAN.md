## 1. タスク概要

実験作業者メニュー画面の「選択プロジェクト」エリアにある「選択」ボタンを押下した際に呼び出されるモーダルを、シンプルなプロジェクト選択専用モーダルに変更する。

## 2. 目的と期待される成果

### 目的
- 現在の3ステップ選択ダイアログ（プロジェクト→メソッド→タスク）から、プロジェクト選択のみに機能を限定
- UIをシンプルにして、プロジェクト情報（名前、説明、所有者）を表示
- 決定/キャンセルボタンで直感的な操作を実現

### 期待される成果
- [x] プロジェクト一覧が表示される（1行目は「未選択」）
- [x] 各プロジェクトの名前、説明、所有者が表示される
- [x] プロジェクトを選択できる
- [x] 「キャンセル」ボタンでモーダルを閉じる（選択状態は変更しない）
- [x] 「決定」ボタンで選択を確定してモーダルを閉じる
- [x] 未選択で「決定」した場合、未選択状態でモーダルを閉じる
