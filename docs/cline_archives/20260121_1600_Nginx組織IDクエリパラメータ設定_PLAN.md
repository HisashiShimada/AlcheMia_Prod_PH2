## 1. タスク概要

本番環境のNginx設定（nginx.conf）を変更して、クライアント証明書認証後に取得した組織IDをクエリパラメータとして設定できるようにします。

## 5. 技術的詳細

### 実装する設定

#### 1. クライアント証明書検証設定
```nginx
# SSL設定
ssl_certificate /path/to/server.crt;
ssl_certificate_key /path/to/server.key;

# クライアント証明書検証
ssl_client_certificate /path/to/ca.crt;
ssl_verify_client optional;  # 移行期はoptional、本番運用時はon推奨
ssl_verify_depth 2;
```

#### 2. CN抽出処理（mapディレクティブ）
```nginx
# httpブロック内で定義
map $ssl_client_s_dn $organization_id {
    default "";
    ~CN=(?<CN>[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}) $CN;
}
```

#### 3. ヘッダー設定
```nginx
# locationブロック内（proxy_pass前）
proxy_set_header X-Client-Cert-DN $ssl_client_s_dn;
proxy_set_header X-Client-Cert-CN $organization_id;
proxy_set_header X-Client-Cert-Verify $ssl_client_verify;
proxy_set_header X-Organization-Id $organization_id;
```

#### 4. クエリパラメータ設定
```nginx
# 既存のクエリパラメータを保持しつつ、orgIdを追加
set $new_args $args;

# argsが空でない場合は & で連結
if ($args != "") {
    set $new_args "$args&orgId=$organization_id";
}

# argsが空の場合は直接設定
if ($args = "") {
    set $new_args "orgId=$organization_id";
}

# プロキシ先に渡す
proxy_pass http://backend$uri?$new_args;
```

### セキュリティ考慮事項

- [ ] 証明書検証失敗時は403エラーを返す

## 7. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |

| 証明書検証失敗でアクセス不可 | 高 | 中 | ssl_verify_client optional で段階的に導入 |
