## 1. タスク概要

既に実装済みの自動ログイン機能を改善し、ユーザーエクスペリエンスを向上させます。

### 現状の問題点
1. **Session Storage使用**: ブラウザを閉じるとトークンとユーザー情報が消えてしまう
2. **ローディング画面なし**: 自動ログイン判定中に通常のログイン画面が一瞬表示されてしまう
3. **情報取得の非効率性**: 自動ログイン時にユーザー情報をAPIから取得し直している
4. **Local Storage未削除**: ログアウト時にLocal Storageの情報が残ったままになる可能性

### 改善内容
1. **Storage変更**: Session Storage → Local Storageに変更（ブラウザを閉じてもデータ保持）
2. **ローディング画面追加**: 自動ログイン判定中は専用のローディング画面を表示
3. **効率的な情報取得**: Local Storageから直接ユーザー情報を取得
4. **完全なクリーンアップ**: ログアウト時にLocal Storageも削除

### ローディング画面の実装

```typescript
// page.tsx に状態を追加
const [isCheckingAutoLogin, setIsCheckingAutoLogin] = useState(true);

// useEffect内で自動ログインチェック
React.useEffect(() => {
  const attemptAutoLogin = async () => {
    try {
      // 自動ログイン処理
      const response = await authService.refreshToken();
      
      // Local Storageに保存
      localStorage.setItem('sessionToken', response.session.token);
      localStorage.setItem('userInfo', JSON.stringify(response.user));
      
      // メニュー画面へ遷移
      setCurrentUser(response.user);
      setCurrentMenuType(response.user.initialScreenFunctionCd);
      setAuthStep('authenticated');
    } catch (error) {
      // 失敗時はログイン画面を表示
      console.log('[Auto-Login] 自動ログイン失敗 - ログイン画面を表示');
    } finally {
      // チェック完了
      setIsCheckingAutoLogin(false);
    }
  };

  attemptAutoLogin();
}, []);

// ローディング画面の表示
if (isCheckingAutoLogin) {
  return (
    <div style={{
      display: 'flex',
      justifyContent: 'center',
      alignItems: 'center',
      height: '100vh',
      flexDirection: 'column',
      gap: '16px'
    }}>
      <Spin size="large" />
      <div>ログイン状態を確認中...</div>
    </div>
  );
}
```

### ログアウト時のクリーンアップ

```typescript
// authService.ts
async logout(): Promise<LogoutResponseData> {
  try {
    const response = await apiClient.post<ApiResponse<LogoutResponseData>>(
      '/auth/logout',
      {}
    );
    
    if (response.data.success) {
      // すべてのトークンとセッション情報を削除
      clearAllTokens();
      if (typeof window !== 'undefined') {
        localStorage.removeItem('userInfo'); // Local Storageに変更
      }
      return response.data.data;
    }
    
    throw new AuthServiceError('ログアウトに失敗しました', 'LOGOUT_FAILED');
  } catch (error) {
    throw handleApiError(error);
  }
}

// page.tsx
const handleLogout = async () => {
  try {
    await authService.logout();
    messageApi.success('ログアウトしました');
  } catch (error) {
    // エラー処理
  } finally {
    // ローカル状態をクリア
    setCurrentUser(null);
    setCurrentMenuType(null);
    setAuthStep('login');
    
    // Local Storageをクリア
    if (typeof window !== 'undefined') {
      localStorage.removeItem('sessionToken');
      localStorage.removeItem('userInfo');
      localStorage.removeItem('devPinCode');
    }
  }
};
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| Local Storageの容量制限 | 低 | 低 | トークンとユーザー情報のみ保存（小容量） |
| セキュリティリスク | 中 | 低 | リフレッシュトークンはhttpOnly Cookieで管理 |
| ブラウザ間でのセッション共有 | 低 | 低 | 同一ブラウザ内でのみ共有（想定通り） |
| ログアウト忘れによる情報残存 | 中 | 中 | トークン有効期限で自動的に無効化 |
