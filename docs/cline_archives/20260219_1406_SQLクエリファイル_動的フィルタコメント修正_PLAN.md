## 5. 技術的詳細

### 修正内容の詳細

#### 修正前（例）:
```sql
-- 動的フィルタ（文字列置換で設定）:
--   {STATUS_FILTER} - ステータスフィルタ条件
--   {SORT_COLUMN} - ソート列
```

#### 修正後:
```sql
-- 動的フィルタ（文字列置換で設定）:
--   STATUS_FILTER - ステータスフィルタ条件
--   SORT_COLUMN - ソート列
```

### 注意事項
- **コメント部分のみ修正**：`-- `で始まる行の説明文のみが対象
- **SQL文中のプレースホルダーは保持**：実際のクエリ内の`{STATUS_FILTER}`等は削除しない
