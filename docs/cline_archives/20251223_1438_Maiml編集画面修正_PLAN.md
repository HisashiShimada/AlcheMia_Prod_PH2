## 1. タスク概要

Maiml編集画面（PetriNetEditor）の以下3点を修正する：

1. **ヘッダー部の表示項目変更**
   - 現状：プロジェクトIDと説明を表示
   - 変更後：プロジェクト名とプロジェクト概要を表示
   - プロジェクト管理画面からパラメータとして渡す

2. **DocumentEditDialogの名称欄デフォルト値対応**
   - 既存ファイル編集時：ファイル名をデフォルト値として設定し、変更不可にする
   - 新規作成時：プロジェクト名をデフォルト値として設定する

3. **DocumentEditDialogのマスタデータプルダウン化**
   - Creator、Vendor、Owner、Instrumentの各項目をプルダウン選択式に変更
   - マスタデータをバックエンドAPIから取得
   - 選択したマスタデータのIDと名称を自動入力

## 5. 技術的詳細

### プロジェクト情報の受け渡し方法
```typescript
// ProjectManagement.tsx
interface ProjectEditParams {
  projectId: string;
  projectName: string;
  projectOverview?: string;
}

const handleEditButtonClick = useCallback(() => {
  if (!selectedProject) return;
  
  const params: ProjectEditParams = {
    projectId: selectedProject.id,
    projectName: selectedProject.name,
    projectOverview: selectedProject.description
  };
  
  onEdit?.(params);
}, [selectedProject, onEdit]);
```

### マスタデータAPIレスポンス形式

interface MasterDataItem {
