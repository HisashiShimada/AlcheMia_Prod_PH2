## 修正パターン

### 主な修正内容: Collapse.Panel非推奨API対応

**修正前:**
```typescript
<Collapse>
  <Panel header="..." key="1">
    {children}
  </Panel>
</Collapse>
```

**修正後:**
```typescript
<Collapse
  items={[
    {
      key: '1',
      label: "...",
      children: {children}
    }
  ]}
/>
```
