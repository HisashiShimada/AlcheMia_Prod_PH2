## 1. タスク概要

TemplateEditorDialogに名前空間テンプレート取り込み機能を追加し、S3から定義済みのテンプレートを読み込めるようにする。

## 2. 目的と期待される成果

### 目的
- ユーザーがS3上の名前空間テンプレート（XMLファイル）を選択して読み込める
- PropertiesまたはContentsに一括でテンプレートを取り込める
- 名前空間由来のデータであることを識別できる

interface Folder {
  name: string;

  files: string[];
  xmlFileCount: number;

}

interface NamespaceData {
  namespaceURI: string;
  hierarchyPath: string[];
  properties: Record<string, PropertyData>;
  contents: Record<string, PropertyData>;

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| S3アクセス権限エラー | 高 | 中 | 適切なエラーハンドリングとユーザーへの通知 |
| XML解析エラー | 中 | 中 | try-catchでエラーをキャッチし、詳細をログ出力 |
| 大量ファイルによるパフォーマンス低下 | 中 | 低 | ページング、遅延読み込みの検討 |
| 既存のPropertiesが上書きされる | 高 | 低 | 確認ダイアログでユーザーに警告 |
