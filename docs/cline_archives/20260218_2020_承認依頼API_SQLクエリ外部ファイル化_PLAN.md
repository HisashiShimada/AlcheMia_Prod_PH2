## 5. 洗い出したSQLクエリ

### 5.1. projectController.ts
```sql
-- projectNameからprojectIdを取得
SELECT project_id 
FROM project 
WHERE organization_id = $1 AND project_name = $2
```

### 5.2. projectService.ts - requestApprovalメソッド

#### クエリ1: プロジェクト存在確認とステータス検証
```sql
SELECT 
  project_id,
  project_name,
  project_status,
  organization_id
FROM project
WHERE organization_id = $1 AND project_id = $2
```

#### クエリ2: プロジェクトステータス更新
```sql
UPDATE project
SET project_status = $1,
    update_at = $2,
    update_user_id = $3
WHERE organization_id = $4 AND project_id = $5
```

#### クエリ3: ユーザー名取得
```sql
SELECT user_name
FROM organization_user
WHERE organization_id = $1 AND user_id = $2
```

## 6. 技術的詳細

### 使用する技術・ライブラリ

### アーキテクチャ上の考慮事項
- リポジトリパターンの採用
- Service層からはリポジトリ層を経由してDBアクセス

- トランザクション管理はpg-promiseのtx()メソッドを使用

## 7. リスクと対策
