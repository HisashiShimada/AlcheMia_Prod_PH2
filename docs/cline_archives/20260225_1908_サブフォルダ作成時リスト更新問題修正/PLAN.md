### 発生した問題と解決方法

**問題の詳細:**
- material配下（ルート直下）でサブフォルダを作成した場合は正常に表示される
- サブフォルダの中でさらにサブフォルダを作成した場合、リロードしないと表示されない

**原因:**
`handleCreateFormatFolder`関数内で、サブフォルダ作成後のファイルリスト再取得時に、常に`undefined`（ルート直下）を指定していたため、現在表示中のサブフォルダ階層のファイルリストが更新されていなかった。

**修正内容:**
現在のフォルダパス（`currentFolderPath`）を考慮して、適切なキャッシュキーでファイルリストを再取得するように修正。

```typescript
// 修正前
const fileResponse = await fetchFormatFiles(selectedFormatId, undefined);
setFormatFilesData(prev => ({
  ...prev,
  [selectedFormatId]: { allFiles: [...] }
}));

// 修正後
const currentPath = currentFolderPath.length > 0 
  ? currentFolderPath.join('/')
  : undefined;

const fileResponse = await fetchFormatFiles(selectedFormatId, currentPath);

const cacheKey = currentPath 
  ? `${selectedFormatId}/${currentPath}`
  : selectedFormatId;

setFormatFilesData(prev => ({
  ...prev,
  [cacheKey]: { allFiles: [...] }
}));
```
