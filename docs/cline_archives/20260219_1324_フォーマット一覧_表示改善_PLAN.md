  const templateType = templateTypeMap[folderName.toLowerCase()] || folderName;

## 5. 技術的詳細

### 問題1: categoryの表示
- **原因**: フロントエンドの`getCategoryLabel`関数が`category`フィールド（'template'/'workflow'）を変換しようとしているが、実際には'protocol', 'material', 'analysis'などを想定していた
- **現状**:
  - バックエンド: `category: 'template'` または `'workflow'`を返す
  - フロントエンド: `getCategoryLabel(format.category)`で表示
  - `getCategoryLabel`は'protocol', 'material'などを日本語に変換
  - 'template'/'workflow'は変換できず、そのまま表示される
- **解決策**: `description`フィールドで具体的な日本語説明を返し、フロントエンドはそれを使用
  - material → 「材料テンプレート」
  - condition → 「条件テンプレート」
  - result → 「結果テンプレート」
  - その他のフォルダ → フォルダ名をそのまま表示
- **注**: モックの`mockFormatFiles.json`は**ファイル一覧**のデータであり、**フォーマット一覧**のデータではない

### 問題2: departmentの表示
- **原因**: バックエンドが`department: ''`（空文字）を返している
- **解決策**: `department: departmentCd`を設定

### 問題3: fileCountの計算
- **原因**: S3のlistFiles結果にフォルダ自体のパス（`xxx/yyy/`）が含まれている
- **解決策**: 末尾が`/`で終わるパスを除外してカウント
- **注**: この修正により空フォルダの`fileCount`は0になるが、**フォルダ自体は表示される**
