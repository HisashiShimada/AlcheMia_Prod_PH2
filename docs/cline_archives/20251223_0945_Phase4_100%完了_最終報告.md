### 1. TemplateEditorDialog.tsx
**エラー:**
```

```

**修正方法（選択肢A - 推奨）:**
```typescript
// TemplateEditorDialog.tsx
export interface TemplateEditorDialogProps {
  open: boolean;
  node: Node | null;
  onClose: () => void;
  onSave: (updatedNode: Node) => void;  // ✅ 引数型を Node に変更
}
```

**修正方法（選択肢B）:**
```typescript
// PetriNetEditor.tsx の handleSaveTemplate を変更
const handleSaveTemplate = useCallback((nodeId: string, templateRef: any) => {
  handleUpdateNodeProperty(nodeId, templateRef);
  setTemplateEditorOpen(false);
  setTemplateEditNode(null);
}, [handleUpdateNodeProperty]);
```
