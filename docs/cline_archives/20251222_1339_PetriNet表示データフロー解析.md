## 概要

進捗確認画面の詳細ダイアログにおけるPetri Net（実験フロー図）の表示において、各種データがどこから来て、どのように処理され、最終的にどのように表示されるかを詳細に解析します。

## 1. データソース

### 1.1. MAIMLファイル（test_omori11.maiml）

**場所:** `frontend/src/data/mock/test_omori11.maiml`

#### Transition定義（例：transition-1764899405147）

```xml
<transition id="transition-1764899405147"/>

<!-- programセクション内のinstruction -->
<instruction id="transition-1764899405147">
  <uuid>462dfb82-8506-4996-92c3-f1a17c0d1ab3</uuid>
  <description>混ぜ合わせる</description>
  <transitionRef id="TR_transition-1764899405147" ref="transition-1764899405147"/>
</instruction>
```

**重要ポイント:**
- `<transition>` 要素は **id属性のみ** を持つ（descriptionなし）
- **description は `<instruction>` 要素内** に記述される
- `instruction/@id` と `transition/@id` は同じ値

#### Place定義（例：material-1764899172116）

```xml
<place id="material-1764899172116">
  <description>material 1</description>
</place>

<!-- programセクション内のmaterialTemplate -->
<materialTemplate id="MTmaterial-1764899172116">
  <uuid>2cefbe2f-0805-453b-93b2-4bdd3ca5aa6e</uuid>
  <name>material01</name>
  <description>material 1</description>
  <placeRef id="MTmaterial-1764899172116TL" ref="material-1764899172116"/>
</materialTemplate>
```

**重要ポイント:**
- `<place>` 要素は **id属性 + description子要素** を持つ
- **name は `<materialTemplate>` 要素内** に記述される
- `materialTemplate/@id` は `MT + place/@id` の形式

#### Step 2: ノード変換（convertToFlowNodes）

```typescript
const convertToFlowNodes = (
  data: PetriNetData,
  progress: TransitionProgress[],
  experimentRecords: ExperimentRecordsData | null
): Node[] => {
  // ...
  
  allNodes.forEach((node) => {
    // Transitionの場合
    if (node.type === 'transition') {
      // ① IDでマッチング
      const transitionProgress = progress.find((p) => p.transitionId === node.id);
      
      // ② 進捗状態判定
      const statusValue = transitionProgress?.progressStatus || '未着手';
      const isCompleted = statusValue === '完了';
      const isInProgress = statusValue === '作業中';
      
      // ③ ノード作成
      flowNodes.push({
        id: node.id,  // "transition-1764899405147"
        type: 'transition',
        position: { x, y },
        data: {
          label: node.data.label || node.id,  // "混ぜ合わせる"
          isCompleted,
          isInProgress,
          progressChip: transitionProgress ? (
            <Tag color={isCompleted ? 'success' : ...}>
              {String(statusValue)}  // "完了"
            </Tag>
          ) : null,
          tooltip: tooltipText
        }
      });
    } else {
      // Placeの場合
      flowNodes.push({
        id: node.id,  // "material-1764899172116"
        type: getNodeType(node),  // "materialTemplate"
        position: { x, y },
        data: {
          label: node.data.label || node.id,  // "material 1"
          stereotype: node.data.stereotype  // "materialTemplate"
        }
      });
    }
  });
}
```

## 4. マッチングロジック

### 4.1. 現在のマッチングロジック（シンプル版）

```typescript

```

**マッチング条件:**
- `progress[].transitionId` === `node.id`
- 例: "transition-1764899405147" === "transition-1764899405147"

### 4.2. マッチング成功の条件

✅ **成功条件:**
1. mockPetriNetStructure.jsonの`transitions[].id`
2. mockProjects.jsonの`transitionProgress[].transitionId`
3. 上記2つが **完全一致** する

❌ **失敗パターン:**
- ID不一致: "trans_001" vs "transition-1764899405147"
- 名前でマッチング: "試料調製" vs "transition-1764899405147"（名前では一致しない）

## 7. 問題の原因と解決策

### 7.1. 過去の問題

**問題:** Transitionが緑色にならない

**原因:**
1. mockProjects.jsonのTransition IDが古い形式（"trans_001"）だった
2. mockPetriNetStructure.jsonのTransition IDは新しい形式（"transition-1764899405147"）
3. IDが一致せず、マッチングが失敗していた

### 7.2. 解決方法

**修正内容:**
- mockProjects.jsonのTransition IDを実際のMAIMLファイルに合わせて修正
- マッチングロジックをシンプルなID一致に戻す

**結果:**
- ✅ Transition IDが一致
- ✅ 進捗情報がマッチング成功
- ✅ Transitionが緑色で表示される

## 9. まとめ

### 9.1. データの流れ

```
【ソース】
MAIML (test_omori11.maiml)
  - Transition ID: "transition-1764899405147"
  - Description: "混ぜ合わせる"

【構造データ】
mockPetriNetStructure.json
  - id: "transition-1764899405147"
  - data.label: "混ぜ合わせる"

【進捗データ】
mockProjects.json
  - transitionId: "transition-1764899405147"
  - transitionName: "混ぜ合わせる"
  - progressStatus: "完了"

【マッチング】
PetriNetVisualization.tsx
  - node.id === progress.transitionId
  - "transition-1764899405147" === "transition-1764899405147" ✅

【表示】
TransitionNode
  - 下部ラベル: "混ぜ合わせる"
  - 上部タグ: "完了"
  - 色: 緑 + グロー効果
```

### 8.2. 重要なポイント

1. **Transition IDの一貫性が最重要**
   - MAIMLファイル → mockPetriNetStructure.json → mockProjects.json で同じIDを使用

2. **ラベル（label）とID（id）は別物**
   - ID: マッチングに使用（"transition-1764899405147"）
   - ラベル: 表示に使用（"混ぜ合わせる"）

3. **進捗状態（progressStatus）が色を決定**
   - "完了" → 緑
   - "作業中" → 青
   - その他 → 黒

4. **マッチングはIDベースのみ**
   - 名前でのマッチングは行わない（シンプルで確実）
