# ビューアボタン押下時の全体構造

## 作成日時
2025-12-19 14:01

## 完全な階層構造図

### 現在の実装（問題あり）

```
ProjectManagement
  └─ FileListTable
      └─ ビューアボタンクリック
          ↓
      handleViewFile(file) 呼び出し
          ↓
      openDialogs配列に追加（複数ダイアログ管理）
          ↓
      ┌─────────────────────────────────────────────────┐
      │ ViewRendererDialog (Draggable, z-index: 1000+n) │
      │   ├─ タイトルバー（ドラッグ可能）                │
      │   └─ ViewRenderer                               │
      │       └─ PetriNetViewer                         │
      │           ├─ React Flow（全体ペトリネット）      │
      │           │                                     │
      │           ├─ StructuredPropertySelector         │ ← Placeノードクリック時
      │           │   (Modal, body直下Portal, z-index: 1000)
      │           │                                     │
      │           └─ SubNetViewer                       │ ← Transitionノードクリック時
      │               (Modal, body直下Portal, z-index: 1000)
      │                 ├─ React Flow（サブネット）      │
      │                 └─ StructuredPropertySelector   │ ← **問題発生**
      │                     (Modal, body直下Portal, z-index: 1000)
      └─────────────────────────────────────────────────┘
```

### 実際のDOM構造（現在）

```html
<body>
  <div id="root">
    <ProjectManagement>
      <FileListTable>
        <!-- ビューアボタン -->
      </FileListTable>
    </ProjectManagement>
  </div>
  
  <!-- ViewRendererDialog（複数可能） -->
  <div class="draggable" style="position: fixed; z-index: 1000">
    <ViewRendererDialog>
      <ViewRenderer>
        <PetriNetViewer>
          <ReactFlow />
        </PetriNetViewer>
      </ViewRenderer>
    </ViewRendererDialog>
  </div>
  
  <!-- PlaceノードクリックでのStructuredPropertySelector（Portal） -->
  <div class="ant-modal-root" style="z-index: 1000">
    <StructuredPropertySelector Modal>
      <!-- プロパティ選択UI -->
    </StructuredPropertySelector>
  </div>
  
  <!-- TransitionノードクリックでのSubNetViewer（Portal） -->
  <div class="ant-modal-root" style="z-index: 1000">
    <SubNetViewer Modal>
      <ReactFlow />
    </SubNetViewer>
  </div>
  
  <!-- SubNetViewer内でPlaceノードクリック（Portal） -->
  <div class="ant-modal-root" style="z-index: 1000">
    <StructuredPropertySelector Modal>
      <!-- プロパティ選択UI -->
    </StructuredPropertySelector>
  </div>
</body>
```

## 問題点の詳細

### 問題1: z-index競合（複数のModal）
- ViewRendererDialog: z-index: 1000 + n（nは開いた順）
- SubNetViewer Modal: z-index: 1000（デフォルト）
- StructuredPropertySelector Modal: z-index: 1000（デフォルト）
- すべてbody直下のPortalで独立してレンダリング
- → どれが前面に来るか不定

### 問題2: モーダルのネスト
- ViewRendererDialog内でPetriNetViewer
- PetriNetViewer内でSubNetViewer（Modal）
- SubNetViewer（Modal）内でStructuredPropertySelector（Modal）
- → 3層のModal構造で管理が複雑

### 問題3: 背景のブロック
- SubNetViewerとStructuredPropertySelectorの両方にmask
- 複数のmaskが重なり、背景が完全にブロックされる

### 問題4: ViewRendererDialogの制約
- 現在はDraggableのみでResizableではない
- 複数のViewRendererDialogを開ける（5個まで）
- SubNetViewerは別Modal → ViewRendererDialogの管理外

## 修正後の構造

```
ProjectManagement
  └─ FileListTable
      └─ ビューアボタンクリック
          ↓
      handleViewFile(file) または handleViewTransition(node) 呼び出し
          ↓
      openDialogs配列に追加（contentTypeで分岐）
          ↓
      ┌─────────────────────────────────────────────────────┐
      │ ViewRendererDialog (react-rnd, z-index: 1000+n)     │
      │   ├─ タイトルバー（ドラッグ可能）                    │
      │   ├─ リサイズハンドル                               │
      │   │                                                 │
      │   └─ コンテンツ（contentTypeで分岐）                │
      │       │                                             │
      │       ├─ contentType === 'file'                     │
      │       │   └─ ViewRenderer                          │
      │       │       └─ PetriNetViewer                    │
      │       │           ├─ React Flow                    │
      │       │           └─ StructuredPropertySelector    │ ← Placeノード用
      │       │               (Modal, z-index: 1000)       │
      │       │                                            │
      │       └─ contentType === 'subnet'                  │
      │           └─ SubNetViewer (div, Modalではない)     │
      │               ├─ React Flow (左ペイン)             │
      │               └─ StructuredPropertySelector        │ ← 右ペイン埋め込み
      │                   (div, Modalではない)             │
      └─────────────────────────────────────────────────────┘
```

### 修正後のDOM構造

## 修正方針

### 1. ViewRendererDialogの拡張

```typescript
interface ViewRendererDialogProps {
  id: string;
  contentType: 'file' | 'subnet';  // 新規追加
  
  // ファイル表示用
  file?: FileData;
  
  // サブネット表示用
  subnetData?: {
    transitionName: string;
    maimlData: string;
    templateMap: Record<string, { element: Element }>;
    petriNetData: any;
  };
  
  zIndex: number;
  initialPosition?: { x: number; y: number };
  onClose: (id: string) => void;
  onFocus: (id: string) => void;
}
```

### 2. PetriNetViewerの修正

Transitionノードクリック時、SubNetViewerのModalを開く代わりに：
```typescript
// Before
setSubNetViewerOpen(true);

// After
// ProjectManagementのhandleViewTransition相当を呼び出す
// または、親コンポーネントに通知
onOpenSubNetViewer?.(transitionName, subnetData);
```

### 3. ProjectManagementの修正

```typescript
// ビューアボタンハンドラ（ファイル）
const handleViewFile = useCallback((file: FileData) => {
  const id = `file-${file.id}-${Date.now()}`;
  const newDialog: OpenDialog = {
    id,
    contentType: 'file',
    file,
    zIndex: nextZIndex,
    position: { x: 100 + offset, y: 100 + offset }
  };
  setOpenDialogs(prev => [...prev, newDialog]);
  setNextZIndex(prev => prev + 1);
}, [nextZIndex, openDialogs]);

// Transitionノードハンドラ（サブネット）
const handleViewSubnet = useCallback((subnetData: SubnetData) => {
  const id = `subnet-${Date.now()}`;
  const newDialog: OpenDialog = {
    id,
    contentType: 'subnet',
    subnetData,
    zIndex: nextZIndex,
    position: { x: 150, y: 150 }
  };
  setOpenDialogs(prev => [...prev, newDialog]);
  setNextZIndex(prev => prev + 1);
}, [nextZIndex]);
```

## 利点

### 修正後の利点
1. **統一されたダイアログ管理**: すべてのフロートウィンドウをViewRendererDialogで管理
2. **z-index階層の明確化**: react-rndで管理し、z-indexが自動的に正しく設定される
3. **リサイズ可能**: react-rndによりドラッグとリサイズの両方が可能
4. **モーダルの簡素化**: SubNetViewer内でModalを使わないため、ネストの問題がない
5. **背景操作可能**: ViewRendererDialogはmask=falseで背景をブロックしない
6. **複数ウィンドウ対応**: ファイルビューアとサブネットビューアを同時に複数開ける
