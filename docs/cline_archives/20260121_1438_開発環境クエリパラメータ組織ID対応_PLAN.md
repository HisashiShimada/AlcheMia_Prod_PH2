## 5. 技術的詳細

### 使用する技術・ライブラリ
- Express.js: リクエストオブジェクトの`req.query`を使用
- 既存のUUID検証パターン: `/^[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}$/i`

### 実装例
```typescript
// クエリパラメータから組織IDを取得
const queryOrgId = req.query.orgId as string | undefined;

// 優先順位: クエリパラメータ > デフォルト値
let orgId: string;

if (queryOrgId) {
  // UUID形式の検証
  const uuidPattern = /^[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}$/i;
  if (uuidPattern.test(queryOrgId)) {
    orgId = queryOrgId;
    console.warn(`[ClientCert] 開発環境: クエリパラメータからorganizationIdを設定 (${orgId})`);
  } else {
    // 無効なUUID形式の場合はデフォルト値を使用
    orgId = 'a0718dc5-21f3-44e6-87e9-cc2ae83f3385';
    console.error(`[ClientCert] 開発環境: 無効なorgId形式 (${queryOrgId})、デフォルト値を使用 (${orgId})`);
  }
} else {
  // クエリパラメータがない場合はデフォルト値を使用
  orgId = 'a0718dc5-21f3-44e6-87e9-cc2ae83f3385';
  console.warn(`[ClientCert] 開発環境: デフォルトorganizationIdを設定 (${orgId})`);
}

req.headers['x-organization-id'] = orgId;
```

### セキュリティ考慮事項

- [ ] UUID形式のバリデーションを実施
- [ ] 本番環境では絶対に動作しない
