### アーキテクチャ上の考慮事項

#### メソッド名での折りたたみ機能
Ant Design TableのexpandableRowを使用せず、独自のグループ化ロジックを実装します。

**実装方針:**
1. タスクデータをmethodNameでグループ化
2. グループヘッダー行とタスク行を交互に配置
3. useState で展開/折りたたみ状態を管理
4. グループヘッダー行はクリックで展開/折りたたみ

**グループ化データ構造:**
```typescript
interface GroupedTask {
  isGroup: true;
  methodName: string;
  taskCount: number;
  expanded: boolean;
}

interface TaskRow extends Task {
  isGroup: false;
}

type TableRow = GroupedTask | TaskRow;
```
