### 発生した問題と解決方法

#### 問題1: 404エラーが発生（11:15発見）
**症状**: フロントエンドから`/api/v1/projects`を呼び出すと404エラーが発生

**原因**: Next.jsの設定でAPIリクエストをバックエンドにプロキシする設定が不足していた

**解決策**: `frontend/next.config.ts`に`rewrites`設定を追加
```typescript
async rewrites() {
  return [
    {
      source: '/api/:path*',
      destination: 'http://localhost:3001/api/:path*',
    },
  ];
}
```

これにより、フロントエンド（localhost:3000）からの`/api/*`リクエストがバックエンド（localhost:3001）にプロキシされるようになった。

**注意**: Next.jsの開発サーバーを再起動する必要がある（設定ファイル変更のため）

#### 問題2: 環境変数でAPI接続先を管理する必要性（11:18発見）
**症状**: next.config.tsのプロキシ設定では本番環境への切り替えが困難

**原因**: ログイン画面のAPIは環境変数（`NEXT_PUBLIC_API_URL`）を使用していたが、プロジェクト一覧APIはハードコーディングされたプロキシ設定を使用していた

**解決策**: 
1. `frontend/.env.local`を作成し、環境変数を定義
```
NEXT_PUBLIC_API_URL=http://localhost:3001/api/v1
```

2. `apiClient.ts`を`authApi.ts`と同じ方式に統一
```typescript
const API_BASE_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3001/api/v1';

export async function fetchProjects(): Promise<ApiResponse<ProjectListResponse>> {
  const response = await fetch(`${API_BASE_URL}/projects`, {
    method: 'GET',
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
    },
  });
  // ...
}
```

3. `next.config.ts`のプロキシ設定を削除（不要になった）

**メリット**:
- 環境変数で接続先を柔軟に変更可能
- 本番環境、ステージング環境、開発環境を簡単に切り替え可能
- ログイン機能とプロジェクト管理機能の接続方式が統一された

**注意**: Next.jsの環境変数変更後は開発サーバーを再起動する必要がある

## 📝 実装コード案

### apiClient.ts の fetchProjects() 修正

```typescript
/**
 * プロジェクト一覧を取得
 */
export async function fetchProjects(): Promise<ApiResponse<ProjectListResponse>> {
  try {
    const response = await fetch('/api/v1/projects', {
      method: 'GET',
      credentials: 'include', // Cookie認証
      headers: {
        'Content-Type': 'application/json',
      },
    });

    if (!response.ok) {
      const errorData = await response.json().catch(() => ({}));
      throw new Error(
        errorData.error?.message || 'プロジェクト一覧の取得に失敗しました'
      );
    }

    const data: ApiResponse<ProjectListResponse> = await response.json();
    return data;
  } catch (error) {
    console.error('fetchProjects error:', error);
    throw error;
  }
}
```
