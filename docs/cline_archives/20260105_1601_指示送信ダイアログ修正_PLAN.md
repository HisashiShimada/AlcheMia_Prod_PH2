## 1. タスク概要

プロジェクト管理画面の指示送信ダイアログ（InstructionDialog.tsx）を以下の通り修正する：
1. タスク詳細セクションからタスク名入力欄を削除
2. 指示セクションに「特定タスク」を指示対象として追加
3. 特定タスク選択時に試行回数に基づくタスク番号選択機能を実装

## 2. 目的と期待される成果

### 目的
- タスク名入力の冗長性を排除し、UI を簡素化する
- タスク単位での指示を可能にし、より細かい作業指示を実現する
- 試行回数に応じたタスク番号選択により、具体的なタスク指定を容易にする

### 期待される成果
- [x] タスク詳細セクションのタスク名入力欄が削除される
- [ ] 指示対象に「特定タスク」が追加される（全体と特定トランジションの間）
- [ ] 特定タスク選択時に試行回数以下のタスク番号が選択できる
- [ ] 試行回数未入力時は適切なメッセージが表示される

### UI変更内容

#### 指示対象選択（変更後）
```tsx
<Radio.Group value={instruction.targetType}>
  <Radio value={TARGET_TYPES.FILE}>
    <FileTextOutlined /> ファイル全体
  </Radio>
  <Radio value={TARGET_TYPES.TASK} disabled={!trialCount}>
    <AimOutlined /> 特定タスク
  </Radio>
  <Radio value={TARGET_TYPES.TRANSITION}>
    <AimOutlined /> 特定トランジション
  </Radio>
</Radio.Group>
```

#### 対象タスク選択（新規）
```tsx
{instruction.targetType === TARGET_TYPES.TASK && (
  <Select
    value={instruction.taskNumber}
    placeholder="タスク番号を選択..."
    disabled={!trialCount || submitting}
  >
    {Array.from({ length: trialCount as number }, (_, i) => (
      <Select.Option key={i + 1} value={i + 1}>
        タスク {i + 1}
      </Select.Option>
    ))}
  </Select>
)}
```
