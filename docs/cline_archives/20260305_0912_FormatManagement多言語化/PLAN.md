## 6. 技術的詳細

### 使用する技術・ライブラリ
- `useLanguage` フック（既存）
- `t()` 翻訳関数（既存）

### 翻訳キーの命名規則
```
formatManagement.{機能}.{詳細}
```

例:
- `formatManagement.messages.file_load_failed`
- `formatManagement.dialog.delete_confirm`
- `formatManagement.buttons.new_subfolder`
- `formatManagement.loading.file_loading`

### 実装パターン例
```typescript
// 変更前
message.error('ファイルの読み込みに失敗しました: ' + (error as Error).message);

// 変更後
message.error(t('formatManagement.messages.file_load_failed') + ': ' + (error as Error).message);
```

```typescript
// 変更前
modal.confirm({
  title: 'ファイル削除',
  content: `「${file.name}」を削除しますか？この操作は取り消せません。`,
  okText: '削除',
  cancelText: 'キャンセル',
});

// 変更後
modal.confirm({
  title: t('formatManagement.dialog.delete_title'),
  content: t('formatManagement.dialog.delete_confirm', { fileName: file.name }),
  okText: t('common.delete'),
  cancelText: t('common.cancel'),
});
```

## 7. リスク と対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 言語ファイルの構造が不明 | 中 | 低 | 既存の多言語化実装を参照して同様のパターンで実装 |
| 翻訳キーの重複 | 低 | 低 | 既存キーを確認してから追加 |
| フォールバック値の設定漏れ | 中 | 中 | すべての`t()`呼び出しにフォールバック値を設定 |
| 動的文字列の処理 | 中 | 中 | パラメータ置換機能を使用 |
