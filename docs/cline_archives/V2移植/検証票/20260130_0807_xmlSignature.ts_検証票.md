## 🔍 詳細比較

### Web Crypto API使用

両バージョンとも同じWeb Crypto APIを使用：

```typescript
// 1. TextEncoderでUTF-8バイト列に変換
const encoder = new TextEncoder();
const data = encoder.encode(xmlContent);

// 2. Web Crypto APIでSHA-256ハッシュ計算
const hashBuffer = await crypto.subtle.digest('SHA-256', data);

// 3. ArrayBufferをUint8Arrayに変換
const hashArray = Array.from(new Uint8Array(hashBuffer));

// 4. Base64エンコード
const hashBase64 = btoa(String.fromCharCode(...hashArray));
```

完全に一致しており、正確な実装です ✅

### XMLDSig仕様準拠

Signature要素のXML構造が完全に一致：

- **xmlns**: `http://www.w3.org/2000/09/xmldsig#`
- **CanonicalizationMethod**: `http://www.w3.org/TR/2001/REC-xml-c14n-20010315#WithComments`
- **SignatureMethod**: `http://www.w3.org/2009/xmldsig11#dsa-sha256`
- **Transform**: `http://www.w3.org/2000/09/xmldsig#enveloped-signature`
- **DigestMethod**: `http://www.w3.org/2001/04/xmlenc#sha256`

W3C XMLDSig仕様に完全準拠 ✅

DigestValue抽出 → Signature除去 → ハッシュ再計算 → 比較：

