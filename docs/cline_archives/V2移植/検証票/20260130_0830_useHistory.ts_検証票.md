### 主要機能

PetriNetEditorV2のUndo/Redo機能を提供するカスタムフックです。

### 実装機能

1. **Undo機能** - 操作を取り消す
2. **Redo機能** - 操作をやり直す
3. **履歴管理** - past/present/futureの3つの状態配列で管理
4. **履歴追加** - pushState関数で新しい状態を追加
5. **履歴リセット** - reset関数で履歴をクリア
6. **履歴サイズ制限** - 最大50件の履歴を保持

### Commandパターン実装

```
past ← [状態1, 状態2, 状態3] → present: 状態4 → future: [状態5, 状態6]
                                     ↑
                                  現在の状態
```

```typescript
const undo = useCallback(() => {
  if (!canUndo) {
    console.log('⚠️ [useHistory] Undo不可: 履歴がありません');
    return;
  }

  setHistory((prevHistory) => {
    const newPast = prevHistory.past.slice(0, -1);
    const newPresent = prevHistory.past[prevHistory.past.length - 1];
    const newFuture = [prevHistory.present, ...prevHistory.future];

    console.log('↶ [useHistory] Undo実行:', {
      pastLength: newPast.length,
      futureLength: newFuture.length,
    });

    return {
      past: newPast,
      present: newPresent,
      future: newFuture,
    };
  });
}, [canUndo]);
```

#### 実装内容の完全一致

1. **canUndoチェック**: 履歴がない場合は早期リターン
2. **pastの更新**: 最後の要素を削除（slice(0, -1)）
3. **presentの更新**: pastの最後の要素を取得
4. **futureの更新**: 現在のpresentをfutureの先頭に追加
5. **ログ出力**: 履歴の長さを記録

## 📋 Commandパターンの実装解説

### Undo操作の流れ

```
実行前:
past: [状態1, 状態2, 状態3]
present: 状態4
future: []

Undo実行:
past: [状態1, 状態2]           ← 最後を削除
present: 状態3                 ← pastの最後を取得
future: [状態4]                ← 現在のpresentを追加
```

### Redo操作の流れ

```
実行前:
past: [状態1, 状態2]
present: 状態3
future: [状態4, 状態5]

Redo実行:
past: [状態1, 状態2, 状態3]    ← 現在のpresentを追加
present: 状態4                 ← futureの最初を取得
future: [状態5]                ← 最初を削除
```

### pushState操作の流れ

```
実行前:
past: [状態1, 状態2]
present: 状態3
future: [状態4, 状態5]  ← これはクリアされる

pushState実行:
past: [状態1, 状態2, 状態3]    ← 現在のpresentを追加
present: 新しい状態            ← 新しい状態を設定
future: []                     ← クリア
```

このCommandパターン実装は標準的かつ完璧です。
