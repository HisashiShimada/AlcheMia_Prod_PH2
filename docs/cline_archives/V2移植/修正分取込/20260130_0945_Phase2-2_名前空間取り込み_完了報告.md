## 機能仕様

### 対応フォーマット

**XML構造:**
```xml
<MaterialTemplate>
  <properties>
    <property key="compound" xsi:type="stringType">
      <value>Sample Compound</value>
      <description>化合物名</description>
    </property>
    <property key="concentration" xsi:type="propertyListType">
      <property key="value" xsi:type="doubleType">
        <value>0.1</value>
      </property>
      <property key="unit" xsi:type="stringType">
        <value>mol/L</value>
      </property>
    </property>
  </properties>
</MaterialTemplate>
```

**変換後のPropertyData形式:**
```typescript
{
  "compound": {
    key: "compound",
    tagName: "property",
    attributes: { "xsi:type": "stringType" },
    elements: { 
      value: "Sample Compound",
      description: "化合物名"
    },
    children: []
  },
  "concentration": {
    key: "concentration",
    tagName: "property",
    attributes: { "xsi:type": "propertyListType" },
    elements: {},
    children: [
      {
        key: "value",
        tagName: "property",
        attributes: { "xsi:type": "doubleType" },
        elements: { value: "0.1" },
        children: []
      },
      {
        key: "unit",
        tagName: "property",
        attributes: { "xsi:type": "stringType" },
        elements: { value: "mol/L" },
        children: []
      }
    ]
  }
}
```

### カテゴリ自動判定

```typescript
const category = node.data.placeType === 'material' ? 'material' :
                 node.data.placeType === 'condition' ? 'condition' : 'result';
```

- MaterialTemplateノード → materialカテゴリ
- ConditionTemplateノード → conditionカテゴリ
- ResultTemplateノード → resultカテゴリ

### マージ仕様

- 既存プロパティ + 取り込みプロパティ = マージ結果
- 同じキーのプロパティは**上書き**される
- 複数のテンプレートから順次取り込み可能
- 取り込み履歴は`importedNamespaces`配列で管理

## 制限事項と注意点

### 制限事項
1. **同じキーのプロパティは上書きされる**
   - マージ時に重複キーは最後の取り込みが優先
   - 意図しない上書きに注意

2. **カテゴリ制限**
   - MaterialTemplateノードではmaterialカテゴリのみ
   - ConditionTemplateノードではconditionカテゴリのみ
   - ResultTemplateノードではresultカテゴリのみ

3. **組織ID必須**
   - localStorageから`organizationPrefix`を取得
   - 未設定の場合はエラー

### 注意点
1. **XML形式の互換性**
   - MaiML標準形式のみ対応
   - 独自形式は解析失敗の可能性

2. **パフォーマンス**
   - 大量のプロパティを含むテンプレートは処理に時間がかかる場合あり
   - ネスト階層が深い場合は再帰処理のため注意

3. **エラーハンドリング**
   - ネットワークエラー時は再試行
   - XML解析エラー時は詳細ログを確認
