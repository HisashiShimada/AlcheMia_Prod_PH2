## 追加API一覧（詳細）

### 問題管理API（api_issue_management.md）を新規作成

#### 0-1. 問題報告API
- **エンドポイント**: POST /api/v1/issues
- **実装状況**: ✅ 実装済み（テスト103件すべてPASS）
- **用途**: タスク・トランジション単位で問題を報告
- **特記事項**: 
  - 問題の種類: material_shortage, equipment_failure, procedure_unclear, safety_concern, quality_issue, time_constraint, other
  - 対象種別: project, task, transition
  - トランザクション保証により整合性を確保
  - Winston構造化ログによる監査証跡を記録

#### 0-2. コメント投稿API
- **エンドポイント**: POST /api/v1/issues/:issueId/comments
- **実装状況**: ✅ 実装済み（テスト103件すべてPASS）
- **用途**: 既存問題にコメントを追加
- **特記事項**: 
  - コメント投稿時に自動的に `issues.updated_at` を更新
  - トランザクション保証により整合性を確保

#### 0-3. 問題一覧取得API
- **エンドポイント**: GET /api/v1/issues
- **実装状況**: ✅ 実装済み（テスト103件すべてPASS）
- **用途**: 問題一覧取得（複合フィルタ対応）
- **特記事項**: 
  - 複合フィルタリング対応（プロジェクト・タスク・トランジション・ステータス・種別等）
  - ソート・ページネーション対応
  - コメント数を自動集計

#### 0-4. 問題詳細取得API
- **エンドポイント**: GET /api/v1/issues/:issueId
- **実装状況**: ✅ 実装済み（テスト103件すべてPASS）
- **用途**: 問題詳細とコメント一覧取得
- **特記事項**: 
  - 問題の詳細情報とすべてのコメントを一括取得
  - コメントは投稿日時の昇順でソート

#### 0-5. 問題ステータス変更API
- **エンドポイント**: PATCH /api/v1/issues/:issueId/status
- **実装状況**: ✅ 実装済み（テスト103件すべてPASS）
- **用途**: 問題ステータスの変更（未解決/解決済）
- **権限**: Manager または Admin ロールが必須
- **特記事項**: 
  - `resolved` に変更時、自動的に `resolved_at` に現在時刻を設定
  - `unresolved` に変更時、`resolved_at` を NULL にクリア
