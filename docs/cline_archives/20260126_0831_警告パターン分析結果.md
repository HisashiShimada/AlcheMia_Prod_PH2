### 2. Collapse.Panel の非推奨API

**問題:**
```tsx
const { Panel } = Collapse;
<Collapse>
  <Panel header="タイトル" key="1">
    コンテンツ
  </Panel>
</Collapse>
```

**修正:**
```tsx
<Collapse items={[
  {
    key: '1',
    label: 'タイトル',
    children: <div>コンテンツ</div>
  }
]} />
```

**該当箇所:** 12箇所（指定フォルダ内）
※ ReactFlowのPanelは除外
