## 1. タスク概要

進捗確認タブから報告された問題を確認できるようにする機能を追加します。現在「問題報告」列に配置されている「報告」ボタンを「確認」ボタンに変更し、押下時に既存の問題報告モーダルを参照専用モードで表示します。

## 2. 目的と期待される成果

### 目的
- 進捗確認タブで、タスクに関連する問題を素早く確認できるようにする
- 問題報告モーダルを再利用し、参照専用モードで表示する

### 期待される成果
- [x] 「問題報告」列が「問題確認」列に変更される
- [x] 「報告」ボタンが「確認」ボタンに変更される
- [x] 「確認」ボタン押下で問題報告モーダルが参照専用モードで表示される
- [x] モーダルには選択されたタスクに紐づく問題のみが表示される
- [x] 参照専用モードでは編集機能が非表示になる

## 5. 技術的詳細

### 使用する技術・ライブラリ
- React 18.2.0: コンポーネント実装
- Ant Design v6: UIコンポーネント（Button, Modal）
- TypeScript: 型定義

### コンポーネント間のデータフロー
```
ProgressCheckTab (親)
  ↓ タスク情報を管理
ProgressCheckTable (子)
  ↓ 「確認」ボタン押下時にコールバック
ProgressCheckTab
  ↓ IssueManagementModalを開く（viewMode=true）
IssueManagementModal
  - 選択されたタスクに紐づく問題を表示
  - 編集機能を非表示
```

### 参照専用モードの実装方針
```typescript
interface IssueManagementModalProps {
  // ... 既存のprops
  viewMode?: boolean; // 追加: 参照専用モード
  filterTaskId?: string; // 追加: フィルタリング用タスクID
}
```

## 6. リスクと対策
