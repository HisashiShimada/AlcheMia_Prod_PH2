## 5. 技術的詳細

### データベース構造

#### organizationテーブル
```sql
organization (
  organization_id uuid PRIMARY KEY,
  organization_name varchar(50),
  organization_display_name varchar(50),
  organization_email varchar(50),
  chief_user_id varchar(50),  -- ⚠️ VARCHAR型
  corporation_id uuid,
  is_active boolean,
  update_at timestamp
)
```

#### organization_userテーブル
```sql
organization_user (
  user_id uuid PRIMARY KEY,  -- ⚠️ UUID型
  organization_id uuid,
  user_name varchar(100)
)
```

#### corporationテーブル
```sql
corporation (
  corporation_id uuid PRIMARY KEY,
  corporation_name varchar(50)
)
```

### JOIN処理の設計

```sql
SELECT 
  o.organization_id,
  o.organization_name,
  o.organization_display_name,
  o.organization_email,
  o.chief_user_id,
  ou.user_name as chief_user_name,  -- JOIN結果
  o.corporation_id,
  c.corporation_name,                -- JOIN結果
  o.is_active,
  o.update_at
FROM organization o
LEFT JOIN organization_user ou 
  ON ou.user_id = o.chief_user_id::uuid  -- ⚠️ 型変換必要
  AND ou.organization_id = o.organization_id
LEFT JOIN corporation c 
  ON c.corporation_id = o.corporation_id
WHERE o.organization_id = $1
```

### 型変換の必要性
- `chief_user_id` (VARCHAR) → `user_id` (UUID)
- キャスト: `o.chief_user_id::uuid`

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| chief_user_idとuser_idの型不一致 | 高 | 高 | `::uuid`でキャスト、型変換エラーをキャッチ |
| chief_user_idがNULLの場合 | 中 | 中 | LEFT JOINを使用、NULL時は空文字を返す |
| corporation_idがNULLの場合 | 中 | 中 | LEFT JOINを使用、NULL時は空文字を返す |
| 既存のorganization_idが見つからない | 低 | 低 | 404エラーを返す |
