## 1. タスク概要

一時パスワードでログイン後、ログイン画面から切り替わらない問題を修正します。

## 2. 問題の原因

### 現在の動作
1. 一時パスワードでログイン成功
2. `showChangePasswordModal = true`に設定
3. しかし`authStep = 'login'`のまま
4. 条件分岐で最初に`if (authStep === 'login')`が評価され、ログイン画面を表示
5. パスワード変更モーダルのコード（フォールバック部分）に到達しない

### 根本原因
- レンダリングロジックで、`showChangePasswordModal`のチェックが`authStep`のチェックより後にある
- モーダルがフォールバック部分にしか記述されていない

## 3. 実装ステップ

### Phase 1: レンダリング順序の修正
- [x] `showChangePasswordModal`が`true`の場合、ログイン画面の上にモーダルを表示
- [x] 条件分岐の順序を変更せず、ログイン画面とPINコード画面にもモーダルを追加

## 5. 技術的詳細

### 修正方針
各認証ステップのレンダリング部分にパスワード変更モーダルを追加：
```tsx
return (
  <>
    {contextHolder}
    <LoginPage ... />
    <ChangePasswordModal
      open={showChangePasswordModal}
      onSuccess={handleChangePasswordSuccess}
    />
  </>
);
```
