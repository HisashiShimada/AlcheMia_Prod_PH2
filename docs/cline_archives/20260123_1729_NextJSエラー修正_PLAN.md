## 1. タスク概要

デバッグログイン部品と実験管理者メニュー画面においてNext.jsのエラーを修正する。
具体的には、`useSearchParams()`フックを使用しているコンポーネントを`Suspense`バウンダリーで囲む必要がある。

## 2. 目的と期待される成果

### 目的
Next.js 15の仕様に準拠し、`useSearchParams()`使用時のエラーを解消する。

### 期待される成果
- [ ] `useSearchParams()`を使用しているページでエラーが発生しない
- [ ] デバッグログイン機能が正常に動作する

- [ ] Suspenseフォールバックが適切に表示される

## 3. エラーの原因

### 確認されたコード構造

**frontend/src/app/page.tsx**
- `'use client'`ディレクティブあり ✅
- `useSearchParams()`を使用 ⚠️
- Suspenseバウンダリーなし ❌

### Next.js 15の要件
Next.js 15（App Router）では、`useSearchParams()`を使用するクライアントコンポーネントは**Suspenseバウンダリー**で囲む必要があります。

理由：
- `useSearchParams()`は動的レンダリングをトリガーする
- 静的生成時にクエリパラメータは存在しない
- Suspenseを使うことで、クライアント側でのハイドレーション時にスムーズに切り替わる

## 6. 技術的詳細

### 修正パターン

#### 修正前（エラーが発生）
```tsx
'use client';

export default function Home() {
  const searchParams = useSearchParams(); // ❌ Suspenseなし
  // ...
}
```

#### 修正後（正常動作）
```tsx
'use client';

import { Suspense } from 'react';

function HomeContent() {
  const searchParams = useSearchParams(); // ✅ Suspense内
  // ...
}

export default function Home() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <HomeContent />
    </Suspense>
  );
}
```
