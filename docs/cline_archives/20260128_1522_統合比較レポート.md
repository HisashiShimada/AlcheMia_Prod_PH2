## 3️⃣ 詳細差分分析（Phase 5）

### 実装アプローチの違い

#### 3.1 テンプレートマップ構築

**V2版:**
```javascript
const { materialTemplates, conditionTemplates, resultTemplates } = 
  buildTemplatesMapsFromMaiML(maimlContent);
```

**現行版:**
```javascript
const structure = parseMaimlToPetriNet(effectiveMaimlData);
const { nodes, edges } = convertToReactFlow(structure);
const materialTemplates = nodes.filter(n => n.type === 'materialTemplate');
```

**評価**: 現行版の方がより統合的で保守しやすい ✅

---

#### 3.2 エラーハンドリング

**V2版:**
```javascript
try {
  // 処理
} catch (error) {
  console.error(error);
  alert('エラーが発生しました');
}
```

**現行版:**
```javascript
try {
  // 処理
} catch (error) {
  console.error('🚨 エラー詳細:', error);
  message.error(`エラー: ${error.message}`);
  // Ant Design message使用
}
```

**評価**: 現行版の方がユーザーフレンドリー ✅

---

### 未実装機能の詳細

#### ローカルダウンロード機能

**V2版の実装:**
```javascript
const handleDownload = useCallback(() => {
  const maimlXml = convertReactFlowToMaiML(nodes, edges, templates, documentData);
  const blob = new Blob([maimlXml], { type: 'application/xml' });
  const url = URL.createObjectURL(blob);
  
  const link = document.createElement('a');
  link.href = url;
  link.download = `${fileName}.maiml`;
  link.click();
  
  URL.revokeObjectURL(url);
}, [nodes, edges, templates, documentData, fileName]);
```

**現行版**: 未実装

**理由**: S3ベースの保存が主要機能のため

**実装優先度**: 低（必要に応じて追加可能）

**実装工数**: 1-2時間

**推奨実装場所**: SaveConfirmDialog内にボタン追加
