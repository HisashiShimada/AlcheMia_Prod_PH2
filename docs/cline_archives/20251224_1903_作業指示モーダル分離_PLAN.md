# タスク計画書: 作業指示モーダル分離

## メタデータ
- **作成日時**: 2025-12-24 19:03
- **タスクID**: 作業指示モーダル分離
- **優先度**: 中
- **推定工数**: 2時間

## 1. タスク概要

実験作業者メニューの「実験記録」タブにおいて、「実験データ記録モーダル」に含まれている「作業指示」セクションを別の独立したモーダルに分離します。これにより、作業指示の確認と実験データの記録を2段階のフローに変更します。

## 2. 目的と期待される成果

### 目的
- 作業指示の確認と実験データの記録を分離し、ユーザビリティを向上させる
- 作業指示を確認してから記録するという明確なフローを実現する

### 期待される成果
- [x] 新しい「作業指示モーダル」が実装される
- [x] トランジション一覧の「記録」ボタンで「作業指示モーダル」が表示される
- [x] 「作業指示モーダル」の「確認完了」ボタンで「実験データ記録モーダル」が表示される
- [x] 「実験データ記録モーダル」から作業指示セクションが削除される
- [x] データ記録の非活性処理が削除される

## 5. 技術的詳細

### 使用する技術・ライブラリ
- React 18.2.0
- Ant Design v6 (Modal, Button, Card, Space, Typography)
- TypeScript

### コンポーネント構造
```
ExperimentRecordTab
├── TransitionList
│   └── [記録] ボタン → InstructionConfirmationModal を開く
│
InstructionConfirmationModal
├── タイトル: 「作業指示 - {トランジション名}」
├── InstructionCard（作業指示の表示）
└── [確認完了] ボタン → DataRecordDialog を開く

DataRecordDialog
├── テンプレート選択
├── データ入力フォーム
├── ステータス選択
├── コメント入力
└── [記録] ボタン
```
