## 11. 重要な発見

### 📌 構造的な違い

1. **UIライブラリの選択**
   - V2版: Material-UI（MUI）
   - 現行版: Ant Design v6
   - これがスタイリングコードの大きな違いの原因

2. **State管理の違い**
   - V2版: viewMode（ビュー切替）
   - 現行版: editorMode（エディタモード）+ categorizedTemplates（テンプレートState分離）
   - 実装方法が異なるが、機能は同等

3. **テンプレート管理**
   - V2版: TemplateContext使用（window.cline*関数でアクセス）
   - 現行版: TemplateProvider + useMemo最適化
   - 現行版のほうが洗練されている

4. **エラー処理**
   - V2版: criticalErrors / nonCriticalErrors分類
   - 現行版: 同じ分類 + applyErrorVisualization関数
   - 実装方法は似ている

### 📌 機能差異

1. **アーク属性表示トグル**
   - V2版: なし
   - 現行版: `showArcLabels` State + useEffect
   - 現行版で追加された機能

2. **SaveDialog（旧版）**
   - V2版: SaveDialog + SaveConfirmDialog両方あり
   - 現行版: SaveConfirmDialogのみ
   - 現行版で統合・簡略化

3. **Document補完機能**
   - V2版: なし
   - 現行版: `fillMissingDocumentFields`関数
   - 現行版で追加された機能
