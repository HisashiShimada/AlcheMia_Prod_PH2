## 1. タスク概要

フォーマット管理画面で使用するフォーマット一覧取得APIを実装します。現在はモックデータを返していますが、実際にS3ストレージから`{organization_id}/formats/{department_cd}/`直下のフォルダ一覧を取得する実装に変更します。

**重要**: 
- 実際のS3構造: `{organization_id}/formats/{department_cd}/condition/` など（organization_idはUUID）
- ログインユーザーの所属部門（department_cd）配下のフォルダのみを表示
- `material/`, `condition/`, `result/`などのテンプレートフォルダと、複数のMAIMLワークフローフォルダが存在

## 6.5. 実装の重要ポイント

### S3フォルダ一覧取得（Service層）

```typescript
// formatService.ts
import { getStorageService } from '@/services/storageService';

interface FormatFolder {
  id: string;
  name: string;
  folderName: string;
  description: string;
  fileCount: number;
  fileType: 'xml' | 'maiml';
  category: string;
  department: string;
  createdAt: string;
  updatedAt: string;
  tags: string[];
}

async getFormatFolders(
  organizationId: string,
  departmentCd: string,
  fileTypeFilter?: 'all' | 'xml' | 'maiml'
): Promise<FormatFolder[]> {
  const storageService = getStorageService();
  
  try {
    // 1. S3の formats/{department_cd}/ 直下のすべてのファイル/フォルダを取得
    const basePath = `formats/${departmentCd}`;
    const allItems = await storageService.listFiles(organizationId, basePath);
    
    // 2. フォルダのみを抽出（重複排除）
    const folderSet = new Set<string>();
    allItems.forEach(item => {
      // formats/{dept_cd}/xxx/... から xxx 部分（フォルダ名）を抽出
      const pathParts = item.key.split('/');
      if (pathParts.length >= 3 && 
          pathParts[0] === 'formats' && 
          pathParts[1] === departmentCd) {
        folderSet.add(pathParts[2]);
      }
    });
    
    // 3. 各フォルダの情報を取得
    const folders: FormatFolder[] = await Promise.all(
      Array.from(folderSet).map(async (folderName) => {
        // フォルダ種別を判定
        const isTemplateFolder = ['material', 'condition', 'result'].includes(folderName.toLowerCase());
        const fileType = isTemplateFolder ? 'xml' : 'maiml';
        
        // ファイル数を取得
        let fileCount = 0;
        try {
          const files = await storageService.listFiles(
            organizationId, 
            `formats/${departmentCd}/${folderName}`
          );
          fileCount = files.length;
        } catch (error) {
          console.error(`Failed to count files in ${folderName}:`, error);
          fileCount = 0;
        }
        
        // 説明文を生成
        let description = '';
        let category = '';
        if (isTemplateFolder) {
          const templateType = folderName.charAt(0).toUpperCase() + folderName.slice(1);
          description = `${templateType}テンプレート`;
          category = 'template';
        } else {
          description = `${folderName}ワークフロー`;
          category = 'workflow';
        }
        
        return {
          id: folderName,
          name: folderName,
          folderName: folderName,
          description,
          fileCount,
          fileType,
          category,
          department: '',
          createdAt: new Date().toISOString(),
          updatedAt: new Date().toISOString(),
          tags: [category, folderName]
        };
      })
    );
    
    // 4. ファイルタイプでフィルタリング
    let filteredFolders = folders;
    if (fileTypeFilter && fileTypeFilter !== 'all') {
      filteredFolders = folders.filter(f => f.fileType === fileTypeFilter);
    }
    
    // 5. ソート（テンプレートフォルダを先頭、その後はアルファベット順）
    filteredFolders.sort((a, b) => {
      if (a.category === 'template' && b.category !== 'template') return -1;
      if (a.category !== 'template' && b.category === 'template') return 1;
      return a.name.localeCompare(b.name);
    });
    
    return filteredFolders;
  } catch (error) {
    console.error('Failed to get format folders:', error);
    throw new Error('フォーマットフォルダ一覧の取得に失敗しました');
  }
}
```

### コントローラー層

```typescript
// formatController.ts
import { Request, Response } from 'express';
import { formatService } from '../services/formatService';
import { organizationRepository } from '../repositories/organizationRepository';

async getFormats(req: Request, res: Response): Promise<void> {
  try {
    // 1. ユーザー情報から組織IDを取得
    const organizationId = req.user.organizationId;
    
    // 2. セッションから部門CDを取得
    const departmentCd = req.session?.departmentCd;
    
    // 3. department_cdの検証
    if (!departmentCd) {
      res.status(401).json({
        success: false,
        error: {
          code: 'SESSION_EXPIRED',
          message: 'セッションが無効です。再ログインしてください。'
        }
      });
      return;
    }
    
    // 3. クエリパラメータ取得
    const fileType = (req.query.file_type as 'all' | 'xml' | 'maiml') || 'all';
    
    // 4. S3からフォーマットフォルダ一覧を取得
    const folders = await formatService.getFormatFolders(
      organizationId,   // organization_id（UUID）を直接使用
      departmentCd,     // 部門CD
      fileType
    );
    
    // 6. レスポンス返却
    res.json({
      success: true,
      data: {
        folders
      },
      meta: {
        timestamp: new Date().toISOString(),
        requestId: req.id
      }
    });
  } catch (error) {
    console.error('Error in getFormats:', error);
    
    // エラーハンドリング
    res.status(500).json({
      success: false,
      error: {
        code: 'SYSTEM_ERROR',
        message: 'フォーマット一覧の取得に失敗しました',
        details: process.env.NODE_ENV === 'development' ? (error as Error).message : undefined
      },
      meta: {
        timestamp: new Date().toISOString(),
        requestId: req.id
      }
    });
  }
}

export const formatController = {
  getFormats
};
```

### 計画からの変更点
1. **表示名生成処理の削除**
   - 当初計画していたフォルダ名から日本語表示名を生成する処理を削除
   - `name`と`folderName`は同じ値（英数字フォルダ名）を返すシンプルな実装に変更
   - 理由: ユーザーからの指示により、表示名生成は不要と判断

2. **権限チェックの実装方法**
   - 当初は`permissionCheck(['experiment_admin', 'system_admin'])`を想定
   - 実際には`checkPermission('040000', 0)`を使用（実験管理者メニュー、読み取り専用）
   - `permissionCheckMiddleware.ts`の仕様を確認して適切な実装に変更

3. **データベース不使用の確認**
   - 計画通りデータベースは使用せず、S3から直接フォルダ一覧を取得
   - 将来的なDB管理は Phase 2 以降で検討

### 発生した問題と解決方法
1. **TypeScriptエラー: req.user が undefined の可能性**
   - 問題: `req.user.organizationId`でTypeScriptエラー
   - 解決: Non-null assertion（`req.user!.organizationId`）を使用
   - 理由: authMiddlewareで検証済みのため安全

2. **TypeScriptエラー: req.id が存在しない**
   - 問題: `req.id`プロパティが型定義に存在しない
   - 解決: `req.headers['x-request-id']`を使用
