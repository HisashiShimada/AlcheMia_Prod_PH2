## 1. タスク概要

「進捗確認」タブと「実験記録」タブで以前実装したレスポンシブデザイン対応を削除し、画面横幅の最小を1024pxとして、テーブルの横スクロールが表示されないようにカラム幅を調整します。

- テーブルの横スクロールを削除し、全カラムが表示されるように調整

#### ProgressCheckTable.tsx

```typescript
// 削除対象
const [windowWidth, setWindowWidth] = useState<number>(...);

useEffect(() => {
  const handleResize = () => {
    setWindowWidth(window.innerWidth);
  };
  window.addEventListener('resize', handleResize);
  return () => window.removeEventListener('resize', handleResize);
}, []);

const isNarrowScreen = windowWidth <= 1400;

const getActionMenu = React.useCallback(...);

const actionColumn: ColumnsType<TableRow>[0] = {...};

// 条件分岐も削除
if (isNarrowScreen) {
  return [...baseColumns, actionColumn];
} else {
  return [...baseColumns, ...buttonColumns];
}
```

#### TransitionList.tsx
```typescript
// 削除対象
const [isNarrowScreen, setIsNarrowScreen] = useState(false);

useEffect(() => {
  const handleResize = () => {
    setIsNarrowScreen(window.innerWidth <= 1500);
  };
  handleResize();
  window.addEventListener('resize', handleResize);
  return () => window.removeEventListener('resize', handleResize);
}, []);

const getMenuItems = (record: Transition): MenuProps['items'] => {...};
```
