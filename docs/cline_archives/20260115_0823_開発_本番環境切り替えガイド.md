# 開発・本番環境切り替えガイド

## 概要

**作成日**: 2026-01-15  
**対象**: 開発者、システム管理者

mmdpfプロジェクトでは、開発環境と本番環境で異なるNginx設定を使用します：

- **開発環境**: HTTP-only（証明書不要、すぐに起動可能）
- **本番環境**: HTTPS + クライアント証明書認証（セキュア）

---

## 📁 ファイル構成

```
mmdpf/
├── docker-compose.yml              # 開発環境用（デフォルト）
├── docker-compose.prod.yml         # 本番環境用
├── config/nginx/
│   ├── nginx.dev.conf              # 開発用Nginx設定（HTTP-only）
│   ├── nginx.prod.conf             # 本番用Nginx設定（HTTPS + 証明書認証）
│   └── ssl.conf                    # SSL/TLS設定（本番環境で使用）
└── certs/                          # 証明書ディレクトリ（本番環境で必要）
    ├── generate-certs.ps1          # 証明書生成スクリプト（Windows）
    ├── generate-certificates.sh    # 証明書生成スクリプト（Linux/Mac）
    ├── ca/                         # CA証明書
    ├── server/                     # サーバー証明書
    └── clients/                    # クライアント証明書
```

## 🛠️ 開発環境での起動方法

### 特徴

- HTTPのみ（http://localhost）
- 証明書不要
- 即座に起動可能

### 起動手順

```bash
# 1. コンテナを起動（デフォルトでdocker-compose.ymlを使用）
docker-compose up -d

# 2. ブラウザでアクセス
# http://localhost
```

### 停止

```bash
docker-compose down
```

### ログ確認

```bash
# Nginxログ
docker logs mmdpf-nginx

# バックエンドログ
docker logs mmdpf-backend

# フロントエンドログ
docker logs mmdpf-frontend
```

## 🔒 本番環境での起動方法

### 前提条件

本番環境では証明書が必要です。証明書を事前に生成してください。

### 証明書生成

#### Windows（PowerShell）

```powershell
cd certs
.\generate-certs.ps1
```

#### Linux / macOS

```bash
cd certs
bash generate-certificates.sh
```

**生成される証明書:**
- `ca/ca.crt` - CA証明書（Nginx用）
- `server/server.crt` - サーバー証明書
- `server/server.key` - サーバー秘密鍵
- `clients/*.p12` - クライアント証明書（ブラウザインポート用）

### 本番環境用環境変数の設定

`backend/.env.production` ファイルを作成：

```env
# データベース
DB_HOST=postgres
DB_PORT=5432
DB_NAME=mmdpf_db
DB_USER=mmdpf_user
DB_PASSWORD=<本番用パスワード>

# JWT
JWT_SECRET=<本番用ランダム文字列>
SESSION_SECRET=<本番用ランダム文字列>

# Swift
SWIFT_AUTH_URL=<本番SwiftのURL>
SWIFT_ACCOUNT=<本番アカウント>
SWIFT_USER=<本番ユーザー>
SWIFT_PASSWORD=<本番パスワード>
```

### 起動手順

```bash
# 1. 本番環境用docker-compose.prod.ymlを使用して起動
docker-compose -f docker-compose.prod.yml up -d

# 2. ブラウザに証明書をインポート
# - clients/c9621ed65def49708e7ffbe97c98e3ed.p12 をインポート
# - パスワード: mmdpf123

# 3. ブラウザでアクセス
# https://localhost または https://<your-domain>
```

### 停止

```bash
docker-compose -f docker-compose.prod.yml down
```

## 🔄 環境の切り替え

### 開発環境から本番環境へ

```bash
# 1. 開発環境を停止
docker-compose down

# 2. 証明書を生成（初回のみ）
cd certs
.\generate-certs.ps1  # Windows
# または
bash generate-certificates.sh  # Linux/Mac

# 3. 本番環境を起動
docker-compose -f docker-compose.prod.yml up -d
```

### 本番環境から開発環境へ

```bash
# 1. 本番環境を停止
docker-compose -f docker-compose.prod.yml down

# 2. 開発環境を起動
docker-compose up -d
```

## 📋 Nginx設定の違い

### 開発環境（nginx.dev.conf）

```nginx
server {
    listen 80;        # HTTPのみ
    server_name localhost;
    
    # 証明書認証なし
    # 直接プロキシ
}
```

### 本番環境（nginx.prod.conf）

```nginx
# HTTPからHTTPSへリダイレクト
server {
    listen 80;
    return 301 https://$host$request_uri;
}

# HTTPS + クライアント証明書認証
server {
    listen 443 ssl http2;
    
    # SSL証明書
    ssl_certificate /etc/nginx/certs/server/server.crt;
    ssl_certificate_key /etc/nginx/certs/server/server.key;
    
    # クライアント証明書検証（必須）
    ssl_client_certificate /etc/nginx/certs/ca/ca.crt;
    ssl_verify_client on;
    
    # 組織IDをヘッダーで渡す
    proxy_set_header X-Organization-Id $org_id;
}
```

## 🔐 クライアント証明書のインポート方法

### Windows（Chrome, Edge）

1. `clients/<organization_id>.p12` ファイルをダブルクリック
2. 証明書のインポート ウィザードで「現在のユーザー」を選択
3. パスワード入力: `mmdpf123`
4. 証明書ストア: **個人**
5. インポート完了

### macOS（Safari, Chrome）

```bash
# キーチェーンに追加
open clients/c9621ed65def49708e7ffbe97c98e3ed.p12
```

1. パスワード入力: `mmdpf123`
2. キーチェーンアクセスで証明書を確認
3. 証明書を右クリック → **情報を見る**
4. **信頼** → **この証明書を使用するとき**: **常に信頼**

### Firefox

1. メニュー → **設定** → **プライバシーとセキュリティ**
2. **証明書** → **証明書を表示**
3. **あなたの証明書** タブ → **インポート**
4. `.p12` ファイルを選択
5. パスワード入力: `mmdpf123`

## ⚠️ トラブルシューティング

### 開発環境でNginxが起動しない

**エラー:** `cannot load certificate`

**原因:** 誤って本番環境用設定を使用している

**解決策:**
```bash
# docker-compose.ymlを確認
# nginx.dev.confがマウントされているか確認
docker-compose down
docker-compose up -d
```

### 本番環境で証明書エラー

**エラー:** `cannot load certificate "/etc/nginx/certs/server/server.crt"`

**原因:** 証明書が生成されていない

**解決策:**
```bash
# 証明書を生成
cd certs
.\generate-certs.ps1  # Windows
# または
bash generate-certificates.sh  # Linux/Mac

# コンテナを再起動
docker-compose -f docker-compose.prod.yml restart nginx
```

### ブラウザで証明書が認識されない

**確認事項:**
1. `.p12` ファイルが正しくインポートされているか
2. パスワード `mmdpf123` が正しく入力されているか
3. ブラウザを再起動したか
4. HTTPSでアクセスしているか（`https://localhost`）
