## 1. タスク概要

「実験データ記録」モーダルにおいて、テンプレート一覧から任意のテンプレートを選択し、選択したテンプレートのプロパティのみを表示・入力できるようにする機能を追加する。

## 2. 目的と期待される成果

### 目的

- テンプレートごとに個別に保存できるようにする
- ユーザビリティの向上

### 期待される成果
- [x] テンプレート一覧から任意のテンプレートを選択できる（単一選択）
