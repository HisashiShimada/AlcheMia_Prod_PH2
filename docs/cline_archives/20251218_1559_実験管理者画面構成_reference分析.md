**作成日**: 2024-12-18 15:59

## 1. 画面遷移フロー

### 1.1. 認証からメイン画面まで

```
[ログイン画面]
    ↓ 認証成功
[組織選択画面] ※複数組織に所属する場合のみ
    ↓ 組織選択
[ログイン後の最初の画面]
    ├─ Organization情報バー（固定ヘッダー）
    ├─ AppHeader（アプリケーションヘッダー）
    ├─ 左ペイン：FileExplorer（ファイル一覧）
    └─ 右ペイン：ViewRenderer（ファイルビューアー）
```

**注記**: ログイン直後は**ファイルビューアー画面**が表示されます。実験管理システムのタブ画面（ファイル管理・進捗管理・作業者管理）は、AppHeaderの「実験管理」ボタンをクリックした後に表示されます。

### 1.2. モード切り替え

実験管理者は以下のモードを切り替え可能：

- **管理者モード** (Manager Mode): ファイル管理・進捗管理・作業者管理
- **作業者モード** (Worker Mode): 実験記録作業
- **システム管理モード** (Admin Mode): ユーザー管理・セッション管理（権限がある場合）

### 2.2. AppHeaderの機能ボタン

実験管理者が使用できる主要なボタン：

1. **実験管理ボタン**
   - クリック → ExperimentManagerへ遷移
   - タブ画面（ファイル管理・進捗管理・作業者管理）を表示

2. **実験記録ボタン**
   - クリック → WorkerDashboardへ遷移
   - 作業者モードに切り替え

3. **編集ボタン**
   - クリック → PetriNetEditorV2起動
   - MAIMLファイルの編集

4. **デバッグボタン**
   - デバッグ情報の表示/非表示

5. **再読込ボタン**
   - ファイル一覧の再読み込み

### 2.3. フローティングボタン（右下固定）

- **🔬 作業者モード**: 作業者モードに切り替え
- **👑 システム管理**: システム管理画面を表示（権限がある場合のみ）
- **🔓 ログアウト**: ログアウト

## 9. セキュリティ考慮事項

### 9.1. マルチテナント分離

- すべてのAPIリクエストに`organizationId`を含める
- クライアント側でもorganization_idをチェック
- S3パスに`org_{organization_id}`プレフィックスを使用

### 9.2. 権限チェック

- システム管理ボタンは権限がある場合のみ表示
- APIレベルでの権限検証
- 作業者モードは一般ユーザーに制限
