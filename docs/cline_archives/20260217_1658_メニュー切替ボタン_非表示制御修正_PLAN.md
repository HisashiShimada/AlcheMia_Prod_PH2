## 1. タスク概要

メニュー切替ボタンのドロップダウンメニューの表示制御を改善します。

### 現状の仕様
- 権限のあるすべてのメニューがドロップダウンに表示される
- 現在開いているメニューは`disabled`（非活性）状態になる
- メニューが0件でもメニュー切替ボタンは常に表示される

### 要望される変更
1. **現在開いているメニューを非表示にする**
   - `disabled`（グレーアウト）ではなく、リストから除外する
2. **切り替え可能なメニューが0件の場合、ボタンそのものを非表示にする**
   - 権限のあるメニューが1つだけの場合は、切り替える先がないのでボタンを非表示

## 2. 目的と期待される成果

### 目的
- ユーザビリティの向上（不要な選択肢を表示しない）
- UI/UXの改善（切り替え不可能な場合はボタンを非表示）

### 期待される成果
- [x] 現在のメニューがドロップダウンに表示されない
- [x] 切り替え可能なメニューが0件の場合、メニュー切替ボタンが非表示になる
- [x] 既存の動作を維持（権限チェック、メニュー切り替え機能）

## 3. 実装ステップ

  - 条件: `onMenuChange` が定義されている場合のみ表示

## 5. 技術的詳細

### 変更前のロジック（現状）
```typescript
// 権限のあるメニューのみをフィルタリング & disabled設定
const menuItems: MenuProps['items'] = allMenuItems
  .filter(item => hasMenuPermission(userPermissions, item.menuType))
  .map(item => ({
    key: item.key,
    label: item.label,
    icon: item.icon,
    disabled: currentMenu === item.menuType,  // ← 現在のメニューを非活性に
    onClick: () => onMenuChange?.(item.menuType),
  }));
```

### 変更後のロジック（新仕様）
```typescript
// 権限のあるメニューのみをフィルタリング & 現在のメニューを除外
const menuItems: MenuProps['items'] = allMenuItems
  .filter(item => 
    hasMenuPermission(userPermissions, item.menuType) &&
    currentMenu !== item.menuType  // ← 現在のメニューを除外
  )
  .map(item => ({
    key: item.key,
    label: item.label,
    icon: item.icon,
    // disabled プロパティは削除
    onClick: () => onMenuChange?.(item.menuType),
  }));
```

### メニュー切替ボタンの表示条件
```typescript
{/* 右側: アクションボタン + メニュー切り替え */}
{(actions || (onMenuChange && menuItems.length > 0)) && (
  <ActionsWrapper hasTabs={!!hasTabs} token={token}>
    <Space size="small">
      {actions}
      {onMenuChange && menuItems.length > 0 && (  // ← 追加条件
        <Dropdown
          menu={{ items: menuItems }}
          trigger={['click']}
          placement="bottomRight"
          // ... 省略
        >
          <Button>メニュー切替</Button>
        </Dropdown>
      )}
    </Space>
  </ActionsWrapper>
)}
```

### アーキテクチャ上の考慮事項
- フィルタリングは純粋関数として実装（副作用なし）
- `menuItems.length`のチェックでボタンの表示/非表示を制御
- 既存のコンポーネントAPIは変更しない（Props互換性を維持）

### セキュリティ考慮事項
- [x] 権限チェックは既存のまま維持（`hasMenuPermission`）
- [x] クライアント側でのフィルタリングのみ（サーバー側でも権限検証されている）
- [x] メニュー表示制御はUI改善のみ（セキュリティへの影響なし）
