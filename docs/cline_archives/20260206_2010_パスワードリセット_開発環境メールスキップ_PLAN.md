#### 修正後の実装
```typescript
// 4. メール送信（開発環境ではスキップ）
if (process.env.NODE_ENV !== 'development') {
  const emailResult = await emailService.sendTempPassword(
    user.mail_address,
    tempPassword,
    user.user_name
  );

  if (!emailResult.success) {
    res.status(500).json({
      success: false,
      error: {
        code: 'SYSTEM_EMAIL_SEND_FAILED',
        message: 'メール送信に失敗しました。しばらく待ってから再試行してください',
      },
      meta: {
        timestamp: new Date().toISOString(),
        requestId,
      },
    });
    return;
  }
}

console.log(`[INFO] 一時パスワード発行: user_id=${user.user_id}, expires_at=${new Date(Date.now() + 24*60*60*1000).toISOString()}`);
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 本番環境で誤って一時パスワードを返す | 高 | 低 | NODE_ENV厳密チェック、コードレビュー |
| 情報漏洩（ユーザー存在確認） | 中 | 低 | ユーザー不存在時は一時パスワードを返さない |
