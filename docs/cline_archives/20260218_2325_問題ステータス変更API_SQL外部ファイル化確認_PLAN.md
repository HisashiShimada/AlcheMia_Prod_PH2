## 5. 技術的詳細

### 対象API
- **エンドポイント**: `PATCH /api/v1/issues/status`
- **機能**: 問題報告のステータスを「未解決 (unresolved)」または「解決済 (resolved)」に変更

### 使用技術・ライブラリ
- **pg-promise**: PostgreSQL接続とクエリ実行
- **loadSqlFile()**: 外部SQLファイル読み込みユーティリティ
- **getPgp()**: pg-promiseインスタンス取得

### 参考実装
- `backend/src/repositories/departmentRepository.ts`: pg-promise使用の模範例
- `backend/src/database/db.ts`: データベース接続管理
