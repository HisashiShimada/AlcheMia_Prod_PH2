## 1. タスク概要

現在のMaiml編集画面（PetriNetEditor）は、ペトリネット編集エリアとテンプレート編集ダイアログが分離されていますが、reference版ではトグルボタンで「ペトリネット修正モード」と「テンプレート修正モード」を切り替える構成になっています。

ユーザーの要求に基づき、reference版のレイアウトを踏襲した構成に変更します。

## 2. 目的と期待される成果

### 目的
- reference版と同じUI/UXを実現
- トグルボタンによるモード切替で、ペトリネット編集とテンプレート編集を統合
- より直感的で使いやすい編集画面を提供

### 問題点
- テンプレート編集が**モーダルダイアログ**で別画面になる
- ペトリネット全体を見ながらテンプレートを編集できない
- reference版の「トグルで切り替え」というUXと異なる

## 4. Reference版の構成（推定）

ユーザーの説明から推定されるreference版の構成：

```
Maiml編集画面
├── ツールバー
│   └── 【トグルボタン】ペトリネット修正 ⇔ テンプレート修正
│
├── ペトリネット修正モード（デフォルト）
│   ├── ReactFlow（フル表示）
│   ├── ノード追加ツール
│   ├── PropertyPanel（ノード選択時）
│   └── 編集操作全般
│
└── テンプレート修正モード
    ├── テンプレート一覧（左側または全画面）
    ├── テンプレート詳細編集エリア（右側）
    └── プロパティ編集フォーム
```

### 特徴
- **トグルボタン**で2つのモードを明示的に切り替え
- テンプレート修正モードでは、ReactFlowエリアをテンプレート編集UIに置き換え
- モーダルダイアログではなく、同一画面内でモード切替

  const [editMode, setEditMode] = useState<EditMode>('petri-net');
  
  // モード切替ハンドラー
  const handleEditModeChange = useCallback((mode: EditMode) => {
    console.log('🔄 [PetriNetEditor] モード切替:', mode);
    setEditMode(mode);
    
    // テンプレート修正モードに切り替える時、選択状態をクリア
    if (mode === 'template') {
      setSelectedNode(null);
      setSelectedEdge(null);
    }

  return (
    <Flex vertical style={{ height: '100%' }}>
      <EditorToolbar
        editMode={editMode}
        onEditModeChange={handleEditModeChange}
        // 既存のprops
      />
      
      {editMode === 'petri-net' ? (
        // ペトリネット修正モード（既存のReactFlow）

          <MethodTabPanel ... />

            <ReactFlow ... />
            {/* PropertyPanel */}
            {/* TemplateListView */}

        // テンプレート修正モード（新規）

### Phase 4: EditorToolbarの修正

#### 4.1 トグルボタンの追加
```typescript
// EditorToolbar.tsx
export interface EditorToolbarProps {
  editMode?: 'petri-net' | 'template';
  onEditModeChange?: (mode: 'petri-net' | 'template') => void;
  // 既存のprops
}

const EditorToolbar: React.FC<EditorToolbarProps> = ({
  editMode = 'petri-net',
  onEditModeChange,
  // ...
}) => {
  return (
    <div style={{ ... }}>
      {/* トグルボタン（最優先表示） */}
      {onEditModeChange && (
        <Space size="small">
          <Button
            type={editMode === 'petri-net' ? 'primary' : 'default'}
            onClick={() => onEditModeChange('petri-net')}
          >
            ペトリネット修正
          </Button>
          <Button
            type={editMode === 'template' ? 'primary' : 'default'}
            onClick={() => onEditModeChange('template')}
          >
            テンプレート修正
          </Button>
        </Space>
      )}
      
      <Divider type="vertical" />
      
      {/* 既存のボタン群（モードに応じて表示切替） */}
      {editMode === 'petri-net' && (
        <Space size="small">
          {/* ノード追加ボタン */}
          {/* Undo/Redo */}
        </Space>
      )}
      
      {/* 共通ボタン */}
      <Space size="small">
        <Button onClick={onSave}>保存</Button>
        <Button onClick={onValidate}>バリデーション</Button>
      </Space>
    </div>
  );
};
```

### Phase 6: 状態管理の改善

#### 6.1 テンプレート編集中の状態保持
```typescript
// テンプレート修正モードで編集中のデータを保持
const [editingTemplateData, setEditingTemplateData] = useState<any>(null);

// モード切替時に編集中データを保存
const handleEditModeChange = useCallback((mode: EditMode) => {
  if (mode === 'petri-net' && editingTemplateData) {
    // 編集中のテンプレートデータをノードに反映
    handleUpdateNodeProperty(editingTemplateData.nodeId, editingTemplateData.data);
    setEditingTemplateData(null);
  }
  setEditMode(mode);
}, [editingTemplateData, handleUpdateNodeProperty]);
```
