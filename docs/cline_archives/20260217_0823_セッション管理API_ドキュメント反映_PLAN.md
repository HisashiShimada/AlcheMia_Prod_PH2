## 5. 技術的詳細

### セッション管理API仕様

#### 5.1. GET /api/v1/sessions
- **目的**: System Adminが自組織のアクティブセッション一覧を取得
- **権限**: System Admin必須
- **マルチテナント分離**: organization_idで自組織のみ取得
- **レスポンス形式**: 
  - セッション一覧（user_id, username, email, role, login_at, expires_at, ip_address, user_agent）
  - ページネーション対応（page, limit, total）
  - ソート対応（login_at降順がデフォルト）
  - フィルタ対応（role, username）

#### 5.2. DELETE /api/v1/sessions/:tokenId
- **目的**: System Adminが特定のセッションを強制終了
- **権限**: System Admin必須
- **マルチテナント分離**: organization_idで自組織のセッションのみ終了可能
- **制約**: 自分自身のセッションは終了不可
- **パラメータ**: tokenId（UUID形式）
