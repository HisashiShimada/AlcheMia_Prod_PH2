## 1. タスク概要

フォーマット管理画面でサブフォルダ内にサブフォルダを作成すると、作成したフォルダが表示されない問題を修正する。ファイルを作成した場合は正常に表示されるため、その処理を参考にして修正を行う。

### 目的

- ファイル作成時と同様の動作を実現する

### 期待される成果
- [ ] サブフォルダ作成後、作成したフォルダが即座に表示される
- [ ] ファイル作成と同じ動作に統一される

## 4. 影響範囲

### 調査対象ファイル
1. `frontend/src/components/project/FormatManagement.tsx` - フォーマット管理画面メインコンポーネント

### 問題箇所
**ファイル**: `frontend/src/components/project/FormatManagement.tsx`  
**行数**: 992-1021行目（`handleCreateFormatFolder`関数内）

**問題の詳細:**
サブフォルダ作成後のファイル一覧更新処理で、常にルートのファイル（`fetchFormatFiles(selectedFormatId, undefined)`）を取得しているため、サブフォルダ内で作成したフォルダが現在の表示に反映されない。

```typescript
// ❌ 問題のコード
const fileResponse = await fetchFormatFiles(selectedFormatId, undefined); // 常にルート
setFormatFilesData(prev => ({
  ...prev,
  [selectedFormatId]: {  // 常にルートのキー
    allFiles: ...
  }
}));
```

キャッシュキーも現在のパスを考慮していないため、サブフォルダ内のファイル一覧が更新されません。

### 修正するファイル
1. `frontend/src/components/project/FormatManagement.tsx`
   - `handleCreateFormatFolder`関数のファイル一覧更新処理
   - `handleCreateFormatFile`関数のファイル一覧更新処理（同じ問題）
