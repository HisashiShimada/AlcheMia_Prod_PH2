## 1. タスク概要

組織（organization）ごとにPINコード入力を一定期間免除できる機能を実装します。組織に設定されたPINコード免除期間（日数）に基づいて、ユーザーは設定された期間内であればPINコード認証をスキップして直接ログインできます。

**注意**: 本フェーズでは設定画面は実装せず、データベーススキーマ追加とログイン時の免除判定機能のみを実装します。設定値はマイグレーションまたはデータベースへの直接挿入で管理します。

### 主な機能
- 組織ごとにPINコード免除期間を設定（0〜365日、0日=免除なし）
- 最終ログイン日時からの経過日数で自動判定
- セキュリティを考慮した適切な実装

### 免除判定ロジック

```typescript
// PinExemptionService.isExemptionApplicable()
async isExemptionApplicable(
  userId: string,
  organizationId: string
): Promise<Result<PinExemptionCheck>> {
  // 1. 組織の免除設定を取得
  const settings = await organizationRepository.getPinExemptionSettings(organizationId);
  
  // 免除期間が0日の場合は免除なし
  if (settings.periodDays === 0) {
    return {
      success: true,
      data: {
        isExempt: false,
        daysSinceLastLogin: null,
        exemptionPeriodDays: 0,
        reason: 'Exemption period is 0'
      }
    };
  }
  
  // 2. 最終ログイン日時を取得
  const lastLogin = await loginHistoryRepository.getLastSuccessfulLogin(
    userId,
    organizationId
  );
  
  if (!lastLogin) {
    return {
      success: true,
      data: {
        isExempt: false,
        daysSinceLastLogin: null,
        exemptionPeriodDays: settings.periodDays,
        reason: 'No previous login history'
      }
    };
  }
  
  // 3. 経過日数を計算
  const daysSince = this.calculateDaysSinceLastLogin(lastLogin.login_at);
  
  // 4. 免除期間内かどうかを判定
  const isExempt = daysSince <= settings.periodDays;
  
  return {
    success: true,
    data: {
      isExempt,
      daysSinceLastLogin: daysSince,
      exemptionPeriodDays: settings.periodDays,
      reason: isExempt ? 'Within exemption period' : 'Exemption period expired'
    }
  };
}

private calculateDaysSinceLastLogin(lastLoginAt: Date): number {
  const now = new Date();
  const diffMs = now.getTime() - lastLoginAt.getTime();
  const diffDays = Math.floor(diffMs / (1000 * 60 * 60 * 24));
  return diffDays;
}
```
