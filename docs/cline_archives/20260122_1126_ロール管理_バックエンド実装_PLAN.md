### データ取得SQL設計

#### 最適化されたSQL（1回のクエリで取得）
```sql
SELECT
    r.role_id,
    r.role_name,
    r.is_active,
    rp.function_id,
    rp.permission,
    cm_func.code_name as function_name,
    cm_perm.code_name as permission_name
FROM 
    role r
LEFT JOIN
    role_permission rp
    ON r.organization_id = rp.organization_id
    AND r.role_id = rp.role_id
LEFT JOIN
    code_master cm_func
    ON r.organization_id = cm_func.organization_id
    AND cm_func.code_division = 'role_function'
    AND rp.function_id = cm_func.code_value
LEFT JOIN
    code_master cm_perm
    ON r.organization_id = cm_perm.organization_id
    AND cm_perm.code_division = 'role_function_permission'
    AND CAST(rp.permission AS VARCHAR) = cm_perm.code_value
WHERE
    r.organization_id = $1
ORDER BY
    r.role_id, rp.function_id;
```

### レスポンス形式
```typescript
{
  success: true,
  data: [
    {
      roleId: "system_admin",
      roleName: "システム管理",
      isActive: true,
      functionName: "システム管理/ユーザー管理/データ管理",
      functionWritePermissions: "システム管理/ユーザー管理/データ管理",
      updatedAt: "2026-01-22T10:00:00Z"
    }
  ],
  meta: {
    timestamp: "2026-01-22T11:26:00Z",
    requestId: "req_abc123"
  }
}
```

### データ集約ロジック
1. SQLで取得した行データをrole_idごとにグループ化
2. 各ロールに対して：
   - permission === 2（書き込み権限）の場合、functionWritePermissionsに追加
   - すべてのfunction_nameをfunctionNameに追加
   - "/"で連結して文字列化
