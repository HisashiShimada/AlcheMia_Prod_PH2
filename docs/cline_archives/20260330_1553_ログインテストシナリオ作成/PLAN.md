## スコープ外（除外項目）

| 除外対象 | 除外理由 |
|---------|---------|
| クライアント証明書エラー画面 | nginx層で制御されるためPlaywrightでは再現困難 |
| PINコード有効期限切れ（タイマー00:00） | 5分待機が必要なため自動テストに不向き |
| PINコード再送信の制限超過 | クールダウン待ちが必要なため |
| パスワードリセット | ログイン画面にリンクが存在するかどうか設計書に記載なし |
| 新規ユーザー登録画面 | UI設計書で「将来実装」と明記 |
| mi_engineer ロールのログイン後遷移 | 本プロジェクトのスコープ外（保留扱い） |

## リスク

| リスク | 対策 |
|--------|------|
| is_entry=0 の組織データが未用意 | テスト実行前にDBへ手動挿入する手順を前提条件に明記 |

| PINコード取得がメール依存 | 二段階認証ありの自動テスト（0-2-1, 0-2-2）はテスト環境でのメールモック前提と明記 |
