## 1. 調査概要

ログイン時のPINコード送信機能と再送信機能で重複しているコードを調査し、共通化の可能性を検証しました。

## 2. 調査結果

### 2.1. 重複コードの特定

**ログイン機能（authController.login）:**
```typescript
// PINコード生成
const pinResult = await pinCodeService.generateAndSave(...);
// メール送信
const emailResult = await emailService.sendPinCode(...);
// エラーハンドリング
// レスポンス生成（マスキング処理含む）
```

**再送信機能（authController.resendPin）:**
```typescript
// PINコード生成
const pinResult = await pinCodeService.generateAndSave(...);
// メール送信
const emailResult = await emailService.sendPinCode(...);
// エラーハンドリング
// レスポンス生成（マスキング処理含む）
```

**重複箇所:**
- PINコード生成処理（約10行）
- メール送信処理（約10行）
- エラーハンドリング（約20行）
- メールアドレスマスキング処理（約5行）

**合計: 約45行の重複コード**

### 2.2. 共通化の可能性

✅ **共通化可能**

両関数は以下の同じ処理フローを持っています：

1. PINコード生成（`pinCodeService.generateAndSave`）
2. メール送信（`emailService.sendPinCode`）
3. エラーハンドリング（DB・メールエラー）
4. レスポンス生成（マスキング処理）

### 4.3. 開発環境での動作

**重要:** 開発環境（`NODE_ENV=development`）では、以前の動作を維持するため、メール送信をスキップします。

```typescript
// authController.ts
const emailServiceForPin = process.env.NODE_ENV === 'development' ? undefined : emailService;
const pinCodeService = new PinCodeService(pool, emailServiceForPin);
```

**動作:**
- **開発環境**: メール送信なし、PINコードはレスポンスに含まれる
- **本番環境**: メール送信あり、PINコードはレスポンスに含まれない
