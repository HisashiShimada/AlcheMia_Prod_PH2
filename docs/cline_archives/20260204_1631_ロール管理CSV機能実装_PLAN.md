## 5. 技術的詳細

### CSV形式仕様

#### ダウンロード時のCSV構造
```csv
role_cd,role_name,function_cd,permission,initial_screen_function_cd,is_active,update_at
ROLE003,データ管理者,データ管理者メニュー,Ⓦ,データ管理者メニュー,true,2026/1/30 10:00
ROLE003,データ管理者,実験管理者メニュー,Ⓡ,データ管理者メニュー,true,2026/1/30 10:00
```

**特徴:**
- 1ロールに対して複数行（権限の数だけ行が存在）
- role_cd, role_name, initial_screen_function_cd, is_active, update_atは各行で同じ値
- function_cdとpermissionが各行で異なる

#### 列の詳細定義

| 列名 | 型 | 説明 | 変換ルール |
|------|-----|------|-----------|
| role_cd | String | ロールCD | そのまま |
| role_name | String | ロール名 | そのまま |
| function_cd | String | 機能名（日本語） | DB: "010000" → CSV: "プロバイダーメニュー" |
| permission | String | 権限記号 | DB: 0 → CSV: "Ⓦ", DB: 1 → CSV: "Ⓡ" |
| initial_screen_function_cd | String | 初期画面機能名（日本語） | DB: "030000" → CSV: "データ管理者メニュー" |
| is_active | Boolean | アクティブ状態 | true/false |
| update_at | String | 更新日時 | "YYYY/M/D H:mm" 形式 |

### データ変換ロジック

#### Enum定義（roleFunctionPermission.enum.ts）
```typescript
export enum FunctionList {
  "010000" = "プロバイダーメニュー",
  "020000" = "システム管理者メニュー",
  "030000" = "データ管理者メニュー",
  "040000" = "実験管理者メニュー",
  "050000" = "実験作業者メニュー",
}

export enum PermissionList {
  WRITER = "Ⓦ",
  READER = "Ⓡ",
}
```

#### 変換関数
```typescript
// ダウンロード時: CD → 名前
function getFunctionName(functionCd: string): string {
  return FunctionList[functionCd] || functionCd;
}

function getPermissionSymbol(permission: number): string {
  return permission === 0 ? PermissionList.WRITER : PermissionList.READER;
}

// アップロード時: 名前 → CD
function getFunctionIdByName(functionName: string): string | null {
  const entries = Object.entries(FunctionList);
  const found = entries.find(([, value]) => value === functionName);
  return found ? found[0] : null;
}

function getPermissionCode(symbol: string): number {
  return symbol === PermissionList.WRITER ? 0 : 1;
}
```

#### CSV内重複チェック
```typescript
const roleCdSet = new Set<string>();
for (const row of rows) {
  const roleCd = row['role_cd'];
  if (roleCdSet.has(roleCd)) {
    errors.push({
      row: rowNumber,
      field: 'role_cd',
      message: `${rowNumber}行目: role_cd「${roleCd}」はCSV内で重複しています`
    });
    break;
  }
  roleCdSet.add(roleCd);
}
```
