## 5. 技術的詳細

### API仕様

**エンドポイント:**
```
POST /api/v1/formats/:folderName/files
```

**リクエストパラメータ:**
```typescript
// URLパラメータ
folderName: string  // 例: "chemistry", "biology"

// リクエストボディ
{
  fileName: string;              // 拡張子なし、1-100文字
  fileType: 'xml';
  templateType: 'material' | 'condition' | 'result';
  description?: string;          // 0-500文字
}
```

**レスポンス（成功時）:**
```typescript
{
  success: true;
  data: {
    filePath: string;     // S3パス（例: "formats/dept_001/material/sample.xml"）
    fileName: string;     // ファイル名（例: "sample.xml"）
    fileType: string;     // 'xml'
    size: number;         // ファイルサイズ（バイト）
    createdAt: string;    // 作成日時（ISO 8601形式）
  };
}
```

**レスポンス（エラー時）:**
```typescript
{
  success: false;
  error: {
    code: string;         // 例: "FILE_EXISTS", "INVALID_FILENAME"
    message: string;      // ユーザー向けメッセージ
    details?: object;     // 詳細情報（開発用）
  };
}
```

### S3パス構築ロジック

```typescript
// コントローラー内での処理
const organizationId = req.organizationId;  // ミドルウェアで設定
const departmentCd = req.user.departmentCd;
const { fileName, templateType } = req.body;

// ファイル名のサニタイゼーション
const sanitizedFileName = fileName
  .replace(/\s+/g, '_')          // スペースを_に変換
  .replace(/[^a-zA-Z0-9_-]/g, '_'); // 英数字・_・-以外を_に変換

// S3パスの構築
const filePath = `formats/${departmentCd}/${templateType}/${sanitizedFileName}.xml`;

// storageServiceでアップロード（organization_idは自動付与）
await storageService.uploadFile(
  organizationId,
  filePath,
  xmlContent,
  { contentType: 'application/xml' }
);

// 実際のS3キー: {organizationId}/formats/{departmentCd}/{templateType}/{fileName}.xml
```

### バリデーションルール

**ファイル名:**
- 必須
- 1文字以上、100文字以内
- 英数字、アンダースコア、ハイフンのみ許可（サニタイゼーション後）
- 拡張子は含めない

**テンプレートタイプ:**
- 必須
- 'material', 'condition', 'result'のいずれか

**概要:**
- オプション
- 0-500文字
