## 🔧 技術的注意点

### 1. React Flow型定義
```typescript
import type { Node, Edge } from 'reactflow';
```
- ローカルでNode型を定義しない（競合を避ける）
- React FlowのNode型を直接使用する

### 2. setState in useEffect警告
```typescript
// ❌ 避ける（eslint警告）
useEffect(() => {
  setState(value);
}, [deps]);

// ✅ 推奨
useEffect(() => {
  // 条件付きで実行
  if (shouldUpdate) {
    setState(value);
  }
}, [deps, shouldUpdate]);
```

### 3. MultiObjectEditor使用方法
```typescript
<MultiObjectEditor
  title="Creators"
  items={creators}
  onAdd={(item) => setCreators([...creators, item])}
  onUpdate={(index, item) => {
    const updated = [...creators];
    updated[index] = item;
    setCreators(updated);
  }}
  onDelete={(index) => {
    setCreators(creators.filter((_, i) => i !== index));
  }}
  onReorder={(newOrder) => setCreators(newOrder)}
  fields={[
    { key: 'id', label: 'ID', type: 'text', required: true },
    { key: 'name', label: 'Name', type: 'text', required: true },
  ]}
/>
```

### 4. UUID生成
```typescript
const generateUuid = () => {
  return `urn:uuid:${crypto.randomUUID()}`;
};
```

### 5. DocumentData型定義
```typescript
// frontend/src/utils/documentParser.ts
export interface DocumentData {
  id: string;
  protocolId: string;
  methodId: string;
  pnmlId: string;
  programId: string;
  name: string;
  description: string;
  date: string;
  uuid: string;
  creators: Array<{ id: string; name: string }>;
  vendors: Array<{ id: string; name: string }>;
  owners: Array<{ id: string; name: string }>;
  instruments: Array<{ id: string; name: string; vendorRef?: string }>;
}
```
