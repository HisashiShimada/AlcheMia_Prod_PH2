## メタデータ
- **作成日時**: 2026-01-28 14:12
- **対象**: PetriNetEditor 現行版 vs Reference版
- **目的**: 実装済み機能の仕様差異を明確化

## 1. UIライブラリとコンポーネント

### Reference版
- **UIライブラリ**: Material-UI (MUI) v5
- **主要コンポーネント**:
  - `Box`, `Paper`, `Tabs`, `Tab`
  - `Button`, `IconButton`, `ButtonGroup`
  - `Dialog`, `DialogTitle`, `DialogContent`, `DialogActions`
  - `Tooltip`, `Chip`, `Alert`
  - `CircularProgress`

### 現行版
- **UIライブラリ**: Ant Design v6
- **主要コンポーネント**:
  - `Flex`, `Space`, `Layout`
  - `Button`, `Tabs`
  - `Modal`（Dialogの代替）
  - `Tooltip`, `Tag`, `Alert`
  - `Spin`

### 影響と対応

#### スタイリングの違い
```javascript
// Reference版（MUI）
<Box sx={{ 
  display: 'flex', 
  flexDirection: 'column',
  gap: 2,
  p: 2 
}}>

// 現行版（Ant Design）
<Flex 
  vertical 
  gap="middle" 
  style={{ padding: token.paddingLG }}
>
```

#### ダイアログの違い
```javascript
// Reference版（MUI Dialog）
<Dialog open={open} onClose={onClose} maxWidth="md" fullWidth>
  <DialogTitle>タイトル</DialogTitle>

    <Button onClick={onClose}>キャンセル</Button>
```

#### ボタングループの違い

## 2. ビューモード切替の実装方式

### Reference版: viewMode + savedPetriNetViewport

```javascript
const [viewMode, setViewMode] = useState('petriNet');
const [savedPetriNetViewport, setSavedPetriNetViewport] = useState(null);

// ビューモード切替時にビューポートを保存/復元
const handleViewModeChange = useCallback((newMode) => {
  if (newMode === 'templates' && viewMode === 'petriNet') {
    const currentViewport = getViewport();
    setSavedPetriNetViewport(currentViewport);
  }
  setViewMode(newMode);
}, [viewMode, getViewport]);

useEffect(() => {
  if (viewMode === 'petriNet' && savedPetriNetViewport) {
    setTimeout(() => {
      setViewport(savedPetriNetViewport, { duration: 300 });
    }, 100);
  }
}, [viewMode, savedPetriNetViewport, setViewport]);

// JSX - 条件分岐でReactFlowとTemplateListを切り替え
{viewMode === 'petriNet' ? (
  <ReactFlow ... />
) : (
  <TemplateList ... />
)}
```

### 現行版: editorMode（ビューポート保存なし）

```typescript
const [editorMode, setEditorMode] = useState<'petri-net' | 'template'>('petri-net');

// シンプルな切替（ビューポート保存なし）
const handleEditModeChange = (newMode: 'petri-net' | 'template') => {
  setEditorMode(newMode);
};

// JSX - 条件分岐でReactFlowとTemplateListを切り替え
{editorMode === 'petri-net' ? (
  <ReactFlow ... />
) : (
  <TemplateList ... />

```

### 主な差異

| 項目 | Reference版 | 現行版 |
|-----|------------|-------|
| State名 | `viewMode` | `editorMode` |
| 値 | `'petriNet'` / `'templates'` | `'petri-net'` / `'template'` |
| ビューポート保存 | ✅ あり | ❌ なし |
| アニメーション | ✅ あり（duration: 300） | ❌ なし |

### UX上の影響
- **Reference版**: モード切替後、元の位置・ズームに戻れる（UX良好）
- **現行版**: モード切替後、デフォルト位置にリセットされる（UX改善の余地）

### 推奨対応

## 5. 複数Method管理の実装詳細

### Reference版: 基本的な実装

```javascript
const [methods, setMethods] = useState([]);
const [activeMethodIndex, setActiveMethodIndex] = useState(0);
const [multiMethodMode, setMultiMethodMode] = useState(false);

// Method切り替え時の処理
const handleMethodTabChange = useCallback((newIndex) => {
  if (activeMethodIndex === newIndex) return;
  
  // 現在のMethodを保存
  const currentViewport = getViewport();
  setMethods(prevMethods => {
    const updated = [...prevMethods];
    updated[activeMethodIndex] = {
      ...updated[activeMethodIndex],
      nodes,
      edges,
      viewport: currentViewport,
    };
    return updated;
  });
  
  // 新しいMethodをロード
  setActiveMethodIndex(newIndex);
  const newMethod = methods[newIndex];
  setNodes(newMethod.nodes);
  setEdges(newMethod.edges);
  setViewport(newMethod.viewport, { duration: 0 });
}, [activeMethodIndex, nodes, edges, methods, getViewport, setNodes, setEdges, setViewport]);
```

### 現行版: 型定義 + 同じロジック

```typescript
const [methods, setMethods] = useState<MethodData[]>([]);
const [activeMethodIndex, setActiveMethodIndex] = useState(0);
const [multiMethodMode, setMultiMethodMode] = useState(false);

// Method切り替え時の処理（Reference版とほぼ同じ）
const handleMethodTabChange = useCallback((newIndex: number) => {
  if (activeMethodIndex === newIndex) return;
  
  const currentViewport = getViewport();

    updated[activeMethodIndex] = {
      ...updated[activeMethodIndex],
      nodes,
      edges,
      viewport: currentViewport,
    };
    return updated;
  });
  
  setActiveMethodIndex(newIndex);
  const newMethod = methods[newIndex];
  setNodes(newMethod.nodes);
  setEdges(newMethod.edges);
  setViewport(newMethod.viewport, { duration: 0 });
}, [activeMethodIndex, nodes, edges, methods, getViewport, setNodes, setEdges, setViewport]);
```

## 6. テンプレート一覧表示の実装方式

### Reference版: buildTemplateMap を使用

```javascript
// テンプレートマップを構築
const templateMap = useMemo(() => {
  return buildTemplateMap(nodes);
}, [nodes]);

// カテゴリ別に分類
const categorizedTemplates = useMemo(() => {
  return {
    material: Object.values(templateMap.materialTemplates || {}),
    condition: Object.values(templateMap.conditionTemplates || {}),
    result: Object.values(templateMap.resultTemplates || {}),
  };
}, [templateMap]);
```

### 現行版: useEffect でノードから直接抽出

```typescript
// ノードからテンプレートデータを直接抽出
useEffect(() => {
  const materialTemplates = nodes
    .filter(n => n.type === 'materialTemplate')
    .map(convertNodeToTemplateData);
  
  const conditionTemplates = nodes
    .filter(n => n.type === 'conditionTemplate')
    .map(convertNodeToTemplateData);
  
  const resultTemplates = nodes
    .filter(n => n.type === 'resultTemplate')
    .map(convertNodeToTemplateData);
  
  setCategorizedTemplates({
    material: materialTemplates,
    condition: conditionTemplates,
    result: resultTemplates,
  });
}, [nodes, convertNodeToTemplateData]);

// 共通テンプレートの抽出（現行版独自）
useEffect(() => {
  const commonMaterial = nodes
    .filter(n => n.type === 'materialTemplate' && !n.data.type)
    .map(convertNodeToTemplateData);
  // ... 以下同様
  
  setCommonTemplatesData({ material, condition, result });
}, [nodes, convertNodeToTemplateData]);
```

### 主な差異

| 項目 | Reference版 | 現行版 |
|-----|------------|-------|
| 抽出方法 | buildTemplateMap | 直接フィルタ + map |
| 共通テンプレート | refMapベース | data.typeがnull/undefined |
| パフォーマンス | useMemo | useEffect + State |
| 依存関係 | 外部関数に依存 | 自己完結 |

### パフォーマンス比較

**Reference版（useMemo）:**
- ✅ ノード変更時のみ再計算
- ✅ 不要な再レンダリングなし
- ❌ buildTemplateMap の実装に依存

**現行版（useEffect）:**
- ⚠️ ノード変更時にStateを更新（再レンダリング）
- ✅ 実装が分かりやすい
- ✅ 外部関数不要

### 推奨改善
⚠️ **useMemo に変更すべき**（パフォーマンス向上）

```typescript
// 推奨実装
```
