## 📝 技術的な注意点

### 認証方式
- **Cookie認証（HTTPOnly）を使用**
- 全てのAPIリクエストに `credentials: 'include'` が必要
- JWTトークンは自動的にCookieから送信される

### エラーハンドリング
```typescript
try {
  const response = await fetch('/api/v1/projects', {
    method: 'GET',
    credentials: 'include',
  });
  
  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.error?.message || 'エラーが発生しました');
  }
  
  return await response.json();
} catch (error) {
  console.error('API Error:', error);
  message.error('プロジェクトの取得に失敗しました');
  throw error;
}
```

### CORS設定
- 開発環境: `http://localhost:3000` （フロントエンド）→ `http://localhost:3001` （バックエンド）
- `credentials: true` が必要

### レスポンス形式
```typescript
interface ApiResponse<T> {
  success: boolean;
  data?: T;
  error?: {
    code: string;
    message: string;
    details?: any[];
  };
  meta?: {
    timestamp: string;
    requestId: string;
  };
}
```
