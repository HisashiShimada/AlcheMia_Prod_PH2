## 1. タスク概要

フォーマット管理画面の左上ツールバーに新規フォルダボタンを追加し、部門直下に新規フォーマットフォルダを作成する機能を実装します。

**要件:**
- 左上ツールバー（リフレッシュボタンの近く）に「新規フォルダ」ボタンを作成
- ボタンは**フォーマット選択なし**でも押せる
- ボタン押下でフォルダ名入力モーダルを表示
- モーダルで作成を押下したら、**ログインユーザーの所属部門**配下（`{organization_id}/formats/{user.department_cd}/`）に新規フォルダを作成

**既存実装との違い:**
- **既存の「新規フォルダ」ボタン**: フォーマット選択後に表示され、選択されたフォーマット配下にサブフォルダを作成
- **今回実装する「新規フォルダ」ボタン**: 左上ツールバーに配置し、部門直下に新規フォーマットフォルダを作成

**実装方針:**
- **データベーステーブルは使用しない**
- **Swiftサーバーにファイルを作成しない**（`.keep`ファイル不要）
- フォーマット一覧は既存の仕組みで表示される
- フォルダ作成APIはフォルダ情報を返すだけ

## 5. 技術的詳細

### API仕様

**エンドポイント**: `POST /api/v1/formats/folders`

**リクエストボディ**:
```typescript
{
  folderName: string;        // 1-255文字、英数字・アンダースコアのみ
}
```

**注意**: 
- `departmentCd`はリクエストボディに含めない（バックエンドでログインユーザーの`req.user.departmentCd`を自動使用）
- `description`は不要（シンプルなフォルダ作成のみ）

**レスポンス（201 Created）**:
```typescript
{
  success: true,
  data: {
    folder_name: string;
    folder_path: string;      // {organization_id}/formats/{department_cd}/{folder_name}
    department_cd: string;
    created_at: string;
  }
}
```

### フォルダ作成の実装方針

**重要**: Swiftサーバーには何もファイルを作成しません。

```typescript
// ログインユーザーの部門を取得
const departmentCd = req.user.departmentCd;
const organizationId = req.user.organizationId;

// フォルダパスを生成
const folderPath = `formats/${departmentCd}/${folderName}`;
const fullPath = `${organizationId}/${folderPath}`;

// レスポンスを返す（Swiftには何も作成しない）
return {
  folder_name: folderName,
  folder_path: fullPath,
  department_cd: departmentCd,
  created_at: new Date().toISOString()
};
```

**理由**: 
- 既存の仕組みで`.keep`ファイルなしでもフォルダが表示される
- ファイルがアップロードされたときに自動的にフォルダが作成される
- 不要なファイルを作成しない（シンプルな実装）

### Swiftフォルダ構造

```
{organization_id}/formats/
└── {department_cd}/              # 部門コード（例: dept_001）
    └── {new_folder_name}/        # 今回作成する新規フォルダ
        └── （後でファイルがアップロードされる）
```

**注意**: 
- フォルダ作成時にSwiftに何も作成しない
- 後でファイルがアップロードされたときに自動的にフォルダが表示される

### バリデーション

```typescript
// folderName のバリデーション
const folderNameRegex = /^[a-zA-Z0-9_]+$/;
if (!folderNameRegex.test(folderName)) {
  throw new ValidationError('フォルダ名は英数字とアンダースコアのみ使用できます');
}

if (folderName.length < 1 || folderName.length > 255) {
  throw new ValidationError('フォルダ名は1〜255文字で指定してください');
}

// ログインユーザーの部門を取得
const departmentCd = req.user.departmentCd;

// departmentCd の存在確認（念のため）
const department = await db
  .selectFrom('department')
  .where('department_cd', '=', departmentCd)
  .where('organization_id', '=', organizationId)
  .selectAll()
  .executeTakeFirst();

if (!department) {
  throw new ValidationError('ユーザーの所属部門が見つかりません');
}

// 重複チェック（Swiftサーバーからフォルダ一覧を取得して確認）
const existingFolders = await storageService.listFiles(
  organizationId,
  `formats/${departmentCd}`
);

const folderExists = existingFolders.some(file => 
  file.key.startsWith(`formats/${departmentCd}/${folderName}/`)
);

if (folderExists) {
  throw new ConflictError('同じ名前のフォルダが既に存在します');
}
```

## 技術補足: Swiftサーバーでのフォルダ表現

### S3/Swift の特性

S3やSwiftには「フォルダ」という概念が存在しません。すべてのデータは「オブジェクト（ファイル）」として保存され、オブジェクトキー（パス）で階層を表現します。

### フォルダを表現する方法

**推奨方法: .keep ファイルを配置**

空のフォルダを表現するために、フォルダパス配下に `.keep` という空ファイルを配置します。

```typescript
// 例: formats/dept_001/chemistry/ フォルダを作成
const folderPath = 'formats/dept_001/chemistry/.keep';
await storageService.uploadFile(
  organizationId,
  folderPath,
  Buffer.from('', 'utf-8'),
  { contentType: 'text/plain' }
);
```

これにより、Swiftサーバー上では以下のオブジェクトが作成されます：
```
{organization_id}/formats/dept_001/chemistry/.keep
```

フォルダ一覧を取得する際は、`listFiles` でプレフィックス検索を行い、`/` で分割して階層構造を構築します。
