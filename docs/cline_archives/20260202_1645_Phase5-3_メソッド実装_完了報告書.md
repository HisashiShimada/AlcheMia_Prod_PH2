### 1. validateForExperimentManager() - 新規実装 ✅

#### 目的
ExperimentManager向けのファイル検証を行い、必須要素の存在とファイル構造の妥当性をチェックする。

#### シグネチャ
```typescript
validateForExperimentManager(): {
  isValid: boolean;
  errors: string[];
  warnings: string[];
  info: {
    hasProtocol: boolean;
    hasMethod: boolean;
    hasData: boolean;
    hasEventLog: boolean;
    protocolName?: string;
    methodCount: number;
    version?: string;
  };
}
```

#### 実装内容
1. **基本情報取得**: `getFileBasicInfo()`を利用
2. **必須要素の検証**:
   - `protocol`セクションの存在確認
   - `protocol.method`セクションの存在確認
3. **警告レベルの検証**:
   - `pnml`セクションの存在確認（警告のみ）
4. **検証結果の返却**:
   - `isValid`: すべての必須要素が存在する場合`true`
   - `errors`: エラーメッセージ配列
   - `warnings`: 警告メッセージ配列
   - `info`: ファイル基本情報

#### コード
```typescript
validateForExperimentManager(): {
  isValid: boolean;
  errors: string[];
  warnings: string[];
  info: {
    hasProtocol: boolean;
    hasMethod: boolean;
    hasData: boolean;
    hasEventLog: boolean;
    protocolName?: string;
    methodCount: number;
    version?: string;
  };
} {
  const validation = {
    isValid: true,
    errors: [] as string[],
    warnings: [] as string[],
    info: this.getFileBasicInfo()
  };
  
  // 必須要素の検証
  if (!this.typedMaiml.protocol) {
    validation.errors.push('protocolセクションが見つかりません');
    validation.isValid = false;
  }
  
  if (!this.typedMaiml.protocol?.method || this.getMethods().length === 0) {
    validation.errors.push('protocol/methodセクションが見つかりません');
    validation.isValid = false;
  }
  
  // 警告レベルの検証
  const methods = this.getMethods();
  if (methods.length > 0) {
    const hasAnyPnml = methods.some(m => m.pnml && m.pnml.length > 0);
    if (!hasAnyPnml) {
      validation.warnings.push('pnmlセクションが見つかりません');
    }
  }
  
  return validation;
}
```
