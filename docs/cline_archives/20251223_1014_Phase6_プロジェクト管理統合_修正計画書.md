### 📝 起動時の動作フロー

#### フロー1: Draftチェック
```
編集ボタン押下
  ↓
Draft（一時保存）が存在する？
  ├─ YES → Draft復元確認ダイアログ表示
  │         ├─「復元する」→ Draft読み込み → エディタ起動
  │         └─「新規作成/既存ファイル」→ フロー2へ
  └─ NO → フロー2へ
```

#### フロー2: MAIMLファイルチェック
```
プロジェクトフォルダにmaimlファイルが存在する？
  ├─ YES → 既存ファイル読み込み → エディタ起動
  └─ NO → 新規ファイル作成 → エディタ起動（空のテンプレート）
```

### 🔑 重要な仕様

1. **Draft（一時保存）の優先**
   - 最新のDraftがあれば、必ず復元確認ダイアログを表示
   - LocalStorageキー: `petri-net-draft-${projectId}`

2. **maimlファイルの判定**
   - プロジェクトフォルダ内の`.maiml`拡張子ファイルを検索
   - 複数ある場合は最新のファイルを使用
   - ない場合は新規作成モード

3. **エディタの表示方式**
   - **モーダルダイアログ**を推奨（既存のViewRendererDialogと統一）
   - フルスクリーン対応（95vw × 95vh）
   - z-index管理（既存ダイアログとの競合回避）

```typescript
// frontend/src/components/viewer/PetriNetEditorDialog.tsx

interface PetriNetEditorDialogProps {
  open: boolean;
  onClose: () => void;
  projectId: string;
  projectName: string;
  mode: 'create' | 'edit' | 'restore';
  maimlContent?: string;  // 既存ファイルまたはDraft
  onSave?: (content: string) => Promise<void>;
}

const PetriNetEditorDialog: React.FC<PetriNetEditorDialogProps> = ({
  open,
  onClose,
  projectId,
  projectName,
  mode,
  maimlContent,
  onSave
}) => {
  const [isLoading, setIsLoading] = useState(false);
  const [hasUnsavedChanges, setHasUnsavedChanges] = useState(false);

  // 閉じる時の確認
  const handleClose = useCallback(() => {
    if (hasUnsavedChanges) {
      Modal.confirm({
        title: '未保存の変更',
        content: '保存せずに閉じますか？',
        okText: '閉じる',
        okType: 'danger',
        cancelText: 'キャンセル',
        onOk: () => {
          onClose();
        }
      });
    } else {
      onClose();
    }
  }, [hasUnsavedChanges, onClose]);

  return (
    <Modal
      title={`実験フロー編集 - ${projectName}`}
      open={open}
      onCancel={handleClose}
      width="95vw"
      style={{ top: 20 }}
      footer={null}
      styles={{
        body: {
          height: 'calc(95vh - 110px)',
          padding: 0,
          overflow: 'hidden'
        }
      }}
      zIndex={1100}  // 既存ダイアログより高く
    >
      {isLoading ? (
        <div style={{ 
          display: 'flex', 
          justifyContent: 'center', 
          alignItems: 'center', 
          height: '100%' 
        }}>
          <Spin size="large" tip="読み込み中..." />
        </div>
      ) : (
        <PetriNetEditor
          initialContent={maimlContent}
          projectId={projectId}
          onSave={onSave}
          onContentChange={() => setHasUnsavedChanges(true)}
        />
      )}
    </Modal>
  );
};
```

```typescript
const handleEditButtonClick = useCallback(async () => {
  if (!selectedProject) {
    message.warning('プロジェクトを選択してください');
    return;
  }

  // Step 1: Draftチェック
  const draftKey = `petri-net-draft-${selectedProject.id}`;
  const draftData = localStorage.getItem(draftKey);
  
  if (draftData) {
    try {
      const draft = JSON.parse(draftData);
      const draftInfo = {
        savedAt: draft.savedAt || new Date().toISOString(),
        methodCount: draft.methods?.length || 0,
        nodeCount: draft.nodes?.length || 0
      };
      
      setDraftInfo(draftInfo);
      setDraftRestoreDialogOpen(true);
      return;  // Draft復元ダイアログで選択を待つ
    } catch (error) {
      console.error('Draft parse error:', error);
      // パースエラーの場合は無視して続行
    }
  }

  // Step 2: maimlファイルチェック
  await checkAndLoadMaimlFile();
}, [selectedProject]);

// maimlファイルをチェックして読み込む
const checkAndLoadMaimlFile = useCallback(async () => {
  if (!selectedProject) return;

  try {
    setIsLoading(true);
    
    // プロジェクトのファイル一覧から.maimlファイルを検索
    const maimlFiles = projectFiles.filter(f => 
      f.name.endsWith('.maiml') && !f.isFolder
    );

    if (maimlFiles.length > 0) {
      // 最新のmaimlファイルを取得
      const latestFile = maimlFiles.sort((a, b) => 
        new Date(b.lastModified).getTime() - new Date(a.lastModified).getTime()
      )[0];

      // ファイル内容を読み込み
      const response = await fetch(latestFile.path);
      const content = await response.text();
      
      setMaimlContent(content);
      setEditorMode('edit');
      setEditorDialogOpen(true);
    } else {
      // maimlファイルがない場合は新規作成
      message.info('MAIMLファイルが見つかりません。新規作成します。');
      setMaimlContent(undefined);
      setEditorMode('create');
      setEditorDialogOpen(true);
    }
  } catch (error) {
    console.error('Failed to load maiml file:', error);
    message.error('ファイルの読み込みに失敗しました');
  } finally {
    setIsLoading(false);
  }
}, [selectedProject, projectFiles]);

// Draft復元ダイアログのハンドラー
const handleRestoreDraft = useCallback(() => {
  setDraftRestoreDialogOpen(false);
  
  // Draftを読み込む
  const draftKey = `petri-net-draft-${selectedProject?.id}`;
  const draftData = localStorage.getItem(draftKey);
  
  if (draftData) {
    // DraftをmaimlContent形式に変換（PetriNetEditorが処理）
    setMaimlContent(draftData);
    setEditorMode('restore');
    setEditorDialogOpen(true);
  }
}, [selectedProject]);

const handleCreateNewOrExisting = useCallback(() => {
  setDraftRestoreDialogOpen(false);
  // maimlファイルチェックへ
  checkAndLoadMaimlFile();
}, [checkAndLoadMaimlFile]);
```

## ⚠️ 注意点

### 1. 既存ダイアログとの競合回避

ProjectManagementは既にViewRendererDialogを使用しているため、z-indexを適切に管理する必要があります。

```typescript
// ViewRendererDialog: z-index 1000台
// PetriNetEditorDialog: z-index 1100台
```

### 2. Draft自動保存との競合

PetriNetEditor内部でDraft自動保存が動作するため、LocalStorageキーの衝突を避ける必要があります。

```typescript
// ProjectManagement用のDraft
`petri-net-draft-${projectId}`

// PetriNetEditor内部のDraft（既存）
`petri-net-draft-${maimlFilename}`
```

→ **PetriNetEditorに projectId を渡して統一**

### 3. ファイル読み込みのパフォーマンス

大きなmaimlファイル（1MB以上）の場合、読み込みに時間がかかる可能性があります。

→ **ローディング状態を適切に表示**
