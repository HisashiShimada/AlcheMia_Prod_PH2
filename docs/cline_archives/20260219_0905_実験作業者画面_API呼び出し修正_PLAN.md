## 5. 技術的詳細

### 使用するAPI

#### 5.1. プロジェクト一覧取得API

**エンドポイント**: `GET /api/v1/projects/worker-accessible`

**用途**: 実験作業者がアクセス可能なプロジェクト一覧を取得

**クエリパラメータ**:
```typescript
{
  page?: number;           // ページ番号（デフォルト: 1）
  limit?: number;          // 1ページあたりの件数（デフォルト: 20）
  status?: '1' | '2' | '3'; // ステータスフィルタ（1: 作業中, 2: 承認待ち, 3: 承認済み）
  sort_by?: 'create_at' | 'project_name' | 'update_at'; // ソート項目
  order?: 'asc' | 'desc';  // ソート順
}
```

**レスポンス**:
```typescript
{
  success: true,
  data: Array<{
    project_id: string;      // UUID
    project_name: string;
    project_cd: string;
    status: 1 | 2 | 3;      // 1: 作業中, 2: 承認待ち, 3: 承認済み
    create_at: string;       // ISO 8601
    update_at: string;       // ISO 8601
  }>,
  pagination: {
    currentPage: number;
    totalPages: number;
    totalItems: number;
    itemsPerPage: number;
  },
  meta: {
    timestamp: string;
    requestId: string;
  }
}
```

#### 5.2. 承認依頼API

**エンドポイント**: `PATCH /api/v1/projects/:projectName/approval-request`

**用途**: 実験作業者が実験作業完了後に実験管理者へ承認依頼を送信

**パスパラメータ**:
- `projectName`: プロジェクト名

**リクエストボディ**:
```typescript
{
  comment?: string; // コメント（任意、最大1000文字）
}
```

**レスポンス**:
```typescript
{
  success: true,
  data: {
    project_id: string;
    project_name: string;
    status: 2;  // 承認待ち
    update_at: string;
  },
  meta: {
    timestamp: string;
    requestId: string;
  }
}
```

**エラーレスポンス**:
- `404 RESOURCE_NOT_FOUND`: プロジェクトが見つからない
- `409 BUSINESS_*`: ビジネスロジックエラー（既に承認依頼済み等）
- `400 VALIDATION_*`: バリデーションエラー

### アーキテクチャ上の考慮事項

1. **非同期処理**: API呼び出しは非同期で行い、ローディング状態を適切に管理
2. **エラーハンドリング**: ネットワークエラー、APIエラーを適切にハンドリング
3. **ユーザーフィードバック**: 成功/失敗を `message` コンポーネントで通知
4. **型安全性**: APIレスポンスの型定義を追加
