## 詳細

### 1. State定義

```typescript
// frontend/src/components/project/TaskRegistrationTab.tsx
const [checkedTaskIds, setCheckedTaskIds] = useState<Set<number>>(new Set());
```

- **型**: `Set<number>`
- **管理対象**: タスクIDの集合
- **初期値**: 空のSet

### 2. チェックボックス変更ハンドラー

```typescript
const handleCheckboxChange = useCallback((taskId: number, checked: boolean) => {
  setCheckedTaskIds(prev => {
    const newSet = new Set(prev);  // 既存Setをコピー
    if (checked) {
      newSet.add(taskId);          // チェック時: 追加
    } else {
      newSet.delete(taskId);       // チェック解除時: 削除
    }
    return newSet;                 // 新しいSetを返す
  });
}, []);
```

**動作**:
- ✅ チェックON → `Set.add(taskId)` で追加
- ✅ チェックOFF → `Set.delete(taskId)` で削除
- 新しいSetオブジェクトを作成して返す（イミュータブル）

### 4. チェックボックスの表示


### 5. 保存時の処理

```typescript
// チェックされたタスクのみをフィルタリング
```

## まとめ

### state管理の特徴

1. **データ構造**: `Set<number>` を使用
   - 重複を自動的に排除
   - `add()`/`delete()` で効率的な追加・削除
   - `has()` で高速な存在確認

2. **更新方法**: イミュータブル
   - 既存Setをコピー → 変更 → 新しいSetを返す
   - Reactの再レンダリングを適切にトリガー

3. **初期化**: APIデータに基づく
   - DB保存済み → 保存済みタスクIDのみ
   - 初回（未保存） → 全タスクID

4. **用途**: 保存対象タスクの選択管理
   - チェックされたタスクのみが保存される
   - 初回保存時は全選択が必須
