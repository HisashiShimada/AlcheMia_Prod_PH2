## 5. 技術的詳細

### Listコンポーネントの代替案

#### Option 1: Tableコンポーネント（推奨）
```typescript
// ❌ Before (非推奨)
<List
  dataSource={items}
  renderItem={(item) => (
    <List.Item>
      <List.Item.Meta
        title={item.title}
        description={item.description}
      />
    </List.Item>
  )}
/>

// ✅ After (推奨)
<Table
  dataSource={items}
  columns={[
    {
      title: '',
      dataIndex: 'title',
      render: (title, record) => (
        <div>
          <div>{title}</div>
          <div style={{ color: token.colorTextSecondary }}>
            {record.description}
          </div>
        </div>
      ),
    },
  ]}
  showHeader={false}
  pagination={false}
  size="small"
/>
```

#### Option 2: カスタム実装（Flexレイアウト）
```typescript
// ✅ シンプルなリストの場合
<Space direction="vertical" style={{ width: '100%' }}>
  {items.map((item) => (
    <Card key={item.id} size="small">
      <div>{item.title}</div>
      <div style={{ color: token.colorTextSecondary }}>
        {item.description}
      </div>
    </Card>
  ))}
</Space>
```
