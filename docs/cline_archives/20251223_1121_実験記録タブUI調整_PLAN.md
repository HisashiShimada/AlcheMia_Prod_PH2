## 13. 修正詳細

### TransitionList.tsx の変更内容
1. **「進捗率」列の削除**
   - Tableのcolumns配列から「進捗率」列の定義を削除
   - Progressコンポーネントとその関連ロジックも削除

2. **タイトルと検索コントロールの縦幅を8pxに調整**
   - Row gutterの垂直方向を `[16, 16]` から `[16, 8]` に変更

### ExperimentRecordTab.tsx の変更内容
1. **メソッド・タスク選択エリアのコンパクト化**
   - メソッド選択のSpaceコンポーネント: `flex: 1` → `minWidth: 300, maxWidth: 400`
   - タスク選択のSpaceコンポーネント: `flex: 1` → `minWidth: 300, maxWidth: 400`
   - 各Selectコンポーネント: `flex: 1, minWidth: 200` → `width: 200`

2. **選択カードの下のmarginを8pxに調整**
   - marginBottom: `token.marginLG` → `8`

3. **「フロー図に切り替え」ボタンの上下余白を8pxに調整**
   - marginBottom: `token.margin` → `8`

4. **「トランジション一覧」タイトルのフォントサイズを16pxに変更**
   - Titleコンポーネントに `fontSize: 16` を追加

5. **「選択」ボタンを右詰めに配置**
   - Buttonコンポーネントに `marginLeft: 'auto'` を追加
