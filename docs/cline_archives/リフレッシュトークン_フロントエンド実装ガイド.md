## 実装パターン

### パターン1: 基本的な実装（推奨）

トークンストレージとAPI呼び出し時の自動更新を実装します。

#### Step 1: トークンストレージの更新

```typescript
// frontend/src/utils/tokenStorage.ts

interface TokenData {
  accessToken: string;
  refreshToken: string;
  expiresAt: string;
}

export const tokenStorage = {
  // トークンペアを保存
  setTokens(accessToken: string, refreshToken: string, expiresAt: string): void {
    sessionStorage.setItem('accessToken', accessToken);
    sessionStorage.setItem('refreshToken', refreshToken);
    sessionStorage.setItem('tokenExpiresAt', expiresAt);
  },

  // アクセストークンを取得
  getAccessToken(): string | null {
    return sessionStorage.getItem('accessToken');
  },

  // リフレッシュトークンを取得
  getRefreshToken(): string | null {
    return sessionStorage.getItem('refreshToken');
  },

  // トークンの有効期限を取得
  getExpiresAt(): string | null {
    return sessionStorage.getItem('tokenExpiresAt');
  },

  // トークンをすべて削除
  clearTokens(): void {
    sessionStorage.removeItem('accessToken');
    sessionStorage.removeItem('refreshToken');
    sessionStorage.removeItem('tokenExpiresAt');
  },

  // トークンの有効期限チェック（余裕を持って5分前にチェック）
  isTokenExpiringSoon(): boolean {
    const expiresAt = this.getExpiresAt();
    if (!expiresAt) return true;

    const expiresTime = new Date(expiresAt).getTime();
    const now = Date.now();
    const fiveMinutes = 5 * 60 * 1000;

    return expiresTime - now < fiveMinutes;
  },
};
```

#### Step 3: トークン更新関数の実装

```typescript
// frontend/src/api/authApi.ts

let isRefreshing = false;
let refreshSubscribers: ((token: string) => void)[] = [];

// トークン更新完了を待機している呼び出し元に通知
function onTokenRefreshed(newToken: string) {
  refreshSubscribers.forEach(callback => callback(newToken));
  refreshSubscribers = [];
}

// トークン更新を待機するサブスクライバーを追加
function addRefreshSubscriber(callback: (token: string) => void) {
  refreshSubscribers.push(callback);
}

/**
 * リフレッシュトークンを使用してアクセストークンを更新
 */
export async function refreshAccessToken(): Promise<string | null> {
  const refreshToken = tokenStorage.getRefreshToken();

  if (!refreshToken) {
    console.error('リフレッシュトークンが見つかりません');
    return null;
  }

  try {
    const response = await fetch(`${API_BASE_URL}/auth/refresh`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ refreshToken }),
    });

    const data = await response.json();

    if (data.success) {
      // 新しいトークンペアを保存
      const now = new Date();
      const expiresAt = new Date(now.getTime() + data.data.expiresIn * 1000).toISOString();
      
      tokenStorage.setTokens(
        data.data.accessToken,
        data.data.refreshToken,
        expiresAt
      );

      return data.data.accessToken;
    } else {
      // リフレッシュトークンも期限切れ → ログイン画面へ
      console.error('リフレッシュトークンが無効です:', data.error.message);
      tokenStorage.clearTokens();
      window.location.href = '/login';
      return null;
    }
  } catch (error) {
    console.error('トークン更新エラー:', error);
    tokenStorage.clearTokens();
    window.location.href = '/login';
    return null;
  }
}
```

#### Step 4: Axios Interceptorの実装

```typescript
// frontend/src/api/axiosInstance.ts

import axios, { AxiosError, InternalAxiosRequestConfig } from 'axios';
import { tokenStorage } from '../utils/tokenStorage';
import { refreshAccessToken } from './authApi';

const axiosInstance = axios.create({
  baseURL: process.env.REACT_APP_API_URL || 'http://localhost:3001/api/v1',
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
});

let isRefreshing = false;
let failedQueue: Array<{
  resolve: (value: string) => void;
  reject: (error: any) => void;
}> = [];

// 待機中のリクエストを処理
function processQueue(error: any, token: string | null = null) {
  failedQueue.forEach(promise => {
    if (error) {
      promise.reject(error);
    } else {
      promise.resolve(token!);
    }
  });

  failedQueue = [];
}

// リクエストインターセプター
axiosInstance.interceptors.request.use(
  async (config: InternalAxiosRequestConfig) => {
    const accessToken = tokenStorage.getAccessToken();

    if (accessToken) {
      config.headers.Authorization = `Bearer ${accessToken}`;
    }

    return config;
  },
  (error) => Promise.reject(error)
);

// レスポンスインターセプター
axiosInstance.interceptors.response.use(
  (response) => response,
  async (error: AxiosError) => {
    const originalRequest = error.config as InternalAxiosRequestConfig & { _retry?: boolean };

    // 401エラーでリトライ未実施の場合
    if (error.response?.status === 401 && !originalRequest._retry) {
      if (isRefreshing) {
        // トークン更新中の場合、キューに追加して待機
        return new Promise((resolve, reject) => {
          failedQueue.push({ resolve, reject });
        })
          .then(token => {
            originalRequest.headers.Authorization = `Bearer ${token}`;
            return axiosInstance(originalRequest);
          })
          .catch(err => Promise.reject(err));
      }

      originalRequest._retry = true;
      isRefreshing = true;

      try {
        // トークン更新
        const newAccessToken = await refreshAccessToken();

        if (newAccessToken) {
          // 待機中のリクエストを再実行
          processQueue(null, newAccessToken);

          // 元のリクエストを再実行
          originalRequest.headers.Authorization = `Bearer ${newAccessToken}`;
          return axiosInstance(originalRequest);
        } else {
          // トークン更新失敗 → ログイン画面へ
          processQueue(new Error('トークン更新失敗'), null);
          return Promise.reject(error);
        }
      } catch (refreshError) {
        processQueue(refreshError, null);
        return Promise.reject(refreshError);
      } finally {
        isRefreshing = false;
      }
    }

    return Promise.reject(error);
  }
);

export default axiosInstance;
```

#### Step 5: ログアウト処理の更新

```typescript
// frontend/src/api/authApi.ts

export async function logout(): Promise<void> {
  const refreshToken = tokenStorage.getRefreshToken();

  try {
    await axiosInstance.post('/auth/logout', {
      refreshToken,  // リフレッシュトークンを送信（Redisから削除）
    });
  } catch (error) {
    console.error('ログアウトエラー:', error);
  } finally {
    // トークンをクリア
    tokenStorage.clearTokens();
    // ログイン画面へ遷移
    window.location.href = '/login';
  }
}
```

### パターン2: 定期的なトークン更新（オプション）

アクティブなユーザーのトークンを定期的に更新します。

```typescript
// frontend/src/hooks/useTokenRefresh.ts

import { useEffect, useRef } from 'react';
import { tokenStorage } from '../utils/tokenStorage';
import { refreshAccessToken } from '../api/authApi';

export function useTokenRefresh() {
  const intervalRef = useRef<NodeJS.Timeout | null>(null);

  useEffect(() => {
    // 5分ごとにトークンをチェックして更新
    intervalRef.current = setInterval(async () => {
      if (tokenStorage.isTokenExpiringSoon()) {
        console.log('トークンの有効期限が近づいています。更新します...');
        await refreshAccessToken();
      }
    }, 5 * 60 * 1000); // 5分

    return () => {
      if (intervalRef.current) {
        clearInterval(intervalRef.current);
      }
    };
  }, []);
}

// 使用例（App.tsxなど）
function App() {
  useTokenRefresh(); // トークンの定期更新

  return (
    <div>
      {/* アプリケーションコンテンツ */}
    </div>
  );
}
```

## アイドルタイムアウトの仕組み

### 動作フロー

```
1. ログイン
   ↓
   アクセストークン: 15分有効
   リフレッシュトークン: 30分有効（Redis TTL）
   
2. 15分以内にAPI呼び出し
   ↓
   401エラー発生（アクセストークン期限切れ）
   ↓
   自動的にトークン更新（/api/auth/refresh）
   ↓
   新しいトークンペアを取得
   リフレッシュトークンのTTLがリセット（30分延長）
   ↓
   元のAPIリクエストを再実行

3. 30分間操作なし
   ↓
   リフレッシュトークンがRedisから自動削除（TTL期限切れ）
   ↓
   次のAPI呼び出しで401エラー
   ↓
   トークン更新失敗
   ↓
   自動ログアウト（ログイン画面へ遷移）
```

### 重要なポイント

1. **アクセストークン（15分）** → 短い有効期限で頻繁に更新
2. **リフレッシュトークン（30分）** → 最後の操作から30分でタイムアウト
3. **自動更新** → ユーザーが操作するたびにトークンが更新され、30分延長される
4. **自動ログアウト** → 30分間操作がなければ、次のAPI呼び出し時に自動ログアウト

## トラブルシューティング

### 問題1: トークン更新が動作しない

**症状:**
- 401エラーが発生し続ける
- ログイン画面に戻されてしまう

**確認事項:**
1. リフレッシュトークンが保存されているか
   ```typescript
   console.log('Refresh Token:', tokenStorage.getRefreshToken());
   ```

2. Axios Interceptorが正しく設定されているか
3. `/api/auth/refresh` エンドポイントが動作しているか
   ```bash
   curl -X POST http://localhost:3001/api/v1/auth/refresh \
     -H "Content-Type: application/json" \
     -d '{"refreshToken":"your-refresh-token"}'
   ```

### 問題2: トークンが頻繁に更新される

**症状:**
- API呼び出しのたびにトークン更新が発生

**原因:**
- `isTokenExpiringSoon()` のチェックロジックが厳しすぎる

**解決策:**
```typescript
// 余裕時間を調整（5分 → 2分）
const twoMinutes = 2 * 60 * 1000;
return expiresTime - now < twoMinutes;
```

### 問題3: 30分経っても自動ログアウトされない

**原因:**
- Redisが起動していない
- 開発環境でフォールバック動作になっている

**確認:**
```bash
# Redisの状態確認
docker ps | grep redis

# Redisのトークンを確認
redis-cli KEYS "mmdpf:refresh_token:*"
```

## まとめ

### 実装の流れ

1. ✅ **tokenStorage.ts** を更新（リフレッシュトークン対応）
2. ✅ **authApi.ts** を更新（ログイン・トークン更新・ログアウト）
3. ✅ **axiosInstance.ts** を実装（Interceptorでトークン自動更新）
4. ✅ **useTokenRefresh.ts** を実装（定期的なトークン更新、オプション）

### メリット

- ✅ セキュリティ向上（短いアクセストークン有効期限）
- ✅ ユーザー体験向上（シームレスなトークン更新）
- ✅ 30分アイドルタイムアウト（自動ログアウト）
- ✅ 開発環境でのフォールバック動作（Redis未起動でも開発可能）

### 注意事項

- リフレッシュトークンは必ず**sessionStorage**に保存（XSS対策）
- 本番環境では必ずRedisを起動する
- トークンはログアウト時に必ずクリアする
