## 1. タスク概要

フォーマット管理画面でサブフォルダに移動した後にフォーマット一覧から別のフォーマットフォルダを切り替えると、そのフォーマットフォルダの内容が正しく表示されない問題を修正する。フォーマット切替時にルートパスを表示するようにする。

## 2. 目的と期待される成果

### 目的
フォーマット切替時にパスをリセットし、常にルートパスから表示されるようにすることで、ユーザーの混乱を防ぐ。

### 期待される成果
- [x] フォーマット切替時に`currentFolderPath`が自動的にリセットされる
- [x] 常にフォーマットのルート階層から表示される
- [x] サブフォルダから別フォーマットに切り替えても正しく表示される

## 3. 問題分析

### 現状の問題
- `FormatFolderTree`コンポーネントで`handleFormatSelect`を使用
- `handleFormatSelect`は`setSelectedFormatId`のみを行い、`currentFolderPath`をリセットしない
- 既に`handleFormatSelectWithReset`というメソッドが用意されているが、使用されていない

### 根本原因
```typescript
// 現在の実装（問題）
<FormatFolderTree
  formats={filteredAndSortedFormats}
  selectedFormatId={selectedFormatId}
  onFormatSelect={handleFormatSelect}  // ← これがパスをリセットしない
  // ...
/>

// 正しい実装候補
const handleFormatSelectWithReset = useCallback((formatId: string) => {
  setSelectedFormatId(formatId);
  setCurrentFolderPath([]);  // ← パスをリセット
}, []);
```
