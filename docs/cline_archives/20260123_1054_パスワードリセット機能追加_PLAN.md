## 1. タスク概要

ログイン画面に既存ユーザーのパスワードリセット機能を追加します。ユーザーがパスワードを忘れた場合、登録済みメールアドレスに仮パスワードを送信し、ログイン後に新しいパスワードへの変更を促します。

- ユーザーがパスワードを忘れた際のセルフサービス機能を提供
- セキュリティを保ちながらユーザビリティを向上
- 管理者の運用負荷を軽減

### 期待される成果

## 5. 技術的詳細

### 使用する技術・ライブラリ
- **crypto (Node.js組み込み)**: 仮パスワード生成
- **nodemailer**: メール送信（既存）
- **bcrypt**: パスワードハッシュ化（既存）
- **Ant Design Modal**: ダイアログUI
- **React Hook Form**: フォーム管理（検討）

### アーキテクチャ上の考慮事項

#### データベーススキーマ変更
```sql
-- user_authenticationテーブルへのカラム追加
ALTER TABLE user_authentication
ADD COLUMN temp_password_flag BOOLEAN DEFAULT false,
ADD COLUMN password_change_required BOOLEAN DEFAULT false,
ADD COLUMN temp_password_created_at TIMESTAMP;
```

#### 仮パスワード生成ロジック
- 8〜12文字のランダムな文字列
- 大文字、小文字、数字を含む
- 記号を1つ以上含む（!@#$%^&*）
- 辞書攻撃対策として予測不可能な文字列

#### メールテンプレート
```
件名: MMDPF - 仮パスワードのご案内

{username} 様

パスワードリセットの要求を受け付けました。

以下の仮パスワードでログインしてください：
仮パスワード: {tempPassword}

※このパスワードの有効期限は24時間です。
※ログイン後、必ず新しいパスワードに変更してください。

このメールに心当たりがない場合は、管理者にお問い合わせください。
```

### セキュリティ考慮事項
- [x] 認証・認可への影響: 仮パスワードフラグによる制御を追加
- [x] データ保護への影響: 仮パスワードもbcryptでハッシュ化
- [x] マルチテナント分離への影響: organization_idによる分離を維持

#### 追加のセキュリティ対策
1. **レート制限**
   - パスワードリセットリクエスト: 15分間に3回まで
   - IPアドレスベースで制限

2. **仮パスワード有効期限**
   - 生成から24時間で自動無効化
   - 期限切れの仮パスワードでのログインを拒否

3. **ログイン履歴記録**
   - 仮パスワード生成操作を記録
   - 仮パスワード使用のログイン試行を記録
   - 不正な試行の検知

4. **パスワード強度チェック**
   - 新パスワードは最低8文字
   - 大文字、小文字、数字、記号を含む
   - 過去のパスワードと同じものは使用不可（オプション）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| メール送信失敗 | 高 | 中 | リトライ機能、エラーハンドリング、管理者通知 |
| 仮パスワードの漏洩 | 高 | 低 | 24時間の有効期限、1回限りの使用、HTTPS通信 |
| スパム攻撃（大量リクエスト） | 中 | 中 | レート制限（15分に3回）、CAPTCHA導入（将来） |
| ユーザー名の推測攻撃 | 中 | 中 | 一律の成功メッセージ（情報漏洩防止） |
| 仮パスワードの推測攻撃 | 高 | 低 | 十分な複雑性（8〜12文字、記号含む）、bcryptハッシュ化 |
| データベース接続エラー | 高 | 低 | トランザクション管理、エラーハンドリング |

## 補足: 実装の詳細仕様

### API仕様

#### 1. パスワードリセットリクエストAPI
```
POST /api/v1/auth/request-temp-password
```

**リクエスト:**
```json
{
  "username": "user001"
}
```

**レスポンス（成功）:**
```json
{
  "success": true,
  "data": {
    "message": "仮パスワードをメールで送信しました",
    "email": "use***@example.com"
  },
  "meta": {
    "timestamp": "2026-01-23T10:54:00Z",
    "requestId": "req_abc123"
  }
}
```

**レスポンス（エラー）:**
```json
{
  "success": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "リクエスト回数が上限を超えました。15分後に再試行してください"
  },
  "meta": {
    "timestamp": "2026-01-23T10:54:00Z",
    "requestId": "req_abc123"
  }
}
```

#### 2. パスワード変更API
```
POST /api/v1/auth/change-password
```

**リクエスト:**
```json
{
  "currentPassword": "temp_pass_123",
  "newPassword": "NewSecure@123",
  "confirmPassword": "NewSecure@123"
}
```

**レスポンス（成功）:**
```json
{
  "success": true,
  "data": {
    "message": "パスワードを変更しました"
  },
  "meta": {
    "timestamp": "2026-01-23T10:54:00Z",
    "requestId": "req_abc123"
  }
}
```

### UI仕様

#### ログイン画面
- パスワード入力フィールドの下に"パスワードをお忘れの方はこちら"リンクを追加
- クリックでパスワードリセットリクエストダイアログを表示

#### パスワードリセットリクエストダイアログ
- タイトル: "パスワードリセット"
- 入力項目:
  - ユーザー名（必須、100文字以内）
- ボタン:
  - "送信"（プライマリ）
  - "キャンセル"（デフォルト）
- 成功時: "仮パスワードをメールで送信しました。メールをご確認ください。"
- エラー時: エラーメッセージ表示

#### パスワード変更画面
- タイトル: "パスワード変更（必須）"
- 説明: "セキュリティのため、新しいパスワードに変更してください。"
- 入力項目:
  - 現在のパスワード（仮パスワード）
  - 新しいパスワード（8文字以上、複雑性チェック）
  - 新しいパスワード（確認用）
- バリデーション:
  - 8文字以上
  - 大文字、小文字、数字を含む
  - 記号を1つ以上含む
  - パスワードと確認用パスワードが一致
- ボタン:
  - "変更"（プライマリ）
  - スキップボタンなし（必須変更）
