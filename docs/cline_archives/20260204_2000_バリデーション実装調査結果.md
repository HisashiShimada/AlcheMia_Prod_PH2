### 1.3 問題点の整理

#### 問題1: バリデーションの重複
- ルートレベルとコントローラーレベルで同じバリデーション処理が重複
- 例: `projectName`の必須チェックがroutesとcontrollerの両方に存在

#### 問題2: validationResult()の未使用
- express-validatorを使っているが、`validationResult()`が呼ばれていない
- バリデーションエラーが自動的に処理されていない

#### 問題3: エラーレスポンス形式の不統一
- routesで定義したバリデーションエラーが無視されている
- コントローラーで独自のエラーレスポンスを生成

#### 問題4: バリデーションロジックの分散
- 各コントローラーで独自のバリデーション処理を実装
- コードの重複が多く、保守性が低い

## 7. 実装例（Phase 3で作成予定）

### 7.1 バリデーションミドルウェア
```typescript
// middleware/validationMiddleware.ts
import { validationResult } from 'express-validator';
import { Request, Response, NextFunction } from 'express';

export const handleValidationErrors = (
  req: Request,
  res: Response,
  next: NextFunction
): void => {
  const errors = validationResult(req);
  
  if (!errors.isEmpty()) {
    const details = errors.array().map(error => ({
      field: error.type === 'field' ? error.path : 'unknown',
      message: error.msg,
      code: 'VALIDATION_ERROR',
    }));
    
    res.status(400).json({
      success: false,
      error: {
        code: 'VALIDATION_ERROR',
        message: 'バリデーションエラーが発生しました',
        details,
      },
      meta: {
        timestamp: new Date().toISOString(),
        requestId: req.headers['x-request-id'] as string,
      },
    });
    return;
  }
  
  next();
};
```

### 7.2 共通バリデーター関数
```typescript
// utils/validators.ts
import { param, body, query } from 'express-validator';

// UUID検証
export const validateUUID = (field: string, location: 'param' | 'body' | 'query' = 'param') => {
  const validator = location === 'param' ? param(field) : 
                   location === 'body' ? body(field) : 
                   query(field);
  
  return validator
    .isUUID()
    .withMessage(`${field}はUUID形式である必要があります`);
};

// 必須文字列（長さ制限付き）
export const validateRequiredString = (
  field: string, 
  minLength: number = 1, 
  maxLength: number = 255
) => {
  return body(field)
    .notEmpty()
    .withMessage(`${field}は必須です`)
    .isLength({ min: minLength, max: maxLength })
    .withMessage(`${field}は${minLength}〜${maxLength}文字である必要があります`);
};

// 列挙型
export const validateEnum = (
  field: string, 
  allowedValues: string[], 
  location: 'query' | 'body' = 'query'
) => {
  const validator = location === 'query' ? query(field) : body(field);
  
  return validator
    .optional()
    .isIn(allowedValues)
    .withMessage(`${field}は次のいずれかである必要があります: ${allowedValues.join(', ')}`);
};
```
