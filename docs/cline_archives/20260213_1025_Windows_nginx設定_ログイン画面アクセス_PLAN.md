## 5. 技術的詳細

### 使用する技術・ライブラリ
- nginx: 最新版（Windows用）
- Node.js: 18+ (既存環境)
- Express.js: バックエンド (ポート3001)
- Next.js: フロントエンド (ポート3000)

### アーキテクチャ構成
```
ブラウザ
  ↓ (http://localhost:80 または 8080)
nginx (リバースプロキシ)
  ├─→ /api/* → バックエンド (localhost:3001)
  └─→ /* → フロントエンド (localhost:3000)
```

### nginx設定のポイント
- upstream設定でバックエンド・フロントエンドを定義
- location /api/ でバックエンドへプロキシ
- location / でフロントエンドへプロキシ
- WebSocket対応（必要に応じて）

### Windows特有の考慮事項
- パスの区切り文字（バックスラッシュ対応）
- ポート80の使用権限（管理者権限または別ポート使用）
- Windowsファイアウォール設定
- プロセスの起動方法（コマンドプロンプトまたはPowerShell）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| ポート80が既に使用されている | 中 | 高 | ポート8080等の代替ポートを使用 |
| バックエンドが起動しない（DB接続エラー） | 高 | 中 | .envファイルの設定ガイド提供、モック対応 |
| nginxの設定ファイルエラー | 中 | 中 | nginx -t でテスト実行、エラー箇所の修正 |
| 依存関係のインストールエラー | 中 | 低 | npm installの再実行、キャッシュクリア |
| Windows Defenderによるブロック | 低 | 低 | 例外設定の追加ガイド |
