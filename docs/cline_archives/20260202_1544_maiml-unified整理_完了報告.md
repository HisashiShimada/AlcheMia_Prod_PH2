## 🔄 パーサーの型使用方針

### 基本方針

```typescript
import type { Transition, MaterialTemplate, Property } from '@/types/maiml-unified';

class MaiMLParser {
  // ✅ 基本メソッド: XSD準拠型をそのまま返す
  getTransitions(): Transition[] {
    const method = this.typedMaiml.protocol.method[0];
    return method.pnml[0].transition;
  }

  // ✅ 拡張メソッド: 必要に応じてインライン型で拡張
  getTransitionsExtended(): Array<Transition & {
    methodId: string;
    hasInstruction: boolean;
    arcCount: number;
  }> {
    const transitions = this.getTransitions();
    return transitions.map(t => ({
      ...t, // ← XSD準拠型をベースに
      methodId: '...', // ← 計算値を追加
      hasInstruction: this.hasInstruction(t.id),
      arcCount: this.getArcCount(t.id)
    }));
  }
}
```

**重要原則:**
- XSD準拠型（maiml-unified.ts）から値を抽出
- 拡張情報は計算値として追加
- 拡張型は必要に応じてインライン定義
