## タスク概要

要求仕様書（R1.5）をもとに作成した要件定義書（v1.0）と、実際のmmdpfシステムの実装内容との差異を分析し、要件定義書を実装内容に整合させた更新版（v1.1）を作成する。

---

## 差異分析結果

要件定義書（v1.0・要求仕様書R1.5ベース）と実際の実装との主な差異は以下の通り。

| 項目 | 要件定義書v1.0（要求仕様書ベース） | 実装（mmdpfシステム） |
|------|----------------------------------|---------------------|
| 認証方式 | 2段階認証 + Azure AD連携 | JWT + PINコードメール認証（独自実装） |
| ユーザーロール数 | 誤記（7種類と記載） | 正：6種類（provider / system_admin / data_admin / experiment_admin / experiment_worker / mi_engineer） |
| アクセス制御 | UNIXアクセス権限・グループ階層モデル | JWT RBAC + マルチテナント分離（organization_id） |
| システム構成 | データレイク／カタログ／マートの3部構成（概念） | React+Next.js / Express API / PostgreSQL / S3・Swift の具体的スタック |
| セキュリティ | 概念的な記述のみ | 具体的実装（bcrypt、Pre-signed URL、クライアント証明書、セキュリティヘッダー、レート制限） |
| 検索機能 | キーワード検索・UUID検索のみ | セマンティック検索（pgvector + 埋め込みモデル）追加 |
| デプロイ環境 | 抽象的な記述 | Docker / Docker Compose、AWS ECS（クラウド）、Ubuntu（オンプレ） |
| 前提条件 | Azure稼働が前提 | S3/Swift・メール送信サービス・Dockerが前提 |
