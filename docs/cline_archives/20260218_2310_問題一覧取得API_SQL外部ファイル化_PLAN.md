## 6. 技術的詳細

### 使用する技術・ライブラリ
- pg-promise: ^11.10.4
- loadSqlFile: 既存のSQLファイルローダー

### 動的SQL構築のアプローチ

#### パターン1: WHERE句の動的追加（departmentRepository参考）
```typescript
let sqlQuery = await loadSqlFile('issues/findByOrganizationData.sql');
const params: any[] = [organizationId];
let paramIndex = 2;

if (filters.projectId) {
  sqlQuery = sqlQuery.replace('ORDER BY', `AND project_id = $${paramIndex}\nORDER BY`);
  params.push(filters.projectId);
  paramIndex++;
}
```

#### パターン2: ORDER BY句の動的置換
```typescript
const sortBy = params.sortBy || 'created_at';
const order = (params.order || 'desc').toUpperCase();
sqlQuery = sqlQuery.replace(
  'ORDER BY created_at DESC',
  `ORDER BY ${sortBy} ${order}`
);
```

### pg-promise vs Pool の使い分け

**pg-promise (getPgp()) を使用:**
- 外部SQLファイルを使用する場合
- トランザクション制御が必要な場合
- 複雑なクエリ操作

**Pool (getPool()) を使用:**
- シンプルなクエリ（将来的には移行を検討）

## 7. リスクと対策
