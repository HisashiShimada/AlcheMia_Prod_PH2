## 作業概要

ユーザーからの指示「ファイル独自定義は全て削除してindex.tsに寄せてください」に基づき、editorv2配下のローカル型定義をすべて`types/index.ts`に統合しました。

## 実施内容

### 1. TemplateEditorDialog.tsx

**削除したローカル型定義:**
```typescript
interface TemplateData {
  id: string;
  uuid?: string;
  name: string;
  description?: string;
  type?: string;
  properties?: Record<string, unknown>;
  contents?: Record<string, unknown>;
  insertion?: { uri?: string; hash?: string; format?: string; };
  placeRefs?: Array<string | { ref?: string; id?: string }>;
  href?: string;
}
```

**対応:**
- `types/index.ts`に`TemplateData`型を追加
- `TemplateEditorDialogProps.onSave`の型シグネチャを`Template`から`TemplateData`に変更
- インポート文を更新: `import type { TemplateData } from '../types'`

### 2. DocumentEditDialog.tsx

**削除したローカル型定義:**
```typescript
export interface DocumentData { ... }
export interface CreatorData { ... }
export interface VendorData { ... }
export interface OwnerData { ... }
export interface InstrumentData { ... }
export interface RefData { ... }
export interface SignatureData { ... }
export interface DocumentEditDialogProps { ... }
```

**対応:**
- `types/index.ts`に`SignatureData`型を追加
- `DocumentData`に`signature?: SignatureData`プロパティを追加
- `DocumentEditDialogProps.documentData`の型を`DocumentData | null | undefined`に修正
- インポート文を更新: `import type { DocumentData, Creator, Vendor, Owner, Instrument } from '../types'`
