## 1. タスク概要

`docs/design/api/api_progress_monitoring.md` の仕様に基づき、トランジションステータス更新API（API #6）をexperimentルートからprogressルートに移動します。

**変更内容:**
- 旧エンドポイント: `PUT /api/v1/experiments/projects/:projectId/methods/:methodId/transitions/:transitionId/status`
- 新エンドポイント: `PATCH /api/v1/progress/projects/:projectName/methods/:methodId/transitions/:transitionId/status`

### 新エンドポイントの仕様

**エンドポイント**: `PATCH /api/v1/progress/projects/:projectName/methods/:methodId/transitions/:transitionId/status`

**パスパラメータ**:
- projectName: string (1-255文字)
- methodId: string (1-255文字)
- transitionId: string (1-255文字)

**リクエストボディ**:
```json
{
  "taskNo": 1,
  "status": "running",
  "progressRate": 50,
  "comment": "実験を開始しました。現在50%完了。"
}
```

**レスポンス**:
```json
{
  "success": true,
  "data": {
    "transitionId": "transition_001",
    "taskNo": 1,
    "methodId": "method_001",
    "projectName": "Sample Project",
    "status": "running",
    "progressRate": 50,
    "comment": "実験を開始しました。現在50%完了。",
    "updatedBy": "880e8400-e29b-41d4-a716-446655440003",
    "updatedAt": "2026-01-27T11:00:00Z"
  },
  "meta": {
    "timestamp": "2026-01-27T11:00:00Z",
    "requestId": "req_def456"
  }
}
```
