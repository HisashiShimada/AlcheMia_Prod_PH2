## 変更仕様

### 変更①: セクション0（テスト実施情報）の追加

ファイル先頭の `---` 区切りの直後、セクション1の前に以下を挿入する。

```markdown
## 0. テスト実施情報

| 項目 | 値 |
|------|-----|
| テスト実施日 | - |
| テスト実施者 | - |
| テスト環境バージョン | - |
| 総合判定 | - |
| 備考 | - |

---
```

### 変更②: スコープ一覧テーブルへの列追加

**変更前のヘッダー:**
```
| テストグループID | テストグループ名 | シナリオ数 | テスト方法 |
|----------------|----------------|-----------|-----------|
```

**変更後のヘッダー:**
```
| テストグループID | テストグループ名 | シナリオ数 | テスト方法 | 合格 | 不合格 | 未実施 |
|----------------|----------------|-----------|-----------|------|-------|-------|
```

各データ行末尾に `| - | - | シナリオ数と同値 |` を追加する（合計行は `| - | - | - |`）。

### 変更③: シナリオ詳細テーブルへの列追加

**変更前のヘッダー:**
```
| シナリオID | シナリオ名 | 種別 | 根拠 | 対応API |
|-----------|-----------|------|------|---------|
```

**変更後のヘッダー:**
```
| シナリオID | シナリオ名 | 種別 | 根拠 | 対応API | 結果 | 備考 |
|-----------|-----------|------|------|---------|------|------|
```

各データ行末尾に `| － | |` を追加する。
