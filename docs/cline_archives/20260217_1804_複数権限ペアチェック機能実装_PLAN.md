## 1. タスク概要

JWTトークンに含まれる権限情報（function_cd、permission）を使用して、APIルートレベルで複数の権限ペアをOR条件でチェックできる機能を実装する。

### 背景
既存の`checkPermission()`関数は単一の(functionId, permission)ペアのみをチェック可能で、複数の異なる権限レベルを持つペアを柔軟にチェックできなかった。

### 要求仕様
- (050000, 1) OR (040000, 0) のように、**異なる権限レベル**を持つ複数ペアをチェックしたい
- いずれか1つのペアにマッチすればアクセスを許可
- 全てのペアにマッチしない場合は403エラーを返却

### アーキテクチャ上の考慮事項

#### ミドルウェアチェーンの順序
```
1. authMiddleware
   ↓ JWT検証、req.userを設定（permissions配列を含む）
2. checkPermission / checkPermissionPairs / checkAnyPermission
   ↓ req.user.permissionsから権限をチェック
3. バリデーション
   ↓
4. handleValidationErrors
   ↓
5. controller
```

#### 関数の使い分け

| 関数 | 用途 | パラメータ | 例 |
|------|------|-----------|-----|
| `checkPermission()` | 単一ペアのチェック | `(functionId, permission)` | `checkPermission('050000', 1)` |
| `checkAnyPermission()` | 同じ権限レベル、複数機能CD | `(functionIds[], permission)` | `checkAnyPermission(['040000', '050000'], 1)` |
| **`checkPermissionPairs()`** | **異なる権限レベル、複数ペア** | `(permissionPairs[])` | `checkPermissionPairs([{functionId: '050000', permission: 1}, {...}])` |

## 8. 実装コード例

### 使用例1: 単一ペア（既存）
```typescript
router.put(
  '/path',
  authMiddleware,
  checkPermission('050000', 1),  // 実験作業者メニュー、読取権限以上
  controller.action
);
```

### 使用例2: 複数ペア（新機能）
```typescript
router.put(
  '/path',
  authMiddleware,
  checkPermissionPairs([
    { functionId: '050000', permission: 1 },  // 実験作業者メニュー、読取権限
    { functionId: '040000', permission: 0 }   // 実験管理者メニュー、書込専用
  ]),
  controller.action
);
```

### 使用例3: 同じ権限レベル、複数機能CD（既存）
```typescript
router.get(
  '/path',
  authMiddleware,
  checkAnyPermission(['040000', '050000'], 1),  // どちらかの機能に読取権限
  controller.action
);
```
