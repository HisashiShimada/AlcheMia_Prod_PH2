## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Table, Dropdown, Tooltip/Popover, Menu
- React Hooks: useState, useEffect, useCallback
- CSS Media Query または window.innerWidth

### レスポンシブ実装方針
```typescript
// 画面幅の監視
const [isNarrowScreen, setIsNarrowScreen] = useState(false);

useEffect(() => {
  const handleResize = () => {
    setIsNarrowScreen(window.innerWidth <= 1500);
  };
  
  handleResize(); // 初期化
  window.addEventListener('resize', handleResize);
  return () => window.removeEventListener('resize', handleResize);
}, []);
```

### ケバブメニュー実装方針
```typescript
const menuItems = [
  {

  render: (_, record) => (

```

### ツールチップ実装方針
```typescript
// ステータスカラムのレンダリング
{
  title: 'ステータス',
  dataIndex: 'status',
  render: (status, record) => {
    const tooltipContent = (
      <div>
        <div>材料：{record.materialCompleted}/{record.materialTotal}</div>
        <div>条件：{record.conditionCompleted}/{record.conditionTotal}</div>
        <div>結果：{record.resultCompleted}/{record.resultTotal}</div>
      </div>
    );
    
    return isNarrowScreen ? (
      <Tooltip title={tooltipContent}>
        <Badge status={status} />
      </Tooltip>
    ) : (
      <Badge status={status} />
    );
  }
}
```

### 実装の詳細

#### 1. レスポンシブロジックの実装
- `useState`で`isNarrowScreen`状態を管理
- `useEffect`でresizeイベントをリッスン
- 1500px以下を判定するロジックを実装
- クリーンアップ処理も実装

#### 2. ケバブメニューの実装
- Ant DesignのDropdownとButtonコンポーネントを使用
- `getMenuItems`関数でメニュー項目を動的生成
- 「記録」と「問題報告」の2つのメニューアイテム
- プロジェクトステータスによる「記録」の活性/非活性制御
- 「説明」カラムの前に配置（操作カラムとして）

#### 3. ステータスカラムのツールチップ実装
- レスポンシブ時のみTooltipを表示
- 材料、条件、結果の完了数/総数を表示
- 総数が0の場合は"-"を表示

#### 4. カラムの表示/非表示切り替え
- スプレッド演算子を使用して動的にカラムを構築
- 1500px超：全カラム表示（材料、条件、結果、記録、問題報告）
- 1500px以下：必須カラムのみ表示 + 操作カラム

#### 5. 横スクロール対策
- `scroll.x`を条件分岐
- レスポンシブ時は`undefined`（横スクロールなし）
- 通常時は`1500`（横スクロール有効）
