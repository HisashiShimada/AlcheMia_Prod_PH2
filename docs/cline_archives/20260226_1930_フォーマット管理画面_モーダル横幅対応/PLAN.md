## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design Modal: width, styles, bodyStyle プロパティ
- Ant Design Drawer: width プロパティ（該当する場合）
- CSS: maxWidth, overflow, flexbox レイアウト

### レイアウト設計方針

#### 推奨モーダルサイズ
```typescript
// 小さいモーダル（フォルダ作成等）
width: 520

// 中サイズモーダル（ファイル作成等）
width: 720

// 大きいモーダル（検索、詳細表示等）
width: 960  // 1024px画面で余裕を持たせる

// 最大サイズ（エディタ等）
width: '90vw'
style: { maxWidth: 1200 }
```

#### フッター固定レイアウト
```typescript
<Modal
  width={960}
  styles={{
    body: {
      maxHeight: 'calc(100vh - 200px)',
      overflowY: 'auto'
    }
  }}
  footer={
    <div style={{ display: 'flex', justifyContent: 'flex-end', gap: 8 }}>
      <Button onClick={onCancel}>キャンセル</Button>
      <Button type="primary" onClick={onOk}>OK</Button>
    </div>
  }
>
  {/* コンテンツ */}
</Modal>
```

### Ant Design Modal API
- `width`: モーダルの横幅（数値または文字列）
- `styles.body`: ボディ部分のスタイル
- `styles.footer`: フッター部分のスタイル
- `centered`: 画面中央に配置
