### ステップ3: 環境変数ファイルを作成

#### 3-1. バックエンドの環境変数

```bash
# バックエンドディレクトリに移動

# サンプルファイルをコピー
cp .env.example .env

# 環境変数ファイルを編集

```

**以下の内容に編集（コピー&ペースト）:**
```bash

# Server Configuration
PORT=3001
HOST=0.0.0.0

# Database Configuration
DB_HOST=postgres
DB_PORT=5432
DB_NAME=mmdpf_db
DB_USER=mmdpf_user
DB_PASSWORD=mmdpf_password

# JWT Configuration
JWT_SECRET=dev-secret-key-change-in-production-2024
JWT_EXPIRES_IN=48h

# Session Configuration
SESSION_SECRET=dev-session-secret-change-in-production-2024
SESSION_COOKIE_MAX_AGE=172800000

# Swift Configuration (OpenStack Swift)
SWIFT_AUTH_URL=http://swift:8080/auth/v1.0
SWIFT_ACCOUNT=test
SWIFT_USER=tester
SWIFT_PASSWORD=testing
SWIFT_CONTAINER=mmdpf-files

# CORS Configuration
CORS_ORIGIN=http://localhost:3000

# Rate Limiting
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX_REQUESTS=100

# Logging
LOG_LEVEL=info
LOG_FILE_PATH=./logs
```

## ⚠️ よくある問題と対処法

### 問題1: ポートが既に使用されている

**エラー:**
```
Error: port is already allocated
```

**解決方法:**
```bash
# 使用中のポートを確認
sudo lsof -i :3000
sudo lsof -i :3001
sudo lsof -i :5432

# プロセスを停止（PIDを確認してから）
sudo kill -9 <PID>

# Dockerを再起動
docker-compose restart
```

### 問題2: Dockerサービスが起動していない

**エラー:**
```
Cannot connect to the Docker daemon
```

**解決方法:**
```bash
# Dockerサービスを起動
sudo systemctl start docker

# 自動起動を有効化
sudo systemctl enable docker

# 状態確認
sudo systemctl status docker
```

### 問題3: コンテナが起動しない

```bash
# すべてのコンテナを停止
docker-compose down

# イメージを再ビルド
docker-compose build --no-cache

# 再起動
docker-compose up -d

# ログを確認
docker-compose logs -f
```

### 問題4: データベース接続エラー

```bash
# PostgreSQLコンテナのログを確認
docker-compose logs postgres

# PostgreSQLコンテナを再起動
docker-compose restart postgres

# 30秒待ってから再度確認
sleep 30
docker-compose ps postgres
```

## 🛠️ 便利なコマンド

### コンテナの管理

```bash
# すべてのコンテナを起動
docker-compose up -d

# すべてのコンテナを停止
docker-compose stop

# すべてのコンテナを削除（データは保持）

# すべてのコンテナとデータを削除（注意！）

docker-compose restart frontend

# コンテナの状態確認
docker-compose ps

# ログをリアルタイム表示
```
