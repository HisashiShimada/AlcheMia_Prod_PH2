## 6. 技術的な考慮事項

### 6.1 Material-UI → Ant Design v6移行

すべてのReference版コンポーネントをAnt Design v6に移行します。

**主な変更:**
- `<Dialog>` → `<Modal>`
- `<IconButton>` → `<Button type="text" icon={...}>`
- `<TextField>` → `<Input>`
- `<Checkbox>` → `<Checkbox>`

### 6.2 TypeScript化

すべてのJavaScriptコンポーネントをTypeScriptに変換します。

**主な変更:**
- `.jsx` → `.tsx`
- PropTypes → TypeScript interface
- 型アノテーションの追加

### 6.3 API統合

バックエンドAPIエンドポイントは既に定義済みですが、処理ロジックが未実装です。

**実装方針:**
- 統一されたレスポンス形式
- エラーハンドリング
- organization_idフィルタリング（マルチテナント対応）
