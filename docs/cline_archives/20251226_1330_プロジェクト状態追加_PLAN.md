## 1. タスク概要

実験作業者メニュー画面にプロジェクトの状態（計画中、タスク実行待ち、タスク実行中、承認待ち、完了）を追加し、状態に応じた操作制御を実装します。

## 2. 目的と期待される成果

### 目的
- プロジェクトのライフサイクル管理を明確化する
- 各状態に応じた適切な操作制限を実装する
- ユーザーが誤った操作を行うことを防ぐ

### 期待される成果

## 5. 技術的詳細

### プロジェクト状態の定義

```typescript
export type ProjectStatus = 
  | 'planning'           // 計画中
  | 'waiting_task'       // タスク実行待ち
  | 'executing_task'     // タスク実行中
  | 'waiting_approval'   // 承認待ち
  | 'completed';         // 完了
```

### 状態判定ヘルパー関数

```typescript
// 編集可能な状態かどうか
const isEditableStatus = (status: ProjectStatus): boolean => {
  return ['waiting_task', 'executing_task', 'waiting_approval'].includes(status);
};

// プロジェクト選択可能な状態かどうか
const isSelectableStatus = (status: ProjectStatus): boolean => {
  return ['waiting_task', 'executing_task', 'waiting_approval'].includes(status);
};
```

### 状態ラベルの多言語対応

```json
{
  "projectStatus": {
    "planning": "計画中",
    "waiting_task": "タスク実行待ち",
    "executing_task": "タスク実行中",
    "waiting_approval": "承認待ち",
    "completed": "完了"
  }
}
```

| リスク | 影響度 | 発生確率 | 対策 |

| 多言語対応の漏れ | 低 | 中 | 全ての状態ラベルを翻訳ファイルに追加 |
