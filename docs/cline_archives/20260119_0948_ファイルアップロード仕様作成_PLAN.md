## 5. 技術的詳細

### アップロードモード
1. **単一ファイルアップロード**: 1ファイルを指定フォルダにアップロード
2. **一括ファイルアップロード**: 複数ファイルを同時にアップロード
3. **フォルダ構造アップロード**: フォルダ階層を保持してアップロード

### マルチパート形式
- Content-Type: multipart/form-data
- ファイルデータ + メタデータ

### S3パス構造
```
org_{organization_prefix}/projects/{project_name}/
├── {uploaded_files}
└── {custom_folder}/
    └── {uploaded_files}
```

### セキュリティ考慮事項
- ファイルサイズ制限（最大100MB）
- ファイル種別制限（ホワイトリスト方式）
- ウイルススキャン（将来実装）
- organization_prefix強制適用
