## 1. タスク概要

実験作業者メニュー画面で進捗確認タブを開いた際に発生する404エラーを修正します。

**現象**:
```
[DEBUG] ProgressCheckTab - Error fetching tasks AxiosError
{message: 'Request failed with status code 404', ...}
```

**根本原因**:
フロントエンドとバックエンドの間でプロジェクトの識別子に不整合があります：
- フロントエンド: `selectedProject`にプロジェクトID（UUID）を保持
- バックエンドAPI: プロジェクト名（projectName）を期待
- 実際の呼び出し: プロジェクトID（UUID）をプロジェクト名として渡している → 404エラー

**発生経緯**:
前回のタスク（`20260219_1752_実験作業者画面_プロジェクト選択_フィールド名不一致修正`）で、プロジェクト選択コンボボックスの値を`projectId`（UUID）に変更したが、API呼び出しは`projectName`を前提としていたため、不整合が発生。

### 修正内容の詳細

#### ExperimentWorkerMenu.tsx

**状態管理の追加:**
```typescript
const [selectedProjectName, setSelectedProjectName] = useState<string>('');
```

**プロジェクト変更ハンドラーの修正:**
```typescript
const handleProjectChange = (value: string | null) => {
  const projectValue = value || '';
  originalHandleProjectChange(projectValue);
  
  // プロジェクト名を取得して保存
  if (projectValue) {
    const selectedProjectData = projects.find(p => p.projectId === projectValue);
    setSelectedProjectName(selectedProjectData?.projectName || '');
  } else {
    setSelectedProjectName('');
  }
  
  // メソッドとタスクをリセット
  setSelectedMethodId(null);
  setSelectedTaskId('');
};
```

**子コンポーネントへのProps追加:**
```typescript
<ProgressCheckTab
  selectedProject={selectedProject}
  selectedProjectName={selectedProjectName}  // 追加
  onProjectChange={handleProjectChange}
  // ...
/>
```

#### ProgressCheckTab.tsx（および他の2つのタブ）

**Props型定義の更新:**
```typescript
interface ProgressCheckTabProps {
  selectedProject: string | null;
  selectedProjectName: string;  // 追加
  onProjectChange: (projectId: string) => void;
  // ...
}
```

**API呼び出しの修正:**
```typescript
// 修正前
const result = await getWorkerTasks(selectedProject);

// 修正後
const result = await getWorkerTasks(selectedProjectName);
```

**プロジェクト選択判定の修正:**
```typescript
if (!selectedProject || !selectedProjectName) {
  setMethods([]);
  setTasks([]);
  setProjectId(null);
  return;
}
```

### データフロー

```
1. ユーザーがプロジェクトを選択
   ↓
2. ExperimentWorkerMenu.handleProjectChange()
   - selectedProject = projectId（UUID）を保存
   - selectedProjectName = projectName（文字列）を保存
   ↓
3. 子コンポーネント（3つのタブ）に両方を渡す
   - selectedProject: UI表示・状態管理に使用
   - selectedProjectName: API呼び出しに使用
   ↓
4. 各タブで getWorkerTasks(selectedProjectName) を呼び出し
   ↓
5. バックエンドAPI: GET /api/v1/progress/projects/:projectName/worker-tasks
   - :projectName にプロジェクト名が渡される
   - 正常にタスク一覧が取得される
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| projectNameが空文字列の場合 | 中 | 低 | 空文字列チェックを追加、APIエラーハンドリング |
| projects配列からprojectNameが見つからない場合 | 中 | 低 | `selectedProjectData?.projectName \|\| ''` でフォールバック |
| 他のコンポーネントでselectedProjectを使用している箇所への影響 | 低 | 低 | selectedProjectは維持するため影響なし |
| API呼び出しタイミングの問題 | 低 | 低 | useEffect依存配列に適切な変数を設定 |
