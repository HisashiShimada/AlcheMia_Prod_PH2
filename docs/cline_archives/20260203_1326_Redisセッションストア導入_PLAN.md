## 1. タスク概要

現在メモリベースで管理されているセッションストレージを、**環境変数で切り替え可能**にします。開発環境ではメモリストア、本番環境ではRedisストアを使用できるようにします。

### 現状の実装
- `express-session`を使用（メモリストア固定）
- JWTトークンをメイン認証に使用
- セッションには`departmentCd`のみ保存
- 環境による切り替えができない

### 改善内容
- **環境変数による切り替え**: `SESSION_STORE_TYPE=memory|redis`
- **メモリストアモード**: 開発環境・簡易テスト用
- **Redisストアモード**: 本番環境・複数サーバー構成用
- **フォールバック機能**: Redis接続失敗時にメモリストアに自動切替

#### 1. Redis接続設定（新規ファイル）

```typescript
// src/config/redis.ts
import { createClient, RedisClientType } from 'redis';

let redisClient: RedisClientType | null = null;
let isRedisEnabled = false;

/**
 * Redisクライアントの初期化（SESSION_STORE_TYPE=redisの場合のみ）
 */
export async function initRedisClient(): Promise<RedisClientType | null> {
  const storeType = process.env.SESSION_STORE_TYPE || 'memory';
  
  if (storeType !== 'redis') {
    logInfo('Redis is disabled (SESSION_STORE_TYPE=' + storeType + ')');
    return null;
  }

  if (redisClient) {
    return redisClient;
  }

  try {
    const redisUrl = process.env.REDIS_URL || 'redis://localhost:6379';
    
    redisClient = createClient({
      url: redisUrl,
      socket: {
        reconnectStrategy: (retries) => {
          if (retries > 10) {
            logError('Redis reconnection failed', new Error('Max retries'));
            return false; // 再接続停止
          }
          return Math.min(retries * 100, 3000);
        }
      }
    });

    // イベントリスナー
    redisClient.on('error', (err) => {
      logError('Redis Client Error', err as Error);
      isRedisEnabled = false;
    });

    redisClient.on('connect', () => {
      logInfo('Redis Client Connected');
      isRedisEnabled = true;
    });

    redisClient.on('ready', () => {
      logInfo('Redis Client Ready');
    });

    // 接続
    await redisClient.connect();
    
    return redisClient;
  } catch (error) {
    logError('Redis initialization failed', error as Error);
    redisClient = null;
    isRedisEnabled = false;
    return null;
  }
}

/**
 * Redisが有効かチェック
 */
export function isRedisAvailable(): boolean {
  return isRedisEnabled && redisClient !== null && redisClient.isOpen;
}

/**
 * Redisクライアントの取得（オプショナル）
 */
export function getRedisClient(): RedisClientType | null {
  return redisClient;
}

/**
 * Redis接続のクローズ
 */
export async function closeRedisClient(): Promise<void> {
  if (redisClient) {
    await redisClient.disconnect();  // quit()ではなくdisconnect()を推奨
    redisClient = null;
    isRedisEnabled = false;
    console.log('Redis Client Closed');
  }
}
```

#### 2. sessionMiddleware.tsの修正（既存ファイル）

```typescript
// src/middleware/sessionMiddleware.ts
import session from 'express-session';
import RedisStore from 'connect-redis';
import { getRedisClient, isRedisAvailable } from '../config/redis';

/**
 * express-sessionミドルウェアのセットアップ
 * 環境変数SESSION_STORE_TYPEでストアを切り替え
 * - memory: メモリストア（開発環境用）
 * - redis: Redisストア（本番環境用）
 */
export function setupSessionMiddleware() {
  const sessionSecret = process.env.SESSION_SECRET || 'maiml-session-secret-change-in-production';
  const storeType = process.env.SESSION_STORE_TYPE || 'memory';
  const maxAge = parseInt(process.env.SESSION_MAX_AGE || '86400000', 10); // デフォルト24時間

  // 共通のCookie設定
  const cookieOptions: session.CookieOptions = {
    httpOnly: true,
    secure: process.env.SESSION_COOKIE_SECURE === 'true' || process.env.NODE_ENV === 'production',
    maxAge,
    sameSite: 'strict',
    path: '/',
  };

  // 共通のセッション設定
  const baseConfig: session.SessionOptions = {
    secret: sessionSecret,
    resave: false,
    saveUninitialized: false,
    rolling: true,  // アクティブなセッションの有効期限を延長
    cookie: cookieOptions,
    name: process.env.SESSION_COOKIE_NAME || 'mmdpf.sid',
  };

  // メモリストアモード
  if (storeType === 'memory') {
    console.log('🗄️  Session Store: MEMORY (development mode)');
    console.warn('⚠️  Sessions will be lost on server restart');
    return session(baseConfig);
  }

  // Redisストアモード
  console.log('🗄️  Session Store: REDIS (production mode)');
  
  const redisClient = getRedisClient();
  
  // Redis接続チェック
  if (!redisClient || !isRedisAvailable()) {
    console.warn('⚠️  Redis is not available. Falling back to MEMORY store.');
    console.warn('⚠️  Sessions will be lost on server restart');
    return session(baseConfig);
  }

  // Redis正常接続時
  console.log('✅ Redis connection established');
  
  return session({
    ...baseConfig,
    store: new RedisStore({
      client: redisClient,
      prefix: 'mmdpf:sess:',
      ttl: Math.floor(maxAge / 1000), // ミリ秒 → 秒
    }),
  });
}
```


**特徴:**

**特徴:**
- ✅ セッション永続化
- ✅ 複数サーバー間でセッション共有可能
- ✅ サーバー再起動でもセッション保持
- ⚠️ Redis環境のセットアップが必要

```yaml
# docker-compose.yml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "3001:3001"
    environment:
      # 開発環境: メモリストア
      - SESSION_STORE_TYPE=memory
      - SESSION_SECRET=dev-secret
      
      # 本番環境: Redisストア（コメントアウト解除）
      # - SESSION_STORE_TYPE=redis
      # - REDIS_URL=redis://redis:6379
    volumes:
      - ./backend:/app
    command: npm run dev

  # Redisサービス（SESSION_STORE_TYPE=redisの場合のみ起動）
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5
    # profiles: ["redis"]  # プロファイル使用時

volumes:
  redis_data:
```

### 起動コマンド例

```bash
# メモリストアモードで起動（Redisなし）
SESSION_STORE_TYPE=memory npm run dev

# Redisストアモードで起動
SESSION_STORE_TYPE=redis npm run dev

# Docker Composeでメモリモード
docker-compose up backend

# Docker ComposeでRedisモード
docker-compose --profile redis up
```

## 🎯 使い分けのガイドライン

### メモリストアを使用すべき場合
- ✅ ローカル開発環境
- ✅ 単体テスト・結合テスト
- ✅ POC（概念実証）
- ✅ シングルサーバー構成の小規模環境

### Redisストアを使用すべき場合
- ✅ 本番環境
- ✅ ステージング環境
- ✅ 複数サーバー構成
- ✅ セッション永続化が必要な場合
- ✅ 負荷分散環境

## ⚠️ 注意事項

### メモリストアモードの制限事項
1. **サーバー再起動でセッション消失**
   - ユーザーは再ログインが必要
   - departmentCdが失われる

2. **複数サーバー間で共有不可**
   - ロードバランサー使用時は非推奨
   - スティッキーセッション設定が必須

3. **メモリ使用量の増加**
   - 長時間稼働でメモリリーク可能性
   - 定期的な再起動推奨

### Redisストアモードの考慮事項
1. **Redis接続失敗時の動作**
   - 自動的にメモリストアにフォールバック
   - 起動時にログで警告表示

2. **パフォーマンス**
   - ネットワークレイテンシの影響を受ける
   - Redis接続プールの適切な設定が重要

3. **セキュリティ**
   - 本番環境ではRedis認証必須
   - TLS暗号化の使用を推奨

### トラブルシューティング

#### ケース1: Redis接続失敗

```
[WARN] Redis initialization failed. Falling back to memory store.
[INFO] 🗄️  Session Store: MEMORY (development mode)
[WARN] ⚠️  Sessions will be lost on server restart
```

**対応:**
1. Redis接続情報を確認
2. Redisサービスが起動しているか確認
3. 一時的にメモリモードで運用可能

#### ケース2: 環境変数設定ミス

```
[WARN] Invalid SESSION_STORE_TYPE: invalid-value. Using 'memory' as fallback.
[INFO] 🗄️  Session Store: MEMORY (development mode)
```

**対応:**
1. SESSION_STORE_TYPEを`memory`または`redis`に設定
2. アプリケーション再起動
