**場所**: `backend/src/repositories/templateDataRepository.ts:85-137`

**目的**: テンプレートデータをUPSERT（INSERT or UPDATE）

```sql
INSERT INTO template_data (
  organization_id,
  project_id,
  method_id,
  task_no,
  place_id,
  template_type,
  template_id,
  data,
  status,
  comment,
  recorded_by,
  recorded_at,
  created_at,
  updated_at
)
VALUES (
  $1, $2, $3, $4, $5, $6, $7, $8::jsonb, $9, $10, $11,
  CURRENT_TIMESTAMP, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP
)
ON CONFLICT (organization_id, project_id, method_id, task_no, place_id)
DO UPDATE SET
  template_type = EXCLUDED.template_type,
  template_id = EXCLUDED.template_id,
  data = EXCLUDED.data,
  status = EXCLUDED.status,
  comment = EXCLUDED.comment,
  recorded_by = EXCLUDED.recorded_by,
  recorded_at = CURRENT_TIMESTAMP,
  updated_at = CURRENT_TIMESTAMP
RETURNING
  id,
  organization_id,
  project_id,
  method_id,
  task_no,
  place_id,
  template_type,
  template_id,
  data,
  status,
  comment,
  recorded_by,
  recorded_at,
  created_at,
  updated_at
```

**パラメータ**:

- $4: taskNo (number)
- $5: placeId (string)
- $6: templateType (string)
- $7: templateId (string)

- $9: status (string | null)
- $10: comment (string | null)
- $11: recordedBy (string)
