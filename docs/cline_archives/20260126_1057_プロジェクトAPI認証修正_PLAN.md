## 5. 技術的詳細

### 修正後のcreateApiClient関数
```typescript
const createApiClient = () => {
  const client = axios.create({
    baseURL: API_BASE_URL,
    timeout: 30000,
    withCredentials: true,
  });

  // リクエストインターセプター
  client.interceptors.request.use(
    (config) => {
      // セッショントークンを取得（Cookie or LocalStorage）
      const sessionToken = getSessionToken();
      
      // 組織IDを取得（Cookie or LocalStorage）
      const organizationId = getOrganizationId();

      // Authorizationヘッダーを追加
      if (sessionToken) {
        config.headers['Authorization'] = `Bearer ${sessionToken}`;
      }

      // X-Organization-Idヘッダーを追加
      if (organizationId) {
        config.headers['X-Organization-Id'] = organizationId;
      }

      return config;
    },
    (error) => Promise.reject(error)
  );

  return client;
};
```

### 認証情報取得関数（例）
```typescript
/**
 * セッショントークンを取得
 * Cookie優先、なければLocalStorageから取得
 */
const getSessionToken = (): string | null => {
  // Cookieから取得を試みる
  const cookies = document.cookie.split(';');
  const sessionCookie = cookies.find(c => c.trim().startsWith('sessionToken='));
  if (sessionCookie) {
    return sessionCookie.split('=')[1];
  }
  
  // LocalStorageから取得
  return localStorage.getItem('sessionToken');
};

/**
 * 組織IDを取得
 * Cookie優先、なければLocalStorageから取得
 */
const getOrganizationId = (): string | null => {
  // Cookieから取得を試みる
  const cookies = document.cookie.split(';');
  const orgCookie = cookies.find(c => c.trim().startsWith('organizationId='));
  if (orgCookie) {
    return orgCookie.split('=')[1];
  }
  
  // LocalStorageから取得
  return localStorage.getItem('organizationId');
};
```

### 発生した問題と解決方法

#### 問題1: Cookie名の不一致
**症状**: 最初の実装でCookie名を`sessionToken`としていたが、認証が通らない可能性があった

**原因調査**:
- `backend/src/controllers/authController.ts`のverifyPin関数を確認
- PINコード検証成功時に`res.cookie('maiml_session', jwtToken, ...)`でCookieを設定していることが判明
- 実際のCookie名は`maiml_session`だった

**解決方法**:
- `getSessionToken`関数のCookie検索を`sessionToken=`から`maiml_session=`に修正
- コメントにも「Cookie名: maiml_session」と明記

#### 実装の最終形
```typescript
const getSessionToken = (): string | null => {
  if (typeof window === 'undefined') {
    return null;
  }

  // Cookie名: maiml_session
  const cookies = document.cookie.split(';');
  const sessionCookie = cookies.find(c => c.trim().startsWith('maiml_session='));
  if (sessionCookie) {
    return sessionCookie.split('=')[1];
  }
  
  // フォールバック: LocalStorage
  try {
    return localStorage.getItem('sessionToken');
  } catch (error) {
    console.error('Failed to get sessionToken from localStorage:', error);
    return null;
  }
};
```
