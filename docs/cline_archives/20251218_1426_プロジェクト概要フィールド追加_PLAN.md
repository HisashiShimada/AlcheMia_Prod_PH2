## 1. タスク概要

プロジェクト管理画面の新規プロジェクト作成フォームに「概要（description）」入力欄を追加し、プロジェクト詳細モーダルでもプロジェクト名の下に概要を表示できるようにする。

## 2. 目的と期待される成果

### 目的
- プロジェクトに詳細な説明情報を持たせることで、プロジェクトの管理性を向上させる
- ユーザーがプロジェクトの目的や内容を一目で理解できるようにする

### 期待される成果
- [x] CreateProjectModalに概要入力欄（TextArea）が追加される
- [x] ProjectDetailModalでプロジェクト名の下に概要が表示される
- [x] 既存のモックデータに概要フィールドが追加される
- [x] 概要の入力は任意（Optional）とする

## 3. 実装ステップ

## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design Input.TextArea: 複数行テキスト入力
- React Hook Form (Form.Item): フォーム管理

### アーキテクチャ上の考慮事項
- CreateProjectDataインターフェースは既にdescriptionフィールドを持っているので、型定義の変更は不要
- 既存のフォームバリデーションパターンを踏襲

### セキュリティ考慮事項
- [x] XSS対策: Ant DesignのTextコンポーネントが自動でエスケープ
- [x] 文字数制限: 500文字まで（maxLength設定）
- [x] 入力サニタイゼーション: 不要（表示時に自動処理）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 既存プロジェクトデータとの互換性 | 低 | 低 | descriptionフィールドは任意なので、未定義でもエラーにならない |
| フォームレイアウトの崩れ | 低 | 低 | Space/Formコンポーネントで適切な間隔を確保 |
| 長文入力時のUI崩れ | 中 | 低 | maxLengthを500文字に制限、TextAreaで複数行表示 |
