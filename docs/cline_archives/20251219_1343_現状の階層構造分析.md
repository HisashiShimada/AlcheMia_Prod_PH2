# 現状のコンポーネント階層構造分析

## 作成日時
2025-12-19 13:56

## 現在の実装状況

### コンポーネント階層図

```
┌─────────────────────────────────────────────────────────┐
│ PetriNetViewer (z-index: auto)                          │
│ ├─ React Flow（ペトリネット全体表示）                    │
│ │                                                        │
│ ├─ StructuredPropertySelector (Modal, z-index: 1000)   │ ← Placeノードクリック時
│ │  └─ プロパティ選択UI                                  │
│ │                                                        │
│ └─ SubNetViewer (Modal, z-index: 1000)                 │ ← Transitionノードクリック時
│    ├─ React Flow（サブネット表示）                      │
│    │                                                     │
│    └─ StructuredPropertySelector (Modal, z-index: 1000)│ ← **問題発生箇所**
│       └─ プロパティ選択UI                               │
└─────────────────────────────────────────────────────────┘

※Modalコンポーネントはbodyタグ直下にレンダリングされる（React Portal）
```

### z-index階層（実際のDOM構造）

```
<body>
  <div id="root">
    <PetriNetViewer>  <!-- z-index: auto -->
      <ReactFlow />
    </PetriNetViewer>
  </div>
  
  <!-- React Portalでレンダリングされる -->
  <div class="ant-modal-root">  <!-- z-index: 1000 -->
    <SubNetViewer Modal>
      <ReactFlow />
    </SubNetViewer>
  </div>
  
  <div class="ant-modal-root">  <!-- z-index: 1000 -->
    <StructuredPropertySelector Modal>
      <!-- プロパティUI -->
    </StructuredPropertySelector>
  </div>
</body>
```

## 問題点の詳細

### 問題1: z-index競合
- SubNetViewer（Modal）と StructuredPropertySelector（Modal）が同じz-indexレベル（1000）
- 両方ともbody直下にPortalでレンダリングされるため、親子関係がない
- 後から開いたModalが前面に来るが、必ずしも意図した順序にならない

### 問題2: モーダルのネスト
- SubNetViewer（Modal）内でPlaceノードをクリック
- → StructuredPropertySelector（Modal）を開く
- → 2つのModalが独立して存在するため、どちらが前面に来るか不定

### 問題3: 背景のブロック
- SubNetViewerが開いているとき、mask（背景暗転）が有効
- その上でStructuredPropertySelectorを開くと、さらにmaskが重なる
- 結果として、背景のPetriNetViewerが完全にブロックされる

### 問題4: リサイズ不可
- SubNetViewerはModalなのでリサイズできない
- Draggableは実装済みだが、サイズ変更ができない

## 理想的な階層構造（修正後）

```
┌─────────────────────────────────────────────────────────┐
│ PetriNetViewer (z-index: auto)                          │
│ ├─ React Flow（ペトリネット全体表示）                    │
│ │                                                        │
│ ├─ StructuredPropertySelector (Modal, z-index: 1000)   │ ← Placeノードクリック時
│ │  └─ プロパティ選択UI                                  │
│ │                                                        │
│ └─ ViewRendererDialog (z-index: 1001, react-rnd)       │ ← Transitionノードクリック時
│    └─ SubNetViewer (div, Modalではない)                │
│       ├─ React Flow（サブネット表示） - 左ペイン        │
│       └─ StructuredPropertySelector (div, Modalではない)│ - 右ペイン
│          └─ プロパティ選択UI                            │
└─────────────────────────────────────────────────────────┘

※ ViewRendererDialog内のコンポーネントはすべてModal化せず、通常のdivベース
※ z-index階層が明確化され、親子関係が正しく保たれる
```

### 実際のDOM構造（修正後）

```
<body>
  <div id="root">
    <PetriNetViewer>  <!-- z-index: auto -->
      <ReactFlow />
    </PetriNetViewer>
  </div>
  
  <!-- React Portalでレンダリング（Placeノード用） -->
  <div class="ant-modal-root">  <!-- z-index: 1000 -->
    <StructuredPropertySelector Modal>
      <!-- プロパティUI -->
    </StructuredPropertySelector>
  </div>
  
  <!-- react-rnd でレンダリング（Transitionノード用） -->
  <div class="react-rnd" style="z-index: 1001">  <!-- ドラッグ&リサイズ可能 -->
    <ViewRendererDialog>
      <SubNetViewer div>  <!-- Modalではない -->
        <div style="display: flex">
          <div style="flex: 1">
            <ReactFlow />  <!-- 左ペイン -->
          </div>
          <div style="width: 400px">
            <StructuredPropertySelector div>  <!-- Modalではない、埋め込み -->
              <!-- プロパティUI -->
            </StructuredPropertySelector>
          </div>
        </div>
      </SubNetViewer>
    </ViewRendererDialog>
  </div>
</body>
```

## 修正方針

### 1. ViewRendererDialogの拡張
- react-rndライブラリを使用してリサイズ機能を追加
- contentTypeプロパティを追加（'file' | 'subnet'）
- SubNetViewer用のデータを受け取れるようにpropsを拡張

### 2. SubNetViewerの非Modal化
- Modalコンポーネントを削除
- 通常のdivベースのコンポーネントに変更
- ViewRendererDialog内のコンテンツとして表示

### 3. StructuredPropertySelectorの埋め込み化
- SubNetViewer内ではModalを使用せず、divベースで右ペインに埋め込み
- embeddedモードを追加（オプション）

### 4. PetriNetViewerの修正
- Transitionノードクリック時、SubNetViewerのModalを開く代わりに
- ViewRendererDialogを開いてその中でSubNetViewerを表示

## 利点

### 修正後の利点
1. **z-index競合の解消**: すべてのコンポーネントがViewRendererDialog内に収まるため、z-index階層が明確
2. **リサイズ可能**: react-rndによりドラッグとリサイズの両方が可能
3. **モーダルの簡素化**: SubNetViewer内でModalを使わないため、ネストの問題がない
4. **背景操作可能**: ViewRendererDialogはmask=falseで背景をブロックしない
5. **統一された実装**: ViewRendererDialogという統一されたフロートウィンドウで管理
