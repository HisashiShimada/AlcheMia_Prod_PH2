## 🏗️ 技術的考慮事項

### 共通API設計のポイント

#### contextパラメータによる保存先判定
```typescript
// リクエストボディ
{
  "context": "project" | "format",
  "contextId": "project_id" | "format_id",
  "file": "ファイルデータ"
}

// バックエンド処理
const s3Key = context === 'project'
  ? `org_${orgPrefix}/projects/${projectName}/${fileName}`
  : `org_${orgPrefix}/formats/${formatPrefix}/${fileName}`;
```

### Maiml編集画面特有の注意点

#### 1. MAIMLパース処理
```typescript
// 複数メソッド構造の検出
const detectMultipleMethods = (maimlContent: string): boolean => {
  // <method>タグを検索
  const methodMatches = maimlContent.match(/<method[^>]*>/g);
  return methodMatches && methodMatches.length > 1;
};

// methodId抽出
const extractMethodIds = (maimlContent: string): string[] => {
  const methodRegex = /<method[^>]*id="([^"]+)"/g;
  const methodIds: string[] = [];
  let match;
  while ((match = methodRegex.exec(maimlContent)) !== null) {
    methodIds.push(match[1]);
  }
  return methodIds;
};
```

#### 2. Base64エンコード/デコード
```typescript
// エンコード（フロントエンド → バックエンド）
const base64Data = btoa(unescape(encodeURIComponent(maimlContent)));

// デコード（バックエンド → フロントエンド）
const maimlContent = atob(base64Data);
```

#### 2. マルチテナント分離

### フロントエンド接続時の注意点

#### 1. useApiフックの活用
```typescript

  fetchFunction,

```

#### 2. エラーハンドリング
```typescript

  const response = await apiFunction();
  if (!response.success) {
    message.error(response.error.message);
    return;
  }
  // 成功処理

  console.error('API Error:', error);
  message.error('通信エラーが発生しました');

```

## ⚠️ リスクと対策

### 1. 共通API設計の複雑性
**リスク**: contextパラメータによる分岐処理が複雑になる  
**対策**: 明確なインターフェース設計、ユニットテスト充実

### 2. S3操作の複雑性
**リスク**: ファイル一覧取得、署名付きURL生成の実装が複雑  
**対策**: `storageService.ts` の既存実装を活用、段階的に実装

### 3. マルチテナント分離の徹底
**リスク**: organization_idフィルタ漏れによるデータ漏洩  
**対策**: 全クエリでチェックリスト確認、コードレビュー必須

### 4. 既存モックデータとの整合性
**リスク**: API接続後にUIが正しく動作しない  
**対策**: レスポンス形式を既存モックデータと完全一致させる

### 5. パフォーマンス問題
**リスク**: 大量ファイル/タスクでの動作遅延  
**対策**: ページネーション実装、キャッシング戦略

### 6. MAIMLパース処理の複雑性
**リスク**: 複数メソッド検出ロジックが複雑で実装ミスのリスク  
**対策**: ユニットテスト充実、既存のmaimlParserユーティリティ活用

### 7. Base64エンコードの文字化け
**リスク**: 日本語文字を含むMAIMLでエンコード/デコードエラー  
**対策**: `unescape(encodeURIComponent())` パターンを厳守
