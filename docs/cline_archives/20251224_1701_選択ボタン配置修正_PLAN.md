## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Space, Button, Select コンポーネント
- React: 既存のReactコンポーネント
- TypeScript: 型定義は変更なし

### レイアウト変更の詳細

#### ExperimentWorkerMenu（プロジェクト選択エリア）
**変更前:**
```tsx
<Space>...</Space>
<Button style={{ marginLeft: 'auto' }}>選択</Button>
```

**変更後:**
```tsx
<Space size="middle">
  <FolderOutlined />
  <Text>プロジェクト:</Text>
  <Select />
  <Button>選択</Button>
</Space>
```

#### MethodTaskSelector（メソッド・タスク選択エリア）
**変更前:**
```tsx
<Space>メソッド...</Space>
<Space>タスク...</Space>
<Button style={{ marginLeft: 'auto' }}>選択</Button>
```

**変更後:**
```tsx
<Space size="middle">
  <PartitionOutlined />
  <Text>メソッド:</Text>
  <Select />
</Space>
<Space size="middle">
  <CheckSquareOutlined />
  <Text>タスク:</Text>
  <Select />
  <Button>選択</Button>
</Space>
```

### UIポリシー準拠
- Spaceコンポーネントの`size="middle"`を使用（16px間隔）
- `token.margin`を使用した一貫性のある間隔設定
