## 📋 タスク概要

ファイル操作後にキャッシュを自動クリアし、最新データを反映する機能を実装します。

---

## 🎯 目的と期待される成果

### 目的

1. **データ整合性の向上**: ファイル操作後に古いキャッシュが残らないようにする
2. **ユーザー体験の向上**: 常に最新のデータを取得できるようにする
3. **不具合の防止**: 古いキャッシュによる表示不整合を防ぐ

### 期待される成果

- [ ] ファイルアップロード後に自動でキャッシュクリア
- [ ] キャッシュクリア失敗してもアップロードは成功
- [ ] キャッシュクリア実行ログが出力される

---

## 📖 Reference版の実装

```javascript
// アップロード成功後にキャッシュクリア

// レスポンス

  // ...

  }

```

### 処理フロー

```

  ↓

次回APIリクエスト時に最新データ取得
```

  }

## ⚠️ 注意事項

### エラーハンドリング

**重要**: キャッシュクリア失敗は警告のみ、処理は続行する

```typescript
try {
  await clearFileCache();
} catch (cacheError) {
  // ❌ throw しない（アップロード処理は成功扱い）
  console.warn('⚠️ [Cache] キャッシュクリアエラー（処理続行）:', cacheError);
}
```

**理由**:
- アップロード自体は成功している
- キャッシュクリアは補助的な処理
- キャッシュは時間経過でも更新される

### パフォーマンス影響

**全クリアの場合**:
- 次回リクエスト時にキャッシュミスが発生
- 一時的にレスポンスが遅くなる可能性
- 通常は許容範囲内

**部分クリアの場合**:
- 影響範囲が限定的
- より望ましい実装
