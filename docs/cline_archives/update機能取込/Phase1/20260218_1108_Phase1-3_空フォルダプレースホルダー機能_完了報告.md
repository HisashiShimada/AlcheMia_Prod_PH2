### 3. サービス層の実装（fileAccessService.ts）

#### createEmptyFolderPlaceholdersメソッド

**実装内容**:
```typescript
async createEmptyFolderPlaceholders(
  organizationId: string,
  emptyFolders: string[]
): Promise<PlaceholderResult[]>
```

**処理フロー**:
1. 各空フォルダパスに対してループ処理
2. プレースホルダーファイルキー生成（`${folderPath}/.folder_placeholder`）
3. 既存ファイルの重複チェック（`fileExists()`）
4. プレースホルダーファイル内容の生成
   ```
   # Folder Placeholder
   Created: 2026-02-18T11:08:00.000Z
   Folder: projects/sample_project/empty_folder
   
   This file is a placeholder to preserve empty folder structure in S3/Swift storage.
   ```
5. S3/Swiftにアップロード（`uploadFile()`）
6. file_metadataテーブルに保存（`saveFileMetadata()`）
7. 結果を配列に格納して返却

**重複チェック**:
- 既にプレースホルダーが存在する場合は`skipped: true`でスキップ

**エラーハンドリング**:
- 個別フォルダのエラーは記録して継続
- DBエラーは警告のみ（S3上にファイルは作成されているため）

## 🔍 実装の特徴

### 1. 重複チェック機能

```typescript
const exists = await this.storageService.fileExists(
  organizationId,
  placeholderKey
);

if (exists) {
  console.log(`⚠️ [Placeholder] スキップ（既存）: ${placeholderKey}`);
  results.push({
    folderPath,
    placeholderKey,
    success: true,
    skipped: true,
  });
  continue;
}
```

- 既にプレースホルダーが存在する場合は作成をスキップ
- 不要な重複アップロードを防止

### 2. プレースホルダーファイルの内容

```
# Folder Placeholder
Created: 2026-02-18T11:08:00.000Z
Folder: projects/sample_project/empty_folder

This file is a placeholder to preserve empty folder structure in S3/Swift storage.
```

- テキスト形式で可読性を確保
- 作成日時とフォルダパスを記録
- 目的を明記

### 3. エラーハンドリング

**個別フォルダのエラー**:
```typescript
catch (error) {
  console.error(`❌ [Placeholder] 作成失敗: ${folderPath}`, error);
  results.push({
    folderPath,
    success: false,
    error: error instanceof Error ? error.message : 'Unknown error',
  });
}
```

**DB保存エラー**:
```typescript
catch (dbError) {
  // DBエラーは警告のみ（S3上にファイルは作成されているので続行）
  console.warn(`⚠️ [Placeholder] DB保存エラー（続行）: ${placeholderKey}`, dbError);
}
```

- 個別フォルダの失敗は記録して継続
- S3上にファイルが作成されていればDB保存失敗は警告のみ

### 4. 詳細なログ出力


## 📝 使用例

### クライアント側の実装例

```typescript
// フォルダアップロード時に空フォルダも含める
const emptyFolders = [
  'projects/sample_project/data/raw',
  'projects/sample_project/results/charts',
  'projects/sample_project/logs/archive',
];

const formData = new FormData();
formData.append('uploadMode', 'folder');
formData.append('targetPath', 'projects/sample_project');
formData.append('emptyFolders', JSON.stringify(emptyFolders));

// ファイル追加
files.forEach(file => formData.append('files', file));

// アップロード
const response = await fetch('/api/v1/files/upload', {
  method: 'POST',
  body: formData,
});

const result = await response.json();

// プレースホルダー作成結果を確認
if (result.data.emptyFolders) {
  const successCount = result.data.emptyFolders.filter(f => f.success).length;
  console.log(`空フォルダプレースホルダー: ${successCount}/${result.data.emptyFolders.length}個作成`);
}
```
