## ⚠️ 注意事項

### 1. メモリ使用量の増加

**現状**: Multerはメモリストレージを使用

```typescript
storage: multer.memoryStorage(),
```

**懸念事項**:
- 500MBファイルのアップロード時、メモリに一時保存される
- 複数同時アップロードでメモリ不足の可能性

**対策**:
- 本番環境でのメモリ監視が必要
- 必要に応じてディスクストレージへの変更を検討

### 2. サーバースペックの確認

**推奨サーバースペック**:
- **RAM**: 最低4GB以上（推奨8GB以上）
- **CPU**: 2コア以上
- **ディスク**: 十分な空き容量

### 3. Nginx設定の反映

**設定を反映するには**:
```bash
# Nginxの設定リロード
docker-compose restart nginx

# または
nginx -s reload
```
