```
  ↓

```

### namespaceOriginフラグの付与

取り込み時に以下の情報を付与：

```typescript
{
  ...propData,
  namespaceOrigin: true,
  namespaceSource: {
    uri: namespaceData.namespaceURI,
    hierarchyPath: namespaceData.hierarchyPath,
    importedAt: new Date().toISOString()
  }
}
```

## 既知の問題と解決

### 問題1: TypeScriptエラー（Folder型）
**エラー内容:**
```
'Folder' 型と 'number' 型が重複していないため、この比較は意図したとおりに表示されない可能性があります。
```

**原因:**
Folder型の`children`が`Record<string, Folder>`として定義されていたが、配列として扱っていた。

**解決:**
```typescript
// 修正前
children: Record<string, Folder>

// 修正後
subfolders: Folder[]
```

### 問題2: eslint警告（useEffect内でのsetState）
**警告内容:**
```
Error: Calling setState synchronously within an effect can trigger cascading renders
```

**対応:**
既存コードの問題であり、今回の実装では新規に発生していない。既存の警告として残す。
