## 5. 技術的詳細

### 新規APIエンドポイント

```typescript
GET /api/v1/formats/:folderName/files?path=subfolder

// リクエストパラメータ
- folderName: フォルダ名（例: maiml_1）
- path: サブフォルダパス（オプション、例: displayTest）

// レスポンス
{
  data: {
    files: [
      {
        id: string;
        name: string;
        path: string;
        size: number;
        lastModified: string;
        type: string;
        isFolder: boolean;
        fileCount?: number;  // フォルダの場合のみ
      }
    ]
  }
}
```

### S3パス構造

```
formats/
└── {departmentCd}/
    └── maiml_1/
        ├── file1.maiml
        ├── file2.maiml
        └── displayTest/
            ├── displayTest.txt
            └── displayTest.xml
```

### フォルダ判定ロジック

S3のlistFiles結果から、フォルダとファイルを区別：
- 末尾が`/`で終わる → フォルダ
- それ以外 → ファイル
