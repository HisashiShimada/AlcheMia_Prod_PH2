## 5. 技術的詳細

### 修正前のエンドポイント
```typescript
POST /api/v1/issues/:issueId/comments
- パスパラメータ: issueId
- ボディパラメータ: comment
- 権限チェック: なし
```

### 修正後のエンドポイント
```typescript
POST /api/v1/issues/comments
- ボディパラメータ: projectName, issueId, comment
- 権限チェック: experiment_worker のみ
```

### バリデーション追加項目
- `projectName`: string, 必須, 空文字列でない
- `issueId`: string, 必須, 空文字列でない
- `comment`: string, 必須, 1-2000文字（既存）

### ミドルウェアチェーン
```typescript
router.post('/comments',
  authMiddleware,
  tenantIsolation,
  checkPermission('050000', 1), // 実験作業機能の書込権限
  [...validators],
  handleValidationErrors,
  issueController.addComment
);
```
