## 1️⃣ 未実装の機能（現行版に存在しない）

### ローカルダウンロード機能

**V2版の実装:**
```javascript
const handleDownload = useCallback(() => {
  const maimlXml = convertReactFlowToMaiML(nodes, edges, templates, documentData);
  const blob = new Blob([maimlXml], { type: 'application/xml' });
  const url = URL.createObjectURL(blob);
  
  const link = document.createElement('a');
  link.href = url;
  link.download = `${fileName}.maiml`;
  link.click();
  
  URL.revokeObjectURL(url);
}, [nodes, edges, templates, documentData, fileName]);
```

**現行版**: ❌ 未実装

**理由**: S3ベースの保存が主要機能のため

**影響度**: 低（必要に応じて追加可能）

**実装工数**: 1-2時間

**推奨実装場所**: `SaveConfirmDialog` 内にボタン追加

**現行版:**

**評価**: 現行版の方がより統合的で保守しやすい ✅
