## 📝 技術的な注意点

### Collapse.Panel → items 変換時の注意
1. **keyの指定**: 必ず一意のkeyを指定
2. **ネスト構造**: childrenプロパティで対応
3. **defaultActiveKey**: そのまま使用可能
4. **イベントハンドラ**: onChange等もそのまま使用可能

### List → Space + map 変換時の注意
1. **key属性**: mapのkey属性は必須
2. **スタイリング**: SpaceのorientationとsizeでLayout制御
3. **アイテム間隔**: size="small|middle|large" または数値指定
4. **width**: 親要素の幅いっぱいに表示する場合は `style={{ width: '100%' }}`
