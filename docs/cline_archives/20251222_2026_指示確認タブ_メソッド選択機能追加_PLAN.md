## 1. タスク概要

実験作業者メニューの「指示確認」タブにメソッド選択エリアとモーダルを追加し、メソッド単位でのフィルタリング機能を実装する。

## 2. 目的と期待される成果

### 目的
- 実験作業者が特定のメソッドに関連する指示のみを確認できるようにする
- 全体指示とメソッド単位指示を効率的に切り替えて確認できるようにする

### 期待される成果
- [ ] メソッド選択エリアの追加（タブ下部に配置）
- [ ] メソッド選択モーダルの実装
- [ ] メソッドフィルタリング機能の実装
- [ ] プロジェクト未選択/メソッド未選択時の適切な表示制御

## 3. 実装ステップ

### Phase 1: メソッド選択モーダルコンポーネントの作成
- [ ] `MethodSelectionModal.tsx`を新規作成
- [ ] モーダルのUI実装（メソッド一覧テーブル、キャンセル/決定ボタン）
- [ ] メソッド選択状態の管理
- [ ] プロジェクトデータからのメソッド取得

### Phase 2: InstructionConfirmationTabの修正
- [ ] メソッド選択エリアのUI追加
  - [ ] アイコン、ラベル、コンボボックス、選択ボタンの配置
  - [ ] プロジェクト未選択時の非活性制御
- [ ] メソッド選択モーダルの統合
- [ ] メソッドフィルタリングロジックの修正
  - [ ] プロジェクト未選択時：何も表示しない
  - [ ] メソッド未選択時：全作業指示を表示

### Phase 3: 状態管理の調整
