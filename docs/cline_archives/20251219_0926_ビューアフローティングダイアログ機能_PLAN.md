## 1. タスク概要

現在のビューアダイアログ（Drawer）をフローティングウィンドウ化し、以下の機能を追加する：

1. **ドラッグ&ドロップ**: ダイアログをマウスでドラッグして自由に移動可能
2. **複数ダイアログ表示**: 複数のファイルを同時に開き、並べて表示可能
3. **独立した状態管理**: 各ダイアログが独立して開閉・管理される

interface ViewRendererDialogProps {

// Modalのラッパーコンポーネントとして実装
const ViewRendererDialog: React.FC<ViewRendererDialogProps> = ({
  id,
  file,
  onClose,
  zIndex,
  onFocus,
  initialPosition = { x: 100, y: 100 }
}) => {
  const dragRef = useRef<HTMLDivElement>(null);
  
  return (
    <Modal
      open={true}
      mask={false}
      maskClosable={false}
      footer={null}
      closable={false}
      width={1200}
      style={{
        top: initialPosition.y,
        left: initialPosition.x,
        zIndex: zIndex,
      }}
      modalRender={(modal) => (
        <Draggable
          handle=".draggable-handle"
          bounds={false}  // 別モニターへの移動を可能にするため制限なし

      }}>

#### ProjectManagement.tsx の改修

```typescript
interface OpenDialog {
  id: string;
  file: FileData;
  zIndex: number;
  position: { x: number; y: number };
}

const ProjectManagement: React.FC = () => {
  const [openDialogs, setOpenDialogs] = useState<OpenDialog[]>([]);
  const [nextZIndex, setNextZIndex] = useState(1000);

  // ダイアログを開く
  const handleViewFile = (file: FileData) => {
    const id = `${file.id}-${Date.now()}`;
    const offset = openDialogs.length * 30;  // カスケード配置
    
    const newDialog: OpenDialog = {
      id,
      file,
      zIndex: nextZIndex,
      position: { x: 100 + offset, y: 100 + offset }
    };
    
    setOpenDialogs(prev => [...prev, newDialog]);
    setNextZIndex(prev => prev + 1);
  };

  // ダイアログを閉じる
  const handleCloseDialog = (id: string) => {
    setOpenDialogs(prev => prev.filter(d => d.id !== id));
  };

  // ダイアログをフォーカス（最前面に）
  const handleFocusDialog = (id: string) => {
    setOpenDialogs(prev => 
      prev.map(d => 
        d.id === id 
          ? { ...d, zIndex: nextZIndex }
          : d
      )
    );
    setNextZIndex(prev => prev + 1);
  };

  return (
    <>
      {/* 既存のUI */}
      <FileListTable onViewFile={handleViewFile} ... />
      
      {/* 複数のフローティングダイアログ */}
      {openDialogs.map(dialog => (
        <ViewRendererDialog
          key={dialog.id}
          id={dialog.id}
          file={dialog.file}
          zIndex={dialog.zIndex}
          initialPosition={dialog.position}
          onClose={handleCloseDialog}
          onFocus={handleFocusDialog}
        />
      ))}
    </>
  );
};
```

### アーキテクチャ上の考慮事項
- **DrawerからModalへの移行**: Modalはフローティング表示に適している
- **react-draggableの使用**: 既にプロジェクトに含まれているため追加インストール不要
- **Z-index管理**: アクティブなダイアログを常に最前面に表示
- **メモリ管理**: 閉じたダイアログのリソースを適切に解放

### セキュリティ考慮事項
- [ ] 大量のダイアログを開くことによるメモリ不足を防ぐ（上限設定: 5個）
- [ ] ダイアログIDの衝突を防ぐ（timestamp使用）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 大量のダイアログによるパフォーマンス低下 | 高 | 中 | ダイアログ数の上限を設定（5個） |
| ドラッグ操作が重い | 中 | 低 | react-draggableの最適化オプション使用 |
| 画面外にダイアログが移動 | 中 | 中 | bounds属性で画面内に制限 |
| Z-index管理の複雑化 | 低 | 中 | シンプルなカウンター方式で管理 |
