## 1. タスク概要

既存のPINコード免除機能の仕様を大幅に変更します。組織ごとの個別設定から、システム全体での統一設定に変更し、組織の二段階認証要否フラグで免除判定を行うように修正します。

### 主な変更点

#### 変更前（旧仕様）
- 組織ごとに`pin_exemption_period_days`で免除期間を設定
- 最終ログイン日時から経過日数で判定

#### 変更後（新仕様）
1. **envファイルで一律設定** - `TWO_FACTOR_AUTH_EXEMPTION_DAYS`で全組織共通の免除期間を設定
2. **organizationテーブルの`is_entry`カラムで判定**
   - `is_entry=false`: 二段階認証なし（常に免除）
   - `is_entry=true`: 二段階認証あり（期間判定）
3. **login_historyテーブルに`entry_execute_flg`追加**
   - 各ログイン時に二段階認証を実施したかどうかを記録
4. **ユーザー個別の最終二段階認証日時で判定**
   - ログインしようとしているユーザー自身の最終二段階認証日時を検索
   - envファイルで設定した日数以上経過していて、かつis_entry=trueなら二段階認証を有効化

```typescript
async isExemptionApplicable(
  userId: string,
  organizationId: string
): Promise<Result<PinExemptionCheck>> {
  // 1. 組織のis_entryを取得
  const isEntry = await organizationRepository.getIsEntry(organizationId);
  
  // is_entry=false の場合は常に免除（二段階認証不要）
  if (!isEntry) {
    return {
      success: true,
      data: {
        isExempt: true,
        daysSinceLastAuth: null,
        exemptionPeriodDays: 0,
        reason: 'Organization does not require two-factor authentication'
      }
    };
  }
  
  // 2. envファイルから免除期間を取得
  const exemptionDays = parseInt(process.env.TWO_FACTOR_AUTH_EXEMPTION_DAYS || '0', 10);
  
  if (exemptionDays === 0) {
    return {
      success: true,
      data: {
        isExempt: false,
        daysSinceLastAuth: null,
        exemptionPeriodDays: 0,
        reason: 'Exemption period is 0'
      }
    };
  }
  
  // 3. ユーザーの最終二段階認証日時を取得
  const lastAuthLogin = await loginHistoryRepository.getLastTwoFactorAuthLogin(
    userId,
    organizationId
  );
  
  if (!lastAuthLogin) {
    return {
      success: true,
      data: {
        isExempt: false,
        daysSinceLastAuth: null,
        exemptionPeriodDays: exemptionDays,
        reason: 'No previous two-factor authentication history'
      }
    };
  }
  
  // 4. 経過日数を計算
  const daysSince = this.calculateDaysSinceLastLogin(lastAuthLogin.login_at);
  
  // 5. 免除期間内かどうかを判定
  const isExempt = daysSince <= exemptionDays;
  
  return {
    success: true,
    data: {
      isExempt,
      daysSinceLastAuth: daysSince,
      exemptionPeriodDays: exemptionDays,
      reason: isExempt 
        ? 'Within exemption period' 
        : 'Exemption period expired (two-factor auth required)'
    }
  };
}
```

### 免除判定ロジック（新仕様）

```typescript
// 判定フロー
1. organizationテーブルからis_entryを取得
   ↓
2. is_entry=false → 常に免除（二段階認証不要）
   ↓
3. is_entry=true → 環境変数TWO_FACTOR_AUTH_EXEMPTION_DAYSを取得
   ↓
4. 免除期間=0日 → 常に二段階認証必要
   ↓
5. login_historyから最終二段階認証日時を取得
   WHERE user_name = $1 
     AND organization_id = $2 
     AND entry_execute_flg = true
   ORDER BY login_at DESC LIMIT 1
   ↓
6. 履歴なし → 二段階認証必要（初回ログイン）
   ↓
7. 経過日数 <= 免除期間 → 免除適用
8. 経過日数 > 免除期間 → 二段階認証必要
```

| リスク | 影響度 | 発生確率 | 対策 |
