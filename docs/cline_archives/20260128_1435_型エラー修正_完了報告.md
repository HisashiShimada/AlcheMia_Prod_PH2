## 1. 修正概要

DocumentEditDialogとdocumentParser間の型の不一致を解消しました。

## 2. 実施した修正

### 修正ファイル
- `frontend/src/utils/documentParser.ts`

### 型定義の変更

#### DocumentData型
```typescript
export interface DocumentData {
  id: string;
  name: string;
  uuid?: string;           // 必須 → オプショナル
  description?: string;    // 必須 → オプショナル
  date: string;
  protocolId?: string;     // 必須 → オプショナル
  methodId?: string;       // 必須 → オプショナル
  pnmlId?: string;         // 必須 → オプショナル
  programId?: string;      // 必須 → オプショナル
  creators: CreatorData[];
  vendors: VendorData[];
  owners: OwnerData[];
  instruments: InstrumentData[];
}
```

#### CreatorData / VendorData / OwnerData / InstrumentData型
```typescript
export interface CreatorData {
  id: string;
  name?: string;           // 必須 → オプショナル
  uuid?: string;           // 必須 → オプショナル
  description?: string;    // 必須 → オプショナル
  annotation?: string;     // 必須 → オプショナル
  vendorRef?: {
    id: string;
    ref: string;
  };
  instrumentRef?: {
    id: string;
    ref: string;
  };
}

// VendorData, OwnerData, InstrumentDataも同様に変更
```

## 3. 修正理由

### 問題
- DocumentEditDialog.tsxでは全てオプショナル（`?`）として定義
- documentParser.tsでは必須（非オプショナル）として定義
- 2つのコンポーネント間でDocumentDataをやり取りする際に型エラーが発生

### 解決策
documentParser.tsの型定義をDocumentEditDialog.tsxに合わせて全てオプショナルに変更しました。

これにより：
- ✅ DocumentEditDialogで新規作成時に空のフィールドを許容
- ✅ documentParserでXMLから抽出した値をそのまま使用
- ✅ fillMissingDocumentFields関数で不足フィールドを補完
- ✅ 両コンポーネント間のデータ受け渡しが型安全に
