### 発生した問題と解決策

**問題1: Map.entries()のイテレーションエラー**
```
error TS2802: Type 'MapIterator<[any, any]>' can only be iterated through when using the '--downlevelIteration' flag
```

**解決策:**
```typescript
// 修正前
for (const [key, value] of map.entries()) { ... }

// 修正後
Array.from(map.entries()).forEach(([key, value]) => { ... });
```
