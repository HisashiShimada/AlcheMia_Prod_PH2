## 1. タスク概要

`docs/design/api/api_list.md` の 6.5 タスクステータス更新エンドポイントを、実装済みの内容に合わせて修正します。

### 背景

タスクステータス更新APIは以下のように実装されています：
- **ルート**: `backend/src/routes/taskRoutes.ts`
- **エンドポイント**: `PUT /api/v1/projects/:projectId/methods/:methodId/tasks/:taskNo/status`
- **コントローラー**: `taskController.updateStatus`
- **ミドルウェア**: `authMiddleware`のみ

しかし、`api_list.md` では以下のように記載されており、実装と乖離しています：
- **エンドポイント**: `PUT /api/v1/tasks/:taskId/status`（誤）
- **実装状態**: ⏳ 未実装（誤）
- **コントローラー**: `ProgressController.updateTaskStatus`（誤）
- **ルートファイル**: `progressRoutes.ts`（誤）
