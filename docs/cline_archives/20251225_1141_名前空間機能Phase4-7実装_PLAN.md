## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Modal, Button, Space, Badge, Radio, Spin
- React Icons: CloudDownloadOutlined, FolderOutlined, FolderOpenOutlined, PlusOutlined, MinusOutlined
- React Hooks: useState（既存）
- カスタムフック: useNamespaceOperations（Phase 2で実装済み）

### データフロー
```
ボタンクリック
  ↓
handleOpenNamespaceDialog()
  ↓
loadS3FolderStructure() [useNamespaceOperations]
  ↓
S3フォルダ構造取得（モック）
  ↓
ダイアログ表示
  ↓
フォルダ選択 → handleSelectNamespaceFolder()
  ↓
loadNamespaceFilesFromS3Folder()
  ↓
ファイル一覧表示
  ↓
ファイル選択 → handleSelectNamespaceFile()
  ↓
analyzeNamespaceFile()
  ↓
プレビュー表示
  ↓
取り込みボタンクリック → handleImportNamespace()
  ↓
Properties/Contents更新 + namespaceOriginフラグ付与
```
