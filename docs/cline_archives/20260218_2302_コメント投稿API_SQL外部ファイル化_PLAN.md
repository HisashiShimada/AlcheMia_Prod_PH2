| No | SQLファイル | 用途 | 内容 |
|----|------------|------|------|
| 1 | `issue_comment/addCommentCheckIssue.sql` | 問題存在確認とロック取得 | `SELECT ... FROM issues WHERE ... FOR UPDATE` |
| 2 | `issue_comment/addCommentGetNextSeq.sql` | シーケンス番号の採番 | `SELECT COALESCE(MAX(sequence_no), 0) + 1` |
| 3 | `issue_comment/addCommentInsert.sql` | コメントレコードの挿入 | `INSERT INTO issue_comment ... RETURNING ...` |
| 4 | `issue_comment/addCommentGetAuthorName.sql` | 投稿者名の取得 | `SELECT user_name FROM organization_user` |

## 5. 参考情報

### SQLファイルの内容

#### 1. addCommentCheckIssue.sql
```sql
-- 問題存在確認とロック取得
SELECT issue_id, organization_id, project_id
FROM issues
WHERE issue_id = $1 AND organization_id = $2
FOR UPDATE
```

#### 2. addCommentGetNextSeq.sql
```sql
-- シーケンス番号の採番
SELECT COALESCE(MAX(sequence_no), 0) + 1 AS next_seq
FROM issue_comment
WHERE organization_id = $1 AND issue_id = $2
```

#### 3. addCommentInsert.sql
```sql
-- コメントレコードの挿入
INSERT INTO issue_comment (
  organization_id, project_id, issue_id, sequence_no,
  comment, author_id, commented_at,
  create_user_id, create_at, update_user_id, update_at
) VALUES (
  $1, $2, $3, $4, $5, $6, NOW(), $6, NOW(), $6, NOW()
)
RETURNING 
  organization_id, project_id, issue_id, sequence_no,
  comment, author_id, commented_at
```

#### 4. addCommentGetAuthorName.sql
```sql
-- 投稿者名の取得
SELECT user_name
FROM organization_user
WHERE organization_id = $1 AND user_id = $2
```
