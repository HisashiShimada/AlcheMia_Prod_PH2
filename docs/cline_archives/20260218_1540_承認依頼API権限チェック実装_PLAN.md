## 補足: API仕様書からの抜粋

### 13. 承認依頼 🔴

**エンドポイント**: `PATCH /api/v1/projects/:projectName/approval-request`

**説明**: 実験作業完了後に実験管理者へ承認依頼を送信

**認証**: 必須

**権限**: `experiment_worker`（書込可）

**優先度**: ⭐⭐⭐ 高

### 実装要件

**ミドルウェアチェーン**:
```typescript
router.patch(
  '/:projectName/approval-request',
  authMiddleware,           // 1. JWT認証
  tenantIsolation,          // 2. テナント分離
  checkPermission('050000', 1),  // 3. 権限チェック（実験作業者、書き込み可）
  [...validation],          // 4. バリデーション
  handleValidationErrors,   // 5. バリデーションエラーハンドリング
  projectController.requestApproval  // 6. コントローラー処理
);
```

### 機能CD定義

- `050000`: 実験作業者メニュー
- 権限レベル `1`: 書き込み可（読み取りも含む）
- 権限レベル `0`: 読み取り専用
