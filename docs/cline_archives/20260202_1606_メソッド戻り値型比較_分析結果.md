**maimlParserTyped.ts:**
```typescript
getTransitions(): TransitionsResult = {
  success: boolean;

    id: string;

  }>;
  category: 'experiment' | 'preparation' | 'finalization' | 'other';
}
```

**判定**: ⚠️ **構造的差異あり**

**差異内容**:

1. **成功/失敗フラグ**:
   - Exp版: `error: string | null` でエラー詳細を返す
   - Typed版: エラー情報なし（例外で処理）

2. **Transition情報**:
   - Exp版: `methodIndex`, `displayName`, `isExperimentRelevant` を含む
   - Typed版: `methodName` を含む、`methodIndex`なし

3. **Arc方向の表現**:
   - Exp版: `direction: 'outgoing' | 'incoming'`
   - Typed版: `type: 'input' | 'output'`

4. **metadata構造**:
   - Exp版: 詳細な診断情報（hasProtocol, hasMethod等）
   - Typed版: シンプルな集計情報（totalMethods, categoryCounts）

**影響度**: 中

**推奨対応**:
```typescript
// 統一案: Typed版を拡張

    direction?: 'outgoing' | 'incoming'; // 互換性のため残す
  }>;
  displayName?: string;     // ✅ 追加
  category: 'experiment' | 'preparation' | 'finalization' | 'other';

}

interface TransitionsResult {

    hasMethod: boolean;     // ✅ 追加（診断用）
    hasPnml: boolean;       // ✅ 追加（診断用）
    totalMethods: number;
    totalTransitions: number;
    categoryCounts: {
      experiment: number;
      preparation: number;
      finalization: number;
      other: number;
    };
    methodBreakdown?: Array<{ // ✅ 追加
```

### 3. getTemplates()

**maimlParserExp.ts:**
```typescript
getTemplates(): {
  materials: Array<{
    id: string;
    type: 'material';
    name: string;
    description: string;
    placeRef: string;
    placeRefs: string[];
    transitionRef: string | null;
    properties: any[];
    hasTemplateRef: boolean;
    hasInsertion: boolean;
    resolvedFromRef: string | null;
  }>;
  conditions: Array<{...}>;  // 同じ構造
  results: Array<{...}>;     // 同じ構造

```

**maimlParserTyped.ts:**
```typescript

  materials: TemplateInfo[];
  conditions: TemplateInfo[];
  results: TemplateInfo[];

// TemplateInfo型定義
interface TemplateInfo {
  id: string;
  type: 'material' | 'condition' | 'result';
  name?: string;
  placeRef?: string;
  transitionRef?: string;
  properties: PropertyInfo[];
}

  key: string;
  type: string;
  description?: string;
  units?: string;
  defaultValue?: string;
  properties?: PropertyInfo[]; // propertyListType用
}
```

**判定**: ⚠️ **構造的差異あり**

**差異内容**:

1. **Template情報の粒度**:
   - Exp版: 詳細情報（`hasTemplateRef`, `hasInsertion`, `resolvedFromRef`, `placeRefs配列`）を含む
   - Typed版: 最小限の情報のみ

2. **Property型**:
   - Exp版: `any[]`（柔軟だが型安全でない）
   - Typed版: `PropertyInfo[]`（型安全）

**影響度**: 中

**推奨対応**:
```typescript
// 統一案: Typed版を拡張
interface TemplateInfo {
  id: string;
  type: 'material' | 'condition' | 'result';
  name?: string;
  description?: string;         // ✅ 追加
  placeRef?: string;
  placeRefs?: string[];         // ✅ 追加（複数対応）
  transitionRef?: string;
  properties: PropertyInfo[];
  hasTemplateRef?: boolean;     // ✅ 追加（診断用）
  hasInsertion?: boolean;       // ✅ 追加（診断用）
  resolvedFromRef?: string;     // ✅ 追加（診断用）
```
