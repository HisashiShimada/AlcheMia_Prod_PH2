## 5. 技術的詳細

### 使用する技術・ライブラリ
- React 18.2.0
- Ant Design v6: Modal, Table, Tag, Button, Space など
- TypeScript

### コンポーネント設計

#### MethodTaskSelectionModal.tsx
```typescript
interface MethodTaskSelectionModalProps {
  open: boolean;
  onClose: () => void;
  selectedProject: string;
  selectedMethodId: string | null;
  selectedTaskId: string | null;
  onSelect: (methodId: string, taskId: string) => void;
}
```

**主な機能:**
1. テーブル表示
   - 列: メソッド名、タスク名、ステータス、進捗率
   - ProgressCheckTable と同様の構造
   - メソッド単位で集約可能（初期状態: 全集約）
   
2. 行選択
   - ラジオボタンまたはクリック選択
   - 集約行は選択不可
   - 選択されたタスクの背景色を変更
   
3. モーダルアクション
   - キャンセル: 選択をリセットしてモーダルを閉じる
   - 決定: 選択されたメソッドID・タスクIDを親に返す

### データフロー
```
ExperimentRecordTab
  ↓ (「選択」ボタン押下)
MethodTaskSelectionModal (open)
  ↓ (テーブル表示、メソッド集約、行選択)
  ↓ (「決定」ボタン押下)
ExperimentRecordTab (methodId, taskId を受け取る)
  ↓
onSelectMethod(methodId), onSelectTask(taskId) を呼び出し
```

### テーブル実装のポイント

1. **集約行 vs 通常行の判定**
   - ProgressCheckTable と同様に `isAggregatedRow()` 型ガードを使用
   - 集約行の型定義: `AggregatedRow`
   - テーブル行の型: `TableRow = Task | AggregatedRow`

2. **メソッド集約の状態管理**
   - `collapsedMethodIds: Set<string>` で管理
   - 初期状態: 全メソッドIDを含むSetを設定
   - メソッド名クリックで集約/展開をトグル

3. **行選択の実装**
   - 通常のTableの `rowSelection` は使用しない（集約行と相性が悪い）
   - 各行に `onClick` ハンドラを設定
   - 選択された行の背景色を変更
   - 集約行はクリック不可

4. **列定義の簡素化**
   - アクションボタン（開始、問題報告、実験記録、強制終了）は不要
   - 選択列（ラジオボタン）を追加（Phase 4で実装）
   - ラジオボタン列は最左に配置
   - 集約行ではラジオボタンを非表示

5. **Phase 4で追加する機能**
   - **ラジオボタン列**: 各タスク行の先頭にRadio.Buttonを配置
   - **選択方法の変更**: 行全体のクリックではなく、ラジオボタンのクリックで選択
   - **選択解除ボタン**: モーダルフッターに「選択解除」ボタンを追加
     - 配置: キャンセルボタンと決定ボタンの間
     - 機能: 選択状態をクリア（selectedTaskId を null に設定）
     - スタイル: デフォルトボタン（typeなし）

### セキュリティ考慮事項
