## 問題点

### 1. 静的インポートの問題
- JSONファイルを直接インポート → ビルド時に埋め込まれる
- APIエンドポイントのシミュレーションができない
- 非同期処理の練習ができない

### 2. 型定義の不足
- `any` 型の多用
- APIレスポンスの型が未定義
- エラーレスポンスの型が未定義

### 3. エラーハンドリングの不足
- try-catchブロックがない
- エラー状態の管理がない
- ユーザーへのエラー通知が不統一

### 4. ローディング状態の不足
- isLoadingフラグがない
- スピナー表示がない
- データ取得中のUX対応なし

### 5. コードの重複
- 各コンポーネントで同じパターンのフィルタリング・ソート処理
- useState, useEffect, useMemoの繰り返し
