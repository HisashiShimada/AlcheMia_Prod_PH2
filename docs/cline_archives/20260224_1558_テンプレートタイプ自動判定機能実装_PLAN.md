## 5. 技術的詳細

### 判定ロジック
```typescript
// formatId または formatName から判定
const folderName = (formatId || formatName || '').toLowerCase();

let templateType: 'material' | 'condition' | 'result' | undefined;

if (folderName === 'material') {
  templateType = 'material';
} else if (folderName === 'condition') {
  templateType = 'condition';
} else if (folderName === 'result') {
  templateType = 'result';
}
```

### アーキテクチャ上の考慮事項
- テンプレートタイプの判定はフロントエンド側で行う
- バックエンド（formatService.ts）の`createFormatFile`関数は変更不要
- XMLファイルの場合のみ判定を行い、MAIMLファイルには影響しない

### セキュリティ考慮事項
- [ ] 入力値のバリデーションは既存の実装を維持
- [ ] 判定できない場合のエラーハンドリングを追加
