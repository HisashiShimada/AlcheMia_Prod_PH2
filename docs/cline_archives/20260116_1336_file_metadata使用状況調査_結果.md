#### 📊 workerRoutes.jsでの使用（パフォーマンス最適化）

**エンドポイント**: `GET /api/worker/assigned-maimls/:workerId`

**使用カラム（6カラム）:**
```sql
SELECT 
  fm.maiml_transitions_count,      -- ✅ 必須: トランジション数
  fm.maiml_places_count,            -- ✅ 必須: プレース数
  fm.maiml_validation_result,      -- ✅ 重要: バリデーション結果
  fm.file_size,                     -- ✅ 有用: ファイルサイズ
  fm.updated_at as file_updated_at  -- ✅ 有用: 更新日時
FROM maiml_work_assignments mwa
LEFT JOIN file_metadata fm ON mwa.maiml_file_key = fm.file_key
WHERE mwa.assigned_worker_id = $1
  AND mwa.organization_id = ANY($2::text[]);
```

**使用目的:**
- S3からMAIMLファイルをダウンロード+パースする代わりに、DBから直接メタデータ取得
- パフォーマンス最適化: **約100倍高速化（数十秒 → 数百ミリ秒）**
- ワーカーダッシュボードでトランジション情報を即座に表示
