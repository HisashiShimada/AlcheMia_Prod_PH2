## 1. タスク概要

自動ログアウト機能に2つの不具合が発見されました。
1. Redis接続状態で、アクセストークンが切れてリフレッシュトークンが有効な場合、APIを実行するとログイン画面にリダイレクトされる（本来はトークン再発行されるべき）
2. 二段階認証失敗時にも401エラーに反応してログイン画面にリダイレクトされる

## 2. 目的と期待される成果

### 目的
- トークン自動更新機能が正しく動作するようにする
- 認証フロー（ログイン・PIN検証）での401エラーでは自動リフレッシュを行わないようにする

## 3. 原因分析

### 不具合①の原因

**場所**: `backend/src/routes/authRoutes.ts` の `/auth/refresh` エンドポイント

**問題点**:
```typescript
router.post(
  '/refresh',
  pinVerifyRateLimit,
  [
    body('refreshToken')
      .notEmpty()
      .withMessage('Refresh token is required'),
  ],
  authController.refreshToken
);
```

- バリデーションで`refreshToken`がbodyに必須とされている
- しかし実際には`authController.refreshToken`はCookieからリフレッシュトークンを取得
- フロントエンドの`authService.refreshAccessToken()`は空のbodyを送信
- **結果**: バリデーションエラー（400 Bad Request）が発生
- 401エラーではないため、`authUtils.ts`のリトライ処理が正しく動作しない

### 不具合②の原因

**場所**: `frontend/src/utils/authUtils.ts` のレスポンスインターセプター

**問題点**:
```typescript
// 401エラーでリトライ未実施の場合のみ処理
if (error.response?.status === 401 && originalRequest && !originalRequest._retry) {
```

- **すべての401エラー**に反応してトークン更新を試みる
- 認証フロー中の正当な401エラー（PIN検証失敗など）でも自動リフレッシュを実行
- `/auth/refresh`への401のみ除外しているが、他の認証エンドポイントは除外されていない

**影響を受けるエンドポイント**:
- `/auth/login` - ログイン失敗時の401
- `/auth/verify-pin` - PIN検証失敗時の401
- `/auth/resend-pin` - セッショントークン無効時の401

## 6. 技術的詳細

### 修正内容の詳細

#### バックエンド修正
```typescript
// 修正前（不具合あり）
router.post(
  '/refresh',
  pinVerifyRateLimit,
  [
    body('refreshToken')
      .notEmpty()
      .withMessage('Refresh token is required'),
  ],
  authController.refreshToken
);

// 修正後（正しい実装）
router.post(
  '/refresh',
  pinVerifyRateLimit,
  // バリデーション削除（リフレッシュトークンはCookieから取得）
  authController.refreshToken
);
```

#### フロントエンド修正
```typescript
// レスポンスインターセプターの条件を追加

const isAuthEndpoint = originalRequest?.url?.includes('/auth/login') ||
                       originalRequest?.url?.includes('/auth/verify-pin') ||
                       originalRequest?.url?.includes('/auth/resend-pin') ||
                       originalRequest?.url?.includes('/auth/refresh');

if (error.response?.status === 401 && originalRequest && !originalRequest._retry && !isAuthEndpoint) {
  // トークン更新処理
}
```
