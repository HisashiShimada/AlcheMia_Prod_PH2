## 1. タスク概要

`backend/src/middleware/rateLimitMiddleware.ts`において、組織IDの取得元を`X-Organization-Id`ヘッダーから`orgId`クエリパラメータに変更する。

## 2. 目的と期待される成果

### 目的
- ログイン前の認証エンドポイントでは、ヘッダーに組織IDを含めることができない
- クエリパラメータで組織IDを受け取る方式に統一する

### 期待される成果
- [x] `loginRateLimit`のkeyGeneratorがクエリパラメータから組織IDを取得
- [x] `passwordResetRequestRateLimit`のkeyGeneratorがクエリパラメータから組織IDを取得
- [x] 既存の動作に影響を与えない変更

## 3. 実装ステップ

### Phase 1: 現状分析
- [x] 現在の組織ID取得箇所を特定
  - `loginRateLimit`: `req.headers['x-organization-id']`
  - `passwordResetRequestRateLimit`: `req.headers['x-organization-id']`
  - `rateLimitMiddleware`内: `req.query.orgId`（既にクエリパラメータ使用）

### Phase 2: keyGenerator修正
- [ ] `loginRateLimit`のkeyGeneratorを修正
  - `req.headers['x-organization-id']` → `req.query.orgId`
- [ ] `passwordResetRequestRateLimit`のkeyGeneratorを修正
  - `req.headers['x-organization-id']` → `req.query.orgId`

### Phase 3: 型安全性の確保
- [ ] 型アサーションを追加（`as string | undefined`）
- [ ] 空文字列チェックを確認

### Phase 4: 動作確認
- [ ] ビルドエラーがないことを確認
- [ ] 既存のレート制限ロジックが正常に動作することを確認

## 4. 影響範囲

### 変更するファイル
1. `backend/src/middleware/rateLimitMiddleware.ts`
   - `loginRateLimit`のkeyGenerator
   - `passwordResetRequestRateLimit`のkeyGenerator

### 影響を受けるエンドポイント
- `POST /api/auth/login` - ログインエンドポイント
- `POST /api/auth/password-reset/request` - パスワードリセット要求

### 影響を受けない箇所
- `pinVerifyRateLimit` - セッショントークンを使用（変更不要）
- `pinResendRateLimit` - セッショントークンを使用（変更不要）
- `rateLimitMiddleware`関数内の処理 - 既にクエリパラメータ使用

## 5. 技術的詳細

### 変更前
```typescript
keyGenerator: (req) => `${req.headers['x-organization-id']}_${req.body.username}`,
```

### 変更後
```typescript
keyGenerator: (req) => `${req.query.orgId}_${req.body.username}`,
```

### 型安全性
```typescript
const organizationId = req.query.orgId as string | undefined;
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
