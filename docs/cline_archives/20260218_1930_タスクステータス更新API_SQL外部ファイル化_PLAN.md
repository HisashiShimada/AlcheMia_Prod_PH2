### 3.2 taskService.ts - updateTaskStatus()

#### SQL 2: タスク取得（排他ロック付き）
```sql
SELECT 
  pt.organization_id,
  pt.project_id,
  p.project_name,
  pt.method_id,
  pt.task_no,
  pt.task_status,
  pt.update_at,
  pt.experiment_user_id,
  ou.user_name as experiment_user_name
FROM project_task pt
LEFT JOIN project p 
  ON p.project_id = pt.project_id 
  AND p.organization_id = pt.organization_id
LEFT JOIN organization_user ou
  ON ou.user_id = pt.experiment_user_id
  AND ou.organization_id = pt.organization_id
WHERE pt.organization_id = $1
  AND pt.project_id = $2
  AND pt.method_id = $3
  AND pt.task_no = $4
FOR UPDATE
```
- **使用箇所**: `taskService.ts` Line 214
- **パラメータ**: `[organizationId, projectId, methodId, taskNo]`
- **用途**: 楽観的ロック制御のためにタスクを排他取得

#### SQL 3: タスクステータス更新
```sql
UPDATE project_task
SET 
  task_status = $1,
  experiment_start_at = CASE 
    WHEN $1 = ${TaskStatusEnum.IN_PROGRESS} AND experiment_start_at IS NULL 
    THEN NOW() 
    ELSE experiment_start_at 
  END,
  experiment_end_at = CASE 
    WHEN $1 = ${TaskStatusEnum.COMPLETED} 
    THEN NOW() 
    ELSE experiment_end_at 
  END,
  update_at = NOW()
WHERE organization_id = $2
  AND project_id = $3
  AND method_id = $4
  AND task_no = $5
  AND update_at = $6
RETURNING 
  organization_id,
  project_id,
  method_id,
  task_no,
  task_status,
  experiment_user_id,
  experiment_start_at,
  experiment_end_at,
  update_at
```
- **使用箇所**: `taskService.ts` Line 297
- **パラメータ**: `[newStatusNum, organizationId, projectId, methodId, taskNo, currentUpdateAt]`
- **用途**: タスクステータスを更新し、タイムスタンプを自動設定
- **注意**: `${TaskStatusEnum.IN_PROGRESS}`と`${TaskStatusEnum.COMPLETED}`は動的に埋め込む必要がある

## 6. 技術的詳細

### 使用する技術・ライブラリ
- pg-promise: データベースアクセス（既存）
- `getPgp()`: pg-promiseインスタンス取得（`backend/src/database/db.ts`）
- `loadSqlFile()`: SQLファイル読み込み（`backend/src/sql/loader.ts`）

### pg-promiseのAPI使用方法
```typescript
// 1件取得（存在しない場合null）
const pgp = getPgp();
const sql = await loadSqlFile('projects/findByName.sql');
const result = await pgp.oneOrNone<ProjectRow>(sql, [projectName, organizationId]);

// トランザクション内での使用
await pgp.tx(async t => {
  const selectSql = await loadSqlFile('tasks/findByIdForUpdate.sql');
  const task = await t.oneOrNone(selectSql, [orgId, projId, methodId, taskNo]);
  
  const updateSql = await loadSqlFile('tasks/updateStatus.sql');
  const updated = await t.one(updateSql, [status, orgId, projId, methodId, taskNo, updateAt]);
  
  return updated;
});
```

### 注意事項
1. **トランザクション処理**: taskService.tsはトランザクション処理を使用しているため、pg-promiseの`tx()`メソッドを使用する必要がある
2. **動的パラメータ**: updateStatus.sqlのCASE文で使用する`TaskStatusEnum`の値を、SQLファイルではプレースホルダーとして記述し、TypeScript側でパラメータとして渡す
3. **FOR UPDATE**: SQL 2は排他ロックが必要なため、`FOR UPDATE`句を維持する
4. **RETURNING句**: SQL 3は更新後の値を返す必要があるため、`RETURNING`句を維持する

### セキュリティ考慮事項

- [ ] organization_idによるマルチテナント分離を維持
