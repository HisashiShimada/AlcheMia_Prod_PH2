## 1. タスク概要

実験作業者用プロジェクト一覧取得API（`GET /api/v1/projects/worker-accessible`）のバリデーションを、プロジェクトのバリデーション方針に従って修正します。

**現状の問題点:**
- コントローラー層でバリデーションを実施している（方針違反）
- express-validatorを使用したルート層のバリデーションが実装されていない
- JwtPayload型定義に`role`プロパティが欠落している

**修正方針:**
- バリデーションをルート層（projectRoutes.ts）に移動
- コントローラー層（workerProjectController.ts）からバリデーション処理を削除
- JwtPayload型定義に`role`プロパティを追加
- バックエンド規約（`.clinerules/development/backend.md`）に準拠

```typescript
async listWorkerAccessible(
  req: Request,
  res: Response,
  _next: NextFunction
): Promise<void> {
  const requestId = (req.headers['x-request-id'] as string) || uuidv4();

  try {
    const { userId, role, organizationId } = req.user!;

    // ✅ バリデーション済みパラメータを直接使用
    const page = parseInt((req.query.page as string) || '1', 10);
    const limit = parseInt((req.query.limit as string) || '20', 10);
    const status = req.query.status as ProjectStatus | undefined;
    const sortBy = (req.query.sort_by as string) || 'create_at';
    const order = (req.query.order as string) || 'desc';

    // Service層の呼び出し
    const result = await this.workerProjectService.listWorkerAccessible(
      userId,
      role,
      organizationId,
      {
        page,
        limit,
        status,
        sortBy: sortBy as 'create_at' | 'project_name' | 'update_at',
        order: order as 'asc' | 'desc',
      }
    );

    // 成功レスポンス
    res.status(200).json({
      success: true,
      data: result.items,
      pagination: result.pagination,
      meta: {
        timestamp: new Date().toISOString(),
        requestId,
      },
    });
  } catch (error: any) {
    // エラーハンドリング（変更なし）
    // ...
  }
}
```

## 5. 技術的詳細

### 使用する技術・ライブラリ
- express-validator: ^7.2.1 - バリデーションルール定義
- TypeScript: 5.7.3 - 型定義

### バリデーション方針
プロジェクトのバックエンド規約（`.clinerules/development/backend.md`）に基づく:

1. **ルート層でバリデーション**: express-validatorを使用
2. **ミドルウェアチェーン**: `auth → [validation] → handleValidationErrors → controller`
3. **コントローラー層**: バリデーション済みパラメータを直接使用
4. **統一エラーレスポンス**: 
   ```json
   {
     "success": false,
     "error": {
       "code": "VALIDATION_ERROR",
       "message": "バリデーションエラーが発生しました",
       "details": [
         {
           "field": "page",
           "message": "ページ番号は1以上の整数である必要があります",
           "code": "INVALID_VALUE"
         }
       ]
     },
     "meta": {
       "timestamp": "2026-02-06T14:22:00Z",
       "requestId": "req_abc123"
     }
   }
   ```

### JwtPayload型定義の問題
- 現状、JwtPayloadに`role`プロパティがない
- しかし、コントローラー層で`req.user.role`を使用している
- これは型安全性の問題であり、Phase 1で修正が必要
