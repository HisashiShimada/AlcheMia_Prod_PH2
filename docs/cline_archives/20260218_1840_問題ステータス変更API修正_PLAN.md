## 1. タスク概要

問題ステータス変更API（PATCH /api/v1/issues/:issueId/status）を、設計書（docs/design/api/api_issue_management.md）の仕様に合わせて修正します。

### 現在の問題点
1. **エンドポイント形式の不一致**: パスパラメータ形式 vs ボディパラメータ形式
2. **projectNameパラメータの欠如**: 仕様では必須だが実装にない
3. **権限チェックの欠如**: permissionCheckミドルウェアが適用されていない
4. **バリデーションの不足**: projectNameのバリデーションがない

| 項目 | 設計書 | 現在の実装 | 修正要否 |
|------|--------|------------|---------|
| エンドポイント | `/issues/status` | `/issues/:issueId/status` | ✅ 要修正 |
| HTTPメソッド | PATCH | PATCH | ✅ OK |
| projectName | ボディで必須 | なし | ✅ 要追加 |
| issueId | ボディで必須 | パスパラメータ | ✅ 要修正 |
| status | ボディで必須 | ボディで必須 | ✅ OK |
| 権限チェック | permissionCheck(['experiment_worker']) | なし | ✅ 要追加 |
| バリデーション | projectName, issueId, status | issueId, status | ✅ 要追加 |

### コード修正箇所サマリー

#### 1. issueRoutes.ts
```typescript
// 変更前
router.patch('/:issueId/status',
  authMiddleware,
  tenantIsolation,
  [param('issueId')...],
  handleValidationErrors,
  issueController.updateStatus
);

// 変更後
router.patch('/status',
  authMiddleware,
  tenantIsolation,
  checkPermission('050000', 1),  // 追加
  [
    body('projectName')...,     // 追加
    body('issueId')...,         // 追加
    body('status')...,
  ],
  handleValidationErrors,
  issueController.updateStatus
);
```

#### 2. issueController.ts
```typescript
// 変更前
const { issueId } = req.params;
const { status } = req.body;
const result = await issueService.updateStatus(organizationId, issueId, userId, status);

// 変更後
const { projectName, issueId, status } = req.body;
const result = await issueService.updateStatus(organizationId, projectName, issueId, userId, status);
```

#### 3. issueService.ts
```typescript
// 変更前
async updateStatus(organizationId, issueId, userId, status)

// 変更後
async updateStatus(organizationId, projectName, issueId, userId, status) {
  // projectNameからprojectId取得処理を追加
  const projectId = await this.issueRepository.getProjectIdByName(organizationId, projectName);
  if (!projectId) {
    throw new NotFoundError('プロジェクトが見つかりません');
  }
  // 既存処理
}
```
