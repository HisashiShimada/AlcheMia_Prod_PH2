# Bitbucket認証エラー解決ガイド

## 作成日時
2026-01-14 09:43

## エラー内容

```
remote: You may not have access to this repository or it no longer exists in this workspace.
fatal: Authentication failed for 'https://bitbucket.org/soft-service-ws/mmdpf.git/'
```

## 原因

このエラーは以下の理由で発生します：

1. **Bitbucketアカウントのパスワードが使えない**
   - 2段階認証が有効な場合、通常のパスワードは使えません
   - アプリパスワードが必要です

2. **リポジトリへのアクセス権限がない**
   - 管理者にアクセス権限を付与してもらう必要があります

3. **URLが間違っている**
   - ユーザー名やリポジトリ名が間違っている可能性があります

---

## 🎯 解決方法（推奨順）

### 方法1: アプリパスワードを使用する（推奨）

Bitbucketの2段階認証が有効な場合、通常のパスワードではなく**アプリパスワード**を使う必要があります。

#### ステップ1: アプリパスワードを取得

1. **Bitbucketにログイン**
   - https://bitbucket.org にアクセス
   - ログイン

2. **個人設定を開く**
   - 右上のアイコンをクリック
   - `Personal settings` を選択

3. **アプリパスワードページに移動**
   - 左メニュー → `App passwords`

4. **新しいアプリパスワードを作成**
   - `Create app password` をクリック
   - ラベル: `WSL2 Ubuntu Development` など任意の名前
   - 権限（Permissions）を選択:
     - ✅ **Repositories**: Read, Write
     - ✅ **Pull requests**: Read, Write
   - `Create` をクリック

5. **パスワードをコピー**
   - 表示されたパスワードをコピー（**一度しか表示されません！**）
   - メモ帳などに保存しておく

#### ステップ2: アプリパスワードでクローン

```bash
# リポジトリをクローン
cd ~/projects
git clone https://ShutoShimogama@bitbucket.org/soft-service-ws/mmdpf.git

# パスワード入力を求められたら
# → アプリパスワードを入力（通常のパスワードではない）
```

---

### 方法2: SSH認証を使用する（セキュア＆便利）

SSH鍵を使うと、パスワード入力が不要になります。

#### ステップ1: SSH鍵を生成

```bash
# SSH鍵を生成（既に存在する場合はスキップ）
ssh-keygen -t ed25519 -C "your.email@example.com"

# Enterを3回押す（デフォルト設定でOK）
# - ファイル名: デフォルト (~/.ssh/id_ed25519)
# - パスフレーズ: 空でOK（または任意）
```

#### ステップ2: 公開鍵をコピー

```bash
# 公開鍵を表示
cat ~/.ssh/id_ed25519.pub

# 表示された内容をすべてコピー
# 例: ssh-ed25519 AAAAC3Nza... your.email@example.com
```

#### ステップ3: BitbucketにSSH鍵を登録

1. **Bitbucketにログイン**
   - https://bitbucket.org にアクセス

2. **個人設定を開く**
   - 右上のアイコン → `Personal settings`

3. **SSH鍵ページに移動**
   - 左メニュー → `SSH keys`

4. **SSH鍵を追加**
   - `Add key` をクリック
   - ラベル: `WSL2 Ubuntu` など任意の名前
   - Key: コピーした公開鍵を貼り付け
   - `Add key` をクリック

#### ステップ4: SSH URLでクローン

```bash
# SSH URLでクローン（パスワード不要）
cd ~/projects
git clone git@bitbucket.org:soft-service-ws/mmdpf.git

# 初回のみ以下のメッセージが表示される
# Are you sure you want to continue connecting (yes/no/[fingerprint])?
# → yes と入力
```

---

### 方法3: アクセス権限を確認する

#### ステップ1: リポジトリへのアクセス権限を確認

1. **Bitbucketにログイン**

2. **リポジトリページに移動**
   - https://bitbucket.org/soft-service-ws/mmdpf

3. **アクセスできるか確認**
   - ページが表示される → アクセス権限あり
   - 404エラー → アクセス権限なし

#### ステップ2: アクセス権限がない場合

**リポジトリ管理者に連絡:**
- リポジトリ管理者にアクセス権限を付与してもらう
- 必要な権限: Read（閲覧）またはWrite（書き込み）

## 🔍 トラブルシューティング

### 問題1: アプリパスワードを入力したが認証失敗

**原因:** アプリパスワードの権限が不足している

**解決方法:**
1. Bitbucketの`App passwords`ページに戻る
2. 作成したアプリパスワードを削除
3. 新しいアプリパスワードを作成（権限を正しく設定）
   - ✅ Repositories: Read, Write

### 問題2: SSH接続でタイムアウト

**原因:** ファイアウォールがSSH（ポート22）をブロックしている

**解決方法:**
```bash
# HTTPS over SSHを使用
nano ~/.ssh/config
```

以下を追加:
```
Host bitbucket.org
  Hostname altssh.bitbucket.org
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519
```

保存後、再度クローンを試す:
```bash
git clone git@bitbucket.org:soft-service-ws/mmdpf.git
```

### 問題3: SSH鍵が認識されない

**原因:** SSH Agentが起動していない

**解決方法:**
```bash
# SSH Agentを起動
eval "$(ssh-agent -s)"

# SSH鍵を追加
ssh-add ~/.ssh/id_ed25519

# 接続テスト
ssh -T git@bitbucket.org

# 期待される出力:
# authenticated via ssh key.
```
