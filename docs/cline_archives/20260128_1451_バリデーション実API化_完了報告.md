```typescript
// 実APIでバリデーション
const apiResponse = await validateMaiml(maimlXml, false);

if (!apiResponse.success || !apiResponse.data) {
  throw new Error(apiResponse.error?.message || 'バリデーションに失敗しました');
}

const result = apiResponse.data;

// エラーを文字列配列からオブジェクト配列に変換（エラー分類用）
const errorObjects = result.errors.map(msg => ({
  code: 'VALIDATION_ERROR',
  message: msg,
  elementType: null,
  elementId: null
}));

// エラー分類を実行
if (errorObjects.length > 0) {
  classifyErrors(errorObjects);
} else {
  setCriticalErrors([]);
  setNonCriticalErrors([]);
}

// ValidationPanel用のフォーマット
setValidationResult({
  valid: result.isValid,
  errors: result.errors,
  warnings: result.warnings,
});
```

## バックエンドAPI仕様

### バリデーションAPI
**エンドポイント**: `POST /api/v1/maiml/validate`

**リクエスト:**
```json
{
  "content": "base64エンコードされたMAIML",
  "strict": false
}
```

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "isValid": true,
    "errors": [],
    "warnings": [],
    "info": [
      "メソッド数: 1",
      "プレース数: 5"
    ],
    "statistics": {
      "places": 5,
      "transitions": 3,
      "arcs": 8,
      "totalNodes": 8
    }
  }
}
```

### 自動補正API
**エンドポイント**: `POST /api/v1/maiml/correct`

**リクエスト:**
```json
{
  "content": "base64エンコードされたMAIML",
  "correctionLevel": "safe"
}
```

**レスポンス:**
```json
{
  "success": true,
  "data": {
    "corrected": true,
    "originalContent": "...",
    "correctedContent": "...",
    "corrections": [
      {
        "type": "MISSING_ATTRIBUTE",
        "message": "id属性を追加しました"
      }
    ]
  }
}
```
