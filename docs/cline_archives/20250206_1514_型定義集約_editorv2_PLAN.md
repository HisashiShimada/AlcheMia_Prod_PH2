#### ✅ 移動対象の型（複数コンポーネントで使用）

   - 使用場所: `PetriNetEditorInner.tsx`, `components/DraftManager.tsx`
   - 説明: Draft情報の型定義

2. **EditState** - 3箇所で使用
   - 定義場所: `hooks/useDraftManager.ts`
   - 使用場所: `PetriNetEditorInner.tsx`, `components/DraftManager.tsx`
   - 説明: 編集状態の型定義

3. **DraftSaveData** - 関連型として移動
   - 定義場所: `hooks/useDraftManager.ts`
   - 使用場所: `hooks/useDraftManager.ts`のみだが、Draft関連として一緒に移動
   - 説明: Draft保存データの型定義

4. **PlaceType** - ノード型定義として移動
   - 定義場所: `nodes/EditablePlaceNode.tsx`
   - 使用場所: 複数のノード関連コンポーネント
   - 説明: Place型の定義（'material' | 'condition' | 'result'）

5. **TemplatesByCategory** - テンプレート管理
   - 定義場所: `components/TemplateViewer/TemplateList.tsx`
   - 使用場所: `PetriNetEditorInner.tsx`
   - 説明: カテゴリ別テンプレート型定義

6. **SaveData** - 保存データ
   - 定義場所: `components/SaveDialog.tsx`
   - 使用場所: 保存関連コンポーネント
   - 説明: 保存メタデータの型定義

7. **EditableTransitionNodeData** - ノードデータ型
   - 定義場所: `nodes/EditableTransitionNode.tsx`
   - 使用場所: ノード関連コンポーネント
   - 説明: Transitionノードのデータ型

8. **EditablePlaceNodeData** - ノードデータ型
   - 定義場所: `nodes/EditablePlaceNode.tsx`
   - 使用場所: ノード関連コンポーネント
