# 本番環境Docker起動手順

## メタデータ
- **作成日時**: 2026-01-15 14:37
- **目的**: 本番環境でDocker Composeを正常に起動するための手順
- **優先度**: 高

## 現在の問題

`docker-compose -f docker-compose.prod.yml up -d` を実行すると以下の警告が表示される：

```
WARNING: The DB_PASSWORD variable is not set. Defaulting to a blank string.
WARNING: The SWIFT_AUTH_URL variable is not set. Defaulting to a blank string.
WARNING: The SWIFT_ACCOUNT variable is not set. Defaulting to a blank string.
WARNING: The SWIFT_USER variable is not set. Defaulting to a blank string.
WARNING: The SWIFT_PASSWORD variable is not set. Defaulting to a blank string.
```

また、Nginxが証明書ファイルを必要とするため、起動に失敗する可能性がある。

## 解決手順

### 1. 環境変数ファイルの作成

プロジェクトルートに `.env.production` ファイルを作成：

```bash
# プロジェクトルートに移動
cd /mnt/c/Users/shuto.shimogama/Documents/mmdpf

# .env.productionファイルを作成
cat > .env.production << 'EOF'
# Database Configuration
DB_NAME=mmdpf_db
DB_USER=mmdpf_user
DB_PASSWORD=your_secure_password_here

# OpenStack Swift Configuration
SWIFT_AUTH_URL=http://swift:8080/auth/v1.0
SWIFT_ACCOUNT=test
SWIFT_USER=tester
SWIFT_PASSWORD=testing
EOF
```

**重要**: `DB_PASSWORD` は強力なパスワードに変更してください。

### 2. docker-compose.prod.ymlの修正

環境変数ファイルを読み込むように修正：

```yaml
services:
  postgres:
    # ... 既存の設定 ...
    env_file:
      - .env.production

  swift:
    # ... 既存の設定 ...
    env_file:
      - .env.production
```

### 3. 証明書の生成

本番環境のNginxはHTTPSとクライアント証明書認証を使用します。

#### 3-1. certsディレクトリに移動

```bash
cd /mnt/c/Users/shuto.shimogama/Documents/mmdpf/certs
```

#### 3-2. 証明書生成スクリプトを実行

```bash
bash generate-certificates.sh
```

このスクリプトは以下を生成します：
- **CA証明書**: `ca/ca.crt` (Nginxで使用)
- **クライアント証明書**: `clients/*.p12` (ブラウザにインポート)
- **サーバー証明書**: `server/server.crt`, `server/server.key`

#### 3-3. サーバー証明書の生成（必要な場合）

`generate-certificates.sh` がサーバー証明書を生成しない場合、別途生成が必要：

```bash
# certsディレクトリで実行
bash generate-server-cert.sh
```

### 4. Docker Composeの再起動

```bash
# プロジェクトルートに戻る
cd /mnt/c/Users/shuto.shimogama/Documents/mmdpf

# 既存のコンテナを停止・削除
docker-compose -f docker-compose.prod.yml down

# 本番環境で起動（環境変数を読み込む）
docker-compose -f docker-compose.prod.yml --env-file .env.production up -d
```

### 5. 動作確認

#### 5-1. コンテナの状態確認

```bash
docker-compose -f docker-compose.prod.yml ps
```

すべてのコンテナが `Up` および `healthy` 状態になることを確認。

#### 5-2. ログ確認

```bash
# すべてのコンテナのログ
docker-compose -f docker-compose.prod.yml logs

# 特定のコンテナのログ
docker-compose -f docker-compose.prod.yml logs backend
docker-compose -f docker-compose.prod.yml logs nginx
```

#### 5-3. Nginxの証明書確認

```bash
# Nginxコンテナ内の証明書を確認
docker exec mmdpf-nginx ls -la /etc/nginx/certs/ca/
docker exec mmdpf-nginx ls -la /etc/nginx/certs/server/
```

### 6. アクセス確認

#### HTTP（HTTPSへリダイレクト）
```bash
curl -I http://localhost/
```

#### HTTPS（クライアント証明書なし - 拒否されるはず）
```bash
curl -I https://localhost/
```

#### HTTPS（クライアント証明書あり）
```bash
# クライアント証明書を指定してアクセス
curl -I --cert certs/clients/c9621ed65def49708e7ffbe97c98e3ed.p12:mmdpf123 \
     --cert-type P12 \
     -k https://localhost/
```

## トラブルシューティング

### 問題1: Nginxが起動しない

**エラー**: `cannot load certificate "/etc/nginx/certs/server/server.crt"`

**原因**: サーバー証明書が存在しない

**解決方法**:
```bash
cd /mnt/c/Users/shuto.shimogama/Documents/mmdpf/certs
bash generate-server-cert.sh
```

### 問題2: 環境変数が読み込まれない

**エラー**: `WARNING: The DB_PASSWORD variable is not set`

**原因**: `.env.production` ファイルが読み込まれていない

**解決方法**:
```bash
# 明示的に環境変数ファイルを指定
docker-compose -f docker-compose.prod.yml --env-file .env.production up -d
```

### 問題3: Swiftが起動しない

**エラー**: `swift service unhealthy`

**原因**: Swift設定が不正

**解決方法**:
```bash
# Swiftコンテナのログを確認
docker logs mmdpf-swift

# Swiftのヘルスチェックを手動で実行
docker exec mmdpf-swift wget --spider -q http://localhost:8080/auth/v1.0
```

### 問題4: PostgreSQLに接続できない

**エラー**: `backend service connection refused`

**原因**: データベースが準備完了していない

**解決方法**:
```bash
# PostgreSQLのログを確認
docker logs mmdpf-postgres

# PostgreSQLのヘルスチェックを手動で実行
docker exec mmdpf-postgres pg_isready -U mmdpf_user
```

## セキュリティ注意事項

### 本番環境での必須対応

1. **環境変数ファイルの保護**
   ```bash
   chmod 600 .env.production
   ```

2. **証明書の秘密鍵の保護**
   ```bash
   chmod 600 certs/ca/ca.key
   chmod 600 certs/server/server.key
   chmod 600 certs/clients/*.key
   ```

3. **Gitにコミットしない**
   ```bash
   # .gitignoreに追加済み
   .env.production
   certs/ca/*.key
   certs/server/*.key
   certs/clients/*.key
   ```

4. **強力なパスワードを設定**
   - DB_PASSWORD: 最低16文字、大小英数字+記号
   - SWIFT_PASSWORD: 最低12文字
   - 証明書パスワード: デフォルトの `mmdpf123` を変更
