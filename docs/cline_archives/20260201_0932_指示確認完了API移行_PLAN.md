## 5. 技術的詳細

### エンドポイント変更

**変更前（10.1）:**
```
PUT /api/v1/instructions/:instructionId/confirm
```

**変更後（2.14）:**
```
PUT /api/v1/projects/:projectName/instructions/:instructionId/confirm
```

### 実装変更点

#### ルートファイル
```typescript
// 変更前
router.put(
  '/instructions/:instructionId/confirm',
  authMiddleware,
  permissionCheck(['experiment_worker', 'experiment_admin', 'system_admin']),
  instructionConfirmationController.confirmInstruction
);

// 変更後
router.put(
  '/projects/:projectName/instructions/:instructionId/confirm',
  authMiddleware,
  permissionCheck(['experiment_worker', 'experiment_admin', 'system_admin']),
  instructionConfirmationController.confirmInstruction
);
```

#### コントローラー
```typescript
// projectNameパラメータのバリデーション追加
const { projectName, instructionId } = req.params;

// プロジェクト存在確認（必要に応じて）
const project = await projectService.getProjectByName(projectName, organizationId);
if (!project) {
  throw new NotFoundError('プロジェクトが存在しません');
}
```
