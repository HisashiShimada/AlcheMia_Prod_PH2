## 5. 技術的詳細

### DDLファイルの構造
各DDLファイルは以下の構造で統一します：
1. DROP TABLE IF EXISTS文
2. CREATE TABLE文（主キー制約を含む）
3. COMMENT ON TABLE文
4. COMMENT ON COLUMN文（各カラムごと）

### A5:SQL Mk-2の疑似命令について
- 元のDDLには`-- * BackupToTempTable`と`-- * RestoreFromTempTable`が含まれていますが、これはA5:SQL Mk-2専用の疑似命令です
- 標準的なPostgreSQLのDDLファイルとして保存するため、これらのコメントは除外します

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| DDLの構文エラー | 低 | 低 | 元のDDLをそのまま使用するため構文エラーは発生しにくい |
| COMMENTの欠落 | 低 | 低 | 元のDDLに含まれるCOMMENT文をすべてコピー |
| 既存DDLとの差異 | 中 | 中 | 既存ファイルを完全に置き換えるため、差分を確認 |
