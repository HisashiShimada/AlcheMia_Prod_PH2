## 5. 技術的詳細

### 権限チェックの仕様

**API**: `PATCH /api/v1/progress/projects/:projectName/methods/:methodId/transitions/:transitionId/status`

**ミドルウェアチェーン**:
```typescript
router.patch(
  '/projects/:projectName/methods/:methodId/transitions/:transitionId/status',
  authMiddleware,                    // 1. JWT認証（セッション検証、req.userに格納）
  checkPermission('050000', 1),      // 2. 権限チェック（機能CD: 050000、権限レベル: 1）
  [/* バリデーションルール */],      // 3. パラメータ・ボディのバリデーション
  handleValidationErrors,            // 4. バリデーションエラーハンドリング
  progressController.updateTransitionStatus  // 5. コントローラー処理
);
```

**権限要件**:
- **機能CD**: `050000` (実験作業者メニュー)
- **権限レベル**: `1` (書込可 = 読み取り + 更新)
- **ロール**: `experiment_worker`

**エラーレスポンス**:
- `401 Unauthorized`: JWT認証失敗（authMiddleware）
- `403 Forbidden`: 権限不足（checkPermission）
  - 機能CDが存在しない場合: `PERMISSION_DENIED`
  - 権限レベルが不足する場合: `INSUFFICIENT_PERMISSION`

### テストケース設計

#### 1. 権限チェック成功ケース
```typescript
describe('PATCH /api/v1/progress/projects/:projectName/methods/:methodId/transitions/:transitionId/status - Permission Check', () => {
  it('should allow access with valid permission (050000, level 1)', async () => {
    // Arrange: experiment_worker権限を持つユーザーでログイン
    const token = generateValidToken({
      userId: 'test-user-id',
      organizationId: 'test-org-id',
      role: 'experiment_worker',
      permissions: [
        { functionId: '050000', permission: 1 }  // 書込可
      ]
    });

    // Act: APIリクエスト送信
    const response = await request(app)
      .patch('/api/v1/progress/projects/test-project/methods/method1/transitions/t1/status')
      .set('Authorization', `Bearer ${token}`)
      .send({
        taskNo: 1,
        status: 'running',
        progressRate: 50,
        comment: 'Test comment'
      });

    // Assert: 権限チェック通過（200 OK or ビジネスロジックエラー）
    expect(response.status).not.toBe(403);
  });
});
```

});
