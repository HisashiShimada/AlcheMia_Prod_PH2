## 5. 技術的詳細

### 参考実装
**InstructionConfirmationTab.tsx のメソッドタブ実装**を参考にする：
```tsx
// メソッド一覧の取得
const methods = useMemo(() => {
  return selectedProject ? projectsData[selectedProject]?.methods || [] : [];
}, [selectedProject]);

// メソッドタブの生成
const methodTabs = useMemo(() => {
  return methods.map((method) => ({
    key: method.methodId,
    label: method.methodName,
  }));
}, [methods]);

// タブUI
<Tabs
  activeKey={selectedMethodId || undefined}
  onChange={onSelectMethod}
  items={methodTabs}
  size="middle"
  type="card"
/>
```

### 実装方針
1. **メソッドタブの配置**:
   - タブバー（進捗確認/指示確認/実験記録）の直下に配置
   - Card コンポーネント内の最上部に配置

2. **メソッド一覧の取得ロジック**:
   ```tsx
   const methods = useMemo(() => {
     return selectedProject ? projectsData[selectedProject]?.methods || [] : [];
   }, [selectedProject]);
   ```

3. **タスクのフィルタリング**:
   ```tsx
   // 選択されたメソッドのタスクのみを取得
   const filteredTasks = useMemo(() => {
     if (!selectedMethodId) return [];
     return tasks.filter(task => task.methodId === selectedMethodId);
   }, [tasks, selectedMethodId]);
   ```

4. **初期メソッド選択**:
   - プロジェクト変更時、最初のメソッドを自動選択
   ```tsx
   useEffect(() => {
     if (methods.length > 0 && !selectedMethodId) {
       onSelectMethod(methods[0].methodId);
     }
   }, [methods, selectedMethodId, onSelectMethod]);
   ```

## 11. 実施記録

### 実施日時
開始: 2026-01-14 09:44

### 計画からの変更点
- ProgressCheckTable.tsx でも MethodListTable が使用されていたため、こちらも修正
- メソッド選択状態の管理を ProgressCheckTab に統合
- TaskListTable への selectedMethodId を null に変更（メソッドはタブで選択済みのため）

### 発生した問題と解決方法
1. **TypeScript型エラー**
   - 問題: Text コンポーネントのインポート漏れ
   - 解決: Typography から Text をインポート追加

2. **関数定義順序エラー**
   - 問題: useCallback で定義した関数が、別の useCallback 内で使用される前に定義されていない
   - 解決: 関数定義の順序を調整（handleOpenIssueReport, handleOpenIssueCheck を先に定義）

3. **純粋でない関数呼び出し警告**
   - 問題: Date.now() を直接 useMemo 内で使用
   - 解決: new Date().getTime() に変更

4. **ProgressCheckTable での使用**
   - 問題: ProgressCheckTable.tsx でも MethodListTable を使用していた
   - 解決: ProgressCheckTable からメソッド一覧テーブルを削除し、タスク一覧のみ表示するように変更

5. **タスク一覧テーブルが表示されない問題（ExperimentWorkerMenu）**
   - 問題: ExperimentWorkerMenu の Tabs コンポーネントに `overflow: 'hidden'` が設定されており、内部コンテンツが隠れていた
   - 解決: `overflow: 'hidden'` を削除し、`marginBottom: 0` のみを設定
   - デバッグログを追加して原因を特定後、不要なログを削除

6. **「メソッドを選択してください」メッセージが表示される問題**
   - 問題: TaskListTable.tsx で `selectedMethodId` が null の場合に「メソッドを選択してください」メッセージを表示していた
   - 原因: ProgressCheckTable.tsx では `selectedMethodId={null}` を渡しており、メソッドは既にタブで選択されているため不要な条件分岐だった
   - 解決: TaskListTable.tsx から以下を削除
     - `selectedMethodId` チェックの条件分岐とメッセージ表示
     - 不要なメソッドフィルタリングロジック（methodTasks）
     - tasks を直接使用するように修正（親コンポーネントで既にフィルタリング済み）
