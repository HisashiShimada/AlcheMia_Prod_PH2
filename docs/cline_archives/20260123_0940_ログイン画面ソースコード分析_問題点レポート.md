### 2. JWT有効期限が異常に長い

**ファイル**: `backend/src/services/jwtService.ts` (行50-53)

```typescript
const fullPayload: JwtPayload = {
  ...payload,
  iat: now,
  exp: now + 9999999999  // ← 約317年！
  // TODO: トークンの有効期限をenvファイルから設定する
  // exp: now + expiresIn
};
```

**問題点:**
- 有効期限が9999999999秒（約317年）
- セキュリティリスク: トークンが漏洩した場合、実質無期限で使用可能

**推奨対応:**
```typescript
// ロール別の有効期限を設定（秒）
const expiresIn = {
  provider: 48 * 60 * 60,        // 48時間
  system_admin: 48 * 60 * 60,    // 48時間
  data_admin: 24 * 60 * 60,      // 24時間
  experiment_admin: 24 * 60 * 60,// 24時間
  experiment_worker: 12 * 60 * 60,// 12時間
  mi_engineer: 24 * 60 * 60,     // 24時間
}[payload.role] || 24 * 60 * 60;

const fullPayload: JwtPayload = {
  ...payload,
  iat: now,
  exp: now + expiresIn
};
```

### 5. 開発環境でPINコードをレスポンスに含める

**ファイル**: `backend/src/controllers/authController.ts` (行244-249)

```typescript
// 開発環境の場合のみPINコードを含める（開発効率化のため）
if (process.env.NODE_ENV === 'development') {
  responseData.pinCode = pinResult.data.pinCode;
  responseData.devMode = true;
}
```

**問題点:**
- 環境変数の設定ミスで本番環境で有効になるリスク
- セキュリティリスク: PINコードがネットワーク経由で平文送信

**推奨対応:**
- さらに厳格な条件を追加
```typescript
if (process.env.NODE_ENV === 'development' && process.env.DEV_PIN_CODE_RESPONSE === 'true') {
  responseData.pinCode = pinResult.data.pinCode;
  responseData.devMode = true;
}
```

### 6. PinCodeInputPageの自動入力処理

**ファイル**: `frontend/src/components/PinCodeInputPage.tsx` (行60-73)

```typescript
useEffect(() => {
  if (typeof window !== 'undefined') {

    if (devPinCode && devPinCode.length === 6) {

      inputRefs.current[0]?.focus();
```

```typescript
    // ... 以下同じ
```

**ファイル**: `backend/src/routes/authRoutes.ts`

```typescript
body('username')
```

```typescript

  // ...
}
```

**問題点:**
- 一貫性がない
- バックエンドのバリデーションエラーは英語で返される

**推奨対応:**
- バックエンドのメッセージを日本語に統一
- またはフロントエンドで翻訳処理を追加

### 9. 冗長なエラーハンドリング

**ファイル**: `frontend/src/components/LoginPage.tsx` (行97-102)

```typescript
try {
  await onLogin({ username: username.trim(), password , organizationId: ''});
} catch (err) {
  // エラーは親コンポーネントで処理
  console.error('Login failed:', err);  // ← 冗長
}
```

**問題点:**
- コメントで「親コンポーネントで処理」と書きながらconsole.errorを出力
- エラーを再スローしていないため、親に伝わらない

**推奨対応:**
```typescript
try {
  await onLogin({ username: username.trim(), password });
} catch (err) {
  // エラーは親コンポーネントで処理済み
  // ここでは何もしない
}
```
