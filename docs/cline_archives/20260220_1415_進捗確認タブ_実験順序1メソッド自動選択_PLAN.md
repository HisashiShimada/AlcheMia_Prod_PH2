## 1. タスク概要

進捗確認タブにおいて、プロジェクト選択後に一番左のタブ（プロジェクトタスクテーブルの実験順序が1のメソッド）が選択されている状態にする。

## 5. 技術的詳細

### 変更前のロジック
```typescript
useEffect(() => {
  if (methods.length > 0 && !selectedMethodId) {
    onSelectMethod(methods[0].methodId);
  }
}, [methods, selectedMethodId, onSelectMethod]);
```

### 変更後のロジック
```typescript
useEffect(() => {
  if (methods.length > 0) {
    // 実験順序でソートして最も小さいメソッドを選択
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, onSelectMethod]);
```

### 修正内容（調査結果反映）
- `!selectedMethodId`条件を削除（2回目以降のプロジェクト選択時に動作しない問題を解決）
- `selectedMethodId`を依存配列から削除
- プロジェクト変更で`methods`が変わるたびに、常に最小の実験順序のメソッドを選択

### アーキテクチャ上の考慮事項
- メソッドの並び順は `experimentOrder` でソートされていることを前提とする
- 実験順序が1のメソッドが存在しない場合は、配列の最初の要素をフォールバックとして使用
