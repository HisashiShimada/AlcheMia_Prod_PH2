# 原因分析レポート: メソッドタブ切替問題

## 作成日時
2026-02-20 15:26

## 問題の症状
進捗確認タブにおいて、未選択のメソッドタブをクリックしても、そのメソッドに切り替わらない。

## 調査結果

### 1. 親コンポーネント（ExperimentWorkerMenu.tsx）の実装

**状態管理:**
```typescript
const [selectedMethodId, setSelectedMethodId] = useState<string | null>(null);
```

**メソッド選択ハンドラー:**
```typescript
const handleSelectMethod = (methodId: string | null) => {
  // メソッドが実際に変更された場合のみタスクをリセット
  if (methodId !== selectedMethodId) {
    setSelectedTaskId('');
  }
  setSelectedMethodId(methodId);
};
```

**Props渡し:**
```typescript
<ProgressCheckTab
  selectedMethodId={selectedMethodId}
  onSelectMethod={handleSelectMethod}
  // ... その他のprops
/>
```

✅ **判定**: 親コンポーネントの実装は正常。状態管理とハンドラーは正しく実装されている。

### 2. 子コンポーネント（ProgressCheckTab.tsx）の実装

**問題箇所を発見:**

```typescript
// プロジェクト変更時に実験順序が最も小さいメソッドを自動選択
useEffect(() => {
  if (methods.length > 0) {
    // 実験順序でソートして最も小さいメソッドを選択
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, onSelectMethod]);
```

**Tabsコンポーネントの実装:**
```typescript
<Tabs
  activeKey={selectedMethodId || undefined}
  onChange={onSelectMethod}
  items={methodTabs}
  type="card"
/>
```

## 根本原因

### 問題1: useEffectの無条件実行

```typescript
useEffect(() => {
  if (methods.length > 0) {
    // 常に最初のメソッドを選択してしまう
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, onSelectMethod]);
```

**問題点:**
- `methods`が変わるたびに、このuseEffectが実行される
- **ユーザーが別のメソッドを選択しても、この処理が実行されて最初のメソッドに戻ってしまう**
- `selectedMethodId`の状態をチェックしていないため、既に選択されているメソッドを上書きしてしまう

### 問題2: 依存配列の問題

- 依存配列に`methods`と`onSelectMethod`が含まれている
- `methods`は`useMemo`で作成されているため、プロジェクト変更時以外は変わらないはず
- しかし、何らかの理由でメソッドリストが再計算されると、このuseEffectが再実行される

## 動作フロー（問題発生時）

```
1. ユーザーがメソッドタブ2をクリック
   ↓
2. Tabsコンポーネントの onChange が発火
   ↓
3. onSelectMethod(methodId2) が呼ばれる
   ↓
4. 親コンポーネントで setSelectedMethodId(methodId2) が実行される
   ↓
5. 親コンポーネントの状態が更新され、子コンポーネントが再レンダリング
   ↓
6. 【問題】useEffect が再実行される（methodsまたはonSelectMethodが変わった？）
   ↓
7. onSelectMethod(sortedMethods[0].methodId) が呼ばれる
   ↓
8. 最初のメソッドに戻ってしまう ❌
```

## 解決策

### 方法1: 条件付き自動選択（推奨）

useEffectに「未選択時のみ」という条件を追加：

```typescript
useEffect(() => {
  if (methods.length > 0 && !selectedMethodId) {
    // ↑ selectedMethodIdがnullの時のみ実行
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, selectedMethodId, onSelectMethod]);
```

**メリット:**
- ユーザーが選択したメソッドを上書きしない
- プロジェクト変更時（selectedMethodIdがリセットされる）は正しく自動選択される
- シンプルで理解しやすい

### 方法2: プロジェクト変更時のみ実行

プロジェクトIDを依存配列に追加し、プロジェクト変更時のみ実行：

```typescript
useEffect(() => {
  if (methods.length > 0) {
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [selectedProject]); // プロジェクトが変わった時のみ実行
```

**デメリット:**
- `selectedProject`を依存配列に入れると、ESLintの警告が出る可能性
- methods, onSelectMethodの変更を無視してしまう

## 推奨する修正方法

**方法1（条件付き自動選択）** を採用します。

理由：
1. ユーザーの選択を尊重する
2. プロジェクト変更時は正しく動作する（親コンポーネントがselectedMethodIdをnullにリセットするため）
3. シンプルで安全

## 修正箇所

**ファイル:** `frontend/src/components/ExperimentWorker/ProgressCheckTab.tsx`

**修正内容:**
```typescript
// 修正前
useEffect(() => {
  if (methods.length > 0) {
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, onSelectMethod]);

// 修正後
useEffect(() => {
  if (methods.length > 0 && !selectedMethodId) {
    // ↑ selectedMethodIdがnullの時のみ実行
    const sortedMethods = [...methods].sort((a, b) => a.experimentOrder - b.experimentOrder);
    onSelectMethod(sortedMethods[0].methodId);
  }
}, [methods, selectedMethodId, onSelectMethod]);
```

## 期待される動作（修正後）

```
1. ユーザーがメソッドタブ2をクリック
   ↓
2. Tabsコンポーネントの onChange が発火
   ↓
3. onSelectMethod(methodId2) が呼ばれる
   ↓
4. 親コンポーネントで setSelectedMethodId(methodId2) が実行される
   ↓
5. 親コンポーネントの状態が更新され、子コンポーネントが再レンダリング
   ↓
6. useEffect が実行されるが、selectedMethodId !== null なので何もしない ✅
   ↓
7. メソッドタブ2が選択された状態で表示される ✅
```

## まとめ

- **根本原因**: useEffectがユーザーの選択を無視して常に最初のメソッドを選択していた
- **修正内容**: `!selectedMethodId`条件を追加し、未選択時のみ自動選択するように変更
- **影響範囲**: ProgressCheckTab.tsx の1箇所のみ
- **リスク**: 低（既存の動作を壊さない安全な修正）
