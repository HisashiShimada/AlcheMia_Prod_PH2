## 5. 技術的詳細

### コントローラーの統合方針
- `InstructionConfirmationController.confirmInstruction` のロジックを `ProjectController.confirmInstruction` に移動
- サービス層（`instructionConfirmationService`）は維持する可能性が高い
- ミドルウェアチェーン: `auth` → `tenantIsolation` → `permissionCheck`（変更なし）

### APIエンドポイント
```
PUT /api/v1/projects/:projectName/instructions/:instructionId/confirm
```
- エンドポイント自体は変更なし
- コントローラーのみ変更
