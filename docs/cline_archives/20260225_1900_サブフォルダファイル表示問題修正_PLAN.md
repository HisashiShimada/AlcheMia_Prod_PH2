## 1. タスク概要

フォーマット管理画面でサブフォルダを開いた際に、正しいファイル（そのサブフォルダ直下のファイル・フォルダのみ）が表示されていない問題を修正する。

## 2. 問題の特定

### 現状の動作

バックエンドの`formatService.getFormatFiles()`メソッドは、`subPath`パラメータを受け取っているが、**実際には使用していない**。常に全階層のファイルを返している。

### 問題箇所

**backend/src/services/formatService.ts - getFormatFiles()メソッド**

```typescript
export async function getFormatFiles(
  organizationId: string,
  departmentCd: string,
  folderName: string,
  subPath?: string  // ← パラメータは受け取っているが使用していない
): Promise<FormatFile[]> {
  // ...
  const basePath = `formats/${departmentCd}/${folderName}`;
  // ← subPathを考慮していない
  
  const allItems = await storageService.listFiles(organizationId, basePath);
  // ← 常に全階層を取得
  
  // ファイルとフォルダを抽出（全階層）← これが問題
  for (const item of allItems) {
    // 全階層のファイル・フォルダを返している
  }
}
```

### 期待される動作

1. **ルート表示時** (`subPath`なし):
   - `formats/{dept_cd}/{folder_name}/`直下のファイル・フォルダのみ表示

2. **サブフォルダ表示時** (`subPath`あり):
   - `formats/{dept_cd}/{folder_name}/{subPath}/`直下のファイル・フォルダのみ表示

## 3. 修正方針

### Step 1: basePathの修正

`subPath`が指定されている場合は、それをbasePathに含める。

```typescript
const basePath = subPath
  ? `formats/${departmentCd}/${folderName}/${subPath}`
  : `formats/${departmentCd}/${folderName}`;
```

### Step 2: ファイル・フォルダの抽出ロジック修正

現在のパスの**直下のみ**を抽出するように変更。

```typescript
// basePathからの相対パスを取得
const relativeParts = pathParts.slice(basePathParts.length);

// 直下のファイル・フォルダのみを対象
if (relativeParts.length === 1) {
  // ファイル: relativeParts[0]がファイル名
} else if (relativeParts.length > 1) {
  // サブフォルダ: relativeParts[0]がフォルダ名
  // 重複排除して追加
}
```

### Step 3: フォルダのfileCountカウント修正

サブフォルダの場合、そのフォルダ配下のファイル数を正しくカウントする。

```typescript
const subFolderPath = subPath
  ? `${subPath}/${folderRelativePath}`
  : folderRelativePath;

const subFolderFullPath = `formats/${departmentCd}/${folderName}/${subFolderPath}`;
const fileCount = allItems.filter(f => {
  // サブフォルダ直下のファイルのみカウント
  if (!f.key.startsWith(`${organizationId}/${subFolderFullPath}/`)) return false;
  if (f.key.endsWith('/')) return false;
  return true;
}).length;
```

## 6. 技術的詳細

### 修正前のロジック（問題）

```typescript
// 全階層のファイルを取得
const allItems = await storageService.listFiles(organizationId, basePath);

// 全階層のファイル・フォルダを抽出
for (const item of allItems) {
  const pathParts = item.key.split('/');
  const relativeParts = pathParts.slice(basePathParts.length);
  
  // 相対パス全体を取得 ← これが問題
  const relativePath = relativeParts.join('/');
  
  // 全階層を処理している
}
```

### 修正後のロジック（解決）

```typescript
// subPathを考慮したbasePathを構築
const basePath = subPath
  ? `formats/${departmentCd}/${folderName}/${subPath}`
  : `formats/${departmentCd}/${folderName}`;

const allItems = await storageService.listFiles(organizationId, basePath);

// 直下のファイル・フォルダのみを抽出
for (const item of allItems) {
  const pathParts = item.key.split('/');
  const basePathParts = `${organizationId}/${basePath}`.split('/');
  const relativeParts = pathParts.slice(basePathParts.length);
  
  // 直下のみを対象
  if (relativeParts.length === 0 || relativeParts[0] === '') {
    continue; // ベースパス自体はスキップ
  }
  
  if (item.key.endsWith('/')) {
    // フォルダ
    const folderRelativePath = relativeParts[0]; // 直下のフォルダ名のみ
    // ...
  } else {
    // ファイル
    if (relativeParts.length === 1) {
      // 直下のファイルのみ
      // ...
    }
  }
}
```
