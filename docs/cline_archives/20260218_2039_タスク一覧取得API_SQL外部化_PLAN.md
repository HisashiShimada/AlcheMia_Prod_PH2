**場所**: `backend/src/controllers/progressController.ts` 259-267行目

FROM project
WHERE project_name = $1

**パラメータ**:

### 実装パターン（departmentRepositoryを参考）

**変更前（現状）**:
```typescript
const pool = getPool();
const projectQuery = `
  SELECT project_id, project_name
  FROM project
  WHERE project_name = $1
    AND organization_id = $2
`;
const projectResult = await pool.query(projectQuery, [projectName, organizationId]);
```

**変更後（目標）**:
```typescript
const pgp = getPgp();
const projectQuery = await loadSqlFile('progress/findProjectByName.sql');
const project = await pgp.oneOrNone(projectQuery, [projectName, organizationId]);
```

- [x] Parameterized Queryを使用（既存実装）
- [x] organization_idフィルタ必須（マルチテナント分離）
