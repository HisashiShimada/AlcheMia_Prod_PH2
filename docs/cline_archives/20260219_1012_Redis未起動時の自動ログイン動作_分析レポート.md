# Redis未起動時の自動ログイン動作 - 分析レポート

## 📋 調査概要

**日時**: 2026-02-19 10:12  
**対象**: 認証システムにおけるRedis未起動時の動作  
**質問**: Redisを起動していないのにログイン画面の自動ログイン機能が動作しているが、これは正しい処理？

---

## 🔍 調査結果サマリー

### 結論

**現在の動作は「開発環境用のフォールバック機能」として意図的に実装されています。**

- ✅ **開発環境では正しい動作**: Redis未起動でも開発作業を継続できる
- ⚠️ **本番環境では危険**: セキュリティリスクが高く、本番環境では使用すべきでない
- 🔧 **改善が必要**: 環境による動作の明確な分離が必要

**問題点**:

## ⚠️ セキュリティリスク

### 1. トークン無効化ができない

**シナリオ**: ユーザーがログアウトしても、リフレッシュトークンが有効なまま

```
ユーザーがログアウト
  ↓
Redis未起動 → トークン削除スキップ
  ↓
⚠️ リフレッシュトークンは依然として有効
  ↓
Cookie にリフレッシュトークンが残っている
  ↓
自動ログインが継続して動作してしまう
```

**影響**:
- ログアウトしても実際にはログアウトされていない
- 共有PCなどで使用した場合、次のユーザーがアクセス可能になるリスク

### 2. セッション管理ができない

**不可能な操作**:
- アクティブセッションの一覧表示
- 特定セッションの強制終了
- 不審なアクセスの検知・遮断

### 3. トークンローテーションが機能しない

**トークンローテーション**とは:
- リフレッシュトークン使用時に、新しいトークンを発行し、古いトークンを無効化する仕組み
- トークン盗難のリスクを軽減するセキュリティ強化機能

**Redis未起動時の問題**:
- 古いトークンが無効化されない
- 盗まれた古いトークンでも認証が通ってしまう

#### 実装案

```typescript
async exists(tokenId: string): Promise<Result<boolean, ServiceError>> {
  if (!RedisConnectionService.isRedisAvailable()) {

    };
```

### 提案2: Redis接続状態の監視とアラート

#### 実装案

```typescript
// RedisConnectionService に追加
export class RedisConnectionService {
  private static healthCheckInterval: NodeJS.Timeout | null = null;
  
  static startHealthCheck() {
    if (process.env.NODE_ENV === 'production') {
      this.healthCheckInterval = setInterval(async () => {
        if (!this.isRedisAvailable()) {
          // アラート送信（管理者通知）
          logError('Redis接続が切断されています', new Error('Redis unavailable'), {
            action: 'redis_health_check',
            severity: 'critical',
          });
          
          // 必要に応じてシステム停止
          // process.exit(1);
        }
      }, 30000); // 30秒ごとに確認
    }
  }
}
```

### 提案3: フォールバック時の動作制限

#### 実装案

```typescript
// フォールバック時はアクセストークンの有効期限を短縮
private getAccessTokenExpiresIn(): number {
  if (!RedisConnectionService.isRedisAvailable()) {
```

### 修正後

```typescript

  // Redis未起動時はトークンが存在しないものとして扱う（通常ログインを強制）
  if (!RedisConnectionService.isRedisAvailable()) {
    console.warn('⚠️  Redis未起動: リフレッシュトークンを無効とみなします。通常ログインを行ってください');
    return {
      success: true,
      data: false  // ✅ 存在しないとして扱う（自動ログイン無効化）
    };
  }
  // ...
}
```

**効果**: Redis未起動時は `false` を返すため、自動ログインが無効化され、通常ログインが強制される

```

  ↓
```

#### 修正後
