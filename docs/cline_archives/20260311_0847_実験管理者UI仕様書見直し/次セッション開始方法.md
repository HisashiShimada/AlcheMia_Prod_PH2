## 注意事項

### ファイル作成時の基本ルール

1. **段階的作成**
   - 大規模ファイル（800行以上）は段階的に作成
   - 初期版（ヘッダー+概要+画面構成）→ 機能詳細 → API連携・関連コンポーネント

2. **実装ファイルを必ず参照**
   - `frontend/src/components/viewer/` 配下のファイルを読み込んで実装ベースで作成
   - Props定義、State管理、主要機能を正確に記載

3. **テンプレート準拠**
   - `UI仕様書作成テンプレート.md` に従って統一フォーマットで作成
   - 概要、画面構成、機能仕様、データ型定義、関連コンポーネント、変更履歴を含める

4. **ツール実行後の確認待ち**
   - 各write_file/replace_in_file実行後、必ずユーザーの確認を待つ
   - 複数ファイルを同時に作成しない
