### 5.2 フロントエンド実装

#### LoginPage.tsx - PINコード受け渡し

```typescript
// ログイン成功後
const response = await authService.login(username, password, organizationId);

if (response.success && response.data) {
  // セッショントークンを保存
  sessionStorage.setItem('tempSessionToken', response.data.sessionToken);
  
  // 開発環境の場合、PINコードを保存
  if (response.data.devMode && response.data.pinCode) {
    sessionStorage.setItem('devPinCode', response.data.pinCode);
  }
  
  // PINコード入力画面へ遷移
  router.push('/pin-code');
}
```

#### PinCodeInputPage.tsx - 自動入力機能

```typescript
const [pinCode, setPinCode] = useState(['', '', '', '', '', '']);
const [isDevMode, setIsDevMode] = useState(false);

useEffect(() => {
  // 開発環境のPINコードを取得
  const devPinCode = sessionStorage.getItem('devPinCode');
  
  if (devPinCode) {
    setIsDevMode(true);
    
    // PINコードを自動入力
    const digits = devPinCode.split('');
    setPinCode(digits);
    
    // sessionStorageから削除（セキュリティ）
    sessionStorage.removeItem('devPinCode');
    
    // オプション: 自動検証
    // setTimeout(() => {
    //   handleVerify();
    // }, 500);
  }
}, []);

// 開発モード表示
{isDevMode && (
  <Alert
    message="開発モード"
    description="PINコードが自動入力されました"
    type="info"
    showIcon
    style={{ marginBottom: 16 }}
  />
)}
```

## 6. セキュリティ考慮事項

### セキュリティ対策
1. ✅ **環境変数での厳密な制御**
   - `NODE_ENV === 'development'` のみで動作
   - 本番環境では絶対にPINコードを含めない

2. ✅ **sessionStorage の使用**
   - ページリロードで消える
   - 他のタブと共有されない
   - 読み取り後即座に削除

3. ✅ **UI での明示的な表示**
   - 開発モードであることを明示
   - ユーザーが認識できるようにする

4. ✅ **本番ビルドチェック**
   - ビルドプロセスでの環境変数確認
   - CI/CDでの検証

### リスク評価

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| 本番環境で誤って有効化 | 高 | 低 | NODE_ENV厳密チェック、CI/CD検証 |
| sessionStorageの漏洩 | 中 | 低 | 読み取り後即削除、有効期限5分 |
| 開発環境の外部公開 | 高 | 低 | ファイアウォール、VPN必須 |
