### 計画からの変更点
- useEffectを削除: destroyOnClose=trueによりモーダルが破棄されるため、useEffectでの状態初期化は不要
- ESLintエラー対応: useEffect内でのsetState呼び出しを削除し、代わりにコンポーネントの再生成により初期値が正しく反映されるように修正

### 発生した問題と解決方法
**問題**: useEffect内でのsetCurrentStatus呼び出しがESLintエラーを引き起こした
```
Error: Calling setState synchronously within an effect can trigger cascading renders
```

**解決方法**: 
- Modal に `destroyOnClose` プロパティが設定されているため、モーダルが閉じる度にコンポーネントが破棄される
- 次回開く時には新しいインスタンスが作成され、`useState(initialStatus)` により正しい初期値が設定される
- よって、useEffectでの状態初期化は不要であることを確認し、useEffectを削除
