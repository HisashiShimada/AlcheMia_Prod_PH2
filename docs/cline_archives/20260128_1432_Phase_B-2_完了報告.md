#### ID変更ハンドラー
```typescript
const handleUpdateNodeIdInternal = useCallback(() => {
  if (!selectedNode || !onUpdateNodeId) return;
  
  if (nodeIdEdit === selectedNode.id) {
    return; // 変更なし
  }
  
  if (!nodeIdEdit || nodeIdEdit.trim() === '') {
    message.error('IDを入力してください');
    return;
  }
  
  // 重複チェック
  const exists = nodes.some(n => n.id === nodeIdEdit && n.id !== selectedNode.id);
  if (exists) {
    message.error('このIDは既に使用されています');
    return;
  }
  
  // 親コンポーネントのハンドラーを呼び出し
  onUpdateNodeId(selectedNode.id, nodeIdEdit);
  
  message.success(`ノードID変更完了: ${selectedNode.id} → ${nodeIdEdit}`);
}, [selectedNode, nodeIdEdit, nodes, onUpdateNodeId]);
```

### 2.2 PetriNetEditor.tsx

#### ID変更ハンドラー実装
```typescript
const handleUpdateNodeId = useCallback((oldId: string, newId: string) => {
  console.log('🔄 [PetriNetEditor] ノードID変更:', { oldId, newId });
  
  // バリデーション
  if (oldId === newId) return;
  if (!newId || newId.trim() === '') {
    alert('IDを入力してください');
    return;
  }
  
  // 重複チェック
  const exists = nodes.some(n => n.id === newId && n.id !== oldId);
  if (exists) {
    alert('このIDは既に使用されています');
    return;
  }
  
  // ノードID変更
  setNodes(nds => {
    const newNodes = nds.map(node =>
      node.id === oldId 
        ? { ...node, id: newId, data: { ...node.data, id: newId } } 
        : node
    );
    
    // 関連エッジも更新
    setEdges(eds => {
      const newEdges = eds.map(edge => ({
        ...edge,
        source: edge.source === oldId ? newId : edge.source,
        target: edge.target === oldId ? newId : edge.target,
      }));
      
      pushState({ nodes: newNodes, edges: newEdges });
      return newEdges;
    });
    
    // 選択状態を更新
    if (selectedNode?.id === oldId) {
      const updatedNode = newNodes.find(n => n.id === newId);
      if (updatedNode) {
        setSelectedNode(updatedNode);
      }
    }
    
    return newNodes;
  });
  
  console.log('✅ [PetriNetEditor] ノードID変更完了:', { oldId, newId });
}, [nodes, selectedNode, setNodes, setEdges, pushState]);
```

## 3. 機能説明

### 3.1 ノードID変更機能の仕様

#### 入力バリデーション
- ✅ 空文字チェック
- ✅ 変更なしチェック（oldId === newId）
- ✅ 重複チェック（既存ノードIDとの衝突）

#### ID変更時の処理
1. ノード自体のIDを変更
2. ノードの`data.id`も同期変更
3. 関連するエッジの`source`/`target`を更新
4. 履歴に保存（Undo/Redo対応）
5. 選択状態を維持（oldIdからnewIdへ）

#### ユーザーフィードバック
- 成功時: `message.success`（グリーンのトースト）
- エラー時: `message.error`（レッドのトースト）

### 3.2 UI設計

#### 配置
- PropertyPanelの「ID」フィールドの下に配置
- 読み取り専用の「ID」表示とは別に、編集可能なInput+Buttonを配置

#### 操作方法
1. Inputにノードの現在のIDがプリセット
2. ユーザーが新しいIDを入力
3. Enterキーまたは「変更」ボタンでID変更実行
4. 変更なしの場合はボタンがdisabled
