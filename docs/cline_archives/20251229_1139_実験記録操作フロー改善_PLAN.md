## 1. タスク概要

実験作業者メニューの「実験記録」タブにおいて、トランジションの記録操作フローを改善し、作業指示の確認を任意にする。

## 2. 目的と期待される成果

### 目的
- ユーザーの作業効率を向上させる
- 作業指示の確認を必須から任意に変更し、柔軟な操作を可能にする
- UIの一貫性を保ちながら、より直感的な操作フローを提供する

### 期待される成果
- [x] 「記録」ボタンから「実験データ記録」モーダルを直接開けるようになる
- [x] 「実験データ記録」モーダルから「作業指示」を確認できるようになる
- [x] 「作業指示」モーダルが情報参照用のモーダルとして機能する

### アーキテクチャ上の考慮事項
- モーダルのネスト: DataRecordDialog内にInstructionConfirmationModalをネストすることになるが、Ant DesignのModalコンポーネントはネストに対応している
- 状態管理: 各モーダルの開閉状態は親コンポーネントで管理する
- プロパティの整合性: InstructionConfirmationModalからonConfirmプロパティを削除しても、既存の使用箇所に影響がないことを確認
