## 3. 現状分析

### 仕様書の要件
```
エンドポイント: PATCH /api/v1/projects/:projectName/approval-request
パスパラメータ: projectName (string, 1-255文字)
HTTPメソッド: PATCH
```

### 現在の実装
```
エンドポイント: POST /api/v1/projects/:projectId/approval-request
パスパラメータ: projectId (UUID)
HTTPメソッド: POST
```

### 差分
1. ✗ HTTPメソッド: POST → PATCH に変更必要
2. ✗ パスパラメータ: `:projectId` (UUID) → `:projectName` (string) に変更必要
3. ✗ バリデーション: UUID検証 → 文字列長検証に変更必要
