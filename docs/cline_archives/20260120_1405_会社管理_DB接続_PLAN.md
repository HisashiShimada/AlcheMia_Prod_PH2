## 5. 技術的詳細

### 使用する技術・ライブラリ
- PostgreSQL: corporationテーブル
- Express.js: バックエンドAPI
- React + Ant Design: フロントエンド
- Axios: HTTP通信

### corporationテーブル構造
```sql
CREATE TABLE corporation (
    corporation_id SERIAL PRIMARY KEY,
    corporation_name VARCHAR(100) NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 表示項目
- corporation_name: 会社名
- updated_at: 更新日時
- is_active: アクティブ/非アクティブ

### APIエンドポイント（予定）
```
GET    /api/master/corporations - 一覧取得（フィルタ・ソート対応）
GET    /api/master/corporations/:id - 単一取得
POST   /api/master/corporations - 新規作成
PUT    /api/master/corporations/:id - 更新
DELETE /api/master/corporations/:id - 削除（論理削除）
```
