### ステータスの選択肢
```typescript
const statusOptions = [
  { value: 'initial', label: '初期状態' },
  { value: 'preparing', label: '準備状態' },
  { value: 'ready', label: '準備完了状態' },
  { value: 'running', label: '動作状態' },
  { value: 'paused', label: '休止状態' },
  { value: 'completed', label: '終状態' },
  { value: 'error', label: '異常終了状態' },

```

### レイアウト順序
```
1. 入力テキストボックス（既存）
2. ステータス更新コンボボックス（新規）
3. コメントテキストボックス（新規）
4. キャンセル・保存ボタン（既存）
```

### 非活性条件
- 作業指示の「確認完了」ボタンが押下されていない場合
- Props で渡される `instructionConfirmed` または類似のフラグで判定
