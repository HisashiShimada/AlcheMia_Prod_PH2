## 5. 技術的詳細

### Reference版の主要機能（初期分析）

#### PetriNetEditorV2
1. **編集モード管理**
   - editMode prop: 'normal' | 'draft'
   - initialEditMode → editMode への変換

2. **ReactFlowProvider ラップ**
   - エントリーポイントでReactFlowProvider提供

3. **props受け渡し**
   - maimlData → initialMaiMLData
   - editMode設定

#### PetriNetViewer
1. **複数Method対応**
   - multiMethodMode
   - methods配列管理
   - activeMethodIndex
   - Tabs UI

2. **API統合**
   - `/api/worker/multiple-methods-structure-from-content`
   - `/api/worker/petri-net-structure-from-content`
   - Base64エンコーディング

3. **SubNetViewer統合**
   - Transitionクリック時のサブネット表示
   - generateSubnetData

4. **Export機能**
   - PNG出力
   - SVG出力
   - JSON出力

5. **テンプレート継承ビュー**
   - TemplateInheritanceViewer

6. **プロパティ管理**
   - StructuredPropertySelector
   - ノード単位のプロパティ選択
