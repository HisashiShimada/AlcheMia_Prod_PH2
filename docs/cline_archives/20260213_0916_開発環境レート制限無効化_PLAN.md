## 1. タスク概要

開発環境（`NODE_ENV=development`）では、連続でログインしてもレート制限がかからないようにする。本番環境では引き続きレート制限を適用する。

## 5. 技術的詳細

### 実装方針

```typescript
export function rateLimitMiddleware(config: RateLimitConfig) {
  return async (req: Request, res: Response, next: NextFunction): Promise<void> => {
    // 開発環境ではレート制限をスキップ
    if (process.env.NODE_ENV !== 'production') {
      console.log(`[Rate Limit] Skipped in ${process.env.NODE_ENV} environment`);
      next();
      return;
    }

    // 既存のレート制限ロジック...
  };
}
```

### 環境変数
- `NODE_ENV`: 環境識別子
  - `development`: 開発環境（レート制限無効）
  - `production`: 本番環境（レート制限有効）
  - 未設定: 開発環境として扱う

### セキュリティ考慮事項
- [ ] 本番環境では必ず`NODE_ENV=production`を設定する
- [ ] 開発環境でのみレート制限を無効化する
- [ ] ログでレート制限のスキップを明示する
