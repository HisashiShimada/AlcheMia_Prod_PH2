## 5. 技術的詳細

### 使用する技術・ライブラリ
- sessionStorage API（Web標準API）
- JSON.stringify/JSON.parse（データのシリアライズ/デシリアライズ）

### アーキテクチャ上の考慮事項
- sessionStorageはタブ・ウィンドウ単位でデータが保持される
- ブラウザを閉じるとデータは削除される
- XSS攻撃に対する脆弱性があるため、機密情報（パスワード等）は保存しない

### セキュリティ考慮事項
- [x] パスワード等の機密情報は保存しない（User型にはパスワードは含まれない）
- [x] sessionStorageは同一オリジン内でのみアクセス可能
- [x] HTTPSを使用して通信を暗号化（本番環境）

### 保存されるデータ構造

```typescript
// User型（frontend/src/types/auth.ts）
interface User {
  id: string;
  username: string;
  email: string;
  role: UserRole;
  organizationId: string;
  organizationName: string;
  displayName: string;
}

// sessionStorageに保存される形式
sessionStorage.setItem('user', JSON.stringify({
  id: '4',
  username: 'experiment_admin',
  email: 'exp.admin@example.com',
  role: 'experiment_admin',
  organizationId: 'org_lab_001',
  organizationName: 'AIML研究所',
  displayName: '実験管理者 三郎'
}));
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| XSS攻撃によるsessionStorageへのアクセス | 高 | 低 | 機密情報（パスワード等）は保存しない。HTTPSを使用。CSP設定を確認。 |
| ブラウザの互換性問題 | 低 | 低 | sessionStorageは広くサポートされているため問題なし |
| JSON.parse時のエラー | 中 | 低 | try-catchで適切にエラーハンドリング（取得時に実装） |
