## 1. タスク概要

問題報告機能において、プロジェクトのステータスが「承認依頼中」の場合の動作を制御する機能を追加します。

## 2. 目的と期待される成果

### 目的
プロジェクトが「承認依頼中」状態の場合、問題報告は閲覧できるが、新規作成や編集はできないようにする。

### 期待される成果
- [x] 「承認依頼中」でも問題報告ボタンは押せる（閲覧目的）
- [x] 「承認依頼中」の場合、モーダル内の編集操作が全て無効化される
- [x] ユーザーが誤って編集操作を行わないようにする

## 5. 技術的詳細

### プロジェクトステータスの定義
```typescript
// 想定されるステータス値
type ProjectStatus = 
  | '作成中'
  | '承認依頼中'
  | '承認済み'
  | '差し戻し'
  | '完了'
  | その他;
```

### 非活性化ロジック
```typescript
const isApprovalPending = projectStatus === '承認依頼中';
const isEditDisabled = isApprovalPending;
```

### 使用するAnt Designコンポーネント
- Button: `disabled` propで非活性化
- Input.TextArea: `disabled` propで非活性化
- Tooltip: 非活性理由を表示
