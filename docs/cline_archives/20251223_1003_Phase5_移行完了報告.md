#### UUID一括生成
```typescript
const autoGenerateUUIDs = useCallback(() => {
  setEditingDocument(prev => {
    const newData = { ...prev };
    if (!newData.uuid) {
      newData.uuid = generateUUID();
    }
    
    ['creators', 'vendors', 'owners', 'instruments'].forEach(key => {
      const arrayKey = key as keyof DocumentData;
      if (newData[arrayKey] && Array.isArray(newData[arrayKey])) {
        (newData[arrayKey] as ObjectData[]) = (newData[arrayKey] as ObjectData[]).map(item => ({
          ...item,
          uuid: item.uuid || generateUUID()
        }));
      }
    });
    
    setHasChanges(true);
    return newData;
  });
}, [generateUUID]);
```

### 2. MultiObjectEditorの実装パターン

#### 遅延更新（Debounce）
```typescript
const handleInternalUpdate = useCallback((property: string, value: any) => {
  setInternalData(prev => ({
    ...prev,
    [property]: value
  }));

  if (updateTimeoutRef.current) {
    clearTimeout(updateTimeoutRef.current);
  }
  updateTimeoutRef.current = setTimeout(() => {
    onUpdate(index, property, value);
  }, 500);
}, [index, onUpdate]);
```

#### Reference管理
```typescript
const handleReferenceUpdate = useCallback((refKey: string, property: string, value: string) => {
  if (!value || value.trim() === '') {
    // 空の場合は削除
    setInternalData(prev => {
      const newData = { ...prev };
      delete (newData as any)[refKey];
      return newData;
    });
  } else {
    // 更新
    setInternalData(prev => ({
      ...prev,
      [refKey]: {
        ...(prev[refKey as keyof ObjectData] as any),
        [property]: value
      }
    }));
  }
}, [index, onUpdate, internalData]);
```

## 💡 技術的ハイライト

### 1. 配列データの後方互換性
単一オブジェクト（`creator`, `vendor`等）と配列（`creators`, `vendors`等）の両方に対応し、スムーズなマイグレーションを実現。

### 2. 遅延更新パターン
500msのdebounceにより、ユーザー入力のパフォーマンスを最適化し、不要な再レンダリングを防止。

### 3. Reference管理
vendorRef/instrumentRefの動的な追加/削除をサポートし、柔軟な参照管理を実現。

### 4. UUID自動生成
一括生成機能により、ユーザーの手間を大幅に削減し、一意性を保証。

### 5. XML署名対応
