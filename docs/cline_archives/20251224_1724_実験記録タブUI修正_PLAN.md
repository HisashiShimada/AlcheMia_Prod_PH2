## 1. タスク概要

「実験作業者メニュー」画面の「実験記録」タブにおいて、以下の2つの修正を実施します：

1. **トランジション一覧の修正**
   - インプット/アウトプットに分けていた列を統合
   - 「材料」「条件」「結果」列はインプット/アウトプットを合わせた数を表示
   - 「記録」列も統合（1つのボタンで記録）

2. **実験データ記録モーダルのテンプレート一覧の修正**
   - 「IN/OUT」列を追加
   - テンプレートごとに「インプット」または「アウトプット」を表示

### DataRecordDialog.tsx の変更詳細

#### テンプレート一覧テーブルに列を追加
```typescript
{
  title: 'IN/OUT',
```
