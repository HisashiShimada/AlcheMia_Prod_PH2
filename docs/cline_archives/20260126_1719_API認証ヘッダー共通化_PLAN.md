## 5. 技術的詳細

### Axiosインターセプター実装方法

```typescript
// リクエストインターセプター
apiClient.interceptors.request.use(
  (config) => {
    const sessionToken = localStorage.getItem('sessionToken');
    if (sessionToken) {
      config.headers.Authorization = `Bearer ${sessionToken}`;
    }
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);
```
