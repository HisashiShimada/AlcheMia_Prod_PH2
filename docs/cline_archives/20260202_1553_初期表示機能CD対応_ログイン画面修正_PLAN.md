## 1. タスク概要

現在のログイン画面では、UserRole型（TypeScript型）を使用してログイン後の表示画面を決定していますが、これをroleテーブルの「初期表示機能CD」カラムを参照する仕様に変更します。

## 2. 目的と期待される成果

### 目的
- データベース駆動の画面表示制御により、コード変更なしで画面遷移ルールを変更可能にする
- UserRole型への依存を排除し、柔軟な権限・画面設計を実現する

### 期待される成果
- [x] roleテーブルに「初期表示機能CD」カラムの追加
- [ ] バックエンドAPIレスポンスに初期表示機能CDを含める

- [ ] ログイン画面のswitch文を初期表示機能CDベースに変更
- [ ] 既存のUserRole型依存コードの影響範囲調査

### 初期表示機能CDの値の例（FunctionList enum準拠）

| UserRole | 初期表示機能CD | FunctionList enum値 | 説明 |

| provider | 010000 | FunctionList["010000"] | プロバイダーメニュー |
| system_admin | 020000 | FunctionList["020000"] | システム管理者メニュー |
| data_admin | 030000 | FunctionList["030000"] | データ管理者メニュー（想定） |
| experiment_admin | 040000 | FunctionList["040000"] | 実験管理者メニュー（想定） |
| experiment_worker | 050000 | FunctionList["050000"] | 実験作業者メニュー（想定） |
| mi_engineer | 060000 | FunctionList["060000"] | MI技術者メニュー（想定） |

**注**: FunctionList enumは未実装のため、数値コードは仮定値です。実装時に確定した値を使用してください。

### switch文の変更イメージ

**現在（UserRoleベース）:**
```typescript
switch (currentMenuType) {
  case 'provider':
    MenuComponent = <ProviderMenu ... />;
    break;
  case 'system_admin':
    MenuComponent = <SystemAdminMenu ... />;
    break;
  // ...
}
```

**変更後（初期表示機能CDベース - 数値コード）:**
```typescript
switch (currentUser.initialDisplayFunctionCd) {
  case '010000':  // FunctionList["010000"] = "プロバイダーメニュー"
    MenuComponent = <ProviderMenu ... />;
    break;
  case '020000':  // FunctionList["020000"] = "システム管理者メニュー"
    MenuComponent = <SystemAdminMenu ... />;
    break;
  case '030000':  // データ管理者メニュー（想定）
    MenuComponent = <DataAdminMenu ... />;
    break;
  case '040000':  // 実験管理者メニュー（想定）
    MenuComponent = <ExperimentAdminMenu ... />;
    break;
  case '050000':  // 実験作業者メニュー（想定）
    MenuComponent = <ExperimentWorkerMenu ... />;
    break;
  default:
    MenuComponent = <div>未定義の機能コード: {currentUser.initialDisplayFunctionCd}</div>;
}
```

**FunctionList enum定義例（未実装）:**
