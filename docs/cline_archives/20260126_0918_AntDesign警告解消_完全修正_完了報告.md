## 🔍 技術的な詳細

### Spin `tip` propの非推奨理由
- Ant Design v5では、Spinコンポーネントの使い方を簡素化
- 読み込み状態はSpinアニメーション自体で十分表現可能
- テキスト表示が必要な場合は、別途Typographyコンポーネントで追加

### Alert `message` → `title`への変更
- Ant Design v5でAPIの一貫性を向上させるための変更
- `title` の方が直感的でわかりやすい命名
- `description` との組み合わせで階層構造を明確化

### Input `addonAfter` → `Space.Compact`への変更
- Ant Design v5の新しいレイアウトコンポーネント `Space.Compact` を推奨
- より柔軟で拡張性の高いレイアウト実装が可能
- 見た目と動作は従来の `addonAfter` と同等を維持
