## 1. タスク概要

ログイン画面にパスワードリセットボタンと仮パスワード送信機能を追加します。

**スコープ:**
- ✅ ログイン画面にパスワードリセットボタン追加
- ✅ ユーザー名入力でメールアドレスに仮パスワード送信
- ✅ 仮パスワードでのログイン機能
- ❌ パスワード変更画面（別タスクで実装予定）
- ❌ ログイン後の強制パスワード変更（別タスクで実装予定）

**理由:**

### 仮パスワード生成ロジック
```typescript
// backend/src/services/tempPasswordService.ts
import crypto from 'crypto';

export class TempPasswordService {
  /**
   * 仮パスワード生成
   * @returns 8〜12文字のランダムな文字列（大文字・小文字・数字・記号を含む）
   */
  generateTempPassword(): string {
    const length = Math.floor(Math.random() * 5) + 8; // 8〜12文字
    const uppercase = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
    const lowercase = 'abcdefghijklmnopqrstuvwxyz';
    const numbers = '0123456789';
    const symbols = '!@#$%^&*';
    const allChars = uppercase + lowercase + numbers + symbols;
    
    let password = '';
    
    // 各カテゴリから最低1文字を含める
    password += uppercase[crypto.randomInt(0, uppercase.length)];
    password += lowercase[crypto.randomInt(0, lowercase.length)];
    password += numbers[crypto.randomInt(0, numbers.length)];
    password += symbols[crypto.randomInt(0, symbols.length)];
    
    // 残りの文字をランダムに追加
    for (let i = password.length; i < length; i++) {
      password += allChars[crypto.randomInt(0, allChars.length)];
    }
    
    // シャッフル
    return password.split('').sort(() => Math.random() - 0.5).join('');
  }
  
  /**
   * 仮パスワードの有効期限チェック
   * @param createdAt 仮パスワード生成日時
   * @returns 有効期限内ならtrue
   */
  isTempPasswordValid(createdAt: Date): boolean {
    const now = new Date();
    const expiryTime = 24 * 60 * 60 * 1000; // 24時間（ミリ秒）
    return (now.getTime() - createdAt.getTime()) < expiryTime;
  }
}
```

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| メール送信失敗 | 高 | 中 | リトライ機能、エラーハンドリング、管理者通知 |
| 仮パスワードの漏洩 | 高 | 低 | 24時間の有効期限、bcryptハッシュ化、HTTPS通信 |
| スパム攻撃（大量リクエスト） | 中 | 中 | レート制限（15分に3回） |
| ユーザー名の推測攻撃 | 中 | 中 | 一律の成功メッセージ（情報漏洩防止） |
| 仮パスワードの推測攻撃 | 高 | 低 | 十分な複雑性（8〜12文字、記号含む）、bcryptハッシュ化 |
| データベース接続エラー | 高 | 低 | トランザクション管理、エラーハンドリング |
