## タスク概要

「メソッド・タスク選択」モーダルのテーブルカラム「タスクの名称」を「タスク番号」に修正する。
タスクには名称がなく taskNo（連番）しか存在しないため、カラム名・データソース・幅を適切に修正する。

## 技術的詳細

### カラム幅の変更方針

| カラム | 変更前 | 変更後 | 理由 |
|--------|--------|--------|------|
| 選択 | 60 | 60 | 変更なし |
| タスク番号（旧：タスクの名称） | 250 | 100 | 数値のみで短いため縮小 |
| ステータス | 100 | 130 | 余白を追加して読みやすく |
| 進捗率 | 100 | 120 | 余白を追加して読みやすく |

### sorter の変更

```typescript
// 変更前（文字列比較）
sorter: (a, b) => a.taskName.localeCompare(b.taskName),

// 変更後（数値比較）
sorter: (a, b) => Number(a.taskNo) - Number(b.taskNo),
```

### フィルタ変更

- `taskNameOptions` → `taskNoOptions`（`taskNo` の一意リストを生成）
- Selectプレースホルダー：「タスク名」→「タスク番号」
- あいまい検索：`task.taskName` → `task.taskNo`
