### 2. validateForExperimentManager()

#### maimlParserExp.tsでの実装
```typescript
validateForExperimentManager() {
  // 戻り値: { isValid, errors, warnings, info }
  // - isValid: boolean
  // - errors: string[]
  // - warnings: string[]
  // - info: FileBasicInfo
  
  // 検証項目:
  // 1. protocolの存在確認
  // 2. protocol.methodの存在確認
  // 3. (その他の検証ロジック)
}
```

#### maimlParserTyped.tsの対応状況
```typescript
// ❌ 対応するメソッドなし
// ✅ 関連メソッド: getFileBasicInfo()
getFileBasicInfo(): {
  hasProtocol: boolean;
  hasMethod: boolean;
  hasData: boolean;
  hasEventLog: boolean;
  protocolName?: string;
  methodCount: number;
  version?: string;
}
```

#### 対応方針: 🆕 新規実装が必要

**理由:**
- maimlParserTyped.tsに同等のメソッドが存在しない
- `getFileBasicInfo()`は一部の情報しか提供しない
- 検証ロジック（errors/warningsの判定）が不足

**実装方法:**
```typescript
/**
 * ExperimentManager向けファイル検証
 * 
 * @returns {Object} 検証結果
 */
validateForExperimentManager(): {
  isValid: boolean;
  errors: string[];
  warnings: string[];
  info: {
    hasProtocol: boolean;
    hasMethod: boolean;
    hasData: boolean;
    hasEventLog: boolean;
    protocolName?: string;
    methodCount: number;
    version?: string;
  };
} {
  const validation = {
    isValid: true,
    errors: [] as string[],
    warnings: [] as string[],
    info: this.getFileBasicInfo()
  };
  
  // 必須要素の検証
  if (!this.typedMaiml.protocol) {
    validation.errors.push('protocolセクションが見つかりません');
    validation.isValid = false;
  }
  
  if (!this.typedMaiml.protocol?.method || this.getMethods().length === 0) {
    validation.errors.push('protocol/methodセクションが見つかりません');
    validation.isValid = false;
  }
  
  // 警告レベルの検証
  const methods = this.getMethods();
  if (methods.length > 0) {
    const hasAnyPnml = methods.some(m => m.pnml && m.pnml.length > 0);
    if (!hasAnyPnml) {
      validation.warnings.push('pnmlセクションが見つかりません');
    }
  }
  
  return validation;
}
```
