# Ant Design v6 Deprecation警告修正 - 影響範囲調査報告

## 調査日時
2026-01-23 17:38

## 概要
コンソールに表示されているAnt Design v6のdeprecation警告について、影響範囲を調査しました。
**結果: 全体で約453件の修正が必要**と判明しました。

## 📊 調査結果サマリー

| 警告種別 | 影響件数 | 深刻度 | 修正難易度 |
|---------|----------|--------|-----------|
| Space `direction` → `orientation` | **300+件** | 低 | 簡単（置換のみ） |
| Card `bordered` → `variant` | **約50件** | 低 | 簡単（値の変換必要） |
| Card `bodyStyle` → `styles.body` | **約43件** | 中 | やや複雑（オブジェクト構造変更） |
| Modal `destroyOnClose` → `destroyOnHidden` | **約10件** | 低 | 簡単（置換のみ） |
| List コンポーネント（非推奨） | **約50件** | 高 | 困難（代替コンポーネント検討） |
| **合計** | **約453件** | - | - |

### 戦略B: 一括修正（非推奨）

- リスク: 高（テストが不十分になる可能性）

## ⚠️ 重要な注意事項

### List コンポーネントの扱い
Ant Design v6では`List`コンポーネントが非推奨となり、将来のメジャーバージョンで削除予定です。

#### 影響度が高いファイル
1. **ProjectFolderTree.tsx** - プロジェクト一覧表示
2. **FormatFolderTree.tsx** - フォーマット一覧表示

これらは**重要な機能**であり、代替方法の慎重な検討が必要です。

#### 代替案
1. **Flex + Card の組み合わせ**
   - 柔軟なレイアウトが可能
   - スタイルの自由度が高い
   
2. **カスタムコンポーネント作成**
   - 既存のListと同じUIを再現
   - 内部実装をFlexベースに変更

3. **一時的な対応: 警告抑制**
   - 短期的な解決策
   - 将来的には代替が必要

## 📋 修正パターン詳細

### Pattern 1: Space (簡単)
```tsx
// ❌ 修正前
<Space direction="vertical">

// ✅ 修正後
<Space orientation="vertical">
```

### Pattern 2: Modal (簡単)
```tsx
// ❌ 修正前
<Modal destroyOnClose>

// ✅ 修正後
<Modal destroyOnHidden>
```

### Pattern 3: Card bordered (やや複雑)
```tsx
// ❌ 修正前
<Card bordered={false}>

// ✅ 修正後
<Card variant="borderless">

// ❌ 修正前
<Card bordered={true}>  // or bordered のみ

// ✅ 修正後
<Card>  // borderedはデフォルトでtrueなので削除
```

### Pattern 4: Card bodyStyle (複雑)
```tsx
// ❌ 修正前
<Card bodyStyle={{ padding: 24, backgroundColor: '#fff' }}>

// ✅ 修正後
<Card styles={{ body: { padding: 24, backgroundColor: '#fff' } }}>
```
