# 実装した解決策の説明

## 現在の実装状況

### 📌 実装したのは「ハイブリッド型（解決策A + B）」です

解決策文書で提案した以下の2つの解決策を**両方とも実装**し、切り替え可能にしました：

1. ✅ **解決策A: Modal + getContainer**
2. ✅ **解決策B: Drawer**
3. ✅ **既存: embedded（埋め込みモード）**

## 実装の詳細

### 1. StructuredPropertySelectorの3モード対応

```typescript
interface StructuredPropertySelectorProps {
  // ... 既存のprops ...
  displayMode?: 'modal' | 'drawer' | 'embedded';  // 3つのモードから選択可能
  getContainer?: () => HTMLElement;  // 親コンテナ指定
}
```

#### 3つのモード

**A. `modal`モード（解決策A）**
```typescript
<Modal
  getContainer={getContainer || (() => document.body)}
  // フローティングダイアログ内にModalを表示
/>
```

**B. `drawer`モード（解決策B）**
```typescript
<Drawer
  placement="right"
  getContainer={getContainer || (() => document.body)}
  style={{ position: 'absolute' }}
  // 右側スライドインDrawer
/>
```

**C. `embedded`モード（既存）**
```typescript
<div>
  {/* Modal/Drawerを使わず直接埋め込み */}
</div>
```

### 2. 現在のデフォルト設定

#### ViewRenderer.tsx（現在の設定）
```typescript
<PetriNetViewer 
  maimlData={fileContent}
  propertyDisplayMode="modal"  // ← 現在は'modal'モード（解決策A）
  containerElementId="petri-net-viewer-container"
/>
```

**つまり、現在は「解決策A（Modal + getContainer）」がデフォルトです。**

### 3. 簡単にDrawerモードに切り替え可能

もし解決策B（Drawer）に変更したい場合は、1行変更するだけです：

```typescript
<PetriNetViewer 
  maimlData={fileContent}
  propertyDisplayMode="drawer"  // ← 'drawer'に変更するだけ
  containerElementId="petri-net-viewer-container"
/>
```

## モード比較表

| モード | 実装状況 | 使用場所 | 特徴 |
|--------|---------|---------|------|
| **modal** | ✅ 実装済み（現在のデフォルト） | ViewRenderer → PetriNetViewer | Modal形式、フローティングダイアログ内で開く |
| **drawer** | ✅ 実装済み（切り替え可能） | （オプション） | 右側スライドイン、よりモダンなUI |
| **embedded** | ✅ 実装済み | SubNetViewer（右ペイン） | 直接埋め込み、常時表示 |

## 各モードの動作

### Modal モード（現在のデフォルト）

**動作:**
```
ViewRendererDialog（フローティング）
  └─ コンテナ要素 (#petri-net-viewer-container)
      └─ PetriNetViewer
          └─ Placeノードクリック
              └─ StructuredPropertySelector（Modal）
                  ├─ getContainer: コンテナ要素を指定
                  └─ フローティングダイアログ内に表示
```

**表示:**
- 中央に表示される独立したModalウィンドウ
- オーバーレイはフローティングダイアログ内のみ
- 幅: 800px

### Drawer モード（切り替え可能）

**動作:**
```
ViewRendererDialog（フローティング）
  └─ コンテナ要素 (#petri-net-viewer-container)
      └─ PetriNetViewer
          └─ Placeノードクリック
              └─ StructuredPropertySelector（Drawer）
                  ├─ getContainer: コンテナ要素を指定
                  ├─ placement: right
                  └─ 右側からスライドイン
```

**表示:**
- 右側からスライドイン
- オーバーレイはフローティングダイアログ内のみ
- 幅: 400px

### Embedded モード（SubNetViewer用）

**動作:**
```
SubNetViewer（Drawer）
  ├─ 左ペイン: React Flow（サブネット）
  └─ 右ペイン: StructuredPropertySelector（embedded）
      └─ Modal/Drawerを使わず直接埋め込み
```

**表示:**
- 常時右ペインに表示
- Modal/Drawerではない
- 幅: 親コンテナの幅

## どのモードを使うべきか？

### Modal モード（解決策A）- 現在のデフォルト ✅

**推奨する場面:**
- ✅ デスクトップ環境
- ✅ 大きな画面で作業
- ✅ 詳細な情報を一度に表示したい

**メリット:**
- 中央に大きく表示
- 既存のUIに近い
- 実装が安定

### Drawer モード（解決策B）- 切り替え可能 ⚡

**推奨する場面:**
- ✅ モバイル・タブレット
- ✅ よりモダンなUI
- ✅ サイドパネル形式が好み

**メリット:**
- スライドインアニメーション
- 画面の右側に配置
- モバイルに最適

### Embedded モード - SubNetViewer専用 📌

**推奨する場面:**
- ✅ SubNetViewer内のプロパティ表示
- ✅ 常時表示が必要な場面

**メリット:**
- 常に表示される
- Modal/Drawerのオーバーヘッドなし

```typescript

  containerElementId="petri-net-viewer-container"
```
