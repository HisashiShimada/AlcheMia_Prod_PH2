## ⚠️ 重要な注意事項

### Phase 3での変更に注意

**getTransitions()の戻り値が変更されています:**

```typescript
// 旧: maimlParserExp.ts
interface TransitionsResult {
  transitions: TransitionInfo[];
  metadata: {...};
}

// 新: maimlParserTyped.ts (Phase 3拡張)
interface TransitionsResult {
  success: boolean;
  error?: string | null;     // Phase 3追加
  transitions: TransitionInfo[];
  metadata: {...};
}

// TransitionInfo も拡張されています
interface TransitionInfo {
  // 既存フィールド
  id: string;
  methodId: string;
  // ...
  
  // Phase 3追加フィールド
  displayName?: string;              // 表示用の整形された名前
  isExperimentRelevant?: boolean;    // 実験関連のTransitionか
}
```

### DO（推奨）

✅ **段階的に移行する**: 一度に全てを変更しない
✅ **テストを実施する**: 各移行後に動作確認
✅ **ロールバック可能にする**: コミットを小さく分ける
✅ **ドキュメントを更新する**: 移行状況を記録
✅ **エラーハンドリングを確認**: `.success`と`.error`プロパティを活用

### DON'T（非推奨）

❌ **一度に全てを変更しない**: リスクが高すぎる
❌ **テストなしで進めない**: 問題発見が遅れる
❌ **並行運用期間を省略しない**: ロールバックが困難になる
❌ **戻り値の構造変更を見落とさない**: Phase 3の拡張に注意
❌ **maimlParserExp.tsを即座に削除しない**: 並行運用期間が必要
