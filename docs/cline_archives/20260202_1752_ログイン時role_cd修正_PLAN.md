## 1. タスク概要

ログイン処理で `column "role" does not exist` エラーが発生しています。
DDLファイルを確認したところ、`organization_user` テーブルのカラム名は `role_cd` が正しく、コード側は既に正しく `role_cd` を参照していますが、`db_table_list.md` のドキュメントに誤記があります。

## 2. 問題の原因

### エラー内容
```
{
  "timestamp": "2026-02-02T08:51:38.138Z",
  "level": "error",
  "message": "Login error",
  "action": "login",
  "errorMessage": "column \"role\" does not exist",
  "errorStack": "error: column \"role\" does not exist\n    at C:\\Users\\shuto.shimogama\\Documents\\mmdpf\\backend\\node_modules\\pg-pool\\index.js:45:11"
}
```

### 原因分析
1. **DDLファイル** (`docs/design/db/ddl/organization_user.sql`)
   - 正しいカラム名: `role_cd`
   
2. **authController.ts**
   - SELECTクエリは正しく `role_cd` を参照している
   - しかし、どこかで `role` を参照しようとしている可能性

3. **db_table_list.md**
   - 誤記: `role` と記載（正しくは `role_cd`）
