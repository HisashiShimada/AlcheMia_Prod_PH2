## 1. タスク概要

サブヘッダーのメニュー切替ドロップダウンを、ホバー表示からクリック表示に変更する。

## 2. 目的と期待される成果

### 目的
- ユーザーの意図しないタイミングでメニューが表示されるのを防ぐ
- より明示的な操作感を提供する
- モバイル/タッチデバイスでの操作性向上

### 期待される成果
- [x] ホバーではメニューが表示されない
- [x] クリックでメニューが表示される
- [x] 再度クリック、または外側クリックでメニューが閉じる
- [x] 既存のスタイルとUI/UXを維持

## 3. 実装ステップ

- [x] SubHeader.tsxのDropdownコンポーネントの`trigger`プロパティを修正

## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Dropdown コンポーネント

### アーキテクチャ上の考慮事項
- Ant DesignのDropdownコンポーネントは、`trigger`プロパティで表示トリガーを制御
- `['hover']`: ホバー時に表示
- `['click']`: クリック時に表示
- `['hover', 'click']`: 両方で表示（非推奨）

### 変更内容
```typescript
// 変更前
<Dropdown
  menu={{ items: menuItems }}
  trigger={['hover']}  // ← ホバー
  placement="bottomRight"
>

// 変更後
<Dropdown
  menu={{ items: menuItems }}
  trigger={['click']}  // ← クリック
  placement="bottomRight"
>
```

### セキュリティ考慮事項
- [x] セキュリティへの影響なし（UI変更のみ）

## 6. リスクと対策

| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| ユーザーが変更に気づかない | 低 | 中 | ボタンにホバーヒントを表示することを検討（今回は対象外） |
