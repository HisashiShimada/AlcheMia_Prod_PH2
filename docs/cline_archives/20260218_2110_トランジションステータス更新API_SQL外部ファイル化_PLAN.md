## 6. 技術的詳細

### 使用する技術・ライブラリ
- pg-promise: データベース接続とクエリ実行
- loadSqlFile(): SQLファイル読み込みユーティリティ

### アーキテクチャ上の考慮事項
- 既存のdepartmentRepositoryパターンに統一
- Poolとpg-promiseの使い分け:
  - 通常のクエリ: pg-promise（外部SQLファイル対応）
  - トランザクション: Pool.client（ProgressService.updateTransitionStatus内）

### pg-promiseとPoolの使い分けルール
```typescript
// 通常のクエリ（外部SQLファイル使用）
const pgp = getPgp();
const sql = await loadSqlFile('transition_data/findById.sql');
const result = await pgp.oneOrNone(sql, [organizationId, projectId, methodId, taskNo, transitionId]);

// トランザクション内のクエリ（Pool.client使用）
const pool = getPool();
const client = await pool.connect();
try {
  await client.query('BEGIN');
  const sql = await loadSqlFile('transition_data/findByTransitionId.sql');
  const result = await client.query(sql, [organizationId, projectId, methodId, transitionId]);
  await client.query('COMMIT');
} catch (error) {
  await client.query('ROLLBACK');
  throw error;
} finally {
  client.release();
}
```

### セキュリティ考慮事項
- [ ] すべてのクエリでParameterized Queryを使用（SQLインジェクション対策）
- [ ] すべてのクエリにorganization_idフィルタを含める（マルチテナント分離）
