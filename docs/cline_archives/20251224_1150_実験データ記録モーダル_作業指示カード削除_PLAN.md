## 1. タスク概要

## 5. 技術的詳細

### 現在の構造
```tsx
{instructions.length > 0 && (
  <div>
    {/* 折りたたみヘッダー + 確認完了ボタン */}
    <div onClick={() => setInstructionsExpanded(!instructionsExpanded)}>
      作業指示 ({instructions.length}件) [確認完了ボタン]
    </div>
    
    {instructionsExpanded && (
      <div
        style={{
          padding: token.paddingMD,
          backgroundColor: token.colorBgContainer,  // ← このカード構造を削除
          border: `1px solid ${token.colorBorderSecondary}`,
          borderRadius: token.borderRadius,
        }}
      >
        {/* 全体指示 */}
        {/* メソッド単位指示 */}
        {/* トランジション単位指示 */}
      </div>
    )}
  </div>
)}
```

### 変更後の構造
```tsx
{instructions.length > 0 && (
  <div>
    {/* 折りたたみヘッダー + 確認完了ボタン（維持） */}
    <div onClick={() => setInstructionsExpanded(!instructionsExpanded)}>
      作業指示 ({instructions.length}件) [確認完了ボタン]
    </div>
    
    {instructionsExpanded && (
      <>
        {/* カード構造を削除してフラットに表示 */}
        {/* 全体指示 */}
        {/* メソッド単位指示 */}
        {/* トランジション単位指示 */}
      </>
    )}
  </div>
)}
```

