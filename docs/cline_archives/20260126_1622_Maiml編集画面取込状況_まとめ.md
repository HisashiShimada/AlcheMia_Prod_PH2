#### 1. Export機能（PNG/SVG/JSON）

**概要**:
ペトリネット図を画像ファイルやJSON形式でエクスポートする機能

**実装場所（Reference）**:
- `reference/frontend/src/components/PetriNetViewer/index.js` (Line 300-400頃)

**依存ライブラリ**:
```json
{
  "html-to-image": "^1.11.11"
}
```

**実装コード例**:
```typescript
import { toPng, toSvg } from 'html-to-image';

// PNG Export
const exportToPng = async () => {
  const element = document.querySelector('.react-flow');
  if (!element) return;
  
  const dataUrl = await toPng(element, {
    backgroundColor: '#ffffff',
    quality: 1.0,
    pixelRatio: 2,
  });
  
  const link = document.createElement('a');
  link.download = `petri-net-${Date.now()}.png`;
  link.href = dataUrl;
  link.click();
};

// SVG Export
const exportToSvg = async () => {
  const element = document.querySelector('.react-flow');
  if (!element) return;
  
  const dataUrl = await toSvg(element, {
    backgroundColor: '#ffffff',
  });
  
  const link = document.createElement('a');
  link.download = `petri-net-${Date.now()}.svg`;
  link.href = dataUrl;
  link.click();
};

// JSON Export
const exportToJson = () => {
  const flowData = {
    nodes: getNodes(),
    edges: getEdges(),
    viewport: getViewport(),
    metadata: {
      exportedAt: new Date().toISOString(),
      nodeCount: nodes.length,
      edgeCount: edges.length,
    }
  };
  
  const dataStr = JSON.stringify(flowData, null, 2);
  const dataBlob = new Blob([dataStr], { type: 'application/json' });
  const url = URL.createObjectURL(dataBlob);
  
  const link = document.createElement('a');
  link.download = `petri-net-${Date.now()}.json`;
  link.href = url;
  link.click();
  
  URL.revokeObjectURL(url);
};
```

**UI統合**:
```typescript
// EditorToolbar.tsx に追加
import { DownloadOutlined } from '@ant-design/icons';
import { Menu, Dropdown } from 'antd';

const exportMenu = (
  <Menu>
    <Menu.Item key="png" onClick={exportToPng}>
      PNG画像として保存
    </Menu.Item>
    <Menu.Item key="svg" onClick={exportToSvg}>
      SVG形式として保存
    </Menu.Item>
    <Menu.Item key="json" onClick={exportToJson}>
      JSON形式として保存
    </Menu.Item>
  </Menu>
);

<Dropdown overlay={exportMenu}>
  <Button icon={<DownloadOutlined />}>
    エクスポート
  </Button>
</Dropdown>
```
