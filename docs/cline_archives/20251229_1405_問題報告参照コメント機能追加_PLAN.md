## 1. タスク概要

「実験作業者メニュー」の「進捗確認」タブ内「実験記録」タブのTransitionListに、問題報告機能を拡張します。既存の問題報告機能に加えて、報告された問題の一覧表示、詳細閲覧、コメント入力機能を追加します。

## 2. 目的と期待される成果

### 目的
- トランジションに関連する問題を一元管理できるようにする
- 問題の進捗状況を可視化する
- 問題に対するコメント機能で情報共有を促進する

### 期待される成果
- [ ] TransitionListに「問題報告」列が追加される

- [ ] 問題に対してコメントを入力できる

### コンポーネント設計

#### IssueManagementModal
```typescript
interface IssueManagementModalProps {
  visible: boolean;
  transitionId: string;
  transitionName: string;
  issues: Issue[];
  onClose: () => void;
  onSubmitIssue: (issue: IssueReportFormData) => void;
  onSubmitComment: (issueId: string, comment: string) => void;
}
```

**主要機能:**
1. 左側: 問題一覧テーブル（タイトル、状態、対象、報告者、報告時刻）
2. 右側: 選択された問題の詳細表示
   - 内容
   - コメント一覧
   - コメント入力フォーム
3. 上部: 新規問題報告ボタン
4. 新規報告フォーム（表示/非表示切替）
   - タイトル入力
   - 対象選択（プロジェクト/タスク/トランジション）
   - 内容入力
   - 保存/キャンセルボタン

### データ構造

```typescript
// 問題状態
export type IssueStatus = 'unresolved' | 'resolved';

// 問題対象タイプ
export type IssueTargetType = 'project' | 'task' | 'transition';

// 問題コメント
export interface IssueComment {
  commentId: string;
  issueId: string;
  content: string;
  createdBy: User;
  createdAt: string;
}

// 問題
export interface Issue {
  issueId: string;
  transitionId: string;
  transitionName: string;
  title: string;
  content: string;
  status: IssueStatus;
  targetType: IssueTargetType;
  reportedBy: User;
  reportedAt: string;
  comments: IssueComment[];
}

// 問題報告フォームデータ
export interface IssueReportFormData {
  title: string;
  targetType: IssueTargetType;
  content: string;
}
```
