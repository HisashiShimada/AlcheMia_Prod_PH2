## 1. タスク概要

指定されたフォルダパス配下のすべてのファイルをZIP形式でまとめて一括ダウンロードする機能を実装します。

### 実装方式
- フォルダパス（キー）を受け取り、そのフォルダ配下のファイルを取得
- バックエンドで複数ファイルをZIPアーカイブに圧縮
- ZIPファイルをストリームとしてフロントエンドに送信
- プロジェクト、フォーマット管理など、あらゆる機能で再利用可能

### 使用例
```
folderPath: "projects/sample_project" → sample_project.zip
folderPath: "formats/chemistry" → chemistry.zip
folderPath: "formats/materials/conditions" → conditions.zip
```

## 5. 技術的詳細

### archiverパッケージ
- ZIP形式のアーカイブ生成ライブラリ
- ストリーム方式でメモリ効率的

### 実装例
```typescript
// バックエンド - Service層
import archiver from 'archiver';

async downloadFolderAsZip(
  organizationId: string,
  folderPath: string
): Promise<{ zipStream: NodeJS.ReadableStream; folderName: string }> {
  // 1. フォルダ配下のファイル一覧を取得
  const files = await this.storageService.listFiles(organizationId, folderPath);
  
  // 2. ZIPアーカイブを作成
  const archive = archiver('zip', { zlib: { level: 6 } });
  
  // 3. 各ファイルをZIPに追加
  for (const file of files) {
    const buffer = await this.storageService.downloadFile(
      organizationId, 
      file.key
    );
    // フォルダパスを除いたファイル名のみをZIPに含める
    const fileName = file.key.replace(`${folderPath}/`, '');
    archive.append(buffer, { name: fileName });
  }
  
  // 4. ZIPを確定
  archive.finalize();
  
  // 5. フォルダ名を抽出（最後のフォルダ名）
  const folderName = folderPath.split('/').pop() || 'download';
  
  return { zipStream: archive, folderName };
}

// コントローラー
const { folderPath } = req.body;
const { zipStream, folderName } = await service.downloadFolderAsZip(
  organizationId,
  folderPath
);

const encodedFileName = encodeURIComponent(`${folderName}.zip`);
res.setHeader('Content-Type', 'application/zip');
res.setHeader('Content-Disposition', `attachment; filename*=UTF-8''${encodedFileName}`);
zipStream.pipe(res);

// フロントエンド
export const downloadFolderAsZip = async (folderPath: string): Promise<void> => {
  const client = createApiClient();
  const response = await client.post('/files/download-folder-as-zip', 
    { folderPath },
    { responseType: 'blob' }
  );
  
  const folderName = folderPath.split('/').pop() || 'download';
  downloadBlobAsFile(response.data, `${folderName}.zip`);
};
```

### 使用例
```typescript
// プロジェクトフォルダ全体をダウンロード

// → sample_project.zip

// フォーマットフォルダ全体をダウンロード

// → chemistry.zip

// サブフォルダをダウンロード

```
