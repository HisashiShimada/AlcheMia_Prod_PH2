# フォーマットファイル判定ロジック（修正版）

## 日時
2025-12-26 15:33

## 問題点の指摘

**sourceContextは判定に使えない理由:**
- sourceContext: どちらの画面から来たかの判定
- フォーマット取り込みフロー:
  1. フォーマット管理でダウンロード
  2. プロジェクト管理でアップロード ← `sourceContext = 'project'`
  3. 編集 ← `sourceContext = 'project'`
- **どちらも`sourceContext = 'project'`になる**

## 正しい判定方法

### DocumentDataの内容で判定

フォーマット管理で作成されたファイルの特徴:
- ✅ **基本情報が空**: id, name, date, uuid
- ✅ **MaiML ID属性が空**: protocolId, methodId, pnmlId, programId
- ✅ **Creator/Vendor/Ownerは設定済み**: 空でない配列

この特徴を使って「フォーマットファイル（ひな形）」かどうかを判定する。

### 判定関数の実装

```typescript
/**
 * フォーマットファイル（ひな形）かどうかを判定
 * 
 * 判定基準:
 * 1. 基本情報が空またはデフォルト値
 * 2. MaiML ID属性が空またはデフォルト値
 * 3. Creator/Vendor/Ownerのいずれかが存在する
 * 
 * @param doc DocumentData
 * @returns true: フォーマットファイル, false: 通常ファイル
 */
const isFormatTemplate = (doc: DocumentData): boolean => {
  // 基本情報が空またはデフォルト値
  const hasEmptyBasicInfo = 
    !doc.id || doc.id === 'documentID' || doc.id === '' ||
    !doc.name || doc.name === 'document' || doc.name === '' ||
    !doc.date || doc.date === '' ||
    !doc.uuid || doc.uuid === '';
  
  // MaiML ID属性が空またはデフォルト値
  const hasEmptyMaimlIds =
    !doc.protocolId || doc.protocolId === 'protocolID' || doc.protocolId === '' ||
    !doc.methodId || doc.methodId === 'methodID' || doc.methodId === '' ||
    !doc.pnmlId || doc.pnmlId === 'pnmlID' || doc.pnmlId === '' ||
    !doc.programId || doc.programId === 'programID' || doc.programId === '';
  
  // Creator/Vendor/Ownerのいずれかが存在する
  const hasTemplateData = 
    (doc.creators && doc.creators.length > 0) ||
    (doc.vendors && doc.vendors.length > 0) ||
    (doc.owners && doc.owners.length > 0);
  
  // 基本情報が空 OR MaiML ID属性が空 AND テンプレートデータが存在
  return (hasEmptyBasicInfo || hasEmptyMaimlIds) && hasTemplateData;
};
```

## 修正版実装

### PetriNetEditor.tsx の fetchPetriNetData 関数

```typescript
// extractDocumentFromMaiMLで読み込み
const extractedDocument = extractDocumentFromMaiML(effectiveMaimlData || '');
if (extractedDocument) {
  let documentToSet: DocumentData;
  
  // フォーマットファイル判定
  const isTemplate = isFormatTemplate(extractedDocument);
  
  if (isTemplate) {
    // ✅ フォーマットファイル: Creator等引き継ぎ + 基本情報新規生成
    console.log('📄 [PetriNetEditor] フォーマットファイル検出 - 基本情報を新規生成');
    
    const sanitizedBaseName = (originalFileName || projectName || 'template')
      .replace('.maiml', '')
      .replace(/\s+/g, '_')
      .replace(/[^a-zA-Z0-9_]/g, '');
    const uuidFull = crypto.randomUUID();
    
    documentToSet = {
      // 基本情報は新規生成
      id: `document_${sanitizedBaseName}_${crypto.randomUUID().substring(0, 8)}`,
      protocolId: `protocol_${sanitizedBaseName}_${crypto.randomUUID().substring(0, 8)}`,
      methodId: `method_${sanitizedBaseName}_${crypto.randomUUID().substring(0, 8)}`,
      pnmlId: `pnml_${sanitizedBaseName}_${crypto.randomUUID().substring(0, 8)}`,
      programId: `program_${sanitizedBaseName}_${crypto.randomUUID().substring(0, 8)}`,
      name: projectName || sanitizedBaseName,
      description: extractedDocument.description || '',  // 説明は引き継ぐ
      date: new Date().toISOString(),
      uuid: uuidFull,
      
      // Creator/Vendor/Owner/Instrumentsは引き継ぐ
      creators: extractedDocument.creators || [],
      vendors: extractedDocument.vendors || [],
      owners: extractedDocument.owners || [],
      instruments: extractedDocument.instruments || [],
      
      // XML署名は無効化
      signature: { enabled: false },
    };
    
    console.log('📄 [PetriNetEditor] フォーマットファイル処理完了:', {
      isTemplate,
      newDocumentId: documentToSet.id,
      creatorsCount: documentToSet.creators.length,
      vendorsCount: documentToSet.vendors.length,
      ownersCount: documentToSet.owners.length,
    });
  } else {
    // ❌ 通常ファイル: すべてそのまま引き継ぎ
    console.log('📄 [PetriNetEditor] 通常ファイル - すべて引き継ぎ');
    
    documentToSet = {
      ...extractedDocument,
      name: originalFileName 
        ? originalFileName.replace('.maiml', '') 
        : extractedDocument.name || 'document'
    };
  }
  
  setDocumentData(documentToSet);
}
```

## DocumentEditDialogの修正

DocumentEditDialogでも同じ判定ロジックを使用：

```typescript
// DocumentEditDialog.tsx

const DocumentEditDialog: React.FC<DocumentEditDialogProps> = ({
  open,
  documentData,
  onClose,
  onSave,
}) => {
  // フォーマットモード判定
  const isFormatMode = documentData ? isFormatTemplate(documentData) : false;
  
  // バリデーションロジック
  const validateDocumentData = useMemo(() => (data: DocumentData): string[] => {
    const errors: string[] = [];
    
    // フォーマットモードの場合は基本情報のバリデーションをスキップ
    if (!isFormatMode) {
      if (!data.name?.trim()) {
        errors.push('❌ Document name is required');
      }
      
      if (!data.id?.trim()) {
        errors.push('❌ Document ID is required');
      }
      
      // Creator/Vendor/Ownerの必須チェック
      if (!data.creators || data.creators.length === 0) {
        errors.push('❌ At least one Creator is required');
      }
      if (!data.vendors || data.vendors.length === 0) {
        errors.push('❌ At least one Vendor is required');
      }
      if (!data.owners || data.owners.length === 0) {
        errors.push('❌ At least one Owner is required');
      }
    }
    
    // ... その他のバリデーション
    
    return errors;
  }, [isFormatMode]);
  
  // 保存処理
  const handleSave = useCallback(() => {
    const dataToSave = isFormatMode
      ? {
          ...editingDocument,
          // 基本情報を空にする
          name: '',
          id: '',
          description: '',
          date: '',
          uuid: '',
          // MaiML ID属性を空にする
          protocolId: '',
          methodId: '',
          pnmlId: '',
          programId: '',
          // XML署名を無効化
          signature: { enabled: false },
          // Creator/Vendor/Ownerは保持（空にしない）
        }
      : editingDocument;
    
    const errors = validateDocumentData(dataToSave);
    // ...
  }, [editingDocument, isFormatMode, validateDocumentData, onSave, onClose]);
  
  // ... UI表示
  return (
    <Modal>
      {/* フォーマットモードの場合、警告を表示 */}
      {isFormatMode && (
        <Alert
          type="info"
          message="フォーマット管理モード"
          description="このファイルはフォーマット管理で作成されたひな形ファイルです。基本情報、MaiML ID属性、XML署名はプロジェクト取り込み時に設定されるため、ここでは編集できません。"
          showIcon
        />
      )}
      {/* ... */}
    </Modal>
  );
};
```

## 動作フロー

### ケース1: フォーマットファイルをプロジェクトに取り込み

1. **フォーマット管理でMaiMLファイル作成・ダウンロード**
   ```
   Document:
   - id: "" (空)
   - name: "" (空)
   - date: "" (空)
   - uuid: "" (空)
   - protocolId: "" (空)
   - methodId: "" (空)
   - pnmlId: "" (空)
   - programId: "" (空)
   - creators: [Creator1, Creator2]  ← 設定済み
   - vendors: [Vendor1]               ← 設定済み
   - owners: [Owner1]                 ← 設定済み
   ```

2. **プロジェクト管理でアップロード**
   - ファイルをアップロード
   - PetriNetEditorで開く
   - `sourceContext = 'project'`

3. **PetriNetEditor.fetchPetriNetDataで処理**
   ```typescript
   const extractedDocument = extractDocumentFromMaiML(maimlContent);
   const isTemplate = isFormatTemplate(extractedDocument); // ← true
   
   if (isTemplate) {
     // ✅ 基本情報を新規生成
     // ✅ Creator/Vendor/Ownerは引き継ぐ
   }
   ```

4. **結果**
   ```
   Document:
   - id: document_MyProject_abc123de ← 新規生成
   - name: MyProject ← 新規生成
   - date: 2025-12-26T15:30:00Z ← 新規生成
   - uuid: abc123de-f456-7890-ghij... ← 新規生成
   - protocolId: protocol_MyProject_xyz789 ← 新規生成
   - methodId: method_MyProject_uvw456 ← 新規生成
   - pnmlId: pnml_MyProject_rst123 ← 新規生成
   - programId: program_MyProject_mno789 ← 新規生成
   - creators: [Creator1, Creator2] ← 引き継ぎ
   - vendors: [Vendor1] ← 引き継ぎ
   - owners: [Owner1] ← 引き継ぎ
   - signature: { enabled: false } ← 無効化
   ```

5. **DocumentEditDialogで編集**
   - `isFormatMode = false`（基本情報が生成済みなので通常モード）
   - すべてのセクションが編集可能
   - バリデーション正常動作

   - すべてのセクションが編集可能

## まとめ

**判定方法の変更:**
- ❌ sourceContext では判定できない
- ✅ DocumentDataの内容で判定する
  - 基本情報が空 OR MaiML ID属性が空
  - AND Creator/Vendor/Ownerが存在する
  - → フォーマットファイル

**メリット:**
- フローに依存しない
- ファイルの内容だけで判定可能
- 既存のフローを変更不要

**実装箇所:**
1. 判定関数 `isFormatTemplate()` をユーティリティに追加
2. PetriNetEditor.fetchPetriNetDataで判定・処理分岐
3. DocumentEditDialogでも同じ判定を使用
