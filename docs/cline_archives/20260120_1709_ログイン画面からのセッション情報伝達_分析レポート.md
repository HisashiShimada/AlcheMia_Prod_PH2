## 🔐 セキュリティ考慮事項

### 1. JWTトークンの保存場所

**保存先**: HTTPOnly Cookie (`maiml_session`)

**設定箇所** (authController.ts):
```typescript
res.cookie('maiml_session', jwtToken, {
  httpOnly: true,                          // ✅ JavaScriptからアクセス不可
  secure: process.env.NODE_ENV === 'production', // ✅ 本番環境はHTTPSのみ
  sameSite: 'strict',                      // ✅ CSRF対策
  maxAge: maxAge,                          // ロール別有効期限
  path: '/',
});
```

**メリット:**
- XSS攻撃からの保護（JavaScriptから読み取れない）
- CSRF攻撃からの保護（sameSite: 'strict'）

### 2. セッションストレージの使用

**保存先**: `sessionStorage.setItem('user', JSON.stringify(response.user))`

**用途**: ページリロード時のユーザー情報復元（オプション）

**注意点:**
- タブ/ウィンドウごとに独立
- 機密情報（パスワード、トークン）は含まれない
- ユーザーが直接編集可能（サーバー側で再検証必須）

## 🚨 注意事項

### 1. SessionStorage の制限

- タブを閉じると情報が消える
- 別タブでは共有されない
- ページリロード時に情報が失われる可能性（ステート再構築が必要）

**推奨対応**:
```typescript
// ページ初期化時にSessionStorageから復元
useEffect(() => {
  if (typeof window !== 'undefined') {
    const savedUser = sessionStorage.getItem('user');
    if (savedUser) {
      setCurrentUser(JSON.parse(savedUser));
    }
  }
}, []);
```

### 2. セキュリティ

- SessionStorage の内容はユーザーが編集可能
- **サーバー側で必ず再検証すること**
- 機密情報は含めない（JWTトークンは Cookie に保存）
