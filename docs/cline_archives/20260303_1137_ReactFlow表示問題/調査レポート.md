### 3. 考えられる問題の原因

#### 原因1: 特定のMAIML形式での変換エラー

**症状**:
- 特定のMAIML XMLファイルでノードが生成されない
- エラーログに変換エラーが記録される

**確認方法**:
```typescript
// ブラウザDevToolsコンソールで確認
// エラーメッセージのパターン:
// ❌ [reactFlowConverter] React Flow形式変換エラー:
// ❌ [petriNetExtractor] テンプレートマップ構築エラー:
// ❌ [MaimlParserTyped] 型変換失敗:
```

**原因の可能性**:
- XSD型定義と実際のXML構造の不一致
- 必須要素の欠落
- 名前空間の問題

#### 原因2: レイアウト計算の問題

**症状**:
- ノードは生成されるが画面外に配置される
- ノード位置が重複する
- レイアウトが崩れる

**確認方法**:
```typescript
// PetriNetViewer.tsx のログ出力で確認
// ✅ [PetriNetViewer] ペトリネット初期化完了（新方式）
// nodes: X, edges: Y, places: Z, arcs: W
```

**原因の可能性**:
- トポロジカルソートの失敗
- 座標計算のバグ
- fitViewオプションの設定ミス

#### 原因3: エッジ接続の問題

**症状**:
- ノードは表示されるがエッジ（矢印）が表示されない
- 一部のエッジのみ表示される

**確認方法**:
```typescript
// arcsデータの確認
// arcs: [{ source: 'place1', target: 'transition1' }, ...]
```

**原因の可能性**:
- source/target IDの不一致
- arcデータの欠落
- markerEndの設定問題

#### 原因4: ReactFlowProviderの問題

**症状**:
- コンポーネント全体が表示されない
- 白画面になる

**確認方法**:
```typescript
// PetriNetViewer.tsx 行451-457
<ReactFlowProvider>
  <PetriNetViewerInner {...props} />
</ReactFlowProvider>
```

**原因の可能性**:
- ReactFlowProviderの初期化失敗
- スタイルシートの読み込み失敗（'reactflow/dist/style.css'）

```typescript
// reactFlowConverter.ts に追加
const validatePetriNetData = (data: PetriNetData): ValidationResult => {
  const errors: string[] = [];
  
  if (!data.places || data.places.length === 0) {
    errors.push('Placesが空です');
  }
  
  if (!data.transitions || data.transitions.length === 0) {
    errors.push('Transitionsが空です');
  }
  
  if (!data.arcs || data.arcs.length === 0) {
    errors.push('Arcsが空です');
  }
  
  // Arc接続の検証
  data.arcs.forEach(arc => {
    const sourceExists = data.places.some(p => p.id === arc.source) || 
                        data.transitions.some(t => t.id === arc.source);
    const targetExists = data.places.some(p => p.id === arc.target) || 
                        data.transitions.some(t => t.id === arc.target);
    
    if (!sourceExists) {
      errors.push(`Arc source '${arc.source}' が見つかりません`);
    }
    if (!targetExists) {
      errors.push(`Arc target '${arc.target}' が見つかりません`);
    }
  });
  
  return {
    isValid: errors.length === 0,
    errors
  };
};
```

```typescript
const avoidCollision = (
  targetPos: Position,
  existingPositions: Map<string, Position>,
  minDistance: number = 80
): Position => {
  let { x, y } = targetPos;
  let attempts = 0;
  const maxAttempts = 100;
  
  while (attempts < maxAttempts) {
    let hasCollision = false;
    
    for (const [, pos] of existingPositions) {
      const distance = Math.sqrt(
        Math.pow(pos.x - x, 2) + Math.pow(pos.y - y, 2)
      );
      
      if (distance < minDistance) {
        hasCollision = true;
        break;
      }
    }
    
    if (!hasCollision) {
      return { x, y };
    }
    
    // スパイラル配置で次の位置を探す
    const angle = (attempts / maxAttempts) * Math.PI * 2;
    const radius = minDistance * (1 + attempts / maxAttempts);
    x = targetPos.x + radius * Math.cos(angle);
    y = targetPos.y + radius * Math.sin(angle);
    
    attempts++;
  }
  
  console.warn('⚠️ 衝突回避に失敗しました');
  return { x, y };
};
```

## 🎯 最も可能性が高い3つの問題の詳細分析

### 問題1: 特定のMAIML形式での変換エラー

#### 発生シナリオ

**ケース1: XSD型定義と実際のXML構造の不一致**
```xml
<!-- 問題のあるMAIML例 -->
<protocol>
  <method id="method1">
    <!-- pnmlが配列ではなく単一要素 -->
    <pnml id="pnml1">
      <place id="place1" />
    </pnml>
    <!-- XSD定義では配列だがXMLは単一要素 -->
  </method>
</protocol>
```

**症状**:
- コンソールに「型変換失敗」エラー
- ノードが0件になる
- エラーメッセージ: `Cannot read properties of undefined`

**確認方法**:
```typescript
// ブラウザDevToolsコンソールで確認
console.log('🔍 MaiML解析結果:', parser.getMethods());
// 期待: Method配列
// 実際: [] または undefined
```

**対処法**:
```typescript
// maimlParserTyped.ts または変換処理に追加
try {
  const methods = parser.getMethods();
  if (!methods || methods.length === 0) {
    throw new Error('Methodが見つかりません。MAIMLファイルにmethod要素が含まれているか確認してください。');
  }
  
  const targetMethod = methods[0];
  if (!targetMethod.pnml) {
    throw new Error('PNML要素が見つかりません。methodにpnml要素が含まれているか確認してください。');
  }
} catch (error) {
  console.error('❌ MAIML構造エラー:', error);
  setError(error.message);
  return;
}
```

**ケース2: 必須要素の欠落**
```xml
<!-- 問題のあるMAIML例 -->
<protocol>
  <method id="method1">
    <pnml id="pnml1">
      <!-- placesがない -->
      <transition id="trans1" />
      <arc source="place1" target="trans1" />
    </pnml>
  </method>
</protocol>
```

**症状**:
- ノードは表示されるがエッジが表示されない
- レイアウトが崩れる
- コンソール警告: `Place 'place1' not found`

**確認方法**:
```typescript
// reactFlowConverter.ts に追加すべき検証
const validatePetriNetStructure = (petriNetData: PetriNetData) => {
  const placeIds = new Set(petriNetData.places.map(p => p.id));
  const transitionIds = new Set(petriNetData.transitions.map(t => t.id));
  
  const missingNodes: string[] = [];
  
  petriNetData.arcs.forEach(arc => {
    if (!placeIds.has(arc.source) && !transitionIds.has(arc.source)) {
      missingNodes.push(arc.source);
    }
    if (!placeIds.has(arc.target) && !transitionIds.has(arc.target)) {
      missingNodes.push(arc.target);
    }
  });
  
  if (missingNodes.length > 0) {
    console.error('❌ Arc参照エラー:', {
      missingNodes: [...new Set(missingNodes)],
      availablePlaces: Array.from(placeIds),
      availableTransitions: Array.from(transitionIds)
    });
  }
};
```

**ケース3: テンプレート参照の不整合**
```xml
<!-- 問題のあるMAIML例 -->
<protocol>
  <materialTemplate id="mat1">
    <!-- placeRefがない、またはrefが間違っている -->
    <placeRef ref="wrong_place_id" />
  </materialTemplate>
```

```typescript
// 衝突回避処理に上限を設定
const avoidCollisionWithLimit = (
  targetPos: Position,
  existingPositions: Map<string, Position>,
  minDistance: number = 80,
  maxAttempts: number = 50
): Position => {
  let { x, y } = targetPos;
  let attempts = 0;
  
  while (attempts < maxAttempts) {
    let hasCollision = false;
    
    for (const [, pos] of existingPositions) {
      const distance = Math.sqrt(
        Math.pow(pos.x - x, 2) + Math.pow(pos.y - y, 2)
      );
      
      if (distance < minDistance) {
        hasCollision = true;
        break;
      }
    }
    
    if (!hasCollision) {
      return { x, y };
    }
    
    // Y軸方向に移動（無限に広がらないように）
    y += minDistance;
    attempts++;
  }
  
  console.warn(`⚠️ 衝突回避失敗（${attempts}回試行）: ID=${JSON.stringify(targetPos)}`);
  // 失敗時は元の座標を返す（異常な座標よりマシ）
  return targetPos;
};
```

```typescript
const validateAndFilterEdges = (
  edges: Edge<EdgeData>[],
  nodeIds: Set<string>
): Edge<EdgeData>[] => {
  const validEdges: Edge<EdgeData>[] = [];
  const invalidEdges: Edge<EdgeData>[] = [];
  
  edges.forEach(edge => {
    if (nodeIds.has(edge.source) && nodeIds.has(edge.target)) {
      validEdges.push(edge);
    } else {
      invalidEdges.push(edge);
      console.warn('⚠️ 無効なエッジをスキップ:', {
        id: edge.id,
        source: edge.source,
        target: edge.target,

          ? `source '${edge.source}' が見つかりません` 
          : `target '${edge.target}' が見つかりません`
      });
    }
  });
  
  if (invalidEdges.length > 0) {
    console.warn(`⚠️ ${invalidEdges.length}/${edges.length} のエッジが無効でした`);
  }
  
  return validEdges;
};
```

```typescript
const checkDuplicateArcs = (arcs: Arc[]) => {
  const arcKeys = new Map<string, number>();
  
  arcs.forEach(arc => {
    const key = `${arc.source}-${arc.target}`;
```
