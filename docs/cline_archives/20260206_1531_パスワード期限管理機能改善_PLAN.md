## 1. タスク概要

user_authenticationテーブルのパスワード期限管理機能を改善し、一時パスワードと通常パスワードの両方に対応できるようにする。

### 現状の課題
- temp_password_expires_atカラムは一時パスワード専用
- 通常パスワードの期限管理ができない
- 一時パスワードと通常パスワードの区別が曖昧

### 変更内容
1. **カラム名変更**: `temp_password_expires_at` → `password_expires_at`
2. **新規カラム追加**: `is_temporary_password` (boolean)
3. **ログイン処理の改善**: パスワード種別と期限に応じた適切な処理

### ログイン判定ロジック

```typescript
interface PasswordStatus {
  requiresPasswordChange: boolean;
  isPasswordExpired: boolean;
  isTemporaryPassword: boolean;
}

function checkPasswordStatus(
  passwordExpiresAt: Date | null,
  isTemporaryPassword: boolean
): PasswordStatus {
  const now = new Date();
  const isExpired = passwordExpiresAt ? passwordExpiresAt < now : false;
  
  return {
    requiresPasswordChange: isTemporaryPassword || isExpired,
    isPasswordExpired: isExpired,
    isTemporaryPassword
  };
}
```
