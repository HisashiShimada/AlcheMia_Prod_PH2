## 1. タスク概要

指示確認タブのフロー図ダイアログから、メソッド選択機能を削除する。
既存のViewRendererDialogは他の画面でも使用されているため、新しい専用ダイアログを作成し、フロー表示領域のみを共用する。

## 2. 目的と期待される成果

### 目的
- 指示確認タブでは、既に選択されているプロジェクト・メソッドのフロー図のみを表示する
- ダイアログ内でメソッドを切り替えられないようにする
- 既存の他の画面での動作に影響を与えない

### 期待される成果
- [x] 新しいダイアログコンポーネント「InstructionFlowDialog」が作成される

- [x] ViewRendererにメソッド選択UI非表示オプションが追加される
