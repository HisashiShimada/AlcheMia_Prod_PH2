## 📋 保存フロー

### ケース1: 新規ファイルの場合

```
保存ボタン押下
  ↓
プロジェクトフォルダにmaimlファイルが存在しない
  ↓
ファイル名を自動生成: "[プロジェクト名].maiml"
  例: "Material_Synthesis_Project.maiml"
  ↓
プロジェクトフォルダ直下に保存
  パス: /projects/[project-folder]/[プロジェクト名].maiml
  ↓
保存成功
  ├─ 「保存しました」メッセージ表示
  └─ ファイル一覧を更新
```

**例:**
- プロジェクト名: `Material Synthesis Project`
- プロジェクトフォルダ: `/projects/proj_001/`
- 保存先: `/projects/proj_001/Material_Synthesis_Project.maiml`

---

### ケース2: 既存ファイルの編集の場合

```
保存ボタン押下
  ↓
プロジェクトフォルダにmaimlファイルが既に存在
  ↓
【Step 1】既存の最新ファイルをarchiveフォルダに移動
  ├─ archiveフォルダがなければ作成
  ├─ 連番を付与: "[プロジェクト名]_001.maiml", "_002.maiml"...
  └─ 移動先: /projects/[project-folder]/archive/[プロジェクト名]_XXX.maiml
  ↓
【Step 2】新しい内容をプロジェクトフォルダ直下に保存
  ├─ ファイル名: "[プロジェクト名].maiml"（元のファイル名と同じ）
  └─ パス: /projects/[project-folder]/[プロジェクト名].maiml
  ↓
保存成功
  ├─ 「保存しました」メッセージ表示
  └─ ファイル一覧を更新
```

**例:**
- プロジェクト名: `Material Synthesis Project`
- 既存ファイル: `/projects/proj_001/Material_Synthesis_Project.maiml`
- アーカイブ先: `/projects/proj_001/archive/Material_Synthesis_Project_001.maiml`
- 新ファイル: `/projects/proj_001/Material_Synthesis_Project.maiml`

---

### ケース3: 複数回保存した場合

```
1回目の保存:
  既存: Material_Synthesis_Project.maiml
  → archive/Material_Synthesis_Project_001.maiml に移動

2回目の保存:

最終的なフォルダ構造:
/projects/proj_001/
  ├── Material_Synthesis_Project.maiml  (最新版)
```

### 連番付与ロジック

```typescript
// archiveフォルダ内の最大連番を取得
const getNextArchiveNumber = async (
  projectFolder: string,
  baseFilename: string
): Promise<number> => {
  // archiveフォルダ内のファイル一覧を取得
  const archiveFiles = await listFiles(`${projectFolder}/archive`);
  
  // 正規表現で連番を抽出: baseFilename_XXX.maiml
  const pattern = new RegExp(`${baseFilename.replace('.maiml', '')}_(\d+)\.maiml`);
  
  let maxNumber = 0;
  for (const file of archiveFiles) {
    const match = file.name.match(pattern);
    if (match) {
      const num = parseInt(match[1], 10);
      if (num > maxNumber) {
        maxNumber = num;
      }
    }
  }
  
  return maxNumber + 1;
};
```

### 保存処理の実装

```typescript
const handleSaveMaiml = async (content: string) => {
  if (!selectedProject) return;

  try {
    setIsSaving(true);

    const projectFolder = selectedProject.folderName;
    const filename = generateFilename(selectedProject.name);
    const filePath = `${projectFolder}/${filename}`;

    // プロジェクトフォルダ内のmaimlファイルを検索
    const existingFiles = projectFiles.filter(f => 
      f.name.endsWith('.maiml') && !f.isFolder && f.path === filePath
    );

    if (existingFiles.length > 0) {
      // 【ケース2】既存ファイルあり → archiveに移動
      const existingFile = existingFiles[0];
      
      // archiveフォルダがなければ作成
      await createFolderIfNotExists(`${projectFolder}/archive`);
      
      // 次の連番を取得
      const nextNumber = await getNextArchiveNumber(projectFolder, filename);
      const archiveFilename = filename.replace('.maiml', `_${String(nextNumber).padStart(3, '0')}.maiml`);
      const archivePath = `${projectFolder}/archive/${archiveFilename}`;
      
      // 既存ファイルをarchiveに移動
      await moveFile(existingFile.path, archivePath);
      
      // 新しい内容を保存
      await saveFile(filePath, content);
      
      message.success(`保存しました（旧バージョンは ${archiveFilename} に保存されました）`);
    } else {
      // 【ケース1】新規ファイル → 直接保存
      await saveFile(filePath, content);
      
      message.success('保存しました');
    }

    // ファイル一覧を更新
    await refetchProjectFiles();
    
  } catch (error) {
    console.error('Save error:', error);
    message.error('保存に失敗しました');
    throw error;
  } finally {
    setIsSaving(false);
  }
};
```

## ⚠️ 注意点

### 1. ファイル名の一意性
- プロジェクト名が重複する可能性があるため、プロジェクトフォルダで分離
- 同一プロジェクト内では常に同じファイル名を使用

### 2. archiveフォルダの管理
- archiveフォルダは自動作成
- 古いバージョンは削除せず、すべて保持
- 連番は001から開始し、3桁でゼロパディング

### 3. エラーハンドリング
- ファイル移動失敗時のロールバック
- 保存失敗時のDraft保持
- 権限エラーの適切な処理

### 4. パフォーマンス
- 大きなファイル（1MB以上）の移動時間
- archive内のファイル数増加によるパフォーマンス低下
