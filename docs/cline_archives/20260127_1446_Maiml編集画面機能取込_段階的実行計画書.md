## 🎯 取り込むべき機能の整理

### Phase 1: フロントエンド機能の精査と追加実装

Reference版の以下の機能について、現行版への取り込みを検討：

#### 1.1. インライン編集機能（低優先度）

**Reference版:**
- EditablePlaceNode/EditableTransitionNode
- ノード上で直接名前・説明を編集

**現行版:**
- PropertyPanel経由でのモーダル編集
- TemplateEditorDialog での編集

**判断:**
- 現行の実装で十分機能している
- Ant Design v6との統合が複雑
- **取り込み不要** と判断

#### 1.2. テンプレート継承関係の可視化（中優先度）

**Reference版:**
- テンプレート間の継承関係をビジュアル表示

**現行版:**
- PropertyPanelに「テンプレート継承」セレクトボックスあり
- TemplateListViewに継承関係の表示なし

**判断:**
- TemplateListItemに継承元テンプレート名を表示
- **Phase 1-A で実装**

#### 1.3. PlaceReferences（placeRef）機能（高優先度）

**Reference版:**
- Material/Condition/ResultノードからPlaceへの参照
- テンプレートの再利用性を高める機能

**現行版:**
- `commonTemplateRef` プロパティは存在
- UI上での表示・編集機能が不足

**判断:**
- PropertyPanelとTemplateListItemで表示強化
- **Phase 1-B で実装**

#### 1.4. テンプレートID管理の強化（高優先度）

**Reference版:**
- テンプレートに明示的なID属性を付与
- MaiMLのid属性と連動

**現行版:**
- ReactFlowのnode.idを使用
- MaiML出力時のID管理が不明確

**判断:**
- テンプレートID管理機能を追加
- **Phase 1-C で実装**

#### タスク:

1. **ID生成ルールの統一**
   ```typescript
   // utils/idGenerator.ts
   export const generateTemplateId = (
     type: 'material' | 'condition' | 'result',
     name: string
   ): string => {
     const prefix = type.charAt(0).toUpperCase() + type.slice(1);
     const safeName = name.replace(/\s+/g, '_').replace(/[^a-zA-Z0-9_]/g, '');
     const timestamp = Date.now();
     return `${prefix}_${safeName}_${timestamp}`;
   };
   ```
