from origin 'http://localhost:3000' has been blocked by CORS policy:

```

origin: 'http://localhost:3000'
credentials: true
methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS', 'PATCH']
allowedHeaders: ['Content-Type', 'Authorization', 'X-Organization-Id']
```

### 実施内容
1. **現状確認**
   - server.tsにCORS設定が全くないことを確認
   - package.jsonでcorsパッケージが既にインストール済みであることを確認
   - docker-compose.ymlでNODE_ENV=developmentが設定されていることを確認

2. **CORS設定追加**
   - server.tsにcorsパッケージをインポート
   - corsOptionsオブジェクトを作成し、以下を設定：
     - 開発環境: `http://localhost:3000`を許可
     - 本番環境: `process.env.FRONTEND_URL`を使用
     - credentials: true（Cookie送信を許可）
     - methods: GET, POST, PUT, DELETE, OPTIONS, PATCH
     - allowedHeaders: Content-Type, Authorization, X-Organization-Id
     - exposedHeaders: Set-Cookie
     - maxAge: 86400秒（24時間のプリフライトキャッシュ）

3. **セキュリティ考慮事項**
   - 環境変数に基づいて開発環境と本番環境で異なるオリジンを許可
   - credentialsをtrueに設定してCookie/セッション管理をサポート
   - 必要なヘッダーのみを許可してセキュリティを維持

### 次のステップ
サーバーを再起動してCORS設定を有効化してください：

```bash
# Dockerコンテナの再起動

docker-compose down
docker-compose up -d
```

再起動後、ブラウザでログイン画面にアクセスして、CORSエラーが解消されていることを確認してください。
