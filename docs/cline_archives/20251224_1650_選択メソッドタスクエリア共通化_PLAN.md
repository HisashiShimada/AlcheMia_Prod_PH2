## 1. タスク概要

「実験作業者メニュー」画面の「指示確認タブ」と「実験記録タブ」に配置されている「選択メソッド・タスク」エリアのソースコードが重複しているため、共通コンポーネントに抽出してコードの保守性を向上させる。

## 3. 現状分析

### 共通部分の確認結果

両タブの「選択メソッド・タスク」エリアは**ほぼ同一**のコードが重複しています。

#### 構造
```tsx
<div style={{ ... /* コンテナスタイル */ }}>
  <div style={{ width: '100%' }}>
    <div style={{ display: 'flex', ... }}>
      {/* メソッド選択 */}
      <Space>
        <PartitionOutlined />
        <Text strong>メソッド:</Text>
        <Select ... />
      </Space>
      
      {/* タスク選択 */}
      <Space>
        <CheckSquareOutlined />
        <Text strong>タスク:</Text>
        <Select ... />
      </Space>
      
      {/* 選択ボタン */}
      <Button>選択</Button>
    </div>
  </div>
</div>
```

#### 微細な差異

| 項目 | 指示確認タブ | 実験記録タブ | 対応 |
|------|-------------|-------------|------|
| メソッドデータ取得元 | `projectInfo?.methods` | `selectedProjectData?.methods` | propsで統一 |
| タスク選択disabled条件 | `!methodInfo` | `!selectedMethod` | propsで統一 |
| モーダル開く関数 | `setIsModalVisible(true)` | `setModalOpen(true)` | propsで統一 |

これらの差異はすべて**props化**で解決可能です。
