## 5. 技術的詳細

### 使用する技術・ライブラリ
- pg-promise: SQLファイル読み込み
- loadSqlFile(): backend/src/sql/loader.ts

### SQLファイル命名規則
- queries/instructions/{機能名}.sql
- キャメルケースで命名

### パラメータ化
- すべてのクエリでParameterized Queryを使用
- $1, $2, $3... の形式でパラメータを指定

### 共通化の検討
- findUserName.sql: 既存のものはorganization_userテーブル
- confirmInstructionではuser_authenticationテーブルを使用
- テーブルが異なるため、別ファイルとして作成
