## 5. 技術的詳細

### データベース構造（department テーブル）
```sql
CREATE TABLE department (
    organization_id UUID NOT NULL,
    department_cd VARCHAR(50) NOT NULL,
    department_name VARCHAR(50) NOT NULL,
    is_active BOOLEAN NOT NULL,
    create_at TIMESTAMP,
    update_at TIMESTAMP,
    CONSTRAINT department_pkey PRIMARY KEY (organization_id, department_cd)
);
```

### 主要な特徴
- **複合主キー**: organization_id + department_cd
- **マルチテナント対応**: 必ず organization_id でフィルタリング
- **会社管理との違い**: corporation は UUID単独主キー、department は複合主キー

### API仕様

#### 1. 一覧取得
```
GET /api/v1/master/department
Query Parameters:
  - search: 検索テキスト
  - is_active: アクティブフィルタ（true/false）
  - sort_by: ソートフィールド（department_cd/department_name/update_at）
  - sort_order: ソート順（asc/desc）
Headers:
  - x-organization-id: 組織ID（必須）
Response: { success: true, data: [...], meta: {...} }
```

#### 2. ID指定取得
```
GET /api/v1/master/department/:departmentCd
Headers:
  - x-organization-id: 組織ID（必須）
Response: { success: true, data: {...}, meta: {...} }
```

#### 3. 新規作成
```
POST /api/v1/master/department
Headers:
  - x-organization-id: 組織ID（必須）
Body: {
  departmentCd: string,
  departmentName: string,
  isActive: boolean
}
Response: { success: true, data: {...}, meta: {...} }
```

#### 4. 更新
```
PUT /api/v1/master/department/:departmentCd
Headers:
  - x-organization-id: 組織ID（必須）
Body: {
  departmentName?: string,
  isActive?: boolean
}
Response: { success: true, data: {...}, meta: {...} }
```

#### 5. ステータス更新
```
PATCH /api/v1/master/department/:departmentCd/status
Headers:
  - x-organization-id: 組織ID（必須）
Body: { isActive: boolean }
Response: { success: true, data: {...}, meta: {...} }
```

#### 6. CSVアップロード
```
POST /api/v1/master/department/upload-csv
Headers:
  - x-organization-id: 組織ID（必須）
  - Content-Type: multipart/form-data
Body: file (CSV形式)
CSV形式:
  - 部署CD（必須）
  - 部署名（必須）
  - 状態（アクティブ/非アクティブ）
Response: {
  success: true,
  data: { successCount: 10, failureCount: 0, errors: [] },
  meta: {...}
}
```

#### 7. CSVダウンロード
```
GET /api/v1/master/department/download-csv
Query Parameters:
  - search: 検索テキスト
  - is_active: アクティブフィルタ
Headers:
  - x-organization-id: 組織ID（必須）
Response: CSV File (UTF-8 BOM付き)
```

## 6. セキュリティ考慮事項

### マルチテナント分離
- [x] すべてのクエリに organization_id フィルタ必須
- [x] authMiddleware で organization_id を検証
- [x] 複合主キー（organization_id + department_cd）による自動分離

- [x] 部署CDの重複チェック（同一組織内）
- [x] 必須項目チェック（departmentCd, departmentName）
- [x] 文字列長チェック（VARCHAR(50)）

### SQLインジェクション対策
- [x] Parameterized Queries使用
- [x] 文字列連結でのSQL構築禁止
