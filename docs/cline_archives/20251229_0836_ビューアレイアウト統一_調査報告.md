## 1. 問題の概要

StructuredPropertySelectorのチェックボックス押下時に選択状態の変更処理と連携プロパティに設定されていた`handlePropertyToggle`のビューアへの選択プロパティ表示機能が正常に動いていない。

## 2. 調査結果

### 2.1. 以前の実装（コミット 8f07671）

**PetriNetViewer.tsx の handlePropertyToggle:**

```typescript
const handlePropertyToggle = useCallback((structure: 'basic' | 'template' | 'data', property: string) => {
  console.log('🔍 [PetriNetViewer] プロパティトグル:', { structure, property, selectedNodeId });

  if (!selectedNodeId) return;

  setSelectedPropertiesByNode(prev => {
    const nodeProps = prev[selectedNodeId] || { basic: [], template: [], data: [] };
    const newNodeProps = { ...nodeProps };
    const currentList = newNodeProps[structure] || [];

    if (currentList.includes(property)) {
      newNodeProps[structure] = currentList.filter(p => p !== property);
    } else {
      newNodeProps[structure] = [...currentList, property];
    }

    const newState = {
      ...prev,
      [selectedNodeId]: newNodeProps
    };

    console.log('🔍 [PetriNetViewer] 新しい選択状態:', newState);

    // ★★★ 重要: 選択されたプロパティをノードデータに反映 ★★★
    setNodes(nds => nds.map(node => {
      if (node.id === selectedNodeId) {
        // 選択されたプロパティから表示用データを構築
        const selectedPropsData: Record<string, string> = {};

        Object.entries(newNodeProps).forEach(([struct, props]) => {
          props.forEach(propKey => {
            const propData = structuredProperties[struct as keyof typeof structuredProperties]?.[propKey];
            if (propData && typeof propData === 'object' && 'value' in propData) {
              selectedPropsData[propKey] = String(propData.value);
            }
          });
        });

        console.log('🔍 [PetriNetViewer] selectedPropsData:', selectedPropsData);

        // ★★★ ノードのdataに選択されたプロパティを設定 ★★★
        return {
          ...node,
          data: {
            ...node.data,
            selectedProperties: selectedPropsData,
          }
        };
      }
      return node;
    }));

    return newState;
  });
}, [selectedNodeId, structuredProperties, setNodes]);
```

**処理フロー:**
1. `selectedPropertiesByNode`状態を更新（ノード単位で選択状態を管理）
2. **選択されたプロパティの値を`structuredProperties`から取得**
3. **`setNodes`でReact Flowのノードデータに`selectedProperties`として反映**
4. これにより、MaterialTemplateNode等のカスタムノードが`node.data.selectedProperties`を参照して選択されたプロパティを表示できる

### 2.2. 現在の実装（2025-12-29 修正後）

**PetriNetViewer.tsx の handlePropertyToggle:**

```typescript
const handlePropertyToggle = useCallback((structure: 'basic' | 'template' | 'data', property: string) => {
  console.log('🔍 [PetriNetViewer] プロパティトグル:', { structure, property });

  setSelectedProperties(prev => {
```

**処理フロー:**

3. PropertyViewerWithSelectionのDrawer内では選択状態が表示される
4. しかし、React Flowのノード上では選択されたプロパティが表示されない

## 3. 問題の原因

### 3.1. 失われた機能
**ノードデータへのプロパティ反映処理が削除された**

以前の実装では、`handlePropertyToggle`内で以下を実行していました:
```typescript
setNodes(nds => nds.map(node => {
  if (node.id === selectedNodeId) {
    return {
      ...node,
      data: {
        ...node.data,
        selectedProperties: selectedPropsData,  // ← これが重要
      }
    };
  }
  return node;
}));
```

現在の実装ではこの処理がないため、カスタムノード（MaterialTemplateNode等）が`node.data.selectedProperties`を参照しても値が存在しません。

### 3.2. カスタムノードの期待動作

MaterialTemplateNode、ConditionTemplateNode、ResultTemplateNodeは、`node.data.selectedProperties`を参照して選択されたプロパティを表示する機能を持っています（想定）。

**例: MaterialTemplateNode.tsx の期待コード（推測）:**
```typescript
// 選択されたプロパティの表示
{node.data.selectedProperties && (
  <div style={{ marginTop: 8, fontSize: 10 }}>
    {Object.entries(node.data.selectedProperties).map(([key, value]) => (
      <div key={key}>
        <strong>{key}:</strong> {value}
      </div>
    ))}
  </div>
)}
```

### 3.3. structuredProperties の不足

現在の実装では、`structuredProperties`状態も削除されているため、選択されたプロパティのキー名は分かっても、その値を取得できません。
