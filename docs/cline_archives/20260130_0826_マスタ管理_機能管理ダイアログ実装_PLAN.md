### データ構造
```typescript
interface FunctionItem {
  key: string;           // FUNC001, FUNC002, etc.
  label: string;         // 機能名
  description?: string;  // 機能説明
  children?: FunctionItem[]; // サブ機能（マスタ管理のみ使用）
  checked: boolean;      // チェック状態
  writable: boolean;     // 書込可状態
}

// カテゴリ分けは行わず、全機能をフラットに配列で管理
type FunctionList = FunctionItem[];
```
