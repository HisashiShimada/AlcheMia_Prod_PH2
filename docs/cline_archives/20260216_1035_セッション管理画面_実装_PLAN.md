## 1. タスク概要

System Admin用のセッション管理画面を実装します。現在ログイン中の全ユーザーのセッション情報を表示し、管理者がセッションを強制終了できる機能を提供します。

**重要な仕様:**
- ✅ **表示されるユーザーはログインしているユーザーの組織IDと同じユーザーのみ表示する**
- ✅ マルチテナント分離により、他組織のセッション情報は完全に隔離される

## 2. 目的と期待される成果

### 目的

- セッション情報をリアルタイムに更新して最新状態を把握できるようにする

### 3.2. 採用する実装方針（確定版）

**✅ Redis拡張版によるセッション管理**

**セッション情報の取得元:**
- ✅ **Redis**: リフレッシュトークンのメタデータ（RefreshTokenService）
  - **保存内容（拡張版）**: `userId`, `organizationId`, `tokenId`, `issuedAt`, `expiresAt`, `ipAddress`, `userAgent`, **`userName`**, **`email`**
- ❌ **PostgreSQL**: 不要（userName, emailをRedisに保存するため）

**実装の流れ:**
```typescript
1. Redisから全アクティブなトークンメタデータを取得
   ↓ (RedisConnectionService経由でSCAN)
2. 各メタデータから情報を抽出
   - userId, organizationId, tokenId, issuedAt, ipAddress, userAgent
   - userName, email（✨ 拡張で追加）
3. organizationIdでフィルタリング（マルチテナント分離）
   ↓ (リクエストユーザーの組織IDと一致するもののみ)
4. セッション時間を計算
   ↓ (現在時刻 - issuedAt)
5. レスポンスを返す
```

**メリット:**
1. ✅ **既存システムへの影響ゼロ**（マイグレーション不要）
2. ✅ **既存のRefreshTokenServiceをそのまま活用**
3. ✅ **ログイン/ログアウト処理の変更不要**
4. ✅ **迅速な実装が可能**（推定5時間）
5. ✅ **マルチテナント分離が自動的に適用される**
6. ✅ **Cookieを意識する必要なし**（サーバー側で完結）

### 6.2. データ構造

#### Redis（拡張版）
```typescript
// キー: mmdpf:refresh_token:{tokenId}
// 値: JSON文字列
interface StoredRefreshToken {
  userId: string;
  organizationId: string;
  sessionId: string;
  tokenId: string;
  issuedAt: number;      // ログイン時刻（Unix timestamp）
  expiresAt: number;     // 有効期限（Unix timestamp）
  ipAddress?: string;    // IPアドレス
  userAgent?: string;    // User-Agent
  // ✨ 新規追加（Phase 1で実装）
  userName?: string;     // ユーザー名
  email?: string;        // メールアドレス
}
```

**変更方針:**
- ✅ `refreshTokenService.save()` でユーザー名とメールを保存
- ✅ ログイン時に `organization_user` テーブルから取得して含める
- ✅ PostgreSQLへの追加クエリが不要になる
- ✅ パフォーマンスが大幅に向上

**データベーススキーマの変更は不要です。**

### 6.3. API仕様（詳細）

#### API 1: セッション一覧取得

```
GET /api/v1/sessions
```

**重要な動作:**
- ✅ リクエストヘッダーの `X-Organization-Id` と一致するセッションのみ返す
- ✅ 他組織のセッション情報は**完全に隔離**される
- ✅ マルチテナント分離が自動的に適用される

**リクエストヘッダー:**
```
Authorization: Bearer {jwt_token}
X-Organization-Id: {organization_id}  ← この組織IDのセッションのみ取得
```

**クエリパラメータ:**
- `page`: ページ番号（デフォルト: 1）
- `limit`: 1ページあたりの件数（デフォルト: 20、最大: 100）
- `sortBy`: ソート項目（loginTime, lastActivity, sessionDuration）
- `order`: ソート順（asc, desc）

**レスポンス（成功時）:**
