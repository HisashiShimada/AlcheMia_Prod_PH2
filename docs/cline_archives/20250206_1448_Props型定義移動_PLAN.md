## 5. 技術的詳細

### 型定義の移動パターン

#### パターン1: 基本的な移動
```typescript
// 移動前（types/index.ts）
export interface EditorToolbarProps {
  onAddNode: (nodeType: string) => void;
  // ...
}

// 移動後（EditorToolbar.tsx）
// ファイル先頭付近に型定義を追加
interface EditorToolbarProps {
  onAddNode: (nodeType: string) => void;
  // ...
}

export const EditorToolbar: React.FC<EditorToolbarProps> = ({ ... }) => {
  // ...
};
```

#### パターン2: 外部から参照される場合
```typescript
// 移動後（EditorToolbar.tsx）
// exportを維持
export interface EditorToolbarProps {
  onAddNode: (nodeType: string) => void;
  // ...
}
```

### 共通型の判断基準
以下は types/index.ts に残す（共通型）：
- NodeData, EdgeData（ReactFlow関連の基本型）
- NodeType, Position（基本的なデータ構造）
- MethodData, DocumentData（複数コンポーネント間で共有）
- ValidationError, ValidationResult（バリデーション関連）
- Template, Property等のMAIML構造型
- Hook戻り値型（UseHistoryReturn等）
- ユーティリティ型（ClipboardData等）
