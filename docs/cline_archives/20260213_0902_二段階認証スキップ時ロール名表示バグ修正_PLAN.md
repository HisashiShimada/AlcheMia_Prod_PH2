## 1. タスク概要

二段階認証をスキップしてログインした場合、ログイン後の右上に表示されるロール名が`role_cd`（例: "experiment_admin"）になってしまう問題を修正します。

## 2. 目的と期待される成果

### 目的
PIN免除機能によって二段階認証をスキップした場合でも、通常のログイン時と同様に正しいロール名（例: "実験管理者"）を表示する。

### 期待される成果
- [x] 二段階認証スキップ時も正しいロール名が表示される
- [x] 通常のPIN検証後と同じレスポンス形式になる
- [x] フロントエンドの表示が統一される

## 3. 問題の原因分析

### 現状の動作比較

#### 🔴 問題: 二段階認証スキップ時（authHelpers.ts）
```typescript
// backend/src/controllers/authHelpers.ts:77
user: {
  roleName: user.role_cd,  // ❌ role_cdを設定（例: "experiment_admin"）
  roleCd: user.role_cd,
  ...
}
```

#### ✅ 正常: PIN検証後（authController.ts）
```typescript
// backend/src/controllers/authController.ts:210付近
user: {
  roleName: userInfo.roleName,  // ✅ 正しいrole_name（例: "実験管理者"）
  roleCd: userInfo.roleCd,
  ...
}
```

### 根本原因
`authHelpers.ts`の`issueSessionTokens`関数で、roleテーブルから`initial_screen_function_cd`のみ取得しており、`role_name`を取得していない。
