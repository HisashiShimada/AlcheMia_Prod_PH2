## 2. 必要な環境変数

### 2.1 SMTP接続設定（必須）

| 環境変数 | 説明 | 例 | デフォルト値 |
|---------|------|-----|------------|
| `SMTP_HOST` | SMTPサーバーのホスト名 | `smtp.gmail.com` | `localhost` |
| `SMTP_PORT` | SMTPサーバーのポート番号 | `587` (TLS) または `465` (SSL) | `587` |
| `SMTP_SECURE` | SSL/TLS使用フラグ | `true` (465) または `false` (587) | `false` |
| `SMTP_USER` | SMTP認証ユーザー名 | `your-email@gmail.com` | - |
| `SMTP_PASSWORD` | SMTP認証パスワード | `your-app-password` | - |

### 2.2 送信元設定（必須）

| 環境変数 | 説明 | 例 | デフォルト値 |
|---------|------|-----|------------|
| `SMTP_FROM_ADDRESS` | 送信元メールアドレス | `noreply@mmdpf.example.com` | `noreply@mmdpf.example.com` |
| `SMTP_FROM_NAME` | 送信元表示名 | `MMDPF Authentication` | `MMDPF Authentication` |

### 2.3 フロントエンドURL（パスワードリセット用）

| 環境変数 | 説明 | 例 | デフォルト値 |
|---------|------|-----|------------|
| `FRONTEND_URL` | フロントエンドのベースURL | `https://mmdpf.example.com` | `http://localhost:3000` |

## 3. メールサービスプロバイダーの選択肢

### 3.1 Gmail（開発・テスト用）

**メリット:**
- ✅ 無料で使用可能
- ✅ 設定が簡単
- ✅ 信頼性が高い

**デメリット:**
- ❌ 1日500通の送信制限
- ❌ アプリパスワードの設定が必要（2段階認証必須）
- ❌ 本番環境での使用は非推奨

**設定例:**
```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password  # Googleアカウントのアプリパスワード
SMTP_FROM_ADDRESS=your-email@gmail.com
SMTP_FROM_NAME=MMDPF Authentication
```

**アプリパスワード取得方法:**
1. Googleアカウントで2段階認証を有効化
2. https://myaccount.google.com/apppasswords にアクセス
3. 「アプリパスワード」を生成
4. 生成された16桁のパスワードを`SMTP_PASSWORD`に設定

---

### 3.2 SendGrid（推奨 - 本番環境）

**メリット:**
- ✅ 無料プラン: 1日100通まで
- ✅ API/SMTP両対応
- ✅ 配信状況の追跡が可能
- ✅ 高い到達率
- ✅ 開封率・クリック率の分析

**デメリット:**
- ❌ アカウント作成が必要
- ❌ ドメイン認証が推奨される

**料金プラン:**
- Free: $0/月（100通/日）
- Essentials: $19.95/月（50,000通/月）
- Pro: $89.95/月（100,000通/月）

**設定例:**
```bash
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=apikey
SMTP_PASSWORD=SG.xxxxxxxxxxxxxxxxxxxx  # SendGrid APIキー
SMTP_FROM_ADDRESS=noreply@your-domain.com
SMTP_FROM_NAME=MMDPF Authentication
```

**セットアップ手順:**
1. https://sendgrid.com/ でアカウント作成
2. Settings > API Keys > Create API Key
3. "Full Access" または "Mail Send" 権限を付与
4. 生成されたAPIキーを`SMTP_PASSWORD`に設定
5. Sender Authentication でドメイン認証（推奨）

## 6. トラブルシューティング

### 6.1 メールが送信されない

#### 原因1: SMTP認証情報が不正
```bash
# エラーメッセージ例:
# "535 Authentication failed"
# "535-5.7.8 Username and Password not accepted"

# 対処方法:
# 1. SMTP_USER と SMTP_PASSWORD を再確認
# 2. アプリパスワードを再生成（Gmail）
# 3. APIキーを再生成（SendGrid）
```

#### 原因2: ファイアウォールでブロック
```bash
# エラーメッセージ例:
# "ETIMEDOUT"
# "ECONNREFUSED"

# 対処方法:
# 1. ポート587/465が開いているか確認
telnet smtp.sendgrid.net 587

# 2. ファイアウォール設定を確認
# 3. プロキシ設定を確認
```

#### 原因3: SPF/DKIM設定不足
```bash
# 症状: メールが迷惑メールフォルダに入る

# 対処方法:
# 1. ドメイン認証を実施（SendGrid/SES）
# 2. SPFレコードをDNSに追加
# 3. DKIMレコードをDNSに追加
```

---

### 6.2 メールの到達率を上げる方法

#### 1. Sender Authenticationを実施
```bash
# SendGrid: Settings > Sender Authentication
# Amazon SES: Verified Identities > Verify Domain
```

#### 2. SPFレコード設定
```dns
# DNSにTXTレコードを追加
example.com. IN TXT "v=spf1 include:sendgrid.net ~all"
```

#### 3. DKIMレコード設定
```dns
# SendGridまたはSESが提供するDKIMレコードをDNSに追加
```

#### 4. DMARCレコード設定
```dns
# DNSにTXTレコードを追加
_dmarc.example.com. IN TXT "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"
```
