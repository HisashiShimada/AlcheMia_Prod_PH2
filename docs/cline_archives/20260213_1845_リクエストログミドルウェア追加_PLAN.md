## 1. タスク概要

バックエンドで受け取るすべてのHTTPリクエストをコンソールにログ出力できるようにする。開発・デバッグ時にリクエストの内容を確認しやすくするため。

## 2. 目的と期待される成果

### 目的
- リクエストの詳細情報（メソッド、URL、ヘッダー、ボディなど）をコンソールで確認できるようにする
- デバッグ・開発時の効率を向上させる
- API呼び出しの流れを可視化する

### 期待される成果
- [ ] リクエスト情報をコンソールに出力するミドルウェアの実装
- [ ] すべてのAPIルートに適用
- [ ] 見やすいフォーマットでログ出力
