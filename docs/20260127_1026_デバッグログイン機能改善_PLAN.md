```typescript
const debugPanel = isDevelopment ? (
  <DebugLoginPanel
    onLogin={(cred) => {
      // 選択されたユーザーのorganizationIdを使用
      const user = demoUsers[cred.username];
      return handleLogin({
        ...cred,
        organizationId: user?.user.organizationId || 'org_lab_001'
      });
    }}
    loading={loading}
    debugUsers={...}
  />
) : undefined;
```

### DebugLoginPanel.tsx の改善点

#### 1. エラーハンドリングの改善
```typescript
const handleDebugLogin = async () => {
  if (!selectedDebugUser) return;
  
  const user = debugUsers.find(u => u.username === selectedDebugUser);
  if (!user) return;

  try {
    await onLogin({
      username: user.username,
      password: user.password,
    });
  } catch (err) {
    // エラーは親コンポーネント（page.tsx）でハンドリングされる
    // ここでは何もしない（既にpage.tsxでエラー表示される）
  }
};
```

#### 2. UIの改善
- ボタンスタイルをより明確に
- 選択中のユーザー情報をカードで表示
- ローディング状態を視覚化

**重要な発見**:
- LoginPage.tsxでは`organizationId`に**空文字列**を渡している
- これはTODOコメントにある通り「クライアント証明書を導入するまでの仮実装」

### 修正方針の変更

**当初の計画**: 各ユーザーの正しいorganizationIdを使用
- provider → 'org_system'
- その他 → 'org_lab_001'

**変更後の方針**: LoginPage.tsxと同様に空文字列を使用
- すべてのデバッグログインで `organizationId: ''` を渡す
- バックエンドで適切に処理される想定
