### 主要なリレーションシップ

1. **companies ← organizations**
   - 1:N（1つの会社は複数の組織を持つ）

2. **organizations ← users**
   - 1:N（1つの組織は複数のユーザーを持つ）

3. **users → organizations (representative_admin)**
   - N:1（代表管理者）

4. **departments → organizations**
   - N:1（部署は1つの組織に所属）

5. **users → departments**
   - N:1（ユーザーは1つの部署に所属）

6. **users → roles**
   - N:1（ユーザーは1つのロールを持つ）

7. **roles ← role_functions**
   - 1:N（1つのロールは複数の機能を持つ）

8. **users ← user_sessions**
   - 1:N（1人のユーザーは複数のセッションを持つ）

9. **laboratory_equipment_masters → equipment_vendors**
   - N:1（機器は1つのベンダーに所属）

10. **laboratory_equipment_masters → equipment_types**
    - N:1（機器は1つの種別に所属）

11. **laboratory_equipment_masters → equipment_attributes**
    - N:1（機器は1つの属性を持つ）

### データ型・制約

- **主キー**: SERIAL (PostgreSQL)
- **外部キー**: INTEGER
- **コード**: VARCHAR(50)
- **名称**: VARCHAR(255)
- **メールアドレス**: VARCHAR(255)
- **URL**: TEXT
- **フラグ**: BOOLEAN
- **タイムスタンプ**: TIMESTAMP WITH TIME ZONE
