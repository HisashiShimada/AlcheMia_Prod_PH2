# convertProperties メソッド統合案

## 📋 現状分析

### 問題点の発見

`convertPropertiesArrayToNestedFormat` と `convertPropertiesArrayToChildren` を確認したところ：

1. **返却構造が同じ**
   - 両方とも `NestedPropertyNode` 型の構造を生成
   - `key`, `tagName`, `attributes`, `elements`, `children` を持つ
   
2. **違いはkeyの扱いのみ**
   - `convertPropertiesArrayToNestedFormat`: `Record<string, NestedPropertyNode>` (key-value形式)
   - `convertPropertiesArrayToChildren`: `NestedPropertyNode[]` (配列形式)
   
3. **XSD準拠Property型で置き換え可能**
   - `tagName` を追加するだけでProperty型で表現可能

---

## 🎯 統合修正案

### 新規型定義: PropertyWithTagName

```typescript
/**
 * XSD準拠Property型 + key と tagName拡張
 * NestedPropertyNodeの代替として使用
 */
interface PropertyWithTagName extends Property {
  /** プロパティキー（必須） */
  key: string;
  /** XMLタグ名（拡張フィールド） */
  tagName?: string;
  /** 子プロパティ（再帰構造） */
  properties?: PropertyWithTagName[];
}
```

### 統合メソッド: convertToPropertyWithTagName

```typescript
/**
 * パース後のプロパティ配列をPropertyWithTagName配列に変換
 * @param propertiesArray - MaimlParserTypedの出力プロパティ（any[]）
 * @returns PropertyWithTagName配列
 */
const convertToPropertyWithTagName = (
  propertiesArray: any[]
): PropertyWithTagName[] => {
  if (!Array.isArray(propertiesArray)) {
    console.warn('[convertToPropertyWithTagName] 配列ではありません');
    return [];
  }
  
  return propertiesArray
    .filter(prop => {
      // insertion typeは除外
      return prop.type !== 'insertion' && prop.xsiType !== 'insertion';
    })
    .map(prop => {
      const converted: PropertyWithTagName = {
        key: prop.key || prop.name || `prop_${Date.now()}`,
        tagName: prop.tagName || 'property',
        'xsi:type': (prop.type || prop.xsiType || 'stringType') as PropertyType,
        value: prop.defaultValue,
        description: prop.description,
        units: prop.units,
        formatString: prop.formatString,
        scaleFactor: prop.scaleFactor,
        properties: undefined // 後で設定
      };
      
      // 子プロパティがある場合は再帰的に変換
      if (prop.properties && Array.isArray(prop.properties) && prop.properties.length > 0) {
        converted.properties = convertToPropertyWithTagName(prop.properties);
      }
      
      return converted;
    });
};
```

## 🔄 使用箇所の修正

### buildTemplateMap での使用

#### 現状
```typescript
const { insertion, properties } = extractInsertionFromProperties(t.property || [], t.id);
const nestedProperties = convertPropertiesArrayToNestedFormat(properties);

templateMap[placeId] = {
  // ...
  properties: properties,              // ❌ any[]
  propertiesNested: nestedProperties,  // ❌ Record<string, any>
  // ...
};
```

#### 修正後
```typescript
const { insertion, properties } = extractInsertionFromProperties(t.property || [], t.id);
const convertedProperties = convertToPropertyWithTagName(properties);

// key-value形式が必要な場合はこちら
const propertiesNested = Object.fromEntries(
  convertedProperties.map(p => [p.key, p])
);

templateMap[placeId] = {
  // ...
  properties: convertedProperties,     // ✅ PropertyWithTagName[]
  propertiesNested: propertiesNested,  // ✅ Record<string, PropertyWithTagName>
  // ...
};
```

## 🔍 NestedPropertyNode との違い

### NestedPropertyNode（現状）
```typescript
export interface NestedPropertyNode {
  key: string;
  tagName: string;
  attributes: Record<string, string>;  // ❌ 別構造
  elements: Record<string, any>;       // ❌ 別構造
  children: NestedPropertyNode[];
}
```

### PropertyWithTagName（提案）
```typescript
interface PropertyWithTagName extends Property {
  tagName?: string;                    // ✅ 追加のみ
  'xsi:type': PropertyType;
  value?: string | number | boolean;
  description?: string;
  units?: string;
  formatString?: string;
  scaleFactor?: number;
  properties?: PropertyWithTagName[];  // ✅ XSD準拠の再帰
}
```

**利点:**
- XSD型と完全互換
- `attributes` や `elements` といった中間構造が不要
- シンプルでフラットな構造

/**
 * PropertyWithTagName を NestedPropertyNode に変換
 */
const toNestedPropertyNode = (
  prop: PropertyWithTagName
): NestedPropertyNode => {
  return {
    key: prop.key,
    tagName: prop.tagName || 'property',
    attributes: {
      'xsi:type': prop['xsi:type'],
      ...(prop.units && { units: prop.units }),
      ...(prop.formatString && { formatString: prop.formatString }),
      ...(prop.scaleFactor && { scaleFactor: prop.scaleFactor.toString() })
    },
    elements: {
      ...(prop.value !== undefined && { value: prop.value }),
      ...(prop.description && { description: prop.description })
    },
    children: (prop.properties || []).map(toNestedPropertyNode)
  };
};
