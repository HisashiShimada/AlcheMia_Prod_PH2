# OpenStack Swift GUI アクセス方法

## 概要

OpenStack Swift自体には標準でWeb UIは含まれていませんが、以下の方法でエクスプローラー（GUI）のようにアクセスできます。

---

## 方法1: S3互換ブラウザツールを使用（推奨）

OpenStack SwiftはS3互換APIを提供しているため、S3ブラウザツールでアクセス可能です。

### 1.1. Cyberduck（推奨）

**特徴:**
- ✅ 無料（オープンソース）
- ✅ Windows, macOS, Linux対応
- ✅ S3とSwiftの両方に対応
- ✅ ドラッグ&ドロップでファイル操作可能

**インストール:**
```bash
# Ubuntu/Debian
sudo apt install cyberduck

# macOS (Homebrew)
brew install --cask cyberduck

# または公式サイトからダウンロード
# https://cyberduck.io/
```

**接続設定:**
1. Cyberduckを起動
2. 「新規接続」をクリック
3. プロトコルで「Amazon S3」を選択
4. 以下を入力：
   ```
   サーバー: localhost
   ポート: 8080
   アクセスキーID: test:tester
   シークレットアクセスキー: testing
   ```
5. 「詳細設定」→「パススタイルを使用」にチェック
6. 「接続」をクリック

**スクリーンショット（イメージ）:**
```
┌─────────────────────────────────────────┐
│ 新規接続                                 │
├─────────────────────────────────────────┤
│ プロトコル: [Amazon S3 ▼]               │
│ サーバー: [localhost        ]           │
│ ポート: [8080]                          │
│ アクセスキーID: [test:tester]           │
│ シークレットキー: [testing]             │
│                                         │
│ ☑ パススタイルを使用                    │
│                                         │
│           [キャンセル] [接続]           │
└─────────────────────────────────────────┘
```

### 1.2. S3 Browser（Windows専用）

**特徴:**
- ✅ 無料版あり
- ✅ Windows専用
- ✅ エクスプローラー風UI

**ダウンロード:**
https://s3browser.com/

**接続設定:**
```
Account Type: S3 Compatible Storage
REST Endpoint: localhost:8080
Access Key ID: test:tester
Secret Access Key: testing
Use secure transfer (SSL/TLS): OFF
Signature Version: Signature V4
```

### 1.3. CloudBerry Explorer（有料）

**特徴:**
- Windows専用
- 有料だが機能が豊富
- S3互換ストレージに対応

## 方法2: Webブラウザから直接アクセス

### 2.1. Swift Browser（簡易Web UI）の追加

Docker Composeに簡易Web UIを追加できます。

**docker-compose.ymlに追加:**

```yaml
services:
  # 既存のswiftサービス
  swift:
    image: bouncestorage/swift-aio:latest
    # ... (既存設定)

  # Swift Browser（Web UI）
  swift-browser:
    image: nginx:alpine
    container_name: mmdpf-swift-browser
    ports:
      - "8081:80"
    volumes:
      - ./swift-browser:/usr/share/nginx/html:ro
    depends_on:
      - swift
    networks:
      - mmdpf-network
```

**swift-browser/index.html を作成:**

```html

<html lang="ja">
<head>

<body>
    <div class="header">
        <h1>🗂️ Swift Browser</h1>
        <p>OpenStack Swift Web Interface</p>
    </div>

    <div class="container">
        <div class="auth-form" id="authForm">
            <h3>接続設定</h3>
            <input type="text" id="endpoint" placeholder="Endpoint (例: http://localhost:8080)" value="http://localhost:8080">
            <input type="text" id="username" placeholder="Username (例: test:tester)" value="test:tester">
            <input type="password" id="password" placeholder="Password" value="testing">
            <input type="text" id="container" placeholder="Container名" value="mmdpf-files">
            <button onclick="connect()">接続</button>
        </div>

        <div id="status"></div>

        <div class="upload-form" id="uploadForm" style="display:none;">
            <h3>ファイルアップロード</h3>
            <input type="text" id="uploadPath" placeholder="アップロード先パス (例: test/file.txt)">
            <input type="file" id="fileInput">
            <button onclick="uploadFile()">アップロード</button>
        </div>

        <div class="file-list" id="fileList"></div>
    </div>

    <script>
        let authToken = '';
        let storageUrl = '';
        let currentContainer = '';

        async function connect() {
            const endpoint = document.getElementById('endpoint').value;
            const username = document.getElementById('username').value;
            const password = document.getElementById('password').value;
            currentContainer = document.getElementById('container').value;

            showStatus('接続中...', 'info');

            try {
                // Swift認証
                const authResponse = await fetch(`${endpoint}/auth/v1.0`, {
                    method: 'GET',
                    headers: {
                        'X-Auth-User': username,
                        'X-Auth-Key': password
                    }
                });

                if (!authResponse.ok) {
                    throw new Error('認証に失敗しました');
                }

                authToken = authResponse.headers.get('X-Auth-Token');
                storageUrl = authResponse.headers.get('X-Storage-Url');

                showStatus('接続成功！', 'success');
                document.getElementById('uploadForm').style.display = 'block';
                loadFiles();
            } catch (error) {
                showStatus(`エラー: ${error.message}`, 'error');
            }
        }

        async function loadFiles() {
            showStatus('ファイル一覧を読み込み中...', 'info');

            try {
                const response = await fetch(`${storageUrl}/${currentContainer}`, {
                    headers: {
                        'X-Auth-Token': authToken
                    }
                });

                if (!response.ok) {
                    throw new Error('ファイル一覧の取得に失敗しました');
                }

                const files = await response.text();
                const fileList = files.split('\n').filter(f => f.trim());

                displayFiles(fileList);
                showStatus(`${fileList.length} 件のファイルを表示`, 'success');
            } catch (error) {
                showStatus(`エラー: ${error.message}`, 'error');
            }
        }

        function displayFiles(files) {
            const fileListDiv = document.getElementById('fileList');
            fileListDiv.innerHTML = '<h3>ファイル一覧</h3>';

            if (files.length === 0) {
                fileListDiv.innerHTML += '<p>ファイルがありません</p>';
                return;
            }

            files.forEach(file => {
                const fileItem = document.createElement('div');
                fileItem.className = 'file-item';
                fileItem.innerHTML = `
                    <span class="file-name">📄 ${file}</span>
                    <div class="file-actions">
                        <button class="btn-download" onclick="downloadFile('${file}')">ダウンロード</button>
                        <button class="btn-delete" onclick="deleteFile('${file}')">削除</button>
                    </div>
                `;
                fileListDiv.appendChild(fileItem);
            });
        }

        async function uploadFile() {
            const fileInput = document.getElementById('fileInput');
            const uploadPath = document.getElementById('uploadPath').value;
            const file = fileInput.files[0];

            if (!file) {
                showStatus('ファイルを選択してください', 'error');
                return;
            }

            const filePath = uploadPath || file.name;

            showStatus(`${filePath} をアップロード中...`, 'info');

            try {
                const response = await fetch(`${storageUrl}/${currentContainer}/${filePath}`, {
                    method: 'PUT',
                    headers: {
                        'X-Auth-Token': authToken,
                        'Content-Type': file.type || 'application/octet-stream'
                    },
                    body: file
                });

                if (!response.ok) {
                    throw new Error('アップロードに失敗しました');
                }

                showStatus('アップロード成功！', 'success');
                document.getElementById('fileInput').value = '';
                document.getElementById('uploadPath').value = '';
                loadFiles();
            } catch (error) {
                showStatus(`エラー: ${error.message}`, 'error');
            }
        }

        async function downloadFile(fileName) {
            try {
                const response = await fetch(`${storageUrl}/${currentContainer}/${fileName}`, {
                    headers: {
                        'X-Auth-Token': authToken
                    }
                });

                if (!response.ok) {
                    throw new Error('ダウンロードに失敗しました');
                }

                const blob = await response.blob();
                const url = window.URL.createObjectURL(blob);
                const a = document.createElement('a');
                a.href = url;
                a.download = fileName.split('/').pop();
                document.body.appendChild(a);
                a.click();
                window.URL.revokeObjectURL(url);
                document.body.removeChild(a);

                showStatus('ダウンロード完了', 'success');
            } catch (error) {
                showStatus(`エラー: ${error.message}`, 'error');
            }
        }

        async function deleteFile(fileName) {
            if (!confirm(`${fileName} を削除しますか？`)) {
                return;
            }

            try {
                const response = await fetch(`${storageUrl}/${currentContainer}/${fileName}`, {
                    method: 'DELETE',
                    headers: {
                        'X-Auth-Token': authToken
                    }
                });

                if (!response.ok) {
                    throw new Error('削除に失敗しました');
                }

                showStatus('削除成功', 'success');
                loadFiles();
            } catch (error) {
                showStatus(`エラー: ${error.message}`, 'error');
            }
        }

        function showStatus(message, type) {
            const statusDiv = document.getElementById('status');
            statusDiv.textContent = message;
            statusDiv.className = type;
        }
    </script>
</body>
</html>
```

**使用方法:**

```bash
# swift-browserディレクトリを作成
mkdir -p swift-browser

# index.htmlを配置（上記HTMLを保存）

# コンテナを起動
docker-compose up -d swift-browser

# ブラウザでアクセス
# http://localhost:8081
```

## 方法3: コマンドラインツール（CLI）

GUIではありませんが、対話的にファイル操作が可能です。

### 3.1. swift CLI

```bash
# Swiftコンテナ内で実行
docker exec -it mmdpf-swift bash

# ファイル一覧
swift -A http://localhost:8080/auth/v1.0 \
  -U test:tester -K testing list mmdpf-files

# ファイルアップロード
swift -A http://localhost:8080/auth/v1.0 \
  -U test:tester -K testing \
  upload mmdpf-files local-file.txt

# ファイルダウンロード
swift -A http://localhost:8080/auth/v1.0 \
  -U test:tester -K testing \
  download mmdpf-files remote-file.txt
```

### 3.2. AWS CLI（S3互換）

```bash
# AWS CLIをインストール
pip install awscli

# エンドポイント設定
aws configure set aws_access_key_id test:tester
aws configure set aws_secret_access_key testing
aws configure set region us-east-1

# ファイル一覧
aws s3 ls s3://mmdpf-files/ \
  --endpoint-url http://localhost:8080

# ファイルアップロード
aws s3 cp local-file.txt s3://mmdpf-files/ \
  --endpoint-url http://localhost:8080

# ファイルダウンロード
aws s3 cp s3://mmdpf-files/file.txt ./ \
  --endpoint-url http://localhost:8080
```

## トラブルシューティング

### Cyberduckで接続できない

**症状:** 「接続できません」エラー

**対策:**
1. Swiftコンテナが起動しているか確認
   ```bash
   docker-compose ps swift
   ```

2. ポート8080が開いているか確認
   ```bash
   curl http://localhost:8080/info
   ```

3. 認証情報が正しいか確認
   ```bash
   curl -v -H "X-Auth-User: test:tester" \
     -H "X-Auth-Key: testing" \
     http://localhost:8080/auth/v1.0
   ```

### Web UIでCORSエラーが発生

**症状:** ブラウザのコンソールに「CORS policy」エラー

**対策:**
SwiftコンテナにCORS設定を追加する必要があります。
（bouncestorage/swift-aioでは標準でCORSが有効）
