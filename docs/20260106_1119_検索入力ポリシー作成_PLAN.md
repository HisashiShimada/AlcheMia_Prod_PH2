## 5. 技術的詳細

### 使用する技術・ライブラリ
- Ant Design v6: Input コンポーネント
- Ant Design Icons: SearchOutlined
- React 18.2.0
- TypeScript

### 検索入力の主要パターン
1. **基本検索**: 250px固定幅、検索アイコン、クリアボタン
2. **テーブル検索**: 親要素幅、左寄せ配置
3. **ヘッダー検索**: グローバル検索バー
4. **インラインフィルタ**: 複数条件検索
5. **ドロップダウン付き検索**: カテゴリ選択+検索
