## BF-01：prefixを登録する

## Mermaid

```mermaid
flowchart TD
  A([開始]) --> B[実験管理者：名前空間管理画面を開く]
  B --> C[実験管理者：prefix登録フォームを入力\nprefix名を入力・対応URIを自動入力]
  C --> D{システム：重複チェック}
  D -- 重複あり --> E[システム：エラー表示]
  E --> C
  D -- 重複なし --> F[実験管理者：登録ボタンを押す]
  F --> G[システム：prefixを保存]
  G --> H([終了])
```

## 業務概要

実験管理者が自分の名前空間に対してprefixを登録する。登録したprefixはMaiMLファイルの`xmlns`宣言で使用できるようになる。

## 前提条件

- 実験管理者としてログイン済み
- 個人名前空間またはチーム名前空間が存在すること

## 終了条件

- prefixが正常に登録され、一覧に表示される

## 関連ユースケース

- UC-01：prefixを登録する

## 確認事項

- なし

## BF-03：prefixを非アクティブ化する

## Mermaid

```mermaid
flowchart TD
  A([開始]) --> B[実験管理者：prefix一覧から対象prefixを選択]
  B --> C[実験管理者：非アクティブ化ボタンを押す]
  C --> D{システム：対象prefixを使用中のMaiMLファイルを確認}
  D -- 使用中ファイルあり --> E[システム：影響ファイルが存在することを警告表示]
  E --> F{実験管理者：続行するか判断}
  F -- 中止 --> G([終了：中止])
  F -- 続行 --> H[システム：prefixを非アクティブ化]
  D -- 使用中ファイルなし --> H
  H --> I([終了])
```

## 業務概要

使用を停止したいprefixを非アクティブ化する。使用中のMaiMLファイルがある場合は影響の警告が表示され、利用者が続行を判断する。

## 前提条件

- 実験管理者としてログイン済み
- 対象prefixが自分の名前空間に存在すること

## 終了条件

- prefixが非アクティブ化される、または中止される

## 関連ユースケース

- UC-03：prefixを非アクティブ化する

## 確認事項

- 非アクティブ化後、そのprefixを使用しているMaiMLファイルの挙動（エラー扱いになるか）を確認

## BF-17：MaiMLファイルにprefixを宣言する

## Mermaid

```mermaid
flowchart TD
  A([開始]) --> B[実験管理者：プロジェクトを開始]
  B --> C[システム：利用可能なprefixを全件取得\nアクセス可能な全階層のprefixを対象とする]
  C --> D{システム：同一prefix名が複数階層に存在するか}
  D -- 存在する --> E[システム：最下位階層の名前空間URIを採用]
  D -- 存在しない --> F[システム：そのままURIを使用]
  E --> G[システム：xmlns宣言をMaiMLファイルに自動生成・記述]
  F --> G
  G --> H([終了])
```

## 業務概要
