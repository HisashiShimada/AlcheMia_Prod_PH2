## BF-01-01：不確かさ基準キーを登録する

## Mermaid

```mermaid
flowchart TD
  Start([開始]) --> A[不確かさ基準キー管理画面を開く]
  A --> B[新規作成ボタンを押す]
  B --> C[継承元・キー名を入力する]
  C --> D{評価方式は定性か？}
  D -- 定性 --> E[選択肢を入力する\n例：確か / 曖昧 / 不確か]
  E --> F[保存する]
  D -- 定量 --> E2[型・単位・フォーマット・倍率を入力する]
  E2 --> F
  F --> G{入力内容に不備はあるか？}
  G -- あり --> C
  G -- なし --> End([登録完了])
```

## 業務概要

実験管理者が、自分のスコープ（会社・部門・グループ・個人）に不確かさ評価の基準キーを新規登録する。キー名・評価方式（定性/定量）・型・単位・説明を入力し、定性評価の場合は選択肢もあわせて登録する。

## 前提条件

- 実験管理者としてログインしていること
- 不確かさ基準キー管理画面にアクセスできること

## 終了条件

- 入力した基準キーが自分のスコープに登録されること

## 関連ユースケース

- UC-01-01：不確かさ基準キーを登録する

## Mermaid

```mermaid
flowchart TD
  Start([開始]) --> A[不確かさ基準キー管理画面を開く]
```

- システムにログインしていること
- 上位層に参照可能な基準キーが登録されていること

## 終了条件

- 上位層の基準キーを自分のスコープで利用できる状態になること

## 関連ユースケース

## BF-01-04：定性評価スキームを定義する

## Mermaid

```mermaid
flowchart TD
  Start([開始]) --> A[不確かさ基準管理画面を開く]
  A --> B[新規不確かさ基準作成ボタンを押す]
  B --> C[定性評価を入力する\n例：5段階信頼性・GLP準拠評価]
  C --> D[選択肢を追加する\n例：信頼高 / 普通 / 信頼低 等]
  D --> E{選択肢を追加するか？}
  E -- はい --> D
  E -- いいえ --> F[保存する]
  F --> G{入力内容に不備はあるか？}
  G -- あり --> C
  G -- なし --> End([スキーム定義完了])
```

## 業務概要

実験管理者が、組織・個人固有の定性評価スキーム（選択肢の種類）をカスタム定義する。標準の3段階（確か/曖昧/不確か）以外に、5段階信頼性やGLP準拠評価など独自の評価体系を作成できる。

## 前提条件

- 実験管理者としてログインしていること

## 終了条件

- カスタムスキームが登録され、実験計画で選択できる状態になること

## 終了条件

## BF-03-01：実験計画で不確かさ評価基準を設定する

## Mermaid

```mermaid
flowchart TD
  Start([開始]) --> A[実験計画画面を開く]
  A --> B{全タスク共通で設定するか？}
  B -- はい --> C[一括タブで共通の不確かさ評価基準を設定する]
  C --> D[各タスクへ一括展開する]
  D --> L[設定を保存する]
  B -- いいえ --> F[特定タスクのプロパティを選択する]
  F --> G[プロパティごとに評価方式を選択する\n定量 / 定性 / 未設定]
  G --> H{定量評価を選択したか？}
  H -- はい --> I[許容値をあわせて設定する]
  I --> J{定性評価を選択したか？}
  H -- いいえ --> J
  J -- はい --> K[使用する定性評価スキームを指定する]
  K --> L
  J -- いいえ --> L
  L --> End([実験計画への不確かさ基準設定完了])
```

## 業務概要

実験管理者が、実験計画時に各プロパティ（property要素）に対して不確かさの評価基準を設定する。全タスク共通の設定は「一括」タブで行い各タスクへ展開することができる。定量評価の場合は許容値、定性評価の場合は使用するスキームをあわせて指定する。

## 前提条件

- 実験管理者としてログインしていること
- 実験計画が作成済みであること
- 利用する不確かさ基準キー・定性評価スキームが登録されていること

## 終了条件

- 各プロパティに不確かさ評価基準が設定され、MaiMLファイルに記録されること

## 関連ユースケース

- UC-03-01：プロパティに不確かさ評価基準を設定する
- UC-03-02：全タスク共通の不確かさ基準を一括設定する
- UC-03-03：定量評価の許容値を設定する

## BF-05-01：定量的な不確かさ評価を記録する

```mermaid
flowchart TD
  Start([開始]) --> A[実験記録画面を開く]

  E --> F[保存する]
  C -- いいえ --> G[定量評価欄を空白のまま保存する]
```

- 実験作業者としてログインしていること
- Global名前空間に定量評価用の標準キーが登録されていること

- 選択した基準キーと入力値がMaiMLの `<uncertainty>` 要素として保存されること（未入力の場合は要素なし）

## BF-06-01：不確かさ評価の承認依頼〜承認・差し戻し

## Mermaid

```mermaid
flowchart TD
  Start([開始]) --> A[実験作業者：不確かさ評価の入力が完了する]
  A --> B[実験作業者：実験結果と一体で承認依頼を送信する\nプロジェクト全体単位]
  B --> C[実験管理者：承認依頼の通知を受け取る]
  C --> D[実験管理者：不確かさの記録内容を確認する]
  D --> E{承認するか？}
  E -- 承認 --> F[実験管理者：承認を確定する]
  F --> End([承認完了\n不確かさデータが確定])
  E -- 差し戻し --> G[実験管理者：差し戻し理由を入力する]
  G --> H[実験管理者：差し戻しを送信する\nチェックアウト状態に自動移行]
  H --> I[実験作業者：差し戻し理由を確認し修正する]
  I --> B
```

## 業務概要

実験作業者が不確かさ評価の入力完了後、実験結果（実績値）の承認依頼と一体でプロジェクト全体単位に承認依頼を出す。実験管理者が内容を確認し、承認または差し戻しを行う。差し戻し時は理由の入力が必須で、承認NGの場合はチェックアウト状態に自動移行する。

## 前提条件

- 実験作業者が不確かさ評価を含む実験記録を入力済みであること
- 実験管理者が承認権限を持っていること

## 終了条件

- 承認：不確かさデータが確定済みとして管理されること
- 差し戻し：実験作業者へ修正依頼が送られ、チェックアウト状態に戻ること

## 関連ユースケース

- UC-06-01：不確かさ評価の承認依頼を出す
- UC-06-02：不確かさ評価を承認・差し戻しする
