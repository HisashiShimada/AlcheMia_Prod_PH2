## 目的1：不確かさ基準（キー）を組織・個人の階層構造で定義・管理したい

### F-01-01：不確かさ基準キー登録機能

| 項目 | 内容 |
|------|------|
| **機能名** | 不確かさ基準キー登録機能 |
| **機能概要** | 不確かさ基準（キー名・評価方式・型・単位・説明など）を、組織の階層（会社→部門→グループ）または個人の単位で登録できる機能 |
| **実現したいこと** | 組織・個人ごとに異なる不確かさ基準を階層構造で登録・管理し、実験現場に合った基準を使えるようにする |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的1 |
| **関連する要件** | 仕様書 §3.2（名前空間スコープ階層）、仕様書 §4.1.2（テンプレート新規作成） |
| **確認事項** |  |

| 項目 | 内容 |

## 目的4：実験記録時に、定性的な不確かさ評価を記録したい

### F-04-01：定性評価ワンクリック記録機能

| 項目 | 内容 |
|------|------|
| **機能名** | 定性評価ワンクリック記録機能 |
| **機能概要** | 実験作業者が実験記録画面で各プロパティに対して定性評価の選択肢ボタン（例：確か / 曖昧 / 不確か）をワンクリックで選択・記録できる機能。記録した評価値はMaiMLの `<uncertainty>` 要素として保存される |
| **実現したいこと** | 作業者が考えることなく直感的に評価を記録できるようにし、実験作業中の入力負荷を最小化する |
| **主な利用者** | 実験作業者 |
| **関連する目的** | 目的4 |
| **関連する要件** | 仕様書 §4.2.2（不確かさ付与操作）、仕様書 §4.3.1（MaiML出力仕様）、仕様書 §6.1（標準3段階評価スキーム）、2026.06.18 議事録：作業者が不確かさを入れるときに、できるだけ考えさせたくない |
| **確認事項** |  |

### F-04-02：定性評価デフォルトスキーム適用機能

| 項目 | 内容 |
|------|------|
| **機能名** | 定性評価デフォルトスキーム適用機能 |
| **機能概要** | 実験計画で評価スキームが設定されていない場合に、デフォルトで「確か / 曖昧 / 不確か」の標準3段階スキームを自動適用する機能 |
| **実現したいこと** | スキームが未設定の場合でも作業者が評価できるよう、標準的な選択肢を自動的に提供する |
| **主な利用者** | 実験作業者 |
| **関連する目的** | 目的4 |
| **関連する要件** | 2026.07.02 議事録：設定されていなければデフォルトで「確か、曖昧、不確か」を設定 |
| **確認事項** |  |

### F-04-03：評価コメント・理由記録機能

| 項目 | 内容 |
|------|------|
| **機能名** | 評価コメント・理由記録機能 |
| **機能概要** | 定性評価に加えて付与理由・コメントを任意で記録できる機能。記録した内容はMaiMLファイルに保存される |

| **関連する目的** | 目的4 |
| **関連する要件** | 仕様書 §4.2.2（不確かさ付与操作） |
| **確認事項** | コメントの記録場所（MaiMLのどの要素に記録するか）をお客様と確認 |

### F-04-04：キーボード操作対応機能

## 目的6：不確かさの記録内容を承認ワークフローで確定させたい

### F-06-01：不確かさ承認依頼機能

| 項目 | 内容 |
|------|------|
| **機能名** | 不確かさ承認依頼機能 |
| **機能概要** | 実験作業者が不確かさの付与を完了後、実験管理者に承認依頼を出せる機能。不確かさの承認依頼は実験結果（実績値）の承認依頼と一体で行う |
| **実現したいこと** | 不確かさ評価を「実験作業者が付与→管理者が確認・承認」の流れで管理し、確定済みデータとして扱えるようにする |
| **主な利用者** | 実験作業者 |
| **関連する目的** | 目的6 |
| **関連する要件** | 仕様書 §4.2.4（承認ワークフロー）、2026.06.18 議事録：実験指示タブと承認タブはあわせて、実験結果承認のなかに不確かさの承認も組み込むこと、**[追記 2026.07.29]** 承認はプロジェクト全体単位で実施 |
| **確認事項** |  |

### F-06-02：不確かさ承認・差し戻し機能

| 項目 | 内容 |
|------|------|
| **機能名** | 不確かさ承認・差し戻し機能 |
| **機能概要** | 実験管理者が不確かさの記録内容を確認し、承認または差し戻しができる機能。差し戻し時は理由の入力を可能とする。不確かさの承認は実験結果承認と同一の画面・フローで行う |
| **実現したいこと** | 不確かさ評価の正確性を管理者が確認・承認することで、データの信頼性を確保する |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的6 |
| **関連する要件** | 仕様書 §5.2.3（承認レビュー画面）、202606.23 議事録：不確かさ承認と実験の承認機能を合わせて1画面とした、**[追記 2026.07.29]** 承認NG押下で自動的にチェックアウトする |
