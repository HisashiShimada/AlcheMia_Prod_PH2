## 目的1：実験管理者が実験作業者への指示をMaiMLファイルに記入できるようにしたい

### F-01-01：指示記入機能

| 項目 | 内容 |
|------|------|
| **機能名** | 指示記入機能 |
| **機能概要** | 実験管理者がUIの操作で実験作業者への指示（使用装置・パラメータ・注意事項など）をMaiMLファイルの対象条件に対して入力できる機能 |
| **実現したいこと** | XMLの構造を意識せずに指示を入力でき、MaiMLファイルに正しく記録されるようにする |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的1 |
| **関連する要件** | MAIML-SPEC-003 v5.5 §7.1（指示記入パネル）、MAIML-SPEC-003 v5.5 §9（実験計画・実施ワークフロー手順①〜⑥） |

---

### F-01-02：XMLプレビュー機能

| 項目 | 内容 |
|------|------|
| **機能名** | XMLプレビュー機能 |
| **機能概要** | 実験管理者が指示を入力しながら、対応するXML構造をリアルタイムで確認できる機能 |
| **実現したいこと** | 入力内容がXMLにどう反映されるかを即座に確認でき、記入ミスを防ぐ |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的1 |
| **関連する要件** | MAIML-SPEC-003 v5.5 §7.1（指示記入パネル） |

---

### F-01-03：指示配布機能

| 項目 | 内容 |
|------|------|
| **機能名** | 指示配布機能 |
| **機能概要** | 実験管理者が記入済みの指示（MaiMLファイル）を実験作業者へ配布でき、配布された指示を実験作業者が参照できる機能 |
| **実現したいこと** | 記入した指示を実験作業者へ確実に届け、参照できるようにする |
| **主な利用者** | 実験管理者、実験作業者 |
| **関連する目的** | 目的1 |
| **関連する要件** | MAIML-SPEC-003 v5.5 §9（実験計画・実施ワークフロー手順①〜⑥） |

---

## 目的2：使用装置・担当作業者を指定してMaiMLファイルに記録したい

### F-02-01：装置選択・記録機能

| 項目 | 内容 |
|------|------|
| **機能名** | 装置選択・記録機能 |
| **機能概要** | 実験管理者が使用する装置をUI上のドロップダウンから選択し、MaiMLファイルの適切なプロパティにUUIDが記録される機能。装置は特定機器個体または装置種類で指定できる。 |
| **実現したいこと** | UIで装置を選択するだけでMaiMLの適切な場所にUUIDが記録され、手入力によるミスを防ぐ |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的2 |
| **関連する要件** | MAIML-SPEC-003 v5.5 §3（装置・作業者参照の記載方法）、MAIML-SPEC-003 v5.5 §7.1.2（装置指定セクション） |

| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的2 |

| 項目 | 内容 |
|------|------|
| **機能名** | 装置名人間可読化表示機能 |
| **機能概要** | 指示一覧ビューで、UUIDだけでなく装置名を読みやすい形式で表示する機能。選択時に自動的に `<description>` 要素に装置名が書き込まれる。 |

## 目的3：安全上・操作上の注意事項を実験作業者に確実に伝えたい

### F-03-01：注意事項種別記入機能

| 項目 | 内容 |
|------|------|
| **機能名** | 注意事項種別記入機能 |
| **機能概要** | 実験管理者がプロジェクトに対して注意事項（caution）・禁止事項（prohibitedAction）・操作注記（operationNote）・確認事項（checkItem）を種別ごとに入力し、MaiMLファイルに記録できる機能。 |
| **実現したいこと** | 注意事項を種別ごとに体系的に記録し、実験作業者が種別に応じた形式で参照できるようにする |
| **主な利用者** | 実験管理者 |
| **関連する目的** | 目的3 |
| **関連する要件** | MAIML-SPEC-003 v5.5 §6.3（標準キー一覧：caution / operationNote / checkItem / prohibitedAction） |

---

### F-03-02：注意事項強調表示機能

| 項目 | 内容 |
|------|------|
| **機能名** | 注意事項強調表示機能 |
| **機能概要** | 実験作業者の作業画面で、注意事項・禁止事項が見落とされないよう最優先で強調表示（赤枠・アイコン付きなど）される機能。 |
| **実現したいこと** | 実験作業者が作業中に注意事項を見落とさないよう、視覚的に目立つ形で表示する |
| **主な利用者** | 実験作業者 |
| **関連する目的** | 目的3 |
| **関連する要件** | MAIML-SPEC-004 v1.0 §3.3.2（指示パネル：注意事項・確認事項の表示）、MAIML-SPEC-004 v1.0 §5.2（指示カテゴリと表示スタイル） |
