## BF-01：実験作業者への指示をMaiMLに記入する

### Mermaid

```mermaid
flowchart TD
    Start([開始]) --> A[実験管理者：プロジェクト・実験条件を選択する]
    A --> B[実験管理者：指示記入パネルを開く]
    B --> C[実験管理者：装置・パラメータ・注意事項などを入力する]
    C --> D{入力内容を確認する}
    D -- 修正が必要 --> C
    D -- 問題なし --> E[実験管理者：指示を保存する]
    E --> End([終了])
```

### 業務概要

実験管理者が、指示記入パネルを通じてXML構造を意識せずに実験条件への指示を入力し、MaiMLファイルに保存する。

### 前提条件

- プロジェクト・実験条件（MaiMLファイル）が作成済みであること

### 終了条件

- 入力した指示がMaiMLファイルに保存されていること

### 関連ユースケース

- UC-01：実験作業者への指示をMaiMLに記入する

### 確認事項

## BF-02：記入した指示をXMLプレビューで確認する

### Mermaid

```mermaid
flowchart TD
    Start([開始]) --> A[実験管理者：指示記入パネルで内容を入力する]
    A --> B[システム：入力内容に対応するXML構造をリアルタイムで表示する]
    B --> C{XMLの内容を確認する}
    C -- 誤りあり --> A
    C -- 問題なし --> End([終了])
```

### 業務概要

実験管理者が指示を入力しながら、リアルタイムで対応するXML構造をプレビューで確認し、記入ミスを防ぐ。

### 前提条件

- 指示記入パネルが開かれていること

### 終了条件

- XMLプレビューで入力内容が正しく反映されていることを確認できること

### 関連ユースケース

- UC-02：記入した指示をXMLプレビューで確認する

### 確認事項

- プレビューの更新タイミング（リアルタイム・保存時）を確認

## BF-10：担当タスクを選択して指示・装置情報を確認する

### 終了条件

## BF-16：実験結果を承認・差し戻しする

### Mermaid

```mermaid
flowchart TD
    Start([開始]) --> A[実験管理者：承認依頼を受け取る]
    A --> B[実験管理者：実験結果・不確かさ評価を同一画面で確認する]
    B --> C{承認するか}
    C -- 承認 --> D[実験管理者：承認操作を行う]
    D --> E[システム：実験結果を確定済みとして記録する]
    E --> End([終了])
    C -- 差し戻し --> F[実験管理者：差し戻し理由を入力する]
    F --> G[システム：実験作業者に差し戻しを通知する]
    G --> End
```

### 業務概要

実験管理者が実験結果と不確かさ評価を同一の画面・フローで確認し、承認または差し戻しを行う。差し戻し時は理由を入力できる。

### 前提条件

- 実験作業者から承認依頼が送信済みであること

### 終了条件

- 承認の場合：実験結果が確定済みとして記録されること
- 差し戻しの場合：実験作業者に差し戻しが通知されること

### 関連ユースケース

- UC-16：実験結果を承認・差し戻しする

### 確認事項

- 差し戻しパターン（記録ミスの書き直し・部分再実験・全体再実験）ごとの導線をお客様と確認
