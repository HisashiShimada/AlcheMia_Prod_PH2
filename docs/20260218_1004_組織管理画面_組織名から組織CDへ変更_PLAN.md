## 1. タスク概要

組織管理画面について、以下の①～⑤の対応を実施します。

①一覧内の「組織名」⇒「組織CD」としてほしい
②一覧内のフィルタについて「組織名」のコンボボックスは「組織表示名」でフィルタするように修正する。またそれに伴い、曖昧検索欄から「組織表示名」を除外して代わりに「組織CD」を含める。
③「組織CD」はorganizationテーブルのorganization_cd（組織CD）より取得する。（重複不可）
④組織追加ダイアログ、組織編集ダイアログ内の「組織名」も「組織CD」としてorganizationテーブルのorganization_cdを見るようにする。
⑤組織追加ダイアログ内の「組織CD」は編集可能だが、組織編集ダイアログ内の「組織CD」は編集不可（非活性）とする。

## 5. 技術的詳細

### DBスキーマ
```sql
CREATE TABLE organization (
  organization_id uuid NOT NULL,
  organization_cd character varying(50),      -- 組織CD
  organization_display_name character varying(50),  -- 組織表示名
  organization_email character varying(50),
  chief_user_id character varying(50),
  corporation_id uuid,
  is_entry INTEGER,
  is_active BOOLEAN,
  create_user_id VARCHAR(50),
  create_at timestamp,
  update_user_id VARCHAR(50),
  update_at timestamp,
  CONSTRAINT organization_PKC PRIMARY KEY (organization_id)
);

CREATE INDEX idx_organization_organization_cd ON organization(organization_cd);
```
