# ロール別業務内容一覧

> 要求仕様書（MaiMLシステム要求仕様書 概要版 R1.5）を基に、各ロールの業務内容を一覧化したもの

---

## ① プロバイダー
> ※仕様書上の「システム管理者（ICTシステム管理者）」に相当する役割として、システム全体の提供・管理を担う

| # | 業務内容 |
|---|---------|
| 1 | ユーザーID/PWの発行・登録 |
| 2 | 部門／グループの作成・設定 |
| 3 | アクセス権限（パーミッション）の管理 |
| 4 | システムの開発・テスト・要求仕様充足の確認 |
| 5 | システム運用責任の管理（IT管理部門・ICT管理部門との調整） |
| 6 | システムダウン時の異常状態の詳細通知の受信 |
| 7 | メンテナンス等の事前通知の発信 |
| 8 | システム稼働状況の管理・最適化 |

---

## ② システム管理者
> ※仕様書上では「プロバイダー」との区別は明示されていないが、運用管理側の担当者として整理

| # | 業務内容 |
|---|---------|
| 1 | ユーザーID/PWの発行・登録 |
| 2 | 部門／グループの作成・設定 |
| 3 | アクセス権限（パーミッション）の管理 |
| 4 | システム異常時の通知受信・対応 |
| 5 | メンテナンス等の事前通知の発信 |
| 6 | システム操作履歴の閲覧（全ユーザー分） |
| 7 | 接続機器のタイムアウト異常通知の受信 |
| 8 | システム稼働状況・パフォーマンスの管理 |

---

## ③ データ管理者
> MaiMLの知識を保有し、データ基盤を管理する担当者

| # | 業務内容 |
|---|---------|
| 1 | 名前空間の定義（`<property>`・`<content>`要素の定義） |
| 2 | プロパティの登録・エディタのカスタマイズ |
| 3 | 実験機器・計測機器の登録（一般名・ベンダー名・型番・シリアル番号） |
| 4 | ユーザー詳細情報の登録・設定 |
| 5 | ワークフローベースの作成（慣れてから実験管理者への移譲も可） |
| 6 | バックアップのタイミング・バックアップ先の設定 |
| 7 | データの削除権限の行使（ごみ箱内ファイルの削除含む） |
| 8 | データ管理者による操作履歴の閲覧（自身・システム管理者） |
| 9 | 削除データの関係者への通知 |
| 10 | ファイルからのデータ入力（外注試験報告書・Excel読み込み） |
| 11 | データマート内の保存データの削除権限の行使 |
| 12 | システムダウン時の異常状態の詳細通知の受信 |

---

## ④ 実験管理者
> 実験の設計と実行を担う現場の管理者

| # | 業務内容 |
|---|---------|
| 1 | プロジェクトの作成（ワークフローベースを選択して作成） |
| 2 | ワークフローの修正（プロジェクト内のワークフロー編集） |
| 3 | タスクの作成（プロパティ一覧をダウンロード・値入力・アップロードで複数タスク生成） |
| 4 | 実験前のワークフロー・作業手順・実験タスクの設定 |
| 5 | 実験タスク実行中のワークフロー・作業手順の修正（チェックイン操作が必要） |
| 6 | 実験作業者への指示事項の入力・提示 |
| 7 | 実験中の進捗・実験作業者のメモの閲覧 |
| 8 | 実験結果の信頼性フラグの記録（○／△／×）の付記（実験中断時・終了時） |
| 9 | データマートの作成（データカタログ・データレイクの検索→データセット生成） |
| 10 | 解析に利用するデータの指定・検索・構造化・蓄積 |
| 11 | 外部からのデータ（外注試験報告書等）のアップロード（フォーマット変換後） |
| 12 | 実験管理者の操作履歴の閲覧（自身・データ管理者・システム管理者） |
| 13 | ワークフローベースの作成（慣れた後） |
| 14 | システムダウン時の状態通知の受信 |
| 15 | タスク実行状況の確認 |

---

## ⑤ 実験作業者
> ワークフローとタスクに従って実験を着実に遂行する担当者

| # | 業務内容 |
|---|---------|
| 1 | タスクの選択・実行（作業開始・中断・再開） |
| 2 | ワークフローに従った作業手順の順次実行 |
| 3 | 実験条件（実験者名・作業記録・実験結果・計測結果・実験ログ）の登録 |
| 4 | 実験作業中のメモ・気づきの入力（作業手順に紐づいて記録） |
| 5 | 事前設定条件と異なる実験条件で実施した場合の実際条件の記録 |
| 6 | 計測・分析結果の登録（計測・分析システムからのデータ取得） |
| 7 | 作業手順ごとの実験機器・計測装置の操作 |
| 8 | 実験管理者からの指示事項・注意事項の確認 |
| 9 | 実験作業者の操作履歴の閲覧（自身・オーナー実験管理者・データ管理者・システム管理者） |
| 10 | システムダウン時の状態通知の受信 |
| 11 | 削除データの通知の受信 |

---

## 補足事項

- **①プロバイダー**と**②システム管理者**は仕様書内では「システム管理者（ICTシステム管理者）」として統合されています。mmdpfシステムの設計では「プロバイダー」が上位概念として存在しているため、分離して整理しました。
- 仕様書には**MI技術者**も定義されていますが、今回の一覧には含めていません。必要であれば追加します。
- 各ロールの詳細な権限設定は表3（ユーザクラスごとの役割）および8.(8)セキュリティ機能を参照してください。
