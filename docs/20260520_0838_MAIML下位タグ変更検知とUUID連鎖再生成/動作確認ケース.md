## UUID比較の方法

XMLをテキストエディタで開き、以下の xpath に該当するテキストを比較する：

```
/document/protocol/uuid
/document/protocol/method[1]/uuid
/document/protocol/method[1]/pnml/uuid
/document/protocol/method[1]/program/uuid
/document/protocol/method[1]/pnml/place[1]/uuid
/document/protocol/method[1]/pnml/transition[1]/uuid
/document/protocol/method[1]/pnml/arc[1]/uuid
```

またはブラウザコンソールで `savedUuids` state の内容をログ出力して確認することも可能。
